形式定义 / Formalε–N

收敛到 0，究竟在说什么？

∀ ε > 0, ∃ N, ∀ n ≥ N, |1/n − 0| < ε

不管误差带多小，总能找到起点 N，之后所有项都在带内。

为什么是这个 NN = 5
01|1/n − 0| = 1/n
021/n < ε ⇔ n > 1/ε
03N = ⌊1/ε⌋ + 1 = 5

课本速记 N = ⌈1/ε⌉；当 1/ε 是整数时，严格小于要求再 +1。

1 / ε4.0000
1 / N0.2000
最小性 · 1/(N−1) ≥ ε0.2500 ≥ 0.2500 ✓
读法How to read
  1. 带有多宽，决定哪些项合格。
  2. 1/N 的竖线是第一个合格项。
  3. 序号轴上，N 之后整段都是青绿色。

严格小于：边界项 aₙ = ε 不算带内，所以整除时要 +1。
