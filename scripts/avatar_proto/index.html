小析：站在学习者这一侧

原创 2D 同伴的在场样张：把下一步指出来。形象负责社会存在，数学画面负责清楚；每一句台词只做一个数学动作——指认、追问、提示或确认。不是真人出镜，不是讲师，也不是自动解题器。

character bible · v0.1

角色圣经

一页写清楚：小析是谁、怎么说话、什么时候出现、什么不做。

01身份

名字
小析（Xiao Xi）。“析” = 把问题拆开看。
角色
同伴型引导者（peer-guide）。不是讲师、不是监考、不是真人。
一句话
站在学习者旁边，指出下一步该看哪里。
气质
成年 / 中性 / 友好；好奇但克制，不卖萌。

02声音

短句；一句只做一个数学动作。先问，再给一行提示；不替学习者把题做完。不假装人类：不说“我刚看到你”“我一直在后台陪你”“我很担心你”。夸这一步，不夸这个人。

两种人格在开场、提示、反馈、收尾的微文案样例
时刻同伴 peer导师 mentor
开场嗨，我是小析。这条带子是什么？嗨，我是小析。先看带子，再找 N。
提示为什么是 N，不是 N−1？提示：先让 1/N < ε。
答对对，就是这个 N。对。N 取到了。
没接住诶，等等——a₄ 在带里吗？再看一眼：a_N 落在带里吗？
收尾原来 ε 一收紧，N 就得往后跑。小结：ε 定带宽，N 定起点。

03状态

平静neutral出现、等待读题。“先看这条带子。”
好奇curious追问、把问题递回。“那 N 是什么？”
思考thinking提示前的停顿、等学习者算。“先别急，找 N。”
开心happy答对一步、完成小目标。“对，就是这个 N。”
哎呀oops没接住、给方向，不评价人。“再看一眼：a₄ 在带里吗？”

静息 4–7 秒随机眨眼；开场/答对可挥手一次。减少动态时两者都不播放。表情只改眼、眉、嘴与头部角度，不换装、不加装饰。

04外观

圆角几何头身、简单的眼睛、笔记本 + 铅笔两件身份道具；成年/中性比例，避免真实人脸和幼态吉祥物。轮廓在 96px 仍要读得出。

Do

  • 先指画面，再说话
  • 一句一个动作
  • 表情服务于时刻
  • 保持道具一致

Don’t

  • 不讲课、不长篇
  • 不装真人经历
  • 不遮住数学
  • 不堆装饰/闪粉

05出场

开场 5–10s角落一句问候 + 一次挥手；可跳过。
提示按需或停顿后出现；只一行。
反馈对/没接住各一句；说完回平静。
收尾一行小结；不复述整课。

常驻右下角，可隐藏；隐藏后不留空洞。桌面约 158px 高；移动 100–126px。气泡最多 2–3 行。

06接入

先把 SVG + 状态机抽成 Web Component；同一份数据契约接 Rive/Lottie（更细的 idle/挥手）或 Remotion（录课视频）。语音以后再加：默认静音、必须带字幕。

x.setPersona("mentor"); x.hide();

这是视觉探针，不是课程单元：只新增 scripts/avatar_proto/**；不改课程、kernel、front、CI、docs。
