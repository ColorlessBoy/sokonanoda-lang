收束

✓你理解了 ε–N

把定义说死

∀ε>0, ∃N, ∀n≥N, |aₙ−L|<ε

这里 aₙ = 1/n，L = 0。

为什么是 ⌊1/ε⌋ + 1？

带内要求严格小于：1/n < ε ⇔ n > 1/ε。N 取第一个严格大于 1/ε 的整数，所以 N = ⌊1/ε⌋ + 1。

当 1/ε 正好是整数时，那一项 a_N = ε 不算“严格小于”，所以也要 +1。例：ε = 0.10 → 1/ε = 10 → N = 11。
