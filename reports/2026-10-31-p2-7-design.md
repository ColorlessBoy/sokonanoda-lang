Why L286 is expensive: in the second conjunct, `f '' X ≠ (f '' Y) ∩ (f '' Z)`, each `(fun _ => ∅)` has body type `Set ?γ_i`. Unification only proves γ1=γ2=γ3, and **nothing in the declaration fixes γ**. The first conjunct is different: `≠ @Set.univ (Set Nat)` pins β there. So this is a genuinely underdetermined meta, not missing information flow. Neither (A) nor (B) below can remove these misses, because no constraint exists anywhere. Loose still ends with `exercise.open` and no diagnostic. **Unverified: how the old path picks or defers γ.** That is the next probe (§6, step 0).

## 1. Representation for "elaborate an arg against a domain with outer metas" (Q1)

- The domain is exported with `Meta` nodes: `elab_app.rs:320-327` (today `continue` + `blocked` when `unassigned_mvars(q)` is non-empty). `OwnedNode::Meta{id,kind,ty}` (`transfer.rs:56`) carries the meta's **closed** type `Π scope, T` (built at `elab_app.rs:252-258`). `import_owned` rebuilds it with `mk_meta_with_kind` (`transfer.rs:282-285`).
- What the inner session needs:
  1. **Registration.** Lift the input rule at `elab_app.rs:140-152` for `expected` only. Every unassigned `Meta{id,ty}` in `expected` gets `register_at(id, ty, 0)` + `register_kind(Natural)`, same as `solve_metas` at `transfer.rs:324-327`. Scope depth is 0 because contextual metas are closed `?M x1..xd`. No new depth concept.
  2. **No id collision.** The inner session also allocates from `SESSION_META_BASE + k` (`elab_app.rs:163,224,256`). Add `AppRequest::meta_base` (outer base + `1<<20` per nesting level), or have the kernel pick `max(external)+1`.
  3. **Unification.** Nothing new. `app_propagate` (`:405-449`) and finalize (`:290`) run `is_def_eq_at` against `exp_v`, so they can assign externals. Miller: the spine `x1..xd` has levels `< d` and `>= floor 0` (`mvar_miller.rs:13-22`). The closed-assignment rule (`mvar.rs:291-296`, `in_meta_scope` `:323-326`) still holds. An assignment that mentions an inner λ binder is rejected cleanly.
  4. **What comes back: just the meta-free term, no assignment table.** The outer round is a *fresh* session, and its ids are renumbered: `metas.len()+holes.len()` shifts once a hole is filled. So returned assignments could not be imported by id anyway. The outer re-solve gets them again by unifying `infer(arg) ≟ dom` at `:272-273`. `Solved` keeps its meaning: `instantiate_mvars` (`:347`) also substitutes assigned externals, and `:348` rejects leftovers, so an arg that leaves an external unfixed returns `Unsolved` and stays blocked.
  5. **Recheck.** `app_recheck` (`:383-393`) compares against `exp_v`, which still holds external meta *values*. In the same session `is_def_eq` sees their assignments, so this is fine. Unverified that the tc cache never holds a stale pre-assignment value here; `invalidate_on_assign` (`mvar.rs:358`) suggests it doesn't.

## 2. Options (Q2)

**(A) External metas in `expected`** (as in §1). Front: `postpone::elab_ready` (`kernel_app_postpone.rs:203-247`) also receives `blocked` domains and sets `ExpectedHint` with the meta-bearing `OwnedExpr`. Only for **non-λ** args; a blocked λ stays blocked, see Q3. Kernel: `NeedArgs.blocked: Vec<usize>` becomes `Vec<(usize, OwnedExpr)>`.
- Risks: id collision (step 2). An imported domain with metas reaching places other than `expected`: `expected_src` / `hint` are only used as `expected` (`kernel_app.rs:398-400`), but `elab_expr(.., Some(dom_t))` for a non-app arg could push a meta-typed binder into `ElabScope`. Guard: only pass the meta domain as a hint to kernel-path nodes (`take_hint`), and pass `None` as `elab_expr` expected. Rollback: unchanged (`is_def_eq_at` checkpoint). Termination: rounds are still `<= args`, but a blocked arg that now solves counts as progress, so the bound `max_rounds` (`postpone.rs:38-44`) still holds.
- Size: `elab_app.rs` (+~40, already 451 lines, so split the hole/NeedArgs tail into `elab_app_holes.rs`), `kernel_app.rs` + `kernel_app_postpone.rs` (+~30). 3-4 files.
- Covers: `And.left h` / `And.right h` into `?a`/`?b`, `Set.image` β when the arg fixes it, `Set.inter` α when the arg fixes it. **Does not cover** the measured cost (L286, underdetermined).

**(B) One kernel session per application tree.** `explicit_args: &[ArgSpec]` with `ArgSpec::{Term, App(AppRequest), Postponed}`, elaborated recursively in one mctx. Closest to Lean.
- Risks: the front's notation, probe, redo, and hint machinery (`kernel_app_notation.rs`, `kernel_app_probe.rs:150-176`, `kernel_app_hint.rs`) assumes one application per call, so it must be rebuilt. λ args with app bodies need metas created under binders, which the closed-storage rule forbids today (`mvar.rs:320-322` "目前没有调用方在 binder 下造元变量"). Hover and diagnostics attribution changes.
- Size: large, 6+ files plus the kernel scope rule. Covers what A covers plus nothing measured. Not worth it now.

**(C) Smallest options that hit the measured cost.**
- C1 (course, 0 product lines): pin the element type in unit12 L285-286. Measured 14->4 misses, 4.68s, same verdict. Unverified: whether `@Set.empty Nat` passes `scripts/notation-lint.py`. `(∅ : Set Nat)` would be the lint-friendly form if ascription is in the subset (unverified).
- C2 (product): make the underdetermined case cheap *with the same verdict*. This needs step 0 first: what term or deferral the old path produces for a free γ. If it leaves a declaration-level meta that is later reported or defaulted, the kernel path can return the same thing directly (e.g. `Unsolved` -> hand the front a declaration-level meta, as `elab.rs:5241` does) and skip the per-node old path. Size and design are unknown until step 0.

## 3. Args that are not kernel-path applications (Q3)

Confirmed by reading: they need nothing new. A local, a constant, or an annotated λ that elaborates **without** an expected type already succeeds in pass 1 (`kernel_app.rs:376-387`), and its type is unified with the meta-bearing domain **inside the outer session** (`elab_app.rs:272-279`, with postponement to finalize when stuck, `:274-278`). Only args that *fail* without an expected type reach `blocked`. Of those, untyped-binder λs need syntactic Pi layers in the domain (`postpone.rs:221-224` `domain_fits`). With metas, a binder type would be `?M xs`, putting a meta into `ElabScope`. **Excluded from A**: they stay blocked, as today.

## 4. Invariants (Q4)

- Only a meta-free, rechecked term crosses to the front: `elab_app.rs:347-356` (+ `finish` bad-scope check `kernel_app.rs:294-300`); `add_declar` still re-checks everything, including theorem proof terms (K1a-c).
- Flag off means no new line runs: every new branch sits behind `attempt`'s gate (`kernel_app.rs:219`) or inside `elab_app`, which only the gated path calls. The new kernel code is reachable only when `expected` has metas, and no ungated caller passes such an `expected`.
- Judgement: same accept/reject/event counts on the 38-file corpus, both dialects. A can only turn some `Unsolved` into `Solved`. That may change strict accept/reject only where the old path had rejected, and **those must be listed explicitly** (none known; unverified until the corpus run). C1 changes one course file; its events are measured identical (12/3/9/0).

## 6. Recommendation and plan

The measured 8.66s vs 5.06s is **not** an information-flow problem, so A and B don't buy the time. Recommended order:
0. **Probe (no commit):** dump the loose and strict final signature of R1/L286 to see what the old path does with free γ. This decides C2.
1. **C1** (one course commit, if the user accepts course edits): pin L285-286. Test: unit12 strict misses <= loose, `check.py --only "单元 12"`, notation-lint.
2. **C2** (if step 0 shows a cheap equivalent): kernel-path `Unsolved` on a free meta returns the same thing the old path would. Test: R1 `unsolved=0` with events identical to loose, plus a reverse thread-local.
3-5. **A**, only for P2 "删旧 typed app" (it removes fallbacks, not misses):
   - (3) kernel: `expected` externals + `meta_base`, plus a split to `elab_app_holes.rs`. Test: kernel unit tests + collision reverse check.
   - (4) kernel: `NeedArgs.blocked` carries domains. Test: an existing NeedArgs test plus one blocked-with-domain test.
   - (5) front: `elab_ready` hands blocked non-λ domains as hints only. Test: R3/R4 counters + `TEST_NO_EXTERNAL_METAS` reverse check.
6. Corpus run (38 files x 2 dialects, flag off byte-for-byte, flag on accept/reject diff listed).
