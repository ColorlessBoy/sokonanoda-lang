## 0. 一句话

加**第二个开关** `SOKO_STRICT_NO_FALLBACK=1`（只在 `SOKO_STRICT_KERNEL_APP=1` 且 strict 时生效）：开 ⇒ 内核路径
解不出时**不再回落老路**，改由 `kernel_app_report::report` 出**人能读**的错；关 ⇒ 与今天**逐字节相同**。

## 1. 现状（读这三处就够）

| 位置 | 现在是什么 |
|---|---|
| `crates/front/src/compile/kernel_app.rs:58` | `effective(dialect) = dialect.strict() && env_on()`；`key_tag` / `key_bit` 进缓存键 |
| `kernel_app.rs:308` `finish(...)` | 内核结果 ⇒ `Ok(项)`，其余**一律** `Err(Some(why))`（并把 hover 撤掉、作用域恢复） |
| `kernel_app.rs:220` `try_app` / `kernel_app_notation.rs:110` | `Err(Some(why))` ⇒ `probe::fallback(...)` + `census::pending` ⇒ 交回 `MissGuard` 走老路 |
| `crates/front/src/compile/kernel_app_report.rs`（S2，**未接线**） | 纯函数 `report(&AppOutcome, &ReportInput) -> Report`；`Report::{Error,Fallback,Defer}` |

`Report::Fallback(why)` 的四种原因**就是**本刀要保留的例外：`unsupported` · `need_args` ·
`expected_retry`（`ExpectedMismatch` 交 S4 重解）· `argmismatch_text`（正文要内核那台打印器，P2-13 之后另开刀）。

## 2. 要改的四处

1. **开关**（`kernel_app.rs`）：`no_fallback(dialect)` = `effective(dialect) && env 读过一次 == "1"`；
   `#[cfg(test)] TEST_NO_FALLBACK: Cell<Option<bool>>`（同 `TEST_OVERRIDE` 的样式，供单测）。
2. **出口**（`finish` 的签名）：`Err(Some(&'static str))` 不够用了 ⇒ 改成一个内部枚举
   `Fallback { why: &'static str }` 或 `Dead(CompileError)` 二选一（名字自定，别用 `Error` 撞名）。
   `finish` / `run` / `run_once` / `attempt` / `try_app` / `try_notation` 的返回类型顺着改（`?` 处一并改）。
   **只在开关开时**才可能产出 `Dead`；开关关 ⇒ 与今天完全同一条路。
3. **报错数据**（`ReportInput` 谁来填）：`render_msg(ctx, head)` / `render_msg(ctx, expr)` 要 `expr` 与 `ctx`；
   `try_app` 手里有 `expr`，`try_notation` 手里只有 `canonical` + `span`（**头不可见**）⇒ 记法路由传
   `head_text = canonical`、`whole_text = canonical`（出路渲染会退化成 `@<头> …`，这正是老路的兜底行为）。
   `ty_text` / `explicit_layers` / `total_layers` 从 `known.get(&canonical)` 取（`KnownName::Decl` 已有这些字段；
   `args.len()` 用 `spine` 的实参数）。**取不到 ⇒ 不进 `report`、按例外回落**（保守：报错数据不全就别报）。
4. **缓存键**：`judge::options_key` 与 `query` 指纹是否已经哈希 `SOKO_*` 环境变量 —— **先核实再动手**：
   `cache/keys.rs:45-56` 的 `flags_state` 会哈希全部 `SOKO_*`（读 `crates/front/src/compile/cache/keys.rs`）。
   若 `judge::options_key` 走同一条 ⇒ 不用改；否则把新开关并进 `key_tag`（`/kapp` → `/kapp/nofb`）。
   **判据**：同一进程里先开开关跑一遍、再关掉跑一遍 ⇒ 读数不许串（照 `tests/kernel_app_keys.rs` 的写法加一条）。

⚠ **2026-11-01 12:50 修正（子代理踩出来的两条，错在我这张单）**：

* **坑 A**：`scripts/strict/corpus-one.sh` **不设** `SOKO_STRICT_KERNEL_APP`（它只 `env -u SOKO_STRICT_AT`）。
  ⇒ 上面「开关关」那两条实际量的是**内核路径整个没开**，只证明"不接线时逐字节不变"，**没有**执行内核路径。

⇒ 正确的口径是**三跑**（同一个新二进制，只有 env 不同）：

| 跑 | 二进制 | env | 作用 |
|---|---|---|---|
| **A** | 旧（HEAD） | `SOKO_STRICT_KERNEL_APP=1` | 今天的 gate-on 基线 |

| **C** | 新 | `SOKO_STRICT_KERNEL_APP=1 SOKO_STRICT_NO_FALLBACK=1`（+ `SOKO_KERNEL_APP_LOG`） | **B vs C 逐行归因**：每个 `dead` 位置对回 B 日志同 `line:col` 的回落位置（`ok` 才是 old_ok>0；`err` 只是换文案） |
