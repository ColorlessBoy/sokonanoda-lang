
Resolve that path against the **repository root**, not against this entry's
directory, then read it before drawing or reviewing a figure.

Quick checklist:

- Latin Modern + Songti SC by default;
- text token: title 100%, body 96%, labels 94%, captions 80% black;
- fixed canvas + four-row grid;
- labels white-backed, never on set boundaries;
- run the PDF/text-box lint before publishing a PNG.
