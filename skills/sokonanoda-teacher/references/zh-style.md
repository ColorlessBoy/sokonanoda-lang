# 中文教学文案文风规范（zh-style）

> 适用：画布讲解注释、提示阶梯（soko:hint）、诊断文案、教学对话。
> 原则一句话：**写给坐在对面的一个人听，像当面讲解，不像写稿。**
> 红线：拒绝翻译腔、AI 味、抖音味、小红书味。来源见文末。

## 一、翻译腔（AI 味的主要成分）

**本质：骨架是英文的中文句子。** 每个字都通顺，整句别扭。

禁用四套路：

1. **用物理动作写思考**：接住、击穿、锋利、拆解、不崩、撑住、落地、收口。
   → 改成中文本来会说的：收到/记下、不成立、站不住脚、分清楚、说得更准。
2. **抽象名词做主语 + 形容词收尾**：「X 的 Y 比 Z 更 W」。
   → 先说人和事：「后面会多出验收和返工」「用户真正付费的是把事做完」。
3. **逻辑胶水直译**：
   - "不是 A，而是 B" → 直接说 B：「真正值钱的是信任」。
   - "如果……那么……" → 把逻辑藏进语气：「他输了，却没认输」。
   - "尽管……但……" → 同上，让语气完成让步。
4. **有现成中文却不写**：同一个"推"字别包揽推荐/推送/推进；
   "硬/稳/强"不做万能好评（"方案很硬"→"办法靠得住"）。

## 二、AI 味结构（维基清单的教学版）

- **否定式煽情**：「这不仅仅是……，更是……」→ 直接说它是什么。
- **虚假范围**：「从 X 到 Y」（X、Y 并不连续）→ 别凑。
- **三段式排比**（"、"×3）、**升华结尾 + 行动号召** → 删。
- **路标词**：值得注意的是、总而言之、首先其次、让我们 → 删。
- **破折号**：一段最多一个；"X 很 Y："起手式 → 别用。
- **万能好评词**（强/稳/硬/精妙/优雅）→ 说清到底好在哪。

## 三、抖音味 / 小红书味（教学文案零容忍）

- 感叹号连用、emoji 堆砌、「家人们」「绝了」「谁懂」「直接封神」。
- 标题党与悬念钩子（「99% 的人不知道」）。
- 痛点轰炸开场（「你是不是也遇到过……」）。
- 我们的语气是：**平静、确定、有点温度**。鼓励可以有（「对了，就是这样」），
  不夸大（「太棒了！！」不行）。

## 四、正面规则

1. **术语先行**：介绍新概念，第一句就是它的专有名词（中文 + 英文对照，
   如「函数类型（function type）」「函数（function）」），然后才是白话
   解释。比喻只能支撑术语，不能替代术语——学习者要能拿这些词对接
   官方文档和其他教材。（第一课实修：比喻堆了"票/机器/规格/实物/过程/
   发牌"六个，唯独没有"函数类型"，被学习者点名。）
2. **比喻唯一化**：全文最多一个核心比喻，出现时明确标注「比喻」；
   不中途换比喻，不堆叠近义比喻。
3. **短句换气，长句承载**；一段说一件事。
4. **先事实，后判断**；术语第一次出现，紧跟一句白话解释。
4b. **语义归属要干爽**：「输入/输出」只配函数；「类型」只说
   "……的类型 / 把……归为一类"。禁止"Nat -> Nat 是输入 Nat 输出 Nat"
   这类把类型说成会干活的句子（第一课实修：这句话误导学习者很久）。
5. 允许口语（「就这么简单」「别急」），不网络化。
6. 写完自查：通读一遍，圈五类——①物理思考动词 ②"X很Y："起手
   ③抽象名词主语句 ④残留英文词 ⑤被比喻替代的术语。圈出即改；
   改法是**重写**，不是修补（把原文盖住，用中文重新说一遍）。
