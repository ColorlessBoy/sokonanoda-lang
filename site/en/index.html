Learn proofs by writing one that checks out

sokonanoda is a teaching language and toolchain for Lean-4-style theorem proving, built on a complete, runnable Lean 4 type checker. Every exercise you finish is graded by the same real kernel — if it's green, it's a real proof.

Three value propositions

  • Grading uses the real kernel, not text matching

    An exercise is solved only when it passes the full dependent type checker. Leaving an unfinished sorry hole is a legal file state; filling it triggers a real kernel judgment, and mistakes come back with line/column and a stable error code.

  • A logic-first course

    Unit 1 has you proving a proposition directly. Universes appear only when you naturally ask "what is the type of a function type?" — the order follows intuition, not a pile of terms.

  • Human and agent read the same feedback

    The compiler emits both human-readable diagnostics and a JSON event stream for agents. A teaching agent can use those events to assign exercises, grade them, and suggest the next step.

First step, no install required

Install the VS Code extension

The platform packages bundle the language server and the sokonanoda CLI, so it works the moment you install — offline, with no Rust toolchain. Open any .sokonanoda file and kernel grading, the goal view, and the course map are all there. See installation steps →

Teaching with AI agents

The repository ships three agent skills any skill-aware agent (Claude Code, opencode, …) can load: sokonanoda-teacher (your proof teacher), sokonanoda-dev (a careful contributor), and sokonanoda-ci (a disciplined releaser). The same --json event stream is the integration surface for any tooling you build.
