English

A teaching language where the kernel does the grading

.sokonanoda files are a sequence of declarations. A declaration whose value is sorry is an exercise. Whether it is solved is decided by a real type checker — never by comparing text.

This is the English summary

The full site is in Chinese, because the project's courses are. Everything below links into it. The pages are written for readers, not translated word for word, and the diagrams and recorded output are language-independent.

§3 Install it

Two paths, and neither needs Rust, Lean or elan:

  • Learners install a VS Code extension that embeds the language server and CLI for your platform, then open a course canvas.
  • Code agents clone the repository and follow AGENTS.md; the grading protocol is a documented JSON event stream.

Install and get started For code agents 

$ git clone https://github.com/ColorlessBoy/sokonanoda-lang
$ cd sokonanoda-lang
$ scripts/soko setup
$ scripts/soko grade playground.sokonanoda --json

$ is the prompt — do not type it.

§4 What it is not

Stated plainly, because it matters
  • It is not a general-purpose proof assistant and not a Lean replacement. It is a teaching language for a specific course sequence.
  • There is no WASM build, so this site cannot run the kernel in your browser. Every demo here is a recording of real output, and each one names the command that produced it.
  • There are no implicit arguments and no typeclasses, so Lean's section / variable style does not work.
  • The kernel is a frozen snapshot of an upstream project — deliberately, so that explanations do not rot.
  • The courses are in Chinese. The language and the tooling are not.
