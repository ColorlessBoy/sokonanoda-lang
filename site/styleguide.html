设计规范：组件与令牌

这一页是本站视觉语言的唯一权威样板。每个组件都配一个**真实**用例—— 数字来自内核实测，代码来自仓库真源码，面板里的目标是真跑出来的。 改任何令牌之前先看这一页，改完再看一遍。

§1 方向：「格纸 · 朱批」

这个产品的产物是判定，材料是格子纸上的推导， 读者是中英混排的技术读者。三个事实各自推出一组视觉决定， 没有一组是"看起来高级"选出来的。

  • 产物是判定  →  颜色是语义的：绿 = 内核真的通过过；朱 = 诊断与诚实的限制
  • 材料是推导  →  方格纸 + 零圆角结构容器 + 发丝线承担全部分隔
  • 读者是技术读者  →  拉丁自托管子集、CJK 走系统栈、⊢ 必须有字形

⊢

一条发丝线，上方是「给定」，下方是「待证」。全站唯一的记忆点。

这个方向贴着两条 AI 默认长相，必须知道边界

公开的反 AI-slop 指导里，第 2 类是「近黑底 + 单一荧光强调色」，第 3 类是 「宽幅报纸式：发丝线 + 零圆角 + 密排」。本方向同时踩在两者的边上。分界是： 单栏（不是密排多栏）、零圆角只给结构容器 （控件仍是 3px）、发丝线只在推理横线上有语义（不是每条边界都画）、 亮色为主（不是近黑底）、强调色低亮度且只做语义 （不是荧光，不是装饰）。

审计规则：看到强调色就问一句

「这里背后有什么真实判定？」答不上来就是装饰性使用，按 bug 处理。 绿只允许出现在内核真的通过过的东西上（实测计数、已发布版本、真实通过态）； 朱只允许出现在诊断、更正、以及诚实的限制上。一个元素只能带一个语义色，不许同时两个。

方格纸

24px 格距 = --sp-5。区块级垂直间距、容器内边距、卡片 gap 全部取 24 的整数倍，所以内容真的落在格线上——格线不是贴图。 格线对底色 1.056:1（上限 1.10），且永不铺在任何文本容器底下。

§3 排版

字族两个：系统 UI 无衬线（正文与界面）与自托管等宽（代码与推导）。 衬线默认不用——"教科书感"由下一节的构件承担，不由衬线承担。

三级标题示例

正文锚在 17px、行高 1.7、行长 40rem。40rem = 640px 约等于 37.6 个汉字，同时满足 WCAG 1.4.8 对 CJK（≤40）与拉丁（≤80）的两个上限。 不要用 ch 做中文行长单位：ch 是拉丁 "0" 的宽度（约 0.5em）， 而汉字约 1em，用 65ch 会得到只有一半宽的容器。

四级标题

中文的强调用着重号而不是倾斜——汉字没有真斜体，浏览器强行压斜很难看。 加粗用于真正的强调，不用来当装饰。 数字一律等宽：329 checked · 0 failed · 第 108 轮。 版本号一律不写死，由 data-site-version 从 site/data/site.json 填入： —。

引用块用左侧 2px 发丝线，不用引号字符——中文引号在混排里容易与标点打架。

  • 列表项之间 8px，嵌套不额外留白
  • 行内代码 scripts/soko grade --json 与正文有区分但不刺眼
  • 按键写作 Alt+B

§4 教科书构件

这一组才是"教科书感"的实际承担者。编号小节、页边注、定理/定义/证明块、 证明结束的墓碑符——这些是数学文本的形状；衬线只是"文学感"的 通用符号，任何主题都能贴（见 D7-design-audit.md §2）。

定义 1.1（隶属）

设 a 是一个对象、A 是一个集合。若 a 是 A 的元素，记作 a ∈ A。

定理 1.2（空集是任何集合的子集）

对任意集合 A，有 ∅ ⊆ A。

取任意 x，设 x ∈ ∅。按定义，空集不含任何元素， 故这是矛盾；由矛盾可推出任意命题，特别地 x ∈ A。 于是 ∀ x, x ∈ ∅ → x ∈ A，即 ∅ ⊆ A。

∅ ⊆ A  ⟺  ∀ x, x ∈ ∅ → x ∈ A

页边注在宽屏上进真正的边栏，窄屏折回正文流。它要求作者真的把旁证写短—— 这是只有内容站才敢用的版式。

§11 折叠与标签页（无 JS 也成立）

折叠是走查页的核心机制：<input type="checkbox"> + <label> + 兄弟节点，靠 :checked ~ 展开。没有 JS 时照样能勾选，功能不丢。

§12 编辑器表面（插图，不是界面）

旧站用 PIL 画的假 VS Code 截图冒充产品界面。现在改成真 HTML/CSS： 几 KB、可换主题、可被读屏朗读、文本可复制，而且每个数字都来自真跑过的内核。 每块面板都必须包在 <figure class="illus"> 里，写明 .illus-tag（这是什么 + "示意"）与 .illus-cap（数据出处）—— 这是"它是插图"的唯一视觉证据。
