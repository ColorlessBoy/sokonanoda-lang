学证明，
从写对一个命题开始

一个自研的 Lean 4 式教学编译器：真内核判卷、判错给教学提示， 编辑器输入全程有提示。装一个 VS Code 扩展就能开始，零工具链依赖。

安装（扩展 / agent） 看怎么用

安装

两条路径，按你的角色选。两者共享同一套课程画布与内核判卷，可以混用。

给学习者

VS Code 扩展（推荐入口）

  1. 在插件市场一键安装

    已装 VS Code？点这里直接弹开安装。 扩展内嵌本平台的 LSP 与 CLI，不需要 Rust、Lean 或任何工具链； 想离线或装指定版本，到 GitHub Releases 下载对应平台的 VSIX。

  2. 克隆仓库、打开课程画布（12 道练习，从零到定理）：
    git clone https://github.com/ColorlessBoy/sokonanoda-lang code sokonanoda-lang/playground.sokonanoda

    也可以让 VS Code 直接克隆：在 VS Code 中克隆。

把带 sorry 的练习换成答案、保存——判对判错由内核说了算； 详细步骤与常见问题见 安装与上手。

给 code agent

复制一段 prompt 就够了

粘进任意 code agent（opencode / Claude Code / Codex / Cursor / …）。 它会自己克隆仓库、读 AGENTS.md、装好版本锁定环境， 然后在画布上出题、按内核事件判卷。

零 cargo、不碰官方 Lean 工具链；判定全程走内核 --json 事件。 它读的技能与协议见 给 Agent。

怎么用

四个最常见的瞬间。所有演示都是扩展里真实存在的功能——演示脚本生成的 画面，与实现一一对应。

卡住了，悬停 sorry

光标落在 sorry 上，hover 直接给这个洞的期望类型、 剩余目标与已引入假设——期望类型会展开定义来算（Not a 展开成 a -> False，洞期望 a）。填之前就知道还差什么。

判对判错，内核说了算

判定永远走完整内核，不做文本比对：判错的证明给红色诊断与教学提示 （哪里写反了、该怎么想），判对的每一行放进官方 Lean 也一样合法。

你的 code agent 也能当老师

任何 code agent（Claude Code / opencode / Codex / Cursor / …）都能判卷驱动 教学循环——把安装 prompt复制给它，它自己装好环境 就能上课；判卷走 --json 内核事件，不做文本比对。
