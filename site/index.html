学证明，
从写对一个命题开始

一个自研的 Lean 4 式教学编译器：真内核判卷、判错给教学提示， 编辑器输入全程有提示。装一个 VS Code 扩展就能开始，零工具链依赖。

安装（扩展 / agent） 看怎么用

安装

两条路径，按你的角色选。两者共享同一套课程画布与内核判卷，可以混用。

给学习者

VS Code 扩展（推荐入口）

  1. 从 VS Code 插件市场 一键安装，或命令行：
    code --install-extension sokonanoda.vsix

    想装指定版本：到 GitHub Releases 下载你平台对应的 VSIX（扩展内嵌本平台的 LSP 与 CLI 二进制， 不需要装 Rust、Lean 或任何工具链）。

  2. 打开课程画布开始做题：
    git clone https://github.com/ColorlessBoy/sokonanoda-lang code sokonanoda-lang/playground.sokonanoda
  3. 把带 sorry 的练习换成答案、保存——判对判错由内核说了算， 悬停 sorry 或 funintro 能看到还差什么。

详细步骤与常见问题见 安装与上手； 编辑器功能细节见 文档。

给 code agent

适配所有 code agent

  1. 克隆仓库（skills/ 与 AGENTS.md 入口随之就位）：
    git clone https://github.com/ColorlessBoy/sokonanoda-lang cd sokonanoda-lang
  2. 让你的 agent（Claude Code / opencode / Codex / Cursor / …）读 AGENTS.md 进入角色——一个入口，不挑 agent：
    把 AGENTS.md 粘进任意 code agent 的上下文即可
  3. 角色技能是标准 Agent Skill 格式，按需加载： sokonanoda-teacher 当老师（出题/判卷/决策）、 sokonanoda-dev 做开发（冻结内核、TDD 三层）、 sokonanoda-ci 推代码与发布。opencode 零配置 自动加载；其它 agent 把 skills/ 拷进各自的技能目录。 判卷走 --json 事件流，agent 无需读源码。

环境准备一条命令：sokonanoda setup（按版本锁定下载 CLI + LSP，跨平台、零 bash）。协议与自定义请求见 文档。

怎么用

四个最常见的瞬间。所有演示都是扩展里真实存在的功能——演示脚本生成的 画面，与实现一一对应。

卡住了，悬停 sorry

光标落在 sorry 上，hover 直接给这个洞的期望类型、 剩余目标与已引入假设——期望类型会展开定义来算（Not a 展开成 a -> False，洞期望 a）。填之前就知道还差什么。

判对判错，内核说了算

判定永远走完整内核，不做文本比对：判错的证明给红色诊断与教学提示 （哪里写反了、该怎么想），判对的每一行放进官方 Lean 也一样合法。

骨架从第一个字符起就在

在值位敲 funintro：弹窗从第一个字符起就预选「替换源代码」项， Tab 接受后骨架落盘，sorry 处于选中态——下一次输入直接覆盖它。 要不要替换都行，不替换也完全等价。

你的 code agent 也能当老师

任何 code agent（Claude Code / opencode / Codex / Cursor / …）读 sokonanoda --json 的每行事件就能判卷驱动教学循环—— 读 AGENTS.md 进入角色，或直接复制 一条现成的提示。判卷走内核，不做文本比对。
