学证明，从写对一个命题开始

sokonanoda 是一个教学用的证明语言与工具链，建立在完整、可运行的 Lean 4 类型检查内核之上。你在编辑器里写的每一道题，都由同一个真正的 内核判定——判过了，就是真的证明。

装 VS Code 扩展，零安装开始 看课程 项目在做什么

三条价值主张

  • 判卷用的是真内核，不是文本比对

    一道题判对，意味着它通过了完整的依赖类型检查器。练习里留着未完成的 sorry 洞是合法状态，填完由内核终审；写错的地方给出带行列和 稳定错误码的诊断。

  • 逻辑先行的课程

    第一单元直接让你证明命题，等自然发问「函数类型的类型是什么」时才引出 宇宙（universe）。题序跟着直觉走，而不是先堆术语。

  • 人和 agent 看同一份反馈

    编译产物既是人读的诊断文本，也是 agent 消费的 JSON 事件流。一个教学 agent 可以读同样的事件来给你出题、判卷、讲下一步。
