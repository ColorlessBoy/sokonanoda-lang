走查一题：逐行看内核的目标状态

写一行，内核就告诉你现在手里有什么、还差什么。这一页把卷 I 单元① 的每一行都问了一遍真内核。

§3 同一个声明里，每一行的回答是一样的

光标停在每一行的第 1 列，也就是停在第一条 tactic 之前。这时内核报的是声明的根状态：所有假设都在，目标还没被拆过。所以练习 1 的三行会看到同一个面板，这不是采样偷懒，是内核的答案如此。

要看到状态随行推进而变化，把 --col 往右挪，或者把 --line 放进 by 块内部。根状态长这样：

  • A : Set α
  • B : Set α
  • h : Set.subset α A B
  • a : α

⊢

Set.mem α a A -> Set.mem α a B

内核报的假设有五个，这里省掉 α : Type，只留和这条目标直接相关的四条。着色和上面的面板同源：Set.mem 与 Set.subset 是 unknown_ident，α / a / A / B / h 是 binder。
