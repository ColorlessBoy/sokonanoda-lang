给 code agent

不用预装什么，也不用先读协议。复制下面这段安装 prompt，粘进任意 code agent （opencode / Claude Code / Codex / Cursor / …）：它会克隆仓库、读 AGENTS.md、加载 teacher 技能、按版本锁定装好环境，然后在 playground.sokonanoda 上出题、用内核事件判卷。 


      
    


    

      它背后读什么（技能与协议）
      
    
        
  • AGENTS.md：项目入口——先读什么、Setup、硬规则速记。
    • 
        
  • skills/：sokonanoda-teacher 是教学循环手册（出题、判卷、提示阶梯），另有 dev / ci 两个开发向技能，以及 update / doctor 两个人工运维命令（刷新缓存、就绪诊断）。
    • 
        
  • docs/protocol.md：--json 事件流契约——人读诊断文本、agent 读 JSON 事件，同一份事实，不会各说各话。
    • 
      

      

        用 opencode 打开本仓库时，技能与 /sokonanoda/* 命令零配置可用；
        DeepSeek Harness 同样零配置（技能名即 /sokonanoda-teacher 等命令，
        运维命令写作 /sokonanoda-update / /sokonanoda-doctor——
        DSH 的命令名不允许斜杠）；
        其它 harness 读技能文件即可。取用发布二进制一律按仓库版本锁定，禁用
        releases/latest。
      

    


    

      本项目硬规则之一：判定永远走内核，禁止文本比对。给 agent 写判卷逻辑时，也请基于内核事件，而不是去比较文件文本。
