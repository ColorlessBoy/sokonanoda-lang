§1

关于与许可

这个项目是什么、从哪里来、用什么许可。以及本站自身遵守的那几条纪律。

§1.1 这是什么

sokonanoda-lang 是一个自研的 Lean 4 式教学编译栈： 一个受限的教学语言 .sokonanoda、一个完整的内核、一个语言服务器、 一个 VS Code 扩展、一门入门课与一门卷 I《集合论》，以及给 code agent 的协议与技能。

它的判定永远走内核，不做文本比对；学习者与 agent 的使用路径零工具链依赖 （不需要 Rust、Lean 或 elan）。

§2 许可与上游

本项目以 Apache-2.0 许可发布。内核部分派生自上游项目， 上游的版权与许可声明随该部分代码一并保留。

上游来源与许可。内核快照钉在一个确定的提交上，不是跟随上游分支。
项目角色许可
intgrah/sokonanoda 上游内核。crates/kernel 是它的一个快照 Apache-2.0
本项目 sokonanoda-lang 教学前端、CLI、语言服务器、VS Code 扩展、课程、官网 Apache-2.0
内核是冻结快照，这是有意的

crates/kernel 钉在上游的一个确定提交上，不跟随上游演进。 教学语言要能回答「这条证明为什么通过」，答案必须长期稳定—— 内核语义一变，过去所有讲解都可能失效。上游血统链见仓库根的 NOTICE.md。

§3 关于这个网站

本站是零构建的静态页面：手写 HTML 与 CSS，没有框架、没有第三方脚本、 没有 CDN、没有分析工具。字体是自托管的子集，编辑器面板是真的 HTML/CSS 而不是截图，全站零位图。

  • 0第三方请求
  • 0位图
  • 0跟踪脚本
  • —站点对应的项目版本

站点的设计语言、组件与令牌写在 设计规范 里；那一页也是本站的视觉样板， 每个组件都配一个真实用例。它遵守的两条纪律值得单独说：

版本号、计数、进展一律不手写

页面上的版本、单元数、判卷计数全部由脚本从 Cargo.toml、course.json、STATUS.md 生成；卫生检查会拒绝任何写死版本号的页面。

演示是真实输出，不是画的

走查页的每一个目标状态、内核页的每一条事件流、诊断页的每一条复现， 都是真跑内核得到的，并随附产生它们的命令。本站没有任何"看起来像"的编造数据。

因此也有代价

没有后端，所以浏览器里不能真的运行内核——本站的功能展示是**预计算的真实输出**， 不是在线 playground。想看它真的跑起来，请 装上扩展 或 看走查一题。
