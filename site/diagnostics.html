    §5 警告与诊断不是一回事

    码表里 4 条是警告，其余 60 条是诊断。 区别只有一个，但它承重：警告永不影响退出码。

    • theorem t : True := True.intro sorry
    • warning · redundant-sorry · exit 0
    • def x : sorry := True.intro
    • diagnostic · elab-hole-misplaced · exit 1

    ⊢

    课程工具只看退出码就会漏掉警告，所以签名腐烂必须报诊断

    两个例子都是本页复现表里的真实运行：一个多余的 sorry 只发警告，退出码 0； 而 sorry 出现在值位以外是诊断，退出码 1。签名烂掉的练习 （theorem 的类型不是命题）走的是后一条路——一旦做成警告，退出码不变， 课程侧就永远发现不了那个练习已经坏了。

    限制

    码表是这一版的冻结快照（docs/design/site-rebuild/content/C1-language.md §4.4，提交 084da05）： 码是稳定契约，只增不改、不重编号、不挪作他用。新增码要等下一版。

    警告不改退出码，但不代表带警告的文件一定 exit 0：同一份文件里可以 既有警告又有诊断，那时退出码由诊断决定。import-has-open-exercises 的复现 就是这样——它 exit 1，因为同一份源码里还有一条 elab-unknown-identifier。

    退出码口径：0 答上了（一个开放的 sorry 练习是合法状态）、 1 文件被拒、2 用法错误。判据看 JSON，不看退出码。
