课程

课程按逻辑先行排列：第一单元直接让你证明命题，等自然发问「函数类型的类型是什么」 时再引出宇宙。题序跟着直觉走，不是先堆术语。每个单元一份画布文件，带讲解、已写好的演示和留着 sorry 的练习；练习留洞是合法状态，填完由内核判定。课程有中文和英文两套，代码逐字节一致，只差注释语言。 单元⑦（量词）补上单元①没展开的 forall 与 Exists，可紧跟单元①使用。

还没装环境？装 VS Code 扩展就能在编辑器里直接写这些练习。

怎么用这些单元

  • 每个单元自包含：带上它需要的公理 / 归纳块，单独一个文件就能编译通过。
  • 每个单元至少有一次 #reduce 自测，方便你确认化简结果。
  • 卡住时，文件里的 -- soko:hint 提示是分级的，一次揭开一条。
  • 真正的答案（解答钥匙）只给 agent 用，不直接发给学习者——你的练习由内核判，不靠对照答案。

学完之后：卷 I《集合论》

这一门教的是语言本身。学完它（或已有等价的 Lean 4 式证明经验）之后， 接着走 卷 I《集合论》：同一门语言、同一个内核、同一套判卷方式， 但换成为数学而写——从「集合 = 谓词」出发，经集合运算、外延性、序对与积、关系与函数、 像与原像、等势，一路做到 Cantor 定理与 Russell 悖论。每单元的画布结构与这里的单元完全一致。
