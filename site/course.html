入门课：十一个单元

这门课从「什么是证明」讲起，假设你没有证明经验。十一个单元，每个单元一个可以独立编译的文件， 每道练习留一个 sorry 洞——把洞填上，完整内核告诉你它对不对。

§1 这门课假设你没有证明经验

入门课从「什么是证明」讲起。你不需要先学一门逻辑课，不需要碰过 Lean 或 Coq， 也不需要装 Rust——会读代码就能开始。

十一个单元，每个单元是一个可以独立编译的文件。文件里只有三样东西： -- 开头的中文讲解、已经写好的演示、值位留着 sorry 的练习。sorry 是合法的开放状态，不是错误：它表示「这里还等着你填」， 内核照常把剩下的目标算给你看。

第一道练习是单元①的第 46 行，theorem true_is_true : True := sorry。 内核对那个洞的回答是这样：

  • True : Prop
  • True.intro : True

⊢

True

横线上面两行是画布自己声明的逻辑骨架 （course/unit1-propositions-proofs.sokonanoda:17-18）； 下面那行来自 scripts/soko query state --file course/unit1-propositions-proofs.sokonanoda --line 46 --col 30 的 goal 字段。第一道练习要的，就是这两行之间那个类型的一个项。

整门课用一条命令就能量完：

  • 11个单元
  • 86条声明被内核接受
  • 65个练习等着填
  • 0条被内核判负

数字来自 scripts/soko course course/course.json --json 的最后一行（course.summary）；每个单元自己那行在 §5。

怎么读这两个数

「86 条声明被内核接受」数的不是 86 道证明——每个画布都自带一份逻辑骨架 （axiom True、And.intro 这类），它们和演示、和你已经填好的练习 一起计入。这个数的作用是：证明这十一个文件真的编译得动。

「65 个练习等着填」才是你要做的量。它是 exercise.open 事件的总数， 也就是整门课里 sorry 的个数。

这两个数都不是进度条。单元⑤ 的通过计数就是 0——它不靠「已经写好的声明」教学， 而是用五条 #check 让内核当场回答类型（expr.typed 五条）， 声明只剩六道练习。计数为 0 说明的是那个单元换了教学手段，不是它坏了。

§2 单元目录：教什么、学完能做什么

顺序是「逻辑先行」（course/README.md:13-16）：单元① 直接证命题， by 写法提前到单元④ 当反馈加速器， 而「函数类型自己的类型是什么」这个问题留到单元⑤ 才揭晓。 下面的编号、标题与顺序逐字取自 course/course.json； 每个单元一行，第一句是它教什么，第二句是学完你能做什么。

  1. ① 命题与证明项 教什么：命题住在 Prop 里，一个类型为命题的项就是它的证明；箭头对应 fun，And/Or/False 由一组公理搭出最小逻辑骨架。
    学完能：自己写出证明项——True 的证明是 True.intro，And a b 的证明是把两份证明交进 And.intro。
  2. ② 等式与 rfl 教什么：第一个具体类型 Nat，以及「相等」这个命题 Eq：两边算出来是同一个值时 rfl 成立，Eq.subst 能把 a = b 当搬运工用。
    学完能：亲手造出 eq_symm 与 eq_trans——对称与传递不再是背下来的公理，而是你自己写的项。
  3. ③ 函数与箭头 教什么：类型里的箭头就是函数；fun 一层层剥参数，let 给中间结果起名，函数可以当参数，也可以当返回值。
    学完能：把 (Nat -> Nat) -> Nat -> Nat 读成「吃一个函数、返回一个函数」，而不是一串符号。
  4. ④ by 写法：tactic 证明 教什么：by 块把证明写成一串命令（intro / exact / apply / assumption / rfl），编译器替你搭出证明项。
    学完能：用 tactic 写证明，并且知道它和手写项是同一件事——课程把它提前到这里，当作反馈加速器。
  5. ⑤ 宇宙：函数类型的类型 教什么：Nat -> Nat 自己的类型是什么：Prop = Sort 0、Type 0 = Sort 1，以及 Eq.{u} 里那个宇宙实参的来历。
    学完能：回答「类型的类型」，并写出宇宙多态的 Eq.symm——单元②里那条机械规则到这里才揭晓。
  6. ⑥ 归纳与递归 Ⅰ 教什么：一个显式 inductive Nat 块 = 类型 + 构造子 + 消去子 Nat.rec + iota 规则；match 递归时自动带上归纳假设 ih。
    学完能：自己搭出自然数，手写 Nat.rec，再用 match 写递归定义。
  7. ⑦ 归纳与递归 Ⅱ 教什么：参数化归纳（Option）、依赖 match（就是数学归纳法）、嵌套与通配模式，最后是带索引的 Vec。
    学完能：对「结果类型随取值变化」的东西分情况证明——这正是数学归纳法的形状。
  8. ⑧ 量词：forall 与 exists 教什么：∀ 的引入写 fun、消去写应用；∃ 的引入交出一个证人加一份性质，消去则把函数交给 Exists.elim。
    学完能：把「每个人」「至少有一个人」写成类型并证明——单元①的箭头里本来就埋着 ∀。
  9. ⑨ 关系与联结词 教什么：把 Or 从公理升级成真的 inductive（自动派生 Or.rec），把 Iff 当 def 展开，把 Le/Even 立成归纳关系。
    学完能：拆开一个「或」，用消去子从两份可能的证据里得到结论；也能归纳地定义「偶数」这类关系。
  10. ⑩ 读证明与综合 教什么：不教新语法——自解释三问、形式与非形式互译、评阅被内核拒绝的证明，最后是一个期末小项目。
    学完能：读一份证明并说出它在干什么；把一句中文数学命题翻成内核可判定的声明。
  11. ⑪ 模块与项目 教什么：import Foo.Bar 必须写在最上方、模块名与路径的对应（- 不是模块名字符）、sokonanoda.toml 项目根与闭包级规则。
    学完能：把编译单元从「一个文件」升级成「入口文件 + import 闭包」，并跑通 course/unit11-project/ 那个真的两文件项目。

每个单元文件都自给自足：不 import 任何东西，打开一个文件就能看到它用到的 全部前置声明（course/README.md:53-58）。所以任何一单元都能单独打开、单独判卷， 判卷还是逐声明容错的——一个练习红了不影响别的练习。 单元⑧（量词）是单元① 的逻辑补充，可以紧跟单元① 教学 （course/README.md:19）。

§3 一次会话长什么样

这门课不是让你从第一页读到最后一页。一次会话是一个循环，四步：

  1. 讲：老师（一个 agent）往画布上追加中文讲解、写好的演示，和一道新练习。
  2. 答：你在洞里作答。可以只写一半——先写前几层 fun，最后一层留 sorry，这是合法状态。
  3. 问：把光标停在 sorry 上，内核告诉你手里已经有什么、还差什么。
  4. 判：老师跑一次判卷，读事件流决定下一步；你也可以自己跑。

第三步是这门课与一本习题册最大的差别。下面这个状态是内核对一个 sorry 的完整回答，不是排版排出来的——上面一列是它给的假设，横线下面是它给的目标。

完整的循环——老师怎么出题、判完之后怎么走、三种「卡住」各自该怎么办——在 怎么学那一页。一题从第一行到最后一行、每一步的目标状态， 在走查一题。

卡住时不必猜。每道练习前面挂着两三条 -- soko:hint 注释， 编辑器里的「提示」节点逐条揭示：先说思路，再说目标该拆成什么形状，最后给该用的构造子或引理名。 答案永远不写进提示——那是留给你的部分。

Nat

判卷是逐声明容错的：一个练习红了，不影响同一文件里其他练习的判定。 这一点由仓库里的测试钉着——crates/cli/tests/course.rs 在 CI 里单独跑一条 cargo test -p sokonanoda-cli --test course --locked， 断言四件事：

  • 十一个画布全部可编译，且每个单元的 decl.checked / exercise.open / expr.reduced 计数与一张 golden 表精确一致；
  • 十一份解答钥匙全部 0 诊断、0 个 exercise.open，且覆盖画布里的每一个练习；
  • course.json 恰好按序列出这十一个文件，unit 是 1 到 11；
  • course/en/ 英文镜像与中文画布的事件计数逐项相等。

所以「这门课是可解的」不是一句承诺：十一份钥匙都真的填完了，改课程会重新判一遍。 本页所有数字都是用已发布的 CLI 量的（当前版本 —）。

§6 这一页不承诺的事

限制

这十一个文件是给 agent 的路线图与素材库，不是一本可以照着念的教科书。 真正上课时，老师会按你的反馈历史重组顺序、拆小步或跳过热身； 你面对的永远只是当前那块画布（playground.sokonanoda 或它的分支）， 不是 course/ 目录本身——课程文件不会直接丢给你当读物 （docs/teaching-session.md:9-18）。所以这一页列的是素材， 不是一份排好日期的课表。

画布是中文的。英文镜像在 course/en/：代码与中文版逐字节一致， 只有 -- 注释换成英文，事件计数由 CI 守着不许漂。 卷 I《集合论》的英文镜像还没做。

答案不在画布里，提示里也没有答案。想知道某道题怎么写，得开口问老师—— 而老师会先给提示，不会一次贴出整份钥匙。
