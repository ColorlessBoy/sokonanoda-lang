怎么学

这一页回答「装好了，然后呢」。五个动作构成循环，每个动作有一条确切命令； 卡住时先看提示阶梯，不要先看答案。读懂目标状态是这里唯一必须练熟的手艺。

  • 一个装好的 sokonanoda（VS Code 扩展或 CLI）
  • 画布 playground.sokonanoda，4 个待填的洞

⊢

你自己写出的一个内核接受的项

§1 五个动作，一步一条命令

教学循环不是课程表，是一台状态机：你改画布，内核重判，老师按判定决定下一步。 判卷只认两个信号——decl.checked（做出来了）与 diagnostic（有问题）。 exercise.open 只是「还是个练习」，它只有签名合法时才会出现。

五步循环：每一步你做什么、跑什么、屏幕上会出现什么。
步 你做什么 命令 你会看到什么
1 开画布 在编辑器里打开 playground.sokonanoda 带 sorry 的声明就是题；注释就是课
2 挑一道题 scripts/soko query holes --file playground.sokonanoda 4 个洞，每个带一个稳定 id，例如 forall_exists:0
3 把某个 sorry 换成你的答案，保存 编辑器里改，不用敲命令 编辑器当场重判：诊断、inlay 提示、目标面板一起更新
4 读内核说什么 scripts/soko playground.sokonanoda checked declaration …，或一行诊断加一句 hint
5 卡住就问老师 scripts/soko query hints --file playground.sokonanoda --line 347 --col 3 这道题的提示阶梯，逐条给（见 §4）

第一次用先确认环境。三条命令，跑在仓库根目录： 

$ scripts/soko setup
$ scripts/soko doctor --json
$ scripts/soko query check --file playground.sokonanoda

$ 是提示符，不用输入。doctor 退出码 0 表示就绪，3 表示未就绪。

scripts/soko 是 harness 中立的启动器：它按版本钉解析出二进制，再原样转发子命令。 sokonanoda 已经在 PATH 上时，上表所有 scripts/soko X 都可以换成 sokonanoda X，两者等价。

两种读法，同一份真相。不加 grade时是人类可读的一行一条； grade 子命令固定出 JSON Lines，--json 加不加都一样——agent 读后者， 你读前者。

画布当前的状态用一条命令问出来，别自己数：

30checked 声明
2checked example
4exercise open
0failed

数字来自 scripts/soko query check --file playground.sokonanoda 的 counts 字段。 同一份判卷还有两条 warning：84 行的 reserved-declaration-name 与 333 行的 redundant-sorry——后者是「答案其实写全了，只多留了一行」，不是「还没做出来」。

改一次跑一次很烦，那就让它常驻：scripts/soko watch playground.sokonanoda 每次保存吐一版 delta 事件流。想连续写几层 fun、最后一层留 sorry， 也可以——部分作答是支持的，剩余目标与已引入的假设会出现在 hover 与目标面板里。
