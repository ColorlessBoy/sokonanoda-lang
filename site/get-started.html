快速开始

按你的身份选一条路。学习者这条是零安装主路径；agent 和贡献者各有独立入口。

学习者：装 VS Code 扩展

这是最省事的路径。扩展里内嵌了语言服务器和 sokonanoda 命令行，按平台打包，装完即用，不需要 Rust 工具链，也不需要联网下载。

  1. 在 VS Code 扩展市场里安装 sokonanoda（VS Code 1.85 及以上）。
  2. 打开任意 .sokonanoda 文件，或仓库里的 playground.sokonanoda（12 道练习，从零到定理）。
  3. 完成。诊断、悬停类型、目标视图、课程地图都已就位。
服务器二进制就在扩展的 bin/<平台>/ 目录里，和扩展本身同一个版本构建， 所以不会出现「服务器新、客户端旧」的错位。

code agent：加载技能

仓库里的 skills/ 目录把「怎么操作这个项目」固化成了 Agent Skill，任何支持该格式的 agent（opencode、Claude Code 等）都能加载。

  • sokonanoda-teacher：当老师的 agent——在画布上出题、用内核的 --json 事件判卷、按提示阶梯带你走。
  • sokonanoda-dev：接手开发的 agent——冻结内核、TDD 三层、文档先行的纪律。
  • sokonanoda-ci：推代码 / 发布 / 查 CI 的 agent——本地验证纪律与发布流程。

若用 opencode 打开本仓库，这三个技能自动可加载，无需软链。其它 harness 把技能目录软链进各自的 skills 目录即可，详见 skills/README。

贡献者：从源码构建

需要 Rust 工具链。从本仓库根目录：

cargo test --workspace
cargo run -q -p sokonanoda-cli --bin sokonanoda -- examples/lesson-01.sokonanoda
cargo run -q -p sokonanoda-cli --bin sokonanoda -- --json examples/lesson-01.sokonanoda
cargo run -q -p sokonanoda-cli --bin sokonanoda repl
cargo run -q -p sokonanoda-lsp --bin sokonanoda-lsp

其中 repl 逐行累积声明，支持 #check / #reduce / #print / #prove。构建与测试全部离线，不调用官方 Lean 工具链。更完整的开发纪律见 文档 与 给 Agent。

取用发布二进制时一律按仓库版本锁定，不要用 releases/latest——否则新服务器可能配上旧客户端。版本号请从 GitHub Releases 读取，不要写死在脚本里。
