快速开始

按你的身份选一条路。学习者这条是零安装主路径；agent 和贡献者各有独立入口。

学习者：装 VS Code 扩展

最省事的路径。扩展里内嵌了语言服务器和 sokonanoda 命令行，按平台 打包，装完即用：不需要 Rust 工具链，也不需要联网下载。

  1. 在 VS Code 插件市场一键安装

    VS Code 1.85 及以上；想离线或装指定版本，到 GitHub Releases 下载对应平台的 VSIX。

  2. 克隆仓库、打开课程画布（12 道练习，从零到定理）： 
    git clone https://github.com/ColorlessBoy/sokonanoda-lang
code sokonanoda-lang/playground.sokonanoda
打开文件后诊断、悬停类型、目标视图、课程地图都已就位；服务器二进制就在扩展的 bin/<平台>/ 目录里，和扩展本身同一个版本构建， 所以不会出现「服务器新、客户端旧」的错位。

code agent：复制一段提示

不用预装技能，也不用读协议。复制下面这段安装 prompt，粘进任意 code agent （opencode / Claude Code / Codex / Cursor / …）：它会克隆仓库、读 AGENTS.md、 按 sokonanoda-teacher 技能装好版本锁定环境，然后在 playground.sokonanoda 上出题、判卷。

用 opencode 打开本仓库时，三份技能（teacher / dev / ci）与 /sokonanoda/* 命令零配置可用；其它 harness 直接读技能文件即可， 细节见 给 Agent。

贡献者：从源码构建

需要 Rust 工具链。从本仓库根目录：

cargo test --workspace
cargo run -q -p sokonanoda-cli --bin sokonanoda -- examples/lesson-01.sokonanoda
cargo run -q -p sokonanoda-cli --bin sokonanoda -- --json examples/lesson-01.sokonanoda
cargo run -q -p sokonanoda-cli --bin sokonanoda repl
cargo run -q -p sokonanoda-lsp --bin sokonanoda-lsp

其中 repl 逐行累积声明，支持 #check / #reduce / #print / #prove。构建与测试全部离线，不调用官方 Lean 工具链。更完整的开发纪律见 文档 与 给 Agent。

取用发布二进制时一律按仓库版本锁定，不要用 releases/latest——否则新服务器可能配上旧客户端。版本号请从 GitHub Releases 读取，不要写死在脚本里。
