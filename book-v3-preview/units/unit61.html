61 实数的加法：三元关系（存在 + 唯一）

Unit 61 — Addition on the Reals: A Ternary Relation (Existence + Uniqueness)

上一单元在代表元层建立了 addSeq，并交清了两条下降义务：cauchy_add（Cauchy 对加法封闭）与 realRel_add（realRel 对加法同余）。二元运算仍然不能直接写成 Real → Real → Real 的函数：Quot.lift 的外层还要一次「函数相等」，而 realRel 只在 Cauchy 序列上自反——商里还有非 Cauchy 代表元形成的「杂点」，同一条 Cauchy 序列在杂点上的像不唯一。

于是把加法写成三元关系：addRel a b c 当且仅当 a、b 有 Cauchy 代表元 x、y，且 c = mk (x+y)。这个关系在 Cauchy 代表元上存在且唯一；在杂点上没有输出——这是诚实的分关系，不是把洞绕过去。定义要经两次 Quot.lift，两次的良定义性就是两个 def 里的函数外延性与命题外延性义务，用的都是课程里已经有的东西，不新增信任。

一个刻意留下的边界：mk z = mk (x+y) 反推 realRel z (x+y) 需要 Quot.exact，而它要求 realRel 在整个 Seq 上自反；本载体拿不到这条（杂点不自反）。所以这里只给「相关推出是同一个输出」的声音方向，反推留作已知边界，不写成公理。

先给出关系在代表元上的形状与两次下降，再证存在、声音方向与唯一性，把它们拼成「存在且唯一」，最后落在常零序列上。

关系在代表元上的形状

addRelRep x y c 读作「c 是 x、y 的和」。两个 Cauchy 守卫是必要的：没有它们，第二次 lift 在杂点上没有 realRel y y 可用。

def addRelRep (x y : Seq) (c : Real) : Prop :=
  Cauchy x ∧ Cauchy y ∧ c = Real.mk (addSeq x y)

两次下降：addRelY 先下降第二个因子，addRel 再下降第一个

固定 x，对 y 做 Quot.lift。外层类型是 Real → Prop，所以良定义性要 funext + propext 把两个 addRelRep 的 ↔ 变成函数相等。Cauchy x 在两边都由假设提供，Cauchy y 与 Cauchy y' 来自 hy；mk 下的等式由 60.4 的 realRel_add 给出。

完整代码 · 24 行
def addRelY (x : Seq) : Real → Real → Prop :=
  @Quot.lift.{1, 1} Seq realRel (Real → Prop)
    (fun (y : Seq) (c : Real) => addRelRep x y c)
    (fun (y y' : Seq) (hy : realRel y y') =>
      funext (fun (c : Real) => addRelRep x y c)
             (fun (c : Real) => addRelRep x y' c)
             (fun (c : Real) =>
               propext (addRelRep x y c) (addRelRep x y' c)
                 (Iff.intro
                   (fun (h : addRelRep x y c) =>
                     And.intro (And.left h)
                       (And.intro (And.left (And.right hy))
                         (Eq.trans (And.right (And.right h))
                           (Real.sound (addSeq x y) (addSeq x y')
                             (realRel_add x x y y'
                               (realRel_refl x (And.left h)) hy)))))
                   (fun (h : addRelRep x y' c) =>
                     And.intro (And.left h)
                       (And.intro (And.left hy)
                         (Eq.trans (And.right (And.right h))
                           (Eq.symm
                             (Real.sound (addSeq x y) (addSeq x y')
                               (realRel_add x x y y'
                                 (realRel_refl x (And.left h)) hy)))))))))

再对第一个因子做一次 Quot.lift。里层要对 b 用 Quot.ind（命题层消去），把 addRelY x (mk y) 烧成代表元形状；两个方向同样用 realRel_add（这次第一个假设是 hx，第二个由 Cauchy y 经 realRel_refl 反射）把 mk 下的代表元换掉。

def addRel (a : Real) : Real → Real → Prop :=
  @Quot.lift.{1, 1} Seq realRel (Real → Real → Prop)
    (fun (x : Seq) => addRelY x)
    (fun (x x' : Seq) (hx : realRel x x') =>
      funext (fun (b : Real) => addRelY x b)
             (fun (b : Real) => addRelY x' b)
             (fun (b : Real) =>
               @Quot.ind.{1} Seq realRel
                 (fun (b : Real) => addRelY x b = addRelY x' b)
                 (fun (y : Seq) =>
                   funext (fun (c : Real) => addRelRep x y c)
                          (fun (c : Real) => addRelRep x' y c)
                          (fun (c : Real) =>
                            propext (addRelRep x y c) (addRelRep x' y c)
                              (Iff.intro
                                (fun (h : addRelRep x y c) =>
                                  And.intro (And.left (And.right hx))
                                    (And.intro (And.left (And.right h))
                                      (Eq.trans (And.right (And.right h))
                                        (Real.sound (addSeq x y) (addSeq x' y)
                                          (realRel_add x x' y y hx
                                            (realRel_refl y (And.left (And.right h))))))))
                                (fun (h : addRelRep x' y c) =>
                                  And.intro (And.left hx)
                                    (And.intro (And.left (And.right h))
                                      (Eq.trans (And.right (And.right h))
                                        (Eq.symm
                                          (Real.sound (addSeq x y) (addSeq x' y)
                                            (realRel_add x x' y y hx
                                              (realRel_refl y (And.left (And.right h))))))))))))
                 b))
    a

61.1 ι 规则：关系作用在 mk 上回到代表元形状

练习 1addRel_mk定理附录解答

ι 规则：addRel 作用在 Cauchy 代表元上按定义归约。

theorem addRel_mk (x y : Seq) (c : Real) :
    (addRel (Real.mk x) (Real.mk y) c) ↔ (addRelRep x y c) :=
  sorry
提示 1思路

addRel 与 addRelY 都是 Quot.lift；作用到 Real.mk x / Real.mk y 上按 ι 归约成 addRelRep x y c。因此两边是定义性相等的命题，两个方向都取恒等函数。

提示 2目标形态

(addRel (Real.mk x) (Real.mk y) c) ↔ (addRelRep x y c)。

提示 3关键件

Iff.intro · ι 归约（两处 Quot.lift 都要真的烧掉）。

查看解答 定理 · 4 行

两次 Quot.lift 都按 ι 归约，所以两边是定义性相等的命题， Iff.intro 的两个人射都取恒等函数。

theorem addRel_mk (x y : Seq) (c : Real) :
    (addRel (Real.mk x) (Real.mk y) c) ↔ (addRelRep x y c) :=
  Iff.intro (fun (h : addRel (Real.mk x) (Real.mk y) c) => h)
            (fun (h : addRelRep x y c) => h)

61.2 引入：Cauchy 代表元的和是关系的一个输出

练习 2addRel_intro定理附录解答

存在性：两个 Cauchy 代表元的和是关系的输出。

theorem addRel_intro (x y : Seq) (hx : Cauchy x) (hy : Cauchy y) :
    addRel (Real.mk x) (Real.mk y) (Real.mk (addSeq x y)) :=
  sorry
提示 1思路

addRel 在 mk 上归约成 addRelRep，于是要交的就是三元组 Cauchy x、Cauchy y 与 mk (addSeq x y) = mk (addSeq x y)；前两个是假设，第三个是 Eq.refl。

提示 2目标形态

addRel (mk x) (mk y) (mk (addSeq x y))。

提示 3关键件

And.intro（两次）· Eq.refl · ι 归约。

查看解答 定理 · 3 行
theorem addRel_intro (x y : Seq) (hx : Cauchy x) (hy : Cauchy y) :
    addRel (Real.mk x) (Real.mk y) (Real.mk (addSeq x y)) :=
  And.intro hx (And.intro hy (Eq.refl (Real.mk (addSeq x y))))

61.3 声音方向：与 addSeq 相关的实数就是那个输出

练习 3addRel_sound定理附录解答

声音方向：相关的输出互相连到同一个 c。

theorem addRel_sound (x y z : Seq) (hx : Cauchy x) (hy : Cauchy y)
    (hz : realRel z (addSeq x y)) :
    addRel (Real.mk x) (Real.mk y) (Real.mk z) :=
  sorry
提示 1思路

hx、hy 填前两个守卫；hz : realRel z (addSeq x y) 经 Real.sound 给出 mk z = mk (addSeq x y)，正好是第三个分量。

提示 2目标形态

realRel z (addSeq x y) → addRel (mk x) (mk y) (mk z)。

提示 3关键件

And.intro（两次）· Real.sound。

查看解答 定理 · 4 行
theorem addRel_sound (x y z : Seq) (hx : Cauchy x) (hy : Cauchy y)
    (hz : realRel z (addSeq x y)) :
    addRel (Real.mk x) (Real.mk y) (Real.mk z) :=
  And.intro hx (And.intro hy (Real.sound z (addSeq x y) hz))

61.4 唯一性：关系的两个输出相等

练习 4addRel_unique定理附录解答

唯一性：同一个和的两个输出相等。

theorem addRel_unique (a b c c' : Real)
    (h : addRel a b c) (h' : addRel a b c') :
    c = c' :=
  sorry
提示 1思路

对 a 做一次 Quot.ind（动机是「对一切 b c c'，两个输出相等」），进入 mk x 后对 b 再做一次 Quot.ind（动机把 c、c' 一起量化）。两次 ι 归约把 h、h' 都变成 c = mk (x+y) 与 c' = mk (x+y)，用 Eq.trans 与 Eq.symm 接起来。

提示 2目标形态

addRel a b c → addRel a b c' → c = c'。

提示 3关键件

Quot.ind（两次，动机都写在 Real 上）· ι 归约 · Eq.trans · Eq.symm · And.right。

查看解答 定理 · 23 行

对 a、b 各做一次 Quot.ind；addRel 的两次 ι 归约把两个假设 都变成 c = mk (x+y) 与 c' = mk (x+y)，直接传递。

theorem addRel_unique (a b c c' : Real)
    (h : addRel a b c) (h' : addRel a b c') :
    c = c' :=
  @Quot.ind.{1} Seq realRel
    (fun (a : Real) =>
      ∀ (b c c' : Real), addRel a b c → addRel a b c' → c = c')
    (fun (x : Seq) =>
      fun (b c c' : Real)
          (h : addRel (Real.mk x) b c)
          (h' : addRel (Real.mk x) b c') =>
        @Quot.ind.{1} Seq realRel
          (fun (b : Real) =>
            ∀ (c c' : Real),
              addRel (Real.mk x) b c → addRel (Real.mk x) b c' → c = c')
          (fun (y : Seq) =>
            fun (c c' : Real)
                (hc : addRel (Real.mk x) (Real.mk y) c)
                (hc' : addRel (Real.mk x) (Real.mk y) c') =>
              Eq.trans
                (And.right (And.right hc))
                (Eq.symm (And.right (And.right hc'))))
          b c c' h h')
    a b c c' h h'

61.5 存在且唯一

练习 5addRel_exists_unique定理附录解答

存在且唯一装成一个命题。

theorem addRel_exists_unique (x y : Seq) (hx : Cauchy x) (hy : Cauchy y) :
    ∃ (c : Real),
      addRel (Real.mk x) (Real.mk y) c ∧
        ∀ (c' : Real), addRel (Real.mk x) (Real.mk y) c' → c' = c :=
  sorry
提示 1思路

见证取 mk (addSeq x y)。存在分量是 61.2；唯一分量对任意 c' 用 61.4，把 c' 与见证的两个证明接起来（注意 61.4 的结论方向是 c' = c）。

提示 2目标形态

∃ c, addRel (mk x) (mk y) c ∧ ∀ c', addRel (mk x) (mk y) c' → c' = c。

提示 3关键件

Exists.intro · And.intro · addRel_intro · addRel_unique。

查看解答 定理 · 10 行
theorem addRel_exists_unique (x y : Seq) (hx : Cauchy x) (hy : Cauchy y) :
    ∃ (c : Real),
      addRel (Real.mk x) (Real.mk y) c ∧
        ∀ (c' : Real), addRel (Real.mk x) (Real.mk y) c' → c' = c :=
  Exists.intro (Real.mk (addSeq x y))
    (And.intro
      (addRel_intro x y hx hy)
      (fun (c' : Real) (hc' : addRel (Real.mk x) (Real.mk y) c') =>
        addRel_unique (Real.mk x) (Real.mk y) c' (Real.mk (addSeq x y))
          hc' (addRel_intro x y hx hy)))
