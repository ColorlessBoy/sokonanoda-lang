42 close 的对称性：实数的相等可以换方向

Unit 42 — Symmetry of Close and Real Equality

㊱ 把实数的相等定义成 realRel x y：x、y 都是 Cauchy 序列，且对任意 eps>0 存在 N，使 n ≥ N 时 close (x n) (y n) eps 成立。其中 close x y eps 说的是「x-y 的绝对值小于 eps」：存在一个 d，它等于 |x-y| 且 d < eps。

练习 1ratSubRep_neg定理附录解答

㊵ 结清了自反性；要和它凑成等价关系，还差对称性：close x y eps 推出 close y x eps，以及 realRel x y 推出 realRel y x。

直觉上「y-x 与 x-y 只差一个负号，绝对值一样」，但代表元层要真的搬过去：y-x 的代表元与 -(x-y) 的代表元并不相同（分母字段是 ratDenRep n m 与 ratDenRep m n），两者相等靠 ratDenRep_comm（㊷.1）；绝对值对取负不变由 ㊶ 提供，但要把它从 -(x-y) 搬到 y-x，还需要「ratAbsRel 只依赖第一个因子的等价类」（㊷.2）。把这两步拼起来就是 close 的对称性（㊷.3），逐点作用到 realRel 上就是实数相等的对称性（㊷.4）。

序的通用替换律收在 lib/RatOrder：ratLeRep_congr 换第一个因子，ratLeRep_congr_snd 换第二个。

㊷.1 减法的反交换：y - x ~ -(x - y)

先证减法的反交换：y-x 与 -(x-y) 相差两次加法交换与一次分母换位。

theorem ratSubRep_neg (x y : ratRep) :
    ratRel (ratSubRep y x) (ratNegRep (ratSubRep x y)) :=
  sorry
提示 1思路

两边都先用 ratSubRep_mk 展开成字面三元组。左边是 qrep (c(m+1)+b(n+1)) (d(m+1)+a(n+1)) (ratDenRep n m)；右边的 ratNegRep 只是交换分子序对，定义性给出 qrep (b(n+1)+c(m+1)) (a(n+1)+d(m+1)) (ratDenRep m n)。于是两边的分子只差两次 add_comm、分母只差 ratDenRep_comm。先把这两个等式写成 qrep … = qrep …（prod_mk_congr + congrArg + Eq.trans），再用 Eq.subst 把 ratRel_refl 从右边三元组搬到左边。

提示 2目标形态

提示 3关键件

㊷.2 ratAbsRel 只依赖第一个因子的等价类

绝对值只依赖第一个因子的等价类：把两个分支里的 u 都换成等价的 v。

theorem ratAbsRel_wd_left (u v : ratRep) (d : ratRep)
    (h : ratRel u v) (hab : ratAbsRel u d) : ratAbsRel v d :=
  sorry
提示 1思路

ratAbsRel u d 是两个分支的析取。第一分支 0 ≤ u ∧ d ~ u 要落到第一分支：0 ≤ u 用 ratLeRep_congr_snd 把第二个因子换成 v（0 ≤ v），d ~ u 再用 ratRel_trans_gen 沿 u ~ v 换成 d ~ v。第二分支 u ≤ 0 ∧ d ~ -u 要落到第二分支：u ≤ 0 用 ratLeRep_congr 把第一个因子换成 v（v ≤ 0），d ~ -v 由 d ~ -u 与 -u ~ -v（ratNegRep_wd）经 ratRel_trans_gen 串起来。

提示 2目标形态

提示 3关键件

㊷.3 close 的对称性

拼成 close 的对称性：同一份绝对值证据可以左右互换。

theorem close_symm (x y eps : ratRep) (h : close x y eps) :
    close y x eps :=
  sorry
提示 1思路

把 close x y eps 拆成 ∃ d, |x-y| ~ d ∧ d < eps，用同一个 d 造 close y x eps。第一分量：㊶ 的 ratAbsRel_neg（通用版本 ratAbsRel_neg_gen） 把 |x-y| ~ d 变成 |-(x-y)| ~ d，再用 ㊷.2 沿 ratRel (-(x-y)) (y-x)（㊷.1 取对称）搬到 |y-x| ~ d；第二分量 d < eps 原样。

提示 2目标形态

close x y eps → close y x eps。

提示 3关键件

Exists.elim · Exists.intro · ratAbsRel_neg_gen · ratAbsRel_wd_left · ratSubRep_neg · ratRel_symm。

查看解答 定理 · 17 行
theorem close_symm (x y eps : ratRep) (h : close x y eps) :
    close y x eps :=
  Exists.elim h
    (fun (d : ratRep)
         (hd : ratAbsRel (ratSubRep x y) d ∧ ratLtRep d eps) =>
      Exists.intro d
        (And.intro
          (ratAbsRel_wd_left
            (ratNegRep (ratSubRep x y))
            (ratSubRep y x)
            d
            (ratRel_symm
              (ratSubRep y x)
              (ratNegRep (ratSubRep x y))
              (ratSubRep_neg x y))
            (ratAbsRel_neg_gen (ratSubRep x y) d (And.left hd)))
          (And.right hd)))

㊷.4 实数相等的对称性

最后逐点作用到实数相等的定义上。

theorem realRel_symm (x y : Seq) (h : realRel x y) : realRel y x :=
  sorry
提示 1思路

realRel x y 是 Cauchy x ∧ Cauchy y ∧ 逐点 close。realRel y x 只要把两个 Cauchy 分量对调，第三分量在每个 n 上调用 ㊷.3 把 close (x n) (y n) eps 翻成 close (y n) (x n) eps。

提示 2目标形态

realRel x y → realRel y x。

提示 3关键件

And.intro · And.left · And.right · Exists.elim · Exists.intro · close_symm。

查看解答 定理 · 6 行
theorem realRel_symm (x y : Seq) (h : realRel x y) : realRel y x :=
  And.intro
    (And.left (And.right h))
    (And.intro
      (And.left h)
      (realRel_close_symm x y (And.right (And.right h))))

theorem ratAbsRel_wd_left_aux (u v : Prod (Prod Nat Nat) Nat) (d : ratRep) :
    ratRel u v → ratAbsRel u d → ratAbsRel v d :=
  match u with
  | prod_mk (prod_mk a b) m =>
    match v with
    | prod_mk (prod_mk a' b') m' =>
      fun (h : ratRel (prod_mk (prod_mk a b) m) (prod_mk (prod_mk a' b') m'))
          (hab : ratAbsRel (prod_mk (prod_mk a b) m) d) =>
        Or.elim
          (fun (h1 : ratLeRep ratZeroRep (prod_mk (prod_mk a b) m) ∧
                     ratRel d (prod_mk (prod_mk a b) m)) =>
            Or.inl (And.intro
              (ratLeRep_congr_snd Nat.zero Nat.zero a b a' b' Nat.zero m m'
                h (And.left h1))
              (ratRel_trans_gen d (prod_mk (prod_mk a b) m)
                (prod_mk (prod_mk a' b') m') (And.right h1) h)))
          (fun (h2 : ratLeRep (prod_mk (prod_mk a b) m) ratZeroRep ∧
                     ratRel d (ratNegRep (prod_mk (prod_mk a b) m))) =>
            Or.inr (And.intro
              (ratLeRep_congr a b a' b' Nat.zero Nat.zero m m' Nat.zero
                h (And.left h2))
              (ratRel_trans_gen d (ratNegRep (prod_mk (prod_mk a b) m))
