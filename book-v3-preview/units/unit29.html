29 有理数的序：代表元公式与自反性

Unit 29 — Order on Rationals

卷 II 把 ℚ 建成 Quot ratRel（单元⑳），并在代表元层结清了加法与乘法的良定义性（㉖–㉘）。接下来进入 ℚ 的性质：序、绝对值、幂、间隙。先做序，因为后面的绝对值与极限都要用它。

序的定义沿用整数序的同一套想法：a−bm+1 ≤ c−dn+1 等价于交叉相乘后的 ℕ 不等式 a·(n+1) + d·(m+1) ≤ c·(m+1) + b·(n+1)。右边不是笔误：(a-b)(n+1) ≤ (c-d)(m+1) 移项后，负部 -b(n+1) 与 -d(m+1) 都搬到对面。分母 (m+1)(n+1) 是正的，所以交叉相乘不改变方向。

这里先立起序的定义、自反、以及「相等蕴含序」；传递性、全序与加法/乘法相容都要先把两个代表元换到公分母，留给后续单元。

有理数的非严格序：交叉相乘后的 ℕ 不等式。

定义ratLeRep声明 1
def ratLeRep (x y : ratRep) : Prop :=
  leRep (mulRep (numOf x) (den (denOf y)))
        (mulRep (numOf y) (den (denOf x)))

严格序：≤ 且不相等（相等仍用商上的 ratRel 表达）。

定义ratLtRep声明 2
def ratLtRep (x y : ratRep) : Prop :=
  ratLeRep x y ∧ ¬ ratRel x y

theorem ratLeRep_of_ratRel (x y : ratRep) (h : ratRel x y) : ratLeRep x y :=
  leRep_wd_pair
    (mulRep (numOf y) (den (denOf x)))
    (mulRep (numOf x) (den (denOf y)))
    (mulRep (numOf y) (den (denOf x)))
    (mulRep (numOf y) (den (denOf x)))
    (intRel_symm
      (mulRep (numOf x) (den (denOf y)))
      (mulRep (numOf y) (den (denOf x))) h)
    (intRel_refl (mulRep (numOf y) (den (denOf x))))
    (leRep_refl (mulRep (numOf y) (den (denOf x))))
