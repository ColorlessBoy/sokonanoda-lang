单元72 完备性盘点：代表元层的结论，放到集合层还剩下多少

前面证了：每个有理 Cauchy 序列 x 在 ℝ 中收敛到自己的类。那是在代表元层说的话。到了集合层，上界、最小上界这些词要用 realLe 重新陈述；我们自然要问：这条完备性还能保住多少？

结论先说：能保住一个具体集合的 LUB——S = {x | x ≤ 0} 的最小上界是 0；但一般定理「每个非空有上界集合都有 LUB」需要选择公理，本课程没有，所以不能写。

为什么只做具体集合？因为选择公理不在本课程里；与其把一般定理写成公理，不如把能构造性拿到的实例做干净：先定义零实数为常零序列的类，再证 0 是 S 的上界且最小，把两件事合成「有 LUB」，最后回到常序列版本的完备性。

这一单元不是新造数，而是检查前面造好的 ℝ 在集合语言里能说到哪一步；边界就是本课程与「完整实数完备性」之间的距离。

72.0 集合层的词汇：上界、最小上界、有 LUB

定义UpperBound声明 1
def UpperBound (S : Real → Prop) (b : Real) : Prop :=
  ∀ (x : Real), S x → realLe x b
定义IsLUB声明 2
def IsLUB (S : Real → Prop) (b : Real) : Prop :=
  UpperBound S b ∧ ∀ (b' : Real), UpperBound S b' → realLe b b'
定义HasLUB声明 3
def HasLUB (S : Real → Prop) : Prop := ∃ (b : Real), IsLUB S b
