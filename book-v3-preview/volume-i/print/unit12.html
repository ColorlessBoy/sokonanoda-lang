── 两条"看起来对"的错证明（12.2 要评的对象；名字都是本课程真有的）──────────────

【错证明 A】命题：对任意 f : α → β 与 C : Set β，有

f′′(f-1′C)=C

证明（错）："→"：设 y ∈ f '' (f ⁻¹' C)。按 Set.mem_image 展开，存在 x 使 x ∈ f ⁻¹' C 且 f x = y；按 Set.mem_preimage，x ∈ f ⁻¹' C 就是 f x ∈ C。沿 f x = y 用 Eq.subst 搬过去，得 y ∈ C。✓"←"：设 y ∈ C。取 x 使 f x = y（"y 的原像"），则 f x ∈ C，即 x ∈ f ⁻¹' C，于是 y = f x ∈ f '' (f ⁻¹' C)。✓ 两边互相包含，故相等。∎

【错证明 B】命题：对任意 f : α → β 与 A B : Set α，有

f′′(A∩B)=f′′A∩f′′B

证明（错）："→"：设 y ∈ f '' (A ∩ B)。存在 x ∈ A ∩ B 使 f x = y；由 Set.mem_inter_iff，x ∈ A 且 x ∈ B，于是 y 同时落在 f '' A 与 f '' B 里。✓"←"：设 y ∈ f '' A ∩ f '' B。存在 x1 ∈ A 与 x2 ∈ B 使 f x1 = y、f x2 = y。由 f x1 = y = f x2 得 x1 = x2，这个点既在 A 里又在 B 里，所以 y ∈ f '' (A ∩ B)。✓ 两边互相包含，故相等。∎

评阅任务（12.2）：两条都假。错在"哪一条推理"上、反例长什么样，由下面三道题（练习 5、6、7）分别负责：改正版 + 证伪。

── 已知边界（本轮实测，环 6 因此从画布移除）──────────────────────────────「等势的复合仍是等势」这条本身成立，但它的证明要把两把复合映射当 lambda 证人交出去，而判卷器今天在这一形状上撞两条边界：① 内核不做 beta 转换（(fun (c : γ) => g (g2 c)) ((fun (a : α) => f2 (f a)) a) 与 g (g2 (f2 (f a))) 在它眼里不是同一个类型）；② cases 拆 Set.Equiv 之后臂里假设的变量编号会与目标对不上（内核原文 expected="$28"actual="$27"）。前端已经把代入后的 redex 消掉（spine::beta_normalize），① 那一半已修；② 仍是开口，记录在 docs/design/course-lean-style.md §9。结论：环 6 的事实留在散文里，证明不进画布；练习 9 的两半不受影响。

练习 2（X 类：形式↔散文互译）。散文：

「关系先复合、再取逆，等于把两个关系各自取逆、再按相反的顺序复合。」

（读法：r • s 里 r : Rel A B 先走、s : Rel B C 后走；⁻¹ 把两个参数对调。所以形式版右边先出现 s 的逆、后出现 r 的逆——顺序正是"相反"。）

theorem xlat_rel_inv_comp (A B C : Type) (r : Rel A B) (s : Rel B C) :
    (r • s) ⁻¹ = (s ⁻¹) • (r ⁻¹) := by

提示 1思路

两个关系相等只能用公理 Rel.ext 逐点证 Iff；把"逆"与"复合"都展开成 ∃ 之后，剩下的只是 ∧ 的两支换序。

提示 2目标形态

(r • s) ⁻¹ = (s ⁻¹) • (r ⁻¹)；逐点是 (∃ (b : B), r a b ∧ s b c) ↔ (∃ (b : B), s b c ∧ r a b)——参数顺序是 c a，与 ⁻¹ 对调有关。

提示 3关键件
