── 大纲条目（docs/design/set-theory-syllabus.md §3 第 7 行）──────────────── 单元号：卷 I ⑦（依赖树 1 → 2 → … → 6 → 7）；先修：单元②（子集/空集——第 9 题的反例要用 ∈ 的两条引理）与单元⑥（关系与复合——本单元只讲函数层的复合，关系层的复合只在演示 1 里作为对照出现，不重复单元⑥ 的练习）。练习配额：T-5 · L-2 · D-2 = 9 题（本文件：T = 题 1/2/3/4/6；L = 题 5/7；D = 题 8/9）。类型记号见 units/README（T 项填空 · L 自证引理 · D 证明或证伪）。

── 实证导入语（这一单元为什么存在）──────────────────────────────────────── Breidenbach, Dubinsky, Hawks & Nichols 1992 的实测（24 个情境、约 60 名本科生）：本该 ~100% 判为函数的场合只有约 40% 的学生答"是函数"——分表征看，图那道（第 19 题）40.7%、方程那道（第 25 题）31%、表格 39.9–48.6%。换句话说，"什么是一个函数"不是自明的：它与你手里的表示形式有关，而课程要做的正是把这两种表示摆在一起对照。

── 本单元只允许用什么（逐步解锁，见 docs/design/set-theory-syllabus.md §2）──

细节清单（5 项，展开）
  • 证明：一律 by tactic 块（缩进两格），白名单只有 intro / exact / apply / assumption / rfl / match / constructor / left / right / use / exfalso / cases / have / sorry——没有 rw / obtain / change / simp / induction / calc / rintro / ·，也没有 ⟨a, b⟩ 匿名构造子；练习里写 sorry 占位，演示（demo_*）一律已证。
  • 语句一律写记法（随 import 生效，本文件一条 infix/notation 都不许写）：∈ ⊆ ∪ ∩ \ ∅ 𝒫（lib.Set）、g ∘ f（lib.Fun，函数复合）、∃ (x : α), p x（lib.Exists，类型写在括号里）；∧ ∨ ↔ ¬ → = ≠ 是语言内建（任何文件零声明可用），∀ 是关键字（原生 Pi）。
  • 记法只是连接符的糖，不是引理名的糖：引理照旧点名写——Eq.refl / Eq.symm / Eq.trans / congrArg / Eq.subst.{1} / And.intro / And.left / And.right / Or.inl / Or.inr / Or.elim / Iff.intro / Iff.mp / Iff.mpr / Exists.intro / Exists.elim / Set.mem_univ / Set.notMem_empty …
  • 库（lib/）：lib.Logic —— True/False/False.elim、Eq 一族、And/Or/Not/Iff/absurd；prelude 另带 Nat、Bool 与 Eq.refl/Eq.subst；lib.Set —— 只在第 9 题的反例里用（∅ 与 univ、∈ 的两条引理）；lib.Exists —— Exists / Exists.intro / Exists.elim（满射与换序题要用）；lib.Fun —— 函数复合（记法 g ∘ f）/ Injective / Surjective / Bijective / LeftInverse / RightInverse / Inverse，以及它们的定义展开引理。
  • 不许用（本语言里根本没有）：选择公理（Classical.choice）、funext、propext。这三样一起决定了第 1 题与第 6 题的形状——请看下面两处说明。

── 概念顺序（本文件的编排）────────────────────────────────────────────── 演示 1：函数 ⇒ 单值关系（"函数即关系"那条路的一小步，用于对照）演示 2：语言原语视角——α → β 是类型，复合就是"先 f 后 g"的应用演示 3：双射 = 单射 ∧ 满射（定义展开）题 1–3：复合（结合律、单射复合、满射复合）题 4–7：单射/满射/双射 ↔ 逆（数据版）——左逆⇒单射、右逆⇒满射、双边逆⇔双射题 8–9：D 类——量词换序的四个变体（哪个恒真、哪个有反例）

── 两条"写死在注释里"的约定 ────────────────────────────────────────────── (1) 复合的顺序：g ∘ f（lib.Fun 的记法；点名形式是 Function.comp）——先 f : α → β、再 g : β → γ，得 α → γ，即第一个函数参数最后作用（Mathlib 同款，见 lib/Fun 文件头）。所以题 2、3 的前提写作 Injective f、Injective g 时，"f 在前"指的是先作用的那个。(2) 没有 funext：语言里证不了 (∀ x, f x = g x) → f = g。所以题 1 的等式只能靠"两边展开后是同一个 λ"（定义上相等）来证，不能逐点证。

── 第 6 题与选择公理（务必读）──────────────────────────────────────────── 若把"双射 ↔ 有逆"写成存在版：

Bijectivef↔∃(g:β→α),Inversefg

那么 "→" 方向就是"每个满射都可以裂开"——与选择公理等价，本语言证不出来（没有 Classical.choice，也没有 funext/propext）。所以第 6 题证的是数据版：逆函数 g 连同"它是右逆"的证据由调用者交出来，此时 Iff 两边都成立。这是一条 "能证多少证多少" 的边界，报告里记在 unprovable。

演示（已写好）：三条，分别对应"关系视角 / 原语视角 / 双射"

演示 1（已写好）：函数 ⇒ 单值关系。把 f 读成关系 fun (x : α) => fun (y : β) => f x = y：同一个 x 不会对上两个 y——这正是"函数即单值关系"那条路的第一条性质（对照：语言原语那条路里，单值性是类型的构造规则，不需要证）。

练习 1comp_assoc定理附录解答

题 1–3：复合（T 类）

练习 1（T 类）：复合结合律——先说清参数顺序：下面写的是 h ∘ (g ∘ f) = (h ∘ g) ∘ f，其中 f : α → β、g : β → γ、h : γ → δ，而 g ∘ f 就是"第一个函数参数最后作用"（见文件头 (1)）。

theorem comp_assoc (α β γ δ : Type) (f : α → β) (g : β → γ) (h : γ → δ) :
    h ∘ (g ∘ f) = (h ∘ g) ∘ f := by
  sorry
提示 1思路

两边都是 α → δ 的函数；没有 funext，别去逐点证——回到复合的定义（g ∘ f 展开成 fun x => g (f x)），看两边是不是同一个 λ。

提示 2目标形态

h ∘ (g ∘ f) = (h ∘ g) ∘ f，两边都是 α → δ 的函数。

提示 3关键件

触发条件是"两边 delta/beta 展开后 λ 体都是 h (g (f x))"（定义上相等）；这种等式不用 intro，点名交 Eq.refl.{1} (α → δ) 一族即可——它是本单元唯一不需要拆前提的题。

theorem comp_assoc (α β γ δ : Type) (f : α → β) (g : β → γ) (h : γ → δ) :
    h ∘ (g ∘ f) = (h ∘ g) ∘ f := by
  exact @Eq.refl.{1} (α → δ) ((h ∘ g) ∘ f)

练习 2（T 类）：单射在复合下封闭。

theorem injective_comp (α β γ : Type) (f : α → β) (g : β → γ)
    (hf : Function.Injective α β f) (hg : Function.Injective β γ g) :
    Function.Injective α γ (g ∘ f) := by
  sorry
提示 1思路

单射的定义是全称命题：intro 两个点，再 intro"它们在复合下相等"这条假设；把这条等式一层一层往回退。

提示 2目标形态

intro 之后手里是 g (f x) = g (f y)（g ∘ f 展开后的样子），目标是 x = y。

提示 3关键件

apply 用引理的结论对齐目标、其余参数变子目标：先用 g 的单射把 x = y 化归成 f x = f y，再用 f 的单射化归成 g (f x) = g (f y)——那正是手里那条假设。

查看解答 定理 · 7 行

题 2：先把复合等式经 g 的单射降到 f 层，再交给 f 的单射。 intro 会把 Function.Injective 展开到 Pi；apply 用引理的结论对齐目标， 其余参数（两个点、以及"值相等"这条前提）变子目标。

theorem injective_comp (α β γ : Type) (f : α → β) (g : β → γ)
    (hf : Function.Injective α β f) (hg : Function.Injective β γ g) :
    Function.Injective α γ (g ∘ f) := by
  intro x y h
  apply hf
  apply hg
  exact h
练习 3surjective_comp定理附录解答

练习 3（T 类）：满射在复合下封闭。原像要穿过两层，这是本题唯一的新东西。

theorem surjective_comp (α β γ : Type) (f : α → β) (g : β → γ)
    (hf : Function.Surjective α β f) (hg : Function.Surjective β γ g) :
    Function.Surjective α γ (g ∘ f) := by
  sorry
提示 1思路

满射是"给每个 z 找一个原像"：先用 g 的满射把 z 拉回中间点，再用 f 的满射把中间点拉回 x。

提示 2目标形态

intro z 之后目标是 ∃ (x : α), (g ∘ f) x = z。

提示 3关键件

hg z 与 hf y 都是 Exists，各用一次点名的 Exists.elim 拆证人（Q 都取目标那个 Exists）；最后由 Exists.intro 把内层证人交出去，等式用 congrArg 把 f x = y 抬过 g，再与 g y = z 经 Eq.trans 接起来。

查看解答 定理 · 14 行

题 3：两次 Exists.elim 拆证人（Q 都取目标那个 Exists）：外层拿到中间点 y 与 hy : g y = z，内层拿到 x 与 hx : f x = y；最后由 Exists.intro 交出内层证人， 等式用 congrArg 把 hx 抬过 g，再与 hy 经 Eq.trans 接起来。

theorem surjective_comp (α β γ : Type) (f : α → β) (g : β → γ)
    (hf : Function.Surjective α β f) (hg : Function.Surjective β γ g) :
    Function.Surjective α γ (g ∘ f) := by
  intro z
  exact @Exists.elim β (fun (y : β) => g y = z)
    (∃ (x : α), (g ∘ f) x = z)
    (hg z)
    (fun (y : β) => fun (hy : g y = z) =>
      @Exists.elim α (fun (x : α) => f x = y)
        (∃ (x : α), (g ∘ f) x = z)
        (hf y)
        (fun (x : α) => fun (hx : f x = y) =>
          Exists.intro x
            (@Eq.trans.{1} γ (g (f x)) (g y) z (congrArg.{1} g hx) hy)))
练习 4leftInverse_injective定理附录解答

题 4–7：逆（数据版）——逆函数由调用者交出来，我们只验证它

练习 4（T 类）：左逆 ⇒ 单射（"单射 ↔ 左可逆"能证的那一半；另一半要选择公理）。

theorem leftInverse_injective (α β : Type) (f : α → β) (g : β → α)
    (h : Function.LeftInverse α β g f) : Function.Injective α β f := by
  sorry
提示 1思路

要从 f x = f y 得到 x = y：把等式沿 g 推过去，两头再各用一次"g (f ·) = ·"。

提示 2目标形态

intro x y 与 hxy : f x = f y 之后，目标是 x = y。

提示 3关键件

链条是 x ← g (f x) → g (f y) → y：左端对 h x : g (f x) = x 用 Eq.symm，中间用 congrArg 把 hxy 抬过 g，右端直接用 h y，两段经 Eq.trans 接。

查看解答 定理 · 8 行

题 4：x ← g (f x) → g (f y) → y，两段用 Eq.trans 接。

theorem leftInverse_injective (α β : Type) (f : α → β) (g : β → α)
    (h : Function.LeftInverse α β g f) : Function.Injective α β f := by
  intro x y hxy
  exact @Eq.trans.{1} α x (g (f x)) y
    (@Eq.symm.{1} α (g (f x)) x (h x))
    (@Eq.trans.{1} α (g (f x)) (g (f y)) y
      (congrArg.{1} g hxy)
      (h y))

题 8–9（D 类）：量词顺序交换的四个变体

把 P x y 读成"f x = y"最直观，四个变体是：(1) ∀ x, ∃ y, P x y —— 不普遍真：β 空而 α 非空时假 (2) ∃ y, ∀ x, P x y —— 不普遍真：见第 9 题的反例 (3) (∃ y, ∀ x, P x y) → (∀ x, ∃ y, P x y) —— 恒真（第 8 题）(4) (∀ x, ∃ y, P x y) → (∃ y, ∀ x, P x y) —— 假（第 9 题）注意 (1)/(2) 与 (3)/(4) 的关系：(3) 与 (4) 就是"两个命题之间的两个方向"，而 (3) 恒真、(4) 有反例——这正是"换序不是等价变换"的全部内容。

实证提醒（Dubinsky & Yiparaki 2000，未发表手稿，引用须注明状态）：94% 的学生至少把一个 "∀∃" 陈述读成 "∃∀"（反向只有 5%）——所以 (4) 不是粗心，是系统性读法。

练习 9swap_converse_false定理附录解答

练习 9（D 类）：换序中假的那个方向：∀ x, ∃ y, P x y 推不出 ∃ y, ∀ x, P x y。判词：假；反例取 P x y := (x = y)，即 Set Nat 上的恒等关系：

  • 前提"每个 x 都有 y"成立——取 y := x 即可（Eq.refl）；
  • 结论"存在一个 y 对所有 x 成立"会逼出 ∅ = univ：把 y 分别代到 x := ∅、x := univ，再用 0 ∈ univ（Set.mem_univ）但 0 ∉ ∅（Set.notMem_empty）制造矛盾。

也就是说 "∃ y ∀ x" 是一种一致性要求，比 "∀ x ∃ y" 强得多——这正是换序不能反过来的原因。

写法说明（设计判断，不是题意）：前提在这里写成具名 binder ∀ (hpre : ∀ (x : Set Nat), ∃ (y : Set Nat), P x y), …，而不是箭头 (∀ (x : Set Nat), ∃ (y : Set Nat), P x y) → …——两者是同一个类型（Lean 里 A → B 就是匿名的 ∀ (_ : A), B），只是记法展开在"箭头右端是 ∃"这个形状上补不出 ∃ 的前导类型参数，具名 binder 能。这条语言缺口见单元报告。

theorem swap_converse_false :
    ¬ (∀ (P : Set Nat → Set Nat → Prop),
      ∀ (hpre : ∀ (x : Set Nat), ∃ (y : Set Nat), P x y),
        (∃ (y : Set Nat), ∀ (x : Set Nat), P x y)) := by
  sorry
提示 1思路

先判假并选好反例（Set Nat 上的恒等关系）；intro 假设 h 后把反例 P 与前提喂给 h，得到 ∃ (y : Set Nat), ∀ (x : Set Nat), x = y，接下来要从它造 False。

提示 2目标形态

目标是 ¬ (∀ (P : Set Nat → Set Nat → Prop), ∀ (hpre : …), (∃ (y : Set Nat), ∀ (x : Set Nat), P x y))；内层要证的是 False。

提示 3关键件

前提用 Exists.intro 与 Eq.refl 造（先用 have 把"喂给假设之后的结论"命名下来）；结论用点名的 Exists.elim 拆出 y 与 hy : ∀ (x : Set Nat), x = y——把 hy 分别用在 univ 与 empty 这两个具体集合上，经 Eq.trans/Eq.symm 逼出 Set.univ Nat = ∅；再用 Eq.subst 把 0 ∈ univ（Set.mem_univ）沿这条等式搬到 0 ∈ ∅，交给 Set.notMem_empty 收尾。

题 9：反例的形式化。把 P 取成 Set Nat 上的恒等关系： 前提：每个 x 都有 y（取 y := x，Eq.refl）——先用 have 把"把反例喂给假设 之后的结论"命名下来（这条 Exists 的形状较长，先命名再拆读起来清楚）；；结论：Exists.elim 拆出 y 与 hy : ∀ x, x = y，用 hy univ 与 hy ∅ 得 univ = ∅； 再把 0 ∈ univ（Set.mem_univ）沿等式搬到 0 ∈ ∅，与 Set.notMem_empty 矛盾。 语句里的前提写成具名 binder（∀ (hpre : …)）而不是箭头：见单元报告的语言缺口。

theorem swap_converse_false :
    ¬ (∀ (P : Set Nat → Set Nat → Prop),
      ∀ (hpre : ∀ (x : Set Nat), ∃ (y : Set Nat), P x y),
        (∃ (y : Set Nat), ∀ (x : Set Nat), P x y)) := by
  intro h
  have hbad : ∃ (y : Set Nat), ∀ (x : Set Nat), x = y :=
    h (fun (x : Set Nat) => fun (y : Set Nat) => x = y)
      (fun (x : Set Nat) =>
        @Exists.intro (Set Nat) (fun (y : Set Nat) => x = y) x (@Eq.refl.{1} (Set Nat) x))  -- soko:notation-ok: R1：目标藏在 hpre 的 ∀ 后，短写补不出
  exact @Exists.elim (Set Nat) (fun (y : Set Nat) => ∀ (x : Set Nat), x = y) False hbad
    (fun (y : Set Nat) => fun (hy : ∀ (x : Set Nat), x = y) =>
      Set.notMem_empty 0
        (@Eq.subst.{1} (Set Nat)
          (fun (X : Set Nat) => 0 ∈ X)
          (@Set.univ Nat) (∅)
          (@Eq.trans.{1} (Set Nat) (@Set.univ Nat) y (∅)
            (hy (@Set.univ Nat))
            (@Eq.symm.{1} (Set Nat) (∅) y (hy (∅))))

unit07 解答钥匙（agent 专用；画布不 import 它）。 9 条练习的证明全部只用 lib/ 与 prelude 里已备好的东西，且全部写成 by tactic 块 （白名单：intro / exact / apply / assumption / rfl / match / constructor / left / right / use / exfalso / cases / have / sorry）——没有 rw / obtain / change / simp / induction / calc / rintro / ·。 语句一律用记法（∀ ∃ → ∧ ↔ ¬ = 与 Set Nat 上的 ∈）；引理名照旧点名 （Eq.symm、congrArg、Exists.intro、And.left、Set.notMem_empty…）—— 记法是连接符的糖，不是引理名的糖。 唯一"证不出来"的是存在版 bijective_iff_inverse 的另一半 Bijective f → ∃ (g : β → α), Inverse f g 它等价于选择公理（每个满射都可裂），本语言没有 Classical.choice / funext / propext， 所以画布第 6 题证的是数据版：逆函数 g 与右逆证据 hg 由调用者交出，此时 Iff 两个方向都成立（见下面 bijective_iff_inverse）。这条边界记在单元报告的 unprovable。 题 1：两边 delta/beta 展开后是同一个 λ，所以 Eq.refl 直接成立（没有 funext， 这是本语言里唯一能证函数等式的方式）。目标用 = 写，证明体点名交 Eq.refl。

theorem comp_assoc (α β γ δ : Type) (f : α → β) (g : β → γ) (h : γ → δ) :
    h ∘ (g ∘ f) = (h ∘ g) ∘ f := by
  exact @Eq.refl.{1} (α → δ) ((h ∘ g) ∘ f)

题 3：两次 Exists.elim 拆证人（Q 都取目标那个 Exists）：外层拿到中间点 y 与 hy : g y = z，内层拿到 x 与 hx : f x = y；最后由 Exists.intro 交出内层证人， 等式用 congrArg 把 hx 抬过 g，再与 hy 经 Eq.trans 接起来。

theorem surjective_comp (α β γ : Type) (f : α → β) (g : β → γ)
    (hf : Function.Surjective α β f) (hg : Function.Surjective β γ g) :
    Function.Surjective α γ (g ∘ f) := by
  intro z
  exact @Exists.elim β (fun (y : β) => g y = z)
    (∃ (x : α), (g ∘ f) x = z)
    (hg z)
    (fun (y : β) => fun (hy : g y = z) =>
      @Exists.elim α (fun (x : α) => f x = y)
        (∃ (x : α), (g ∘ f) x = z)
        (hf y)
        (fun (x : α) => fun (hx : f x = y) =>
          Exists.intro x
            (@Eq.trans.{1} γ (g (f x)) (g y) z (congrArg.{1} g hx) hy)))
