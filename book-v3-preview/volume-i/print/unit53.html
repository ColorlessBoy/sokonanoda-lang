1 个定义 · 12 个定理 · 9 道练习 · 15 条提示 · 解答附录

靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§7.1（ordering relations 之后的"保序映射"）· Halmos《Naive Set Theory》§14（order isomorphism 前夜）。大纲：set-theory-syllabus.md §4.1（I.5 章深化 —— 单元⑬⑭ 讲序关系与良序的性质，本单元讲序之间的映射：嵌入保什么、反射什么 ✓）。

本单元的"该学的定理"：

  • 嵌入的定义与取用子；恒等映射是嵌入；
  • 旗舰一：嵌入的复合还是嵌入（逐点两向合起来 ✓）；
  • 旗舰二：嵌入"反射"序性质 —— 自反 · 对称 · 传递 · 非自反（由 r a b ⟺ s (f a) (f b) 逐条搬过去 ✓）；
  • 全部用点态形态（∀ a b, …），把 def 头留给前提 ✓（配方 ✓）。

53.0 画布给的新词汇：序嵌入 IsEmbedding r s f

读法：f 把 r 序原样搬进 s 序 —— 两个方向都要 ✓（只要求一个方向叫"保序"，那是本单元的练习 1/2 的强弱之别 ✓）

定义IsEmbedding声明 1
def IsEmbedding (α β : Type) (r : Rel α α) (s : Rel β β) (f : α → β) : Prop :=
  ∀ (a b : α), r a b ↔ s (f a) (f b)

查看解答 定理 · 10 行
theorem embedding_comp (α β γ : Type) (r : Rel α α) (s : Rel β β) (t : Rel γ γ)
    (f : α → β) (g : β → γ)
    (hf : IsEmbedding α β r s f) (hg : IsEmbedding β γ s t g) :
    IsEmbedding α γ r t (fun (a : α) => g (f a)) :=
  fun (a : α) => fun (b : α) =>
    @Iff.intro (r a b) (t (g (f a)) (g (f b)))
      (fun (hab : r a b) => embedding_mp β γ s t g hg (f a) (f b)
        (embedding_mp α β r s f hf a b hab))
      (fun (hab : t (g (f a)) (g (f b))) => embedding_mpr α β r s f hf a b
        (embedding_mpr β γ s t g hg (f a) (f b) hab))
