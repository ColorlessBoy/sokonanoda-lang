本单元的"该学的定理"：

细节清单（5 项，展开）
  • 取用子：A ⊆ B + a ∈ A ⇒ a ∈ B ✓（顶层具名 —— 打包的前件 ✓）；
  • A = B ⇒ A ⊆ B（等的左到右 ✓ —— 用 rel_subst_right 在 Set α 上搬 ✓）；
  • 交/并的三条取用子（左取 · 合成 ✓ · 并的"用包含假设消去" ✓ —— 都顶层具名 ✓）；
  • 旗舰：A ⊆ B → B ⊆ A → A = B（互相包含 ⇒ 相等 ✓ —— 教材里最常用的一条 ✓）；
  • 推论：A ⊆ B ⇒ A ∩ B = A ✓ · A ⊆ B ⇒ A ∪ B = B ✓
