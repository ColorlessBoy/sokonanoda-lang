41.3 旗舰：良基 ⇒ 非自反 与 库缺陷的证明

练习 6wf_irreflexive定理附录解答

练习 6（L 类，旗舰）：良基关系一定非自反（¬ r a a）。

theorem wf_irreflexive (α : Type) (r : Rel α α) (hwf : IsWellFounded α r) :
    Irreflexive α r := by
  sorry
提示 1思路

把良基用在单点族 fun x => x = a（见证取 a）⇒ 得极小元 m 与"任何等于 a 的点都不排在 m 前面"；把后者用在 a 上（a 当然等于 a）=> 得 ¬ (r a m)；再把 r a a 沿 m = a 搬成 r a m ⇒ 矛盾。

提示 2目标形态

Irreflexive α r（即 ∀ a, ¬ (r a a)）。

提示 3关键件

hasMin_elim（拆极小元）· And.right hmm 的续应用要套一层 λ（单元㊳ 的实测教训）· rel_subst_right（关系取 fun u v => r u v、等式取 Eq.symm、第二个坐标从 a 换成 m）✓

41.4 良基性的保持：子关系 · 严格化 · 空关系

练习 8wf_of_subrel定理附录解答

练习 8（L 类）：子关系保持良基（r' ⊆ r ⇒ r' 良基）。

theorem wf_of_subrel (α : Type) (r r1 : Rel α α) (hwf : IsWellFounded α r)
    (hsub : ∀ (a : α) (b : α), r1 a b → r a b) : IsWellFounded α r1 := by
  sorry
提示 1思路

给定非空的 P，先在 r 下取极小元 m ⇒ 它在 r' 下也极小（任何 r' y m 都是 r y m ⇒ 用假设那条"不含 P"）。

提示 2目标形态

IsWellFounded r → (∀ a b, r' a b → r a b) → IsWellFounded r'。

提示 3关键件

hasMin_elim · 目标写成展开的 ∃（HasMin 是定义头）·And.right hmm 的续应用要套一层 λ（实测：直接续应用判红）✓

查看解答 定理 · 15 行
theorem wf_of_subrel (α : Type) (r r1 : Rel α α) (hwf : IsWellFounded α r)
    (hsub : ∀ (a : α) (b : α), r1 a b → r a b) : IsWellFounded α r1 :=
  fun (P : α → Prop) => fun (hne : ∃ (x : α), P x) =>
    (fun (hm : HasMin α r P) =>
      @Exists.elim α (fun (m : α) => P m ∧ ∀ (y : α), P y → ¬ (r y m))
        (∃ (m : α), P m ∧ ∀ (y : α), P y → ¬ (r1 y m))
        (hasMin_elim α r P hm)
        (fun (m : α) (hmm : P m ∧ ∀ (y : α), P y → ¬ (r y m)) =>
          Exists.intro m
            (And.intro (And.left hmm)  -- soko:notation-ok: G-30/G-73 形状 ②③：前导实参或 `Eq` 层级在这些位置补不出来
              (fun (y : α) => fun (hy : P y) => fun (hy1 : r1 y m) =>
                (fun (hnot : ¬ (r y m)) => hnot (hsub y m hy1))
                  ((fun (hu : ∀ (y1 : α), P y1 → ¬ (r y1 m)) => hu y hy)
                    (And.right hmm))))))
      (wellFounded_hasMin α r hwf P hne)

编写注记 · 教材对照与课程边界（4 条）

⚠⚠ 本单元起草时查出的库缺陷 L-07（已在第 566 轮修复，这里保留原委做教材）：lib/Order 的 IsWellOrder α r := IsLinearOrder α r ∧ IsWellFounded α r 是非严格版，而 HasMin α r P := ∃ m, P m ∧ ∀ y, P y → ¬ (r y m) 是"极小"版（没有更小的）✓ 两者配不上：IsLinearOrder 含自反 ⇒ 取 P := fun x => x = a（非空）就得到 ∃ m, m = a ∧ ∀ y, y = a → ¬ r y m ⇒ 取 y := m 与自反性得矛盾 ✗ ⇒ IsWellOrder α r 只在空论域上可满足（单元⑬⑭ 的良序定理因此是空真的 ✗）✓ 练习 5 就是把这个事实证明出来（wf_and_refl_empty）✓ 修法（已落地）：非严格良序改用"最小"版 —— lib/Order 新增 HasLeast（四件套）与 IsStrictWellOrder（严格版），IsWellOrder := IsLinearOrder ∧ HasLeast ✓ 本练习仍然是这个事实的证明（在旧定义下它证的就是矛盾）✓

⚠ 另一条如实标注的边界：良基归纳原理本身（(∀ a, (∀ b, r b a → P b) → P a) → ∀ a, P a）证不出来 —— 从"非空子集有极小元"出发要 ¬¬-消去（G-74）；本语言也没有 Acc（G-56）⇒ 本单元只做极小反例原理那一半（练习 3）✓

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 三样：lib.Rel · lib.Order（良基与极小元）· lib.Set。
