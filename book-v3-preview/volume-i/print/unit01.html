1.1 集合就是"论域上的谓词"

x∈A↔Ax
A⊆B↔∀(x:α),Ax→Bx

于是"隶属"不是新东西，就是函数应用；"子集"就是全称箭头。符号只是把底下那层结构写短了——报错看不懂时，把它翻回点名形式就懂了。

theorem mem_of_subset (α : Type) (A B : Set α) (h : A ⊆ B) (a : α) :

提示 1思路

手里 h 是 A ⊆ B，目标是一个元素命题；把 h 当函数用。

目标是 a ∈ B（也就是 B a）。

theorem mem_of_subset (α : Type) (A B : Set α) (h : A ⊆ B) (a : α) :
    a ∈ A → a ∈ B :=
  fun (ha : a ∈ A) => h a ha

练习 3subset_of_mem_singleton定理附录解答

练习 4（T 类）：a ∈ A 推出 {a} ⊆ A。

theorem subset_of_mem_singleton (α : Type) (A : Set α) (a : α) (h : a ∈ A) :
    {a} ⊆ A := by
  sorry
提示 1思路

目标是全称命题；intro 一个元素与"它在 {a} 里"。

提示 2目标形态

intro 之后手里有 hx : x ∈ {a}，目标是 A x。

提示 3关键件

Set.mem_singleton_iff 把 hx 变成等式 x = a；再用 Eq.symm 与 lib.Rel 的 rel_subst_mem 把这个等式搬进目标（本单元还没有 rw，所以写成 exact 的实参）。

查看解答 定理 · 7 行

本单元还没有 rw/subst，所以"把等式搬进目标"这一步是 Eq.subst 的实参位。 项风格下它就是一个嵌套的应用项；等 rw 落地后这条会显著变短。

theorem subset_of_mem_singleton (α : Type) (A : Set α) (a : α) (h : a ∈ A) :
    {a} ⊆ A :=
  fun (x : α) (hx : x ∈ {a}) =>
    @Eq.subst.{1} α (fun (y : α) => A y) a x
      (@Eq.symm.{1} α x a
        (@Iff.mp (x ∈ {a}) (x = a) (Set.mem_singleton_iff x a) hx))  -- soko:notation-ok: 复合项/λ 体的 Eq 型实参隐式反解判红（引擎边界）
      h

练习 6（D 类）：下面两条哪条为真？(i) 若 {a} = {b}，则 a = b。(ii) 若 a = b，则 {a} = {b}。为真的证明，为假的说明理由（写在注释里）。

theorem singleton_eq_singleton_iff (α : Type) (a b : α) :
    ({a} = {b}) ↔ a = b := by
  sorry
提示 1思路

(i) 用"a ∈ {a}"沿等式搬过去再展开；(ii) 两个集合相等就逐元素证 ↔。

提示 2目标形态

目标是 ({a} = {b}) ↔ a = b，两个方向分别如上。

提示 3关键件

(i) lib.Rel 的 rel_subst_mem 把 a ∈ {a} 搬到 {b} 上，再用 Set.mem_singleton_iff 取出等式；(ii) apply Set.ext 之后对每个 x 用 constructor，两边各用一次 Set.mem_singleton_iff 与 Eq.trans。

查看解答 定理 · 22 行
theorem singleton_eq_singleton_iff (α : Type) (a b : α) :
    ({a} = {b}) ↔ a = b :=
  -- 同样要显式 Prop 实参（G-30）：两个分支里都有集合字面量。
  @Iff.intro ({a} = {b}) (a = b)
    -- (i) `{a} = {b}` ⇒ `a = b`：把 `a ∈ {a}` 沿等式搬到 `{b}` 上，再展开。
    (fun (h : {a} = {b}) =>
      @Iff.mp (a ∈ {b}) (a = b) (Set.mem_singleton_iff a b)  -- soko:notation-ok: 复合项/λ 体的 Eq 型实参隐式反解判红（引擎边界）
        (@Eq.subst.{1} (Set α) (fun (X : Set α) => a ∈ X) {a} {b} h
          (Set.mem_singleton_self a)))
    -- (ii) `a = b` ⇒ `{a} = {b}`：外延 + 逐元素两个方向。
    (fun (h : a = b) =>
      Set.ext {a} {b} (fun (x : α) =>
        @Iff.intro (x ∈ {a}) (x ∈ {b})
          (fun (hx : x ∈ {a}) =>
            @Iff.mpr (x ∈ {b}) (x = b) (Set.mem_singleton_iff x b)  -- soko:notation-ok: 复合项/λ 体的 Eq 型实参隐式反解判红（引擎边界）
              (@Eq.trans.{1} α x a b
                (@Iff.mp (x ∈ {a}) (x = a) (Set.mem_singleton_iff x a) hx) h))  -- soko:notation-ok: 复合项/λ 体的 Eq 型实参隐式反解判红（引擎边界）
          (fun (hx : x ∈ {b}) =>
            @Iff.mpr (x ∈ {a}) (x = a) (Set.mem_singleton_iff x a)  -- soko:notation-ok: 复合项/λ 体的 Eq 型实参隐式反解判红（引擎边界）
              (@Eq.trans.{1} α x b a
                (@Iff.mp (x ∈ {b}) (x = b) (Set.mem_singleton_iff x b) hx)  -- soko:notation-ok: 复合项/λ 体的 Eq 型实参隐式反解判红（引擎边界）
                (@Eq.symm.{1} α a b h)))))
