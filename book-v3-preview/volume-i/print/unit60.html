60.4 两条"没有成员"与"论域的补"

练习 7not_mem_inter_compl定理附录解答

练习 7（T 类）：A ∩ Aᶜ 没有成员。

theorem not_mem_inter_compl (α : Type) (A : Set α) (a : α) : ¬ (a ∈ (A ∩ Aᶜ)) := by
  sorry
提示 1关键件

Set.mem_inter_iff · 练习 1（同一个 h 的两半互相冲突 ✓）✓

查看解答 定理 · 7 行
theorem not_mem_inter_compl (α : Type) (A : Set α) (a : α) : ¬ (a ∈ (A ∩ Aᶜ)) :=
  fun (h : a ∈ (A ∩ Aᶜ)) =>
    not_mem_of_mem_compl α A a
      (And.right ((fun (hu : a ∈ (A ∩ Aᶜ) ↔ a ∈ A ∧ a ∈ (Aᶜ)) => Iff.mp hu h)
        (Set.mem_inter_iff a A (Aᶜ))))
      (And.left ((fun (hu : a ∈ (A ∩ Aᶜ) ↔ a ∈ A ∧ a ∈ (Aᶜ)) => Iff.mp hu h)
        (Set.mem_inter_iff a A (Aᶜ))))
练习 8compl_univ_subset_empty定理附录解答

练习 8（T 类，收尾）：univᶜ ⊆ ∅。

theorem compl_univ_subset_empty (α : Type) : (@Set.univ α)ᶜ ⊆ (∅) := by
  sorry
提示 1思路

由"在 univᶜ 里"得"不在论域里"，而库里说每个 a 都在论域里 ✓ ⇒ 矛盾。

提示 2关键件

Set.mem_univ（写全论域实参 ✓）· 练习 1 · False.elim（把目标写全 ✓）✓

查看解答 定理 · 4 行
theorem compl_univ_subset_empty (α : Type) : (@Set.univ α)ᶜ ⊆ (∅) :=
  fun (a : α) (h : a ∈ ((@Set.univ α)ᶜ)) =>
    (@False.elim (a ∈ (∅)))
      (not_mem_of_mem_compl α (@Set.univ α) a h (Set.mem_univ a))
