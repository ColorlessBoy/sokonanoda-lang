Unit 25 — Equivalence Relations and Partitions

13 个定理 · 10 道练习 · 30 条提示 · 解答附录

靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§3.5 Equivalence Relations；Halmos《Naive Set Theory》§10 / §18（等价类与商集那一节）。大纲：set-theory-syllabus.md §4.1（I.10 章第二个单元，本章收口）。

本单元的"该学的定理"（等价关系 = 划分这一定理的两半）：

  • 同类点有同样的类（r a b ⇒ ∀ c, r a c ↔ r b c）；
  • 类相同 ⟺ 相关（把两半合成一条 ↔）；
  • 不同的类不交（¬ r a b ⇒ 没有点同时在两个类里）；
  • 划分的三条：每个类非空 · 每个点落在某个类里 · 有公共点的两个类逐点相同 ✓

读法：Set α 就是 α → Prop ⇒ "等价类"直接写成谓词 Rel.EquivClass α r a（"与 a 相关的那些点"），"商集"写成"是某个等价类"这条性质 Rel.Classes α r ✓—— 于是整章不需要新类型（与 ST1 的谓词式口径一致）✓

写法约定（本单元特有）：几乎每条定理都要三次使用 IsEquivalence 的一条 ——自反 / 对称 / 传递在库里都是定义头（∀）⇒ 用之前先 fun (ht : ∀ (x : α) (y : α) (z : α), r x y → r y z → r x z) => … 把类型写出来（G-73 形状 ①），或者直接用库里的三条取用子 ✓

25.2 本单元的正题：同类点有同样的类

练习 4equivClass_of_rel定理附录解答

练习 4（L 类，旗舰之一）：相关的两个点，它们的类逐点相同。

theorem equivClass_of_rel (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (a b : α) (hab : r a b) : ∀ (c : α), r a c ↔ r b c := by
  sorry
提示 1思路

两个方向各一次 —— 从 r a c 到 r b c：先把 r a b 掉头成 r b a，再与 r a c 接起来；反方向用原来的 r a b 接。

提示 2目标形态

r a b → ∀ c, r a c ↔ r b c。

提示 3关键件

Iff.intro（前导 Prop 实参写全）· 库里的三条取用子（自反/对称/传递都是定义头 ⇒ 先 λ 绑定再应用）· 接的顺序别反（r b a 与 r a c）。

查看解答 定理 · 11 行
theorem equivClass_of_rel (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (a b : α) (hab : r a b) : ∀ (c : α), r a c ↔ r b c :=
  fun (c : α) =>
    @Iff.intro (r a c) (r b c)
      (fun (hac : r a c) =>
        (fun (ht : ∀ (x : α) (y : α) (z : α), r x y → r y z → r x z) =>
          ht b a c ((fun (hs : ∀ (x : α) (y : α), r x y → r y x) => hs a b hab)
            (equivalence_symm α r he)) hac) (equivalence_trans α r he))
      (fun (hbc : r b c) =>
        (fun (ht : ∀ (x : α) (y : α) (z : α), r x y → r y z → r x z) =>
          ht a b c hab hbc) (equivalence_trans α r he))

25.3 划分的第一条：不同的类不交

练习 7equivClass_disjoint定理附录解答

练习 7（L 类，旗舰之一）：不相关的两个点，没有任何点同时在两个类里。

theorem equivClass_disjoint (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (a b : α) (hab : ¬ (r a b)) : ∀ (c : α), ¬ (r a c ∧ r b c) := by
  sorry
提示 1思路

反证。若 r a c 且 r b c：先把 r b c 掉头成 r c b，再与 r a c 接起来得到 r a b —— 与假设冲突。

提示 2目标形态

¬ (r a b) → ∀ c, ¬ (r a c ∧ r b c)。

提示 3关键件

对称与传递的取用子（定义头 ⇒ 先 λ 绑定）· And.left/And.right ·注意接的次序：trans a c b 要 r a c 配 r c b。

查看解答 定理 · 7 行
theorem equivClass_disjoint (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (a b : α) (hab : ¬ (r a b)) : ∀ (c : α), ¬ (r a c ∧ r b c) :=
  fun (c : α) (hc : r a c ∧ r b c) =>
    hab ((fun (ht : ∀ (x : α) (y : α) (z : α), r x y → r y z → r x z) =>
      ht a c b (And.left hc)
        ((fun (hs : ∀ (x : α) (y : α), r x y → r y x) => hs b c (And.right hc))
          (equivalence_symm α r he))) (equivalence_trans α r he))

25.4 划分的另外两条：非空与覆盖

练习 8classes_nonempty定理附录解答

练习 8（L 类）：每个等价类都非空（代表元自己就在里面）。

theorem classes_nonempty (α : Type) (r : Rel α α) (he : IsEquivalence α r)

提示 1思路

把"是某个类"拆成代表元 a 与那句逐点刻画；把刻画用在 c := a 上，右边由自反给出 —— 于是 C a 成立。

提示 2目标形态

Rel.Classes α r C → ∃ a, C a。

提示 3关键件

Exists.elim（前导实参写全，G-73 形状 ②）· Iff.mpr · 自反。

查看解答 定理 · 7 行
theorem classes_nonempty (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (C : α → Prop) (hC : Rel.Classes α r C) : ∃ (a : α), C a :=
  @Exists.elim α (fun (a : α) => ∀ (c : α), C c ↔ r a c) (∃ (a : α), C a)
    ((fun (hs : ∃ (a : α), ∀ (c : α), C c ↔ r a c) => hs) hC)
    (fun (a : α) (ha : ∀ (c : α), C c ↔ r a c) =>
      Exists.intro a
        (Iff.mpr (ha a) ((fun (hu : ∀ (x : α), r x x) => hu a) (equivalence_refl α r he))))
练习 9classes_cover定理附录解答

练习 9（L 类）：每个点都落在某个类里（取它自己的类）。

theorem classes_cover (α : Type) (r : Rel α α) (he : IsEquivalence α r) (a : α) :
    ∃ (C : α → Prop), Rel.Classes α r C ∧ C a := by
  sorry
提示 1思路

见证取 [a] 本身；"它是一个类"由刻画给出（代表元取 a，逐点那一条是自反的恒等），"a 在里面"由练习 3 给出。

提示 2目标形态

提示 3关键件

查看解答 定理 · 9 行
theorem classes_cover (α : Type) (r : Rel α α) (he : IsEquivalence α r) (a : α) :
    ∃ (C : α → Prop), Rel.Classes α r C ∧ C a :=
  Exists.intro (Rel.EquivClass α r a)
    (And.intro
      ((fun (h : ∃ (a' : α), ∀ (c : α), Rel.EquivClass α r a c ↔ r a' c) => h)
        (Exists.intro a
          (fun (c : α) => @Iff.intro (Rel.EquivClass α r a c) (r a c)
            (fun (h : Rel.EquivClass α r a c) => h) (fun (h : r a c) => h))))
      (equivClass_self α r he a))

25.5 必破：有公共点的两个类必相同（划分的"不交"那一半的另一面）

练习 10rel_of_meet定理附录解答

练习 10（D 类）：两个类只要有一个公共点，它们的代表元就相关。

theorem rel_of_meet (α : Type) (r : Rel α α) (he : IsEquivalence α r) (a b : α)
    (h : ∃ (x : α), r a x ∧ r b x) : r a b := by
  sorry
提示 1思路

把公共点 x 拆出来（它在两个类里 ⇒ 两个代表元都与 x 相关）；把第二个掉头，再与第一个接起来 ✓

提示 2目标形态

(∃ x, r a x ∧ r b x) → r a b。

提示 3关键件

Exists.elim（前导实参写全）· 对称与传递的取用子（先 λ 绑定）·And.left/And.right。⚠ 由它 + 练习 4 就得到"有公共点的两个类逐点相同"—— 这正是划分的第三条 ✓

查看解答 定理 · 8 行
theorem rel_of_meet (α : Type) (r : Rel α α) (he : IsEquivalence α r) (a b : α)
    (h : ∃ (x : α), r a x ∧ r b x) : r a b :=
  @Exists.elim α (fun (x : α) => r a x ∧ r b x) (r a b) h
    (fun (x : α) (hx : r a x ∧ r b x) =>
      (fun (ht : ∀ (p : α) (q : α) (s : α), r p q → r q s → r p s) =>
        ht a x b (And.left hx)
          ((fun (hs : ∀ (p : α) (q : α), r p q → r q p) => hs b x (And.right hx))
            (equivalence_symm α r he))) (equivalence_trans α r he))

theorem equivClass_of_rel (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (a b : α) (hab : r a b) : ∀ (c : α), r a c ↔ r b c :=
  fun (c : α) =>
    @Iff.intro (r a c) (r b c)
      (fun (hac : r a c) =>
        (fun (ht : ∀ (x : α) (y : α) (z : α), r x y → r y z → r x z) =>
          ht b a c ((fun (hs : ∀ (x : α) (y : α), r x y → r y x) => hs a b hab)
            (equivalence_symm α r he)) hac) (equivalence_trans α r he))
      (fun (hbc : r b c) =>
        (fun (ht : ∀ (x : α) (y : α) (z : α), r x y → r y z → r x z) =>
          ht a b c hab hbc) (equivalence_trans α r he))

theorem rel_of_equivClass_eq (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (a b : α) (h : ∀ (c : α), r a c ↔ r b c) : r a b :=
  (fun (hs : ∀ (x : α) (y : α), r x y → r y x) =>
    hs b a (Iff.mp (h a) ((fun (hu : ∀ (x : α), r x x) => hu a) (equivalence_refl α r he))))
    (equivalence_symm α r he)

练习 7 · equivClass_disjoint 定理
theorem equivClass_disjoint (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (a b : α) (hab : ¬ (r a b)) : ∀ (c : α), ¬ (r a c ∧ r b c) :=
  fun (c : α) (hc : r a c ∧ r b c) =>
    hab ((fun (ht : ∀ (x : α) (y : α) (z : α), r x y → r y z → r x z) =>
      ht a c b (And.left hc)
        ((fun (hs : ∀ (x : α) (y : α), r x y → r y x) => hs b c (And.right hc))
          (equivalence_symm α r he))) (equivalence_trans α r he))

theorem classes_nonempty (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (C : α → Prop) (hC : Rel.Classes α r C) : ∃ (a : α), C a :=
  @Exists.elim α (fun (a : α) => ∀ (c : α), C c ↔ r a c) (∃ (a : α), C a)
    ((fun (hs : ∃ (a : α), ∀ (c : α), C c ↔ r a c) => hs) hC)
    (fun (a : α) (ha : ∀ (c : α), C c ↔ r a c) =>
      Exists.intro a
        (Iff.mpr (ha a) ((fun (hu : ∀ (x : α), r x x) => hu a) (equivalence_refl α r he))))
练习 9 · classes_cover 定理
theorem classes_cover (α : Type) (r : Rel α α) (he : IsEquivalence α r) (a : α) :
    ∃ (C : α → Prop), Rel.Classes α r C ∧ C a :=
  Exists.intro (Rel.EquivClass α r a)
    (And.intro
      ((fun (h : ∃ (a' : α), ∀ (c : α), Rel.EquivClass α r a c ↔ r a' c) => h)
        (Exists.intro a
          (fun (c : α) => @Iff.intro (Rel.EquivClass α r a c) (r a c)
            (fun (h : Rel.EquivClass α r a c) => h) (fun (h : r a c) => h))))
      (equivClass_self α r he a))

theorem rel_of_meet (α : Type) (r : Rel α α) (he : IsEquivalence α r) (a b : α)
    (h : ∃ (x : α), r a x ∧ r b x) : r a b :=
  @Exists.elim α (fun (x : α) => r a x ∧ r b x) (r a b) h
    (fun (x : α) (hx : r a x ∧ r b x) =>
      (fun (ht : ∀ (p : α) (q : α) (s : α), r p q → r q s → r p s) =>
        ht a x b (And.left hx)
          ((fun (hs : ∀ (p : α) (q : α), r p q → r q p) => hs b x (And.right hx))
            (equivalence_symm α r he))) (equivalence_trans α r he))
