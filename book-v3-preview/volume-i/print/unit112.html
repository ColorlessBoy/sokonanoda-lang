本单元的"该学的定理"：两条单射（f 把 A 送进 B、g 把 B 送进 A，各自单射）⇒ A ≈ B。造法是三段：

  • 链核 C₀ = ⋂{C | C ⊆ A ∧ K(C) ⊆ C}（K(C) = A ∖ g '' (B ∖ f '' C)）——它的不动点性质（K(C₀) = C₀ ✓）是全部功夫所在；
  • 关系版图 R(x,y) = (x ∈ C₀ ∧ f x = y) ∨ (x ∉ C₀ ∧ g y = x) ——在 Prop 层说清"哪一半走 f、哪一半走 g"（不做 Type 层分支 ✓，那会撞 C-04 ✗）；
  • 四件（全 / 单值 / 单射 / 满）⇒ 用 choice 把关系取出成函数 ⇒ 装配 ✓。
