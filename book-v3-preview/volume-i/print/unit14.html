Unit 14 — Well-Orderings and Well-Foundedness

1 个定义 · 12 个定理 · 10 道练习 · 30 条提示 · 解答附录

靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§7.2 Well Orderings（+ §9 Well-Founded Relations 的开头）；Halmos《Naive Set Theory》§17 Well Ordering。大纲：docs/design/set-theory-syllabus.md §4.1（I.5 章第二个单元）。

本单元的"该学的定理"：良基 = 每个非空子集有极小元（本语言没有 Acc，所以取集合论里等价的这条形式，见 lib/Order 文件头的偏离 ③）；良序 = 全序 + 良基；由良基能推出三件硬事实 —— 非自反、子关系仍良基、没有无穷下降链；而空关系是良基的却不自反（两道反例题，说明这两件事不互相包含）。

14.1 良基：每个非空子集都有极小元

读法：HasMin α r P = "P 里有一个元素 m，P 里没有元素排在 m 前面"（极小，不一定最小：偏序里"极小"与"最小"是两回事，全序里才重合）。IsWellFounded α r = "对每个非空 P，HasMin α r P 都成立"。⚠ 本语言没有 Acc（台账 G-56）⇒ 上面这条就是我们的良基定义（Isabelle wf 的对应物）✓

14.3 良基的三条硬后果

练习 6wellFounded_irrefl定理附录解答

练习 6（L 类）：良基 ⇒ 非自反 —— 没有一个元素排在自己前面。

theorem wellFounded_irrefl (α : Type) (r : α → α → Prop)
    (h : IsWellFounded α r) : Irreflexive α r := by
  sorry
提示 1思路

反证。取谓词 r a（"排在 a 前面"），它非空（a 自己在里面，这正是假设）。良基给它一个极小元 m；m 的属性之一就是"没有 r a 里的元素排在 m 前面"。另一方面 a 在 r a 里，于是"a 排在 m 前面"与它冲突。

提示 2目标形态

Irreflexive α r，展开后是 ∀ a, r a a → False。

提示 3关键件

谓词写成部分应用 r a（少写一个 λ，也少一个 G-73 的坑）；hasMin_elim 拆极小元；极小性那一条要先 fun (hall : …) => … 把类型写出来再应用。

查看解答 定理 · 11 行

── 练习 6（L 类）：良基 ⇒ 非自反 ───────────────────────────────────────── 取谓词 r a（"排在 a 前面"），它非空（a 自己在里面）；极小元 m 的极小性 与 a 落在 r a 里直接冲突。

theorem wellFounded_irrefl (α : Type) (r : α → α → Prop)
    (h : IsWellFounded α r) : Irreflexive α r :=
  fun (a : α) (haa : r a a) =>
    (fun (hm : HasMin α r (r a)) =>
      (fun (hel : ∃ (m : α), (r a) m ∧ ∀ (y : α), (r a) y → ¬ (r y m)) =>
        @Exists.elim α (fun (m : α) => (r a) m ∧ ∀ (y : α), (r a) y → ¬ (r y m)) False hel
          (fun (m : α) (hmm : (r a) m ∧ ∀ (y : α), (r a) y → ¬ (r y m)) =>
            (fun (hnot : ¬ (r a m)) => (fun (ham : r a m) => hnot ham) (And.left hmm))
              ((fun (hall : ∀ (y : α), (r a) y → ¬ (r y m)) => hall a haa) (And.right hmm))))
        (hasMin_elim α r (r a) hm))
      (wellFounded_hasMin α r h (r a) (Exists.intro a haa))
练习 7wellFounded_of_subrelation定理附录解答

练习 7（L 类）：子关系保持良基 —— 若 s 蕴含在 r 里，而 r 良基，则 s 也良基。

theorem wellFounded_of_subrelation (α : Type) (r s : α → α → Prop)
    (hsub : ∀ (a b : α), s a b → r a b) (hr : IsWellFounded α r) :
    IsWellFounded α s := by
  sorry
提示 1思路

用良基的智能构造子。给定非空 P，先用 r 的良基拿到极小元 m，再说明它对 s 也极小：若 s y m 则 r y m（子关系假设），与 m 的极小性冲突。

提示 2目标形态

IsWellFounded α s。

提示 3关键件

isWellFounded_intro（吃一个"对每个非空 P 都给出 HasMin"的函数）+ hasMin_intro（在 s 这一侧重新装配极小元）。

查看解答 定理 · 17 行

── 练习 7（L 类）：子关系保持良基 ─────────────────────────────────────────

theorem wellFounded_of_subrelation (α : Type) (r s : α → α → Prop)
    (hsub : ∀ (a b : α), s a b → r a b) (hr : IsWellFounded α r) :
    IsWellFounded α s :=
  isWellFounded_intro α s
    (fun (P : α → Prop) (hP : ∃ (x : α), P x) =>
      (fun (hm : HasMin α r P) =>
        (fun (hel : ∃ (m : α), P m ∧ ∀ (y : α), P y → ¬ (r y m)) =>
          @Exists.elim α (fun (m : α) => P m ∧ ∀ (y : α), P y → ¬ (r y m))
            (HasMin α s P) hel
            (fun (m : α) (hmm : P m ∧ ∀ (y : α), P y → ¬ (r y m)) =>
              hasMin_intro α s P m (And.left hmm)
                (fun (y : α) (hy : P y) (hsy : s y m) =>
                  (fun (hnot : ¬ (r y m)) => hnot (hsub y m hsy))
                    ((fun (hall : ∀ (y' : α), P y' → ¬ (r y' m)) => hall y hy)
                      (And.right hmm)))))
          (hasMin_elim α r P hm))
        (wellFounded_hasMin α r hr P hP))

14.4 必证（本单元旗舰）：良基 ⇒ 没有无穷下降链

下面这个 SeqImage 只是把"序列的像"写成一个谓词 —— 极小元要作用在它上面。

演示（定义）：序列 f 的像 —— "存在 n 使 x = f n"。

定义SeqImage声明 10
def SeqImage (α : Type) (f : Nat → α) : α → Prop :=
  fun (x : α) => ∃ (n : Nat), x = f n
练习 8no_descending_chain定理附录解答

练习 8（L 类）：没有无穷下降链 —— 若每一步都更靠前，就不可能无限走下去。

theorem no_descending_chain (α : Type) (r : α → α → Prop)
    (h : IsWellFounded α r) (f : Nat → α)
    (hstep : ∀ (n : Nat), r (f (Nat.succ n)) (f n)) : False := by
  sorry
提示 1思路

把良基作用在 SeqImage α f 上（它非空：f 0 在里面）。拿到极小元 m 与它的极小性；m 在像里 ⇒ 有 n 使 m = f n；而链的第 n+1 项也在像里，于是极小性说"它不排在 m 前面"——但它排在 f n 前面，也就是排在 m 前面（沿 m = f n 搬）。

提示 2目标形态

False。

提示 3关键件

SeqImage（像）· hasMin_elim（拆极小元）· rel_subst_right（把"排在 f n 前面"沿 m = f n 搬成"排在 m 前面"）·以及存在消去要把前导实参写全（Exists.elim α P Q …，台账 G-73 形状 ②）。

查看解答 定理 · 25 行

── 练习 8（L 类）：没有无穷下降链（本单元旗舰）─────────────────────────── 极小元作用在 SeqImage α f 上：m = f n 极小 ⇒ 链的第 n+1 项不能排在它前面， 而它按定义就排在 f n（也就是 m）前面 —— 沿 m = f n 搬过去即矛盾。

theorem no_descending_chain (α : Type) (r : α → α → Prop)
    (h : IsWellFounded α r) (f : Nat → α)
    (hstep : ∀ (n : Nat), r (f (Nat.succ n)) (f n)) : False :=
  (fun (hm : HasMin α r (SeqImage α f)) =>
    (fun (hel : ∃ (m : α), SeqImage α f m ∧ ∀ (y : α), SeqImage α f y → ¬ (r y m)) =>
      @Exists.elim α (fun (m : α) => SeqImage α f m ∧ ∀ (y : α), SeqImage α f y → ¬ (r y m))
        False hel
        (fun (m : α) (hmm : SeqImage α f m ∧ ∀ (y : α), SeqImage α f y → ¬ (r y m)) =>
          (fun (hPm : SeqImage α f m) =>
            @Exists.elim Nat (fun (k : Nat) => m = f k) False hPm  -- soko:notation-ok: G-73 形状 ②：期望类型是定义头时前导实参必须写全
              (fun (n : Nat) (hn : m = f n) =>
                (fun (hnot : ¬ (r (f (Nat.succ n)) m)) =>
                  (fun (hrr : r (f (Nat.succ n)) m) => hnot hrr)
                    (rel_subst_right α r (f (Nat.succ n)) (f n) m
                      (@Eq.symm.{1} α m (f n) hn) (hstep n)))
                  ((fun (hall : ∀ (y : α), SeqImage α f y → ¬ (r y m)) =>
                    hall (f (Nat.succ n))
                      (Exists.intro (Nat.succ n)
                        (@Eq.refl.{1} α (f (Nat.succ n))))) (And.right hmm))))
            (And.left hmm)))
        (hasMin_elim α r (SeqImage α f) hm))
      (wellFounded_hasMin α r h (SeqImage α f)
        (Exists.intro (f Nat.zero)
          (Exists.intro Nat.zero
            (@Eq.refl.{1} α (f Nat.zero)))))

14.5 必破：良基与自反互不包含

练习 9emptyRelation_wellFounded定理附录解答

空关系既不成立任何一步，也就无所谓"更靠前" —— 它是良基的；但它同时不是自反的。这两道题说明"良基"与"自反/非自反"是两件独立的事。

练习 9（D 类）：空关系是良基的。

theorem emptyRelation_wellFounded (α : Type) :
    IsWellFounded α (EmptyRelation α α) := by

theorem wellFounded_irrefl (α : Type) (r : α → α → Prop)
    (h : IsWellFounded α r) : Irreflexive α r :=
  fun (a : α) (haa : r a a) =>
    (fun (hm : HasMin α r (r a)) =>
      (fun (hel : ∃ (m : α), (r a) m ∧ ∀ (y : α), (r a) y → ¬ (r y m)) =>
        @Exists.elim α (fun (m : α) => (r a) m ∧ ∀ (y : α), (r a) y → ¬ (r y m)) False hel
          (fun (m : α) (hmm : (r a) m ∧ ∀ (y : α), (r a) y → ¬ (r y m)) =>
            (fun (hnot : ¬ (r a m)) => (fun (ham : r a m) => hnot ham) (And.left hmm))
              ((fun (hall : ∀ (y : α), (r a) y → ¬ (r y m)) => hall a haa) (And.right hmm))))
        (hasMin_elim α r (r a) hm))

    (h : IsWellFounded α r) (f : Nat → α)
    (hstep : ∀ (n : Nat), r (f (Nat.succ n)) (f n)) : False :=
  (fun (hm : HasMin α r (SeqImage α f)) =>
    (fun (hel : ∃ (m : α), SeqImage α f m ∧ ∀ (y : α), SeqImage α f y → ¬ (r y m)) =>
      @Exists.elim α (fun (m : α) => SeqImage α f m ∧ ∀ (y : α), SeqImage α f y → ¬ (r y m))
        False hel
        (fun (m : α) (hmm : SeqImage α f m ∧ ∀ (y : α), SeqImage α f y → ¬ (r y m)) =>
          (fun (hPm : SeqImage α f m) =>
            @Exists.elim Nat (fun (k : Nat) => m = f k) False hPm  -- soko:notation-ok: G-73 形状 ②：期望类型是定义头时前导实参必须写全

                    (rel_subst_right α r (f (Nat.succ n)) (f n) m
                      (@Eq.symm.{1} α m (f n) hn) (hstep n)))
                  ((fun (hall : ∀ (y : α), SeqImage α f y → ¬ (r y m)) =>
                    hall (f (Nat.succ n))
                      (Exists.intro (Nat.succ n)
                        (@Eq.refl.{1} α (f (Nat.succ n))))) (And.right hmm))))
            (And.left hmm)))
        (hasMin_elim α r (SeqImage α f) hm))
      (wellFounded_hasMin α r h (SeqImage α f)
        (Exists.intro (f Nat.zero)
          (Exists.intro Nat.zero
            (@Eq.refl.{1} α (f Nat.zero)))))
