11.1 概括公理为什么在这里写不出来

概括公理（comprehension axiom）说：给定任何性质 P，都有集合

{ x | P x }

把恰好满足 P 的对象装起来。Tao §3.2 的 Russell 论证取

P x := 「x 不属于 x」，

得到 Ω = { x | x ∉ x }，然后问「Ω 属不属于 Ω」：答「属于」就说明 Ω 满足 P，按定义它不该属于；答「不属于」就说明它不满足 P，按定义它该属于。

这条论证在本语言里第一步就走不动。卡住的地方是记法：

  • 集合是 Set α，也就是 α → Prop：它总是某个固定类型 α 的谓词。隶属判定 x ∈ A 要求 x : α、A : Set α，两个参数的类型必须对上。
  • 于是「x ∈ x」要成立，同一个 x 得同时是 α 与 Set α——两个不同的类型，写不出来。Russell 集 { x | x ∉ x } 因此连写都写不出，更谈不上判真假。
  • 「一切集合」同样不是一个类型：Set α 与 Set β 是两个类型，Type 不是 Type。「存在一个集合包含一切集合」这句里的量词没有落脚的地方。

类型论对「一切」的处置是逐层给全集：11.2 就是它。

11.2 类型论的答案：每个类型有自己的全集

@Set.univ α 的定义是「不管来什么元素都答 True」，所以它是本类型里最大的集合（最大元），也就是这个类型的论域（universe of discourse）。下面三条把「最大」和「唯一」两件事做出来，第三条把 11.1 里写不出的那句话限制到一个类型内，于是它变成真的。

演示 1（已写好）：本类型里每个集合都被 univ 包含——univ 是「⊆」下的最大元。目标展开是 ∀ x, x ∈ A → x ∈ @Set.univ α，而 x ∈ @Set.univ α 就是 True，每个元素交 True.intro 即可（Set.mem_univ 正是这条）。

11.3 必破（D 类）：把「一切」放大到跨论域，或者加强成「严格更大」

练习 1no_univ_strictly_larger定理附录解答

题面就是 Tao §3.2 的那句话：

「存在一个集合，它包含一切集合。」

请分三层回答，答案本身就是这道题的收获：

① 跨论域读法（「一切集合」= 所有类型的集合）：写不出来。集合总是 Set α，量词必须先固定一个 α；没有一个类型能装下所有类型的集合。② 类型内读法（「一切集合」= 本类型的集合）：真，就是演示 3。③ 类型内，但把「包含」加强成「严格大于每个集合」：假。这就是练习 1，它的证明里藏着 Russell 论证的那一步——把候选者自己代进去。

11.4 「一切集合」在类型论里的合法落点

练习 2mem_powerset_univ定理附录解答

概括公理要的是「把满足性质 P 的对象收成一个集合」。类型论里能收的只有 本类型的对象；要收「本类型的一切集合」，收出来的东西类型就升一层：

𝒫 (@Set.univ α) : Set (Set α)

它就是「一切集合的集合」在这里的合法读音：里面装着本类型的每个集合，而它自己属于 Set (Set α)，不是 α 的元素。于是「它属不属于它自己」这句话不成形。这里绕开 Russell 的办法就是让自指落不到类型上。

    A ∈ 𝒫 (@Set.univ α) := by

目标是「A 属于 𝒫(univ)」，而库里已经把幂集隶属换成了包含关系，先把这步换算用掉。

提示 2目标形态

A ∈ 𝒫 (@Set.univ α)，它展开后就是 A ⊆ @Set.univ α。

提示 3关键件

触发条件是「目标形如 A ∈ 𝒫 B」；用 Set.mem_powerset_iff 换成 A ⊆ B，再把 A ⊆ univ 这一步交出去（演示 1，或就地 intro 后给 True.intro）。

11.5 与 ZF 的对照：没有那个 V，只有一条类型阶梯

练习 3univ_mem_univ_of_sets定理附录解答

ZF 里没有「一切集合的集合」：V = { x | x = x } 是真类（proper class），不是集合（Tao 的 epilogue 另起一套公理化的 ZF 集合论，Mathlib 里对应 ZFSet）。本语言的处置不同：每一层都有自己的全集，没有一个「太大」的东西需要被排除在集合之外——

@Set.univ α : Set α （α 的一切元素）Set.univ (Set α) : Set (Set α) （α 的一切集合）Set.univ (Set (Set α)) : Set (Set (Set α))

每一层的全集都是上一层的一个元素，所以「一切」这个词永远要先回答「哪一层的一切」。（设计判断）这条阶梯与 ZF 的累积层做的是同一件事：把「一切」分层。

练习 3（R 类：读·评译）。

theorem univ_mem_univ_of_sets (α : Type) :
    @Set.univ (Set α) ∈ @Set.univ (Set (Set α)) := by

提示 1思路

本题问的是「Set α 的全集」在上一层类型里算不算成员，而上层的隶属判定由上一层的全集给出。

提示 2目标形态

Set.univ (Set α) ∈ Set.univ (Set (Set α))，两边的东西都属于类型 Set (Set α)。

提示 3关键件

触发条件是「目标是『某元素属于该类型的 Set.univ』」；用 Set.mem_univ，类型参数写 Set (Set α)，元素参数写 Set.univ (Set α)。

查看解答 定理 · 3 行
