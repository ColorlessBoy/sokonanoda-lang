靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§3.5 的后半（"等价关系 = 划分"这一定理的反方向）；Halmos《Naive Set Theory》§10 / §18。大纲：set-theory-syllabus.md §4.1（I.10 章第三个单元）。

单元㉕ 做的是"等价关系 ⇒ 划分"（等价类构成划分）。本单元做反方向：划分 ⇒ 等价关系（"落在同一个块里"），并且证明往返回到原地 ✓—— 两条合起来才是教科书里那句"等价关系与划分是同一件事的两种说法" ✓

读法：划分 P 是一族集合（写成 (α → Prop) → Prop），三条是 ① 每块非空 · ② 每点落在某块里 · ③ 有公共点的两块逐点相同 ✓

写法约定（本单元特有）：一切都从 Rel.ofPartition α P a b 展开出来的那个 ∃ A 出发 ⇒ Exists.elim/Exists.intro 的前导实参一律写全（G-73 形状 ②）；要注意 "两块相同"只能拿到逐点的 ↔，要让"某块属于 P"这条性质搬过去，必须先用 Set.ext（外延公理）把它变成集合相等，再沿等式搬运 ✓

    Rel.ofPartition α P a c :=

        (fun (B : α → Prop) (hB : P B ∧ B b ∧ B c) =>

  @Exists.elim α (fun (a : α) => ∀ (c : α), C c ↔ Rel.ofPartition α P a c) (P C)

26.4 往返：从等价关系造划分、再回去，得到原关系

练习 10ofPartition_of_classes定理附录解答

练习 10（D 类，本单元收尾）：往返恒等 —— 用单元㉕ 的等价类族当划分，再造出关系，得到的正是原来的关系。

theorem ofPartition_of_classes (α : Type) (r : Rel α α) (he : IsEquivalence α r)
    (a b : α) : Rel.ofPartition α (Rel.Classes α r) a b ↔ r a b := by
  sorry
提示 1思路

→：a、b 同在某块 C 里，而 C 是某个点 x 的等价类 ⇒ r x a 且 r x b ⇒ 把第一个掉头成 r a x，再与第二个接起来得 r a b。←：r a b 时见证取 [a] 本身（它是个类、"a 在里面"、b 也在里面）。

    (a b : α) : Rel.ofPartition α (Rel.Classes α r) a b ↔ r a b :=
  @Iff.intro (Rel.ofPartition α (Rel.Classes α r) a b) (r a b)
    (fun (h : Rel.ofPartition α (Rel.Classes α r) a b) =>
      @Exists.elim (α → Prop) (fun (C : α → Prop) => Rel.Classes α r C ∧ C a ∧ C b)
        (r a b) h
        (fun (C : α → Prop) (hC : Rel.Classes α r C ∧ C a ∧ C b) =>
          @Exists.elim α (fun (x : α) => ∀ (c : α), C c ↔ r x c) (r a b)
            ((fun (hs : ∃ (x : α), ∀ (c : α), C c ↔ r x c) => hs) (And.left hC))
