本单元的"该学的定理"：分配律两个方向 · De Morgan 的两条（哪一条能证、哪一条只有一半）· 吸收律 · 逆否（A ⊆ B ⇒ Bᶜ ⊆ Aᶜ）· 差 = 交补 ✓

  • (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ 整条都能证 ✓
  • (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ 只有一个方向能证（Aᶜ ∪ Bᶜ ⊆ (A ∩ B)ᶜ），另一个方向等价于"¬(p ∧ q) → ¬p ∨ ¬q" —— 要排中律 ✗（缺口 G-74）
  • 同理 Aᶜᶜ = A 与 A ∪ Aᶜ = Set.univ 也做不了（都要排中律）⇒ 如实不排 ✓

28.2 差与补：差就是交补

练习 1sdiff_eq_inter_compl定理附录解答

练习 1（T 类）：A \ B = A ∩ Bᶜ（两个方向都是"把合取的两个支换个说法"）。

theorem sdiff_eq_inter_compl (α : Type) (A B : Set α) :
    A \ B = A ∩ Bᶜ := by
  sorry
提示 1思路

逐点证 ↔（用外延公理）；两个方向各自把 A x ∧ ¬ (B x) 原样交出去（Bᶜ 展开就是 ¬ (B x)）。

提示 2目标形态

A \ B = A ∩ Bᶜ。

提示 3关键件

Set.ext（要写全论域）· Iff.intro（前导 Prop 实参写全）·And.intro/And.left/And.right · 后缀记法要加括号（写 (Bᶜ) x）✓

查看解答 定理 · 6 行
theorem sdiff_eq_inter_compl (α : Type) (A B : Set α) :
    A \ B = A ∩ Bᶜ :=
  Set.ext (A \ B) (A ∩ Bᶜ) (fun (x : α) =>
    @Iff.intro ((A \ B) x) ((A ∩ Bᶜ) x)
      (fun (h : A x ∧ ¬ (B x)) => And.intro (And.left h) (And.right h))
      (fun (h : A x ∧ ¬ (B x)) => And.intro (And.left h) (And.right h)))

28.3 分配律：两个方向

练习 2union_inter_distrib_right定理附录解答

练习 2（L 类，旗舰之一）：(A ∪ B) ∩ C = (A ∩ C) ∪ (B ∩ C)。

theorem union_inter_distrib_right (α : Type) (A B C : Set α) :
    (A ∪ B) ∩ C = (A ∩ C) ∪ (B ∩ C) := by
  sorry
提示 1思路

→：把交的两个支拆开，左边那个析取用 Or.elim 分两支，各自造出右边的析取；←：把右边的析取分两支，每支都能给出"在并里"与"在 C 里"。

提示 2目标形态

(A ∪ B) ∩ C = (A ∩ C) ∪ (B ∩ C)。

提示 3关键件

Set.ext · Or.elim/Or.inl/Or.inr（前导 Prop 实参写全）·And.intro/And.left/And.right（注意合取是右嵌套）。

28.4 De Morgan：能证的那条

练习 4compl_union定理附录解答

练习 4（L 类，本单元旗舰）：(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ（整条都能证）。

theorem compl_union (α : Type) (A B : Set α) :
    (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ := by
  sorry
提示 1思路

→：假设 ¬(A x ∨ B x)，两个方向各自"把析取的左/右支喂给假设"；←：假设 ¬A x ∧ ¬B x，反过来对 A x ∨ B x 做 Or.elim，两支分别撞上两个否定。

提示 2目标形态

(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ。

提示 3关键件

Set.ext · Or.elim/Or.inl/Or.inr · 否定是函数 ——"用假设消掉一个析取支"就是把它当函数应用 ✓

查看解答 定理 · 11 行
theorem compl_union (α : Type) (A B : Set α) :
    (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ :=
  Set.ext ((A ∪ B)ᶜ) (Aᶜ ∩ Bᶜ) (fun (x : α) =>
    @Iff.intro (¬ (A x ∨ B x)) (¬ (A x) ∧ ¬ (B x))
      (fun (h : ¬ (A x ∨ B x)) =>
        And.intro
          (fun (ha : A x) => h (@Or.inl (A x) (B x) ha))  -- soko:notation-ok: G-73 形状 ②/③：前导 Prop 实参或 `Eq` 宇宙层级在这些位置补不出来，必须写全

    Aᶜ ∪ Bᶜ ⊆ (A ∩ B)ᶜ := by

提示 1思路

theorem compl_inter_subset (α : Type) (A B : Set α) :
    Aᶜ ∪ Bᶜ ⊆ (A ∩ B)ᶜ :=
  fun (x : α) (h : (Aᶜ) x ∨ (Bᶜ) x) =>
    @Or.elim ((Aᶜ) x) ((Bᶜ) x) (¬ (A x ∧ B x))
      (fun (ha : ¬ (A x)) => fun (hab : A x ∧ B x) => ha (And.left hab))
      (fun (hb : ¬ (B x)) => fun (hab : A x ∧ B x) => hb (And.right hab))
      h

theorem union_absorb (α : Type) (A B : Set α) :
    A ∪ (A ∩ B) = A :=
  Set.ext (A ∪ (A ∩ B)) A (fun (x : α) =>
    @Iff.intro (A x ∨ (A x ∧ B x)) (A x)
      (fun (h : A x ∨ (A x ∧ B x)) =>
        @Or.elim (A x) (A x ∧ B x) (A x)
          (fun (ha : A x) => ha)
          (fun (hab : A x ∧ B x) => And.left hab)
          h)

⚠ 本单元最值得学的一件事：De Morgan 的两条在直觉主义下不对称 ——

⚠ 两条写码边界（本单元实测，写题时会踩）：① 后缀记法不能直接应用：Bᶜ x 解析失败 ⇒ 要写 (Bᶜ) x；② ∅ 出现在 = 或 ⊆ 的右侧时类型推不出来 ⇒ 那两条如实写成"成员层面"的形态 ✓
