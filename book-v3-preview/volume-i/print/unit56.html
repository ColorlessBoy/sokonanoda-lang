8 个定理 · 5 道练习 · 11 条提示 · 解答附录

本单元的"该学的定理/手法"：

  • 总纲三：驳倒 ∃ —— 要说明"没有那样的 x"，得对每个 x 都排除 ✓（(∀ x, ¬ P x) → ¬ (∃ x, P x) ✓ —— 与总纲一（驳倒 ∀ 只需一个反例 ✓）对偶 ✓）；
  • 等式搬运：从 A = B 与 a ∈ A 得 a ∈ B ✓（外延推理的地基 ✓）；
  • 总纲四：驳倒 A = B —— 给一个"在 A 里、不在 B 里"的见证即可 ✓（这是外延公理的逆否用法，教材里最常出现的"集合不等"证法 ✓）；
  • 实例：∄ x, x ∈ ∅ ✓ · a ∈ A ⇒ A ≠ ∅ ✓

56.2 总纲三：驳倒 ∃（要与每个 x 打交道）

练习 1not_exists_of_all_not定理附录解答

练习 1（L 类，总纲三）：驳倒 ∃ 要对每个 x 都排除。

再用"每个 x 都 ¬ P x"的假设把它否掉。

铁律"动机位只放肯定形状"是 Or.elim 专有 ✓，Exists.elim 不受限 ✓）

theorem not_exists_of_all_not (α : Type) (P : α → Prop) (h : ∀ (x : α), ¬ (P x)) :
    ¬ (∃ (x : α), P x) := by
  sorry
提示 1思路

假设 ∃ x, P x；把它拆出一个见证 x 与 P x，

提示 2目标形态

(∀ x, ¬ (P x)) → ¬ (∃ x, P x)。

提示 3关键件

Exists.elim（动机位放 False 是可以的 ✓ ——

查看解答 定理 · 4 行
theorem not_exists_of_all_not (α : Type) (P : α → Prop) (h : ∀ (x : α), ¬ (P x)) :
    ¬ (∃ (x : α), P x) :=
  fun (he : ∃ (x : α), P x) =>
    @Exists.elim α P False he (fun (x : α) (hx : P x) => h x hx)
