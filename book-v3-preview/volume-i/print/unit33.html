练习 2（L 类，旗舰之一）：𝒫 (A ∩ B) = 𝒫 A ∩ 𝒫 B（两个方向都是"逐点拆合取"）。

提示 1思路

→：C ⊆ A ∩ B 给出"每个点同时在两个里" ⇒ 分别打包成两条包含关系；←：两条包含关系各取所需，合成"同时在两个里"。

查看解答 定理 · 17 行
theorem powerset_inter (α : Type) (A B : Set α) :
    𝒫 (A ∩ B) = 𝒫 A ∩ 𝒫 B :=
  Set.ext (𝒫 (A ∩ B)) (𝒫 A ∩ 𝒫 B) (fun (C : Set α) =>
    @Iff.intro (C ∈ 𝒫 (A ∩ B)) (C ∈ (𝒫 A ∩ 𝒫 B))
      (fun (h : C ⊆ A ∩ B) =>
        And.intro
          (fun (x : α) => fun (hx : C x) =>
            (fun (hu : ∀ (y : α), C y → A y ∧ B y) => And.left (hu x hx)) h)
          (fun (x : α) => fun (hx : C x) =>
            (fun (hu : ∀ (y : α), C y → A y ∧ B y) => And.right (hu x hx)) h))
      (fun (h : C ∈ (𝒫 A ∩ 𝒫 B)) =>
        fun (x : α) => fun (hx : C x) =>
          And.intro
            ((fun (hu : ∀ (y : α), C y → A y) => hu x hx)
              ((fun (hp : C ⊆ A ∧ C ⊆ B) => And.left hp) h))
            ((fun (hu : ∀ (y : α), C y → B y) => hu x hx)
              ((fun (hp : C ⊆ A ∧ C ⊆ B) => And.right hp) h))))

theorem sUnion_powerset (α : Type) (A : Set α) :
    ⋃₀ (𝒫 A) = A :=
  Set.ext (⋃₀ (𝒫 A)) A (fun (x : α) =>
    @Iff.intro (x ∈ ⋃₀ (𝒫 A)) (A x)
      (fun (h : x ∈ ⋃₀ (𝒫 A)) =>
        Set.mem_sUnion_elim α (𝒫 A) x (A x) h
          (fun (B : Set α) (hB : B ∈ 𝒫 A) (hxB : x ∈ B) =>
            (fun (hu : ∀ (y : α), B y → A y) => hu x hxB) hB))
      (fun (hx : A x) =>
        Set.mem_sUnion_intro α (𝒫 A) A x
          (fun (y : α) => fun (hy : A y) => hy) hx))

编写注记 · 教材对照与课程边界（3 条）

⚠ 如实记下两件做不成的事（都写进 hint）：① 反方向 𝒫 (A ∪ B) ⊆ 𝒫 A ∪ 𝒫 B 是假的，而举反例要能区分 Bool 的两个构造子 ——本语言的递归子只有 Prop 动机（与 G-58 同源）⇒ 连 true ≠ false 都证不出来（Bool.rec 的动机必须是 Bool → Sort 0，造不出"在 true 上真、在 false 上假"的谓词）✗ ② 𝒫 A → (A → Bool) 这一步做不了 —— 要给每个点判定"在不在集合里"，那要可判定性（Decidable / 排中律），本语言没有（G-74）⇒ 本单元只做 (α → Bool) → 𝒫 α 这个方向 ✓

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 三样：lib.Set · lib.SUnion（广义并）· lib.Rel。

依赖：单元②③（幂集与子集）· 单元㉑（广义并）· 单元㉘（集合代数）—— 本单元把幂集做成代数。
