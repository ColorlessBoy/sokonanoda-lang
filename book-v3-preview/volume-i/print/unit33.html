33.0 画布给的新词汇：特征函数对应的集合

读法：charSet α f 是"f 取真值的那些点" ✓ —— 这是"函数 → 集合"的方向，它不需要任何判定（只是把"取值等于真"写成集合）✓ 反方向（集合 → 函数）要判定每个点在不在集合里 ⇒ 本语言做不了（G-74）✓

定义charSet声明 1
def charSet (α : Type) (f : α → Bool) : Set α :=
  fun (x : α) => (f x) = Bool.true

练习 2（L 类，旗舰之一）：𝒫 (A ∩ B) = 𝒫 A ∩ 𝒫 B（两个方向都是"逐点拆合取"）。

theorem powerset_inter (α : Type) (A B : Set α) :
    𝒫 (A ∩ B) = 𝒫 A ∩ 𝒫 B := by

提示 1思路

→：C ⊆ A ∩ B 给出"每个点同时在两个里" ⇒ 分别打包成两条包含关系；←：两条包含关系各取所需，合成"同时在两个里"。

提示 2目标形态

提示 3关键件

Set.ext（要写全论域与两个集合）· Iff.intro（前导 Prop 实参写全）·And.intro/And.left/And.right · 包含关系是定义头 ⇒ 先 λ 绑定再应用（G-73 形状 ①）✓

查看解答 定理 · 17 行
theorem powerset_inter (α : Type) (A B : Set α) :
    𝒫 (A ∩ B) = 𝒫 A ∩ 𝒫 B :=
  Set.ext (𝒫 (A ∩ B)) (𝒫 A ∩ 𝒫 B) (fun (C : Set α) =>
    @Iff.intro (C ∈ 𝒫 (A ∩ B)) (C ∈ (𝒫 A ∩ 𝒫 B))
      (fun (h : C ⊆ A ∩ B) =>
        And.intro
          (fun (x : α) => fun (hx : C x) =>
            (fun (hu : ∀ (y : α), C y → A y ∧ B y) => And.left (hu x hx)) h)
          (fun (x : α) => fun (hx : C x) =>
            (fun (hu : ∀ (y : α), C y → A y ∧ B y) => And.right (hu x hx)) h))
      (fun (h : C ∈ (𝒫 A ∩ 𝒫 B)) =>
        fun (x : α) => fun (hx : C x) =>
          And.intro
            ((fun (hu : ∀ (y : α), C y → A y) => hu x hx)
              ((fun (hp : C ⊆ A ∧ C ⊆ B) => And.left hp) h))
            ((fun (hu : ∀ (y : α), C y → B y) => hu x hx)
              ((fun (hp : C ⊆ A ∧ C ⊆ B) => And.right hp) h))))

theorem sUnion_powerset (α : Type) (A : Set α) :
    ⋃₀ (𝒫 A) = A :=
  Set.ext (⋃₀ (𝒫 A)) A (fun (x : α) =>
    @Iff.intro (x ∈ ⋃₀ (𝒫 A)) (A x)
      (fun (h : x ∈ ⋃₀ (𝒫 A)) =>
        Set.mem_sUnion_elim α (𝒫 A) x (A x) h
          (fun (B : Set α) (hB : B ∈ 𝒫 A) (hxB : x ∈ B) =>
            (fun (hu : ∀ (y : α), B y → A y) => hu x hxB) hB))
      (fun (hx : A x) =>
        Set.mem_sUnion_intro α (𝒫 A) A x
          (fun (y : α) => fun (hy : A y) => hy) hx))
