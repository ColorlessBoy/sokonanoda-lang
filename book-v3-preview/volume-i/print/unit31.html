13 个定理 · 10 道练习 · 30 条提示 · 解答附录

靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§7.1 Orderings 的 order-preserving map 那一段；Halmos《Naive Set Theory》§14 Order。大纲：set-theory-syllabus.md §4.1（I.11 章第四个单元）。

本单元的"该学的定理"：单调的合成还是单调 · 常函数单调 ·单调把上界/下界送到像上 · 序反射（"像上有序 ⇒ 原来有序"） ·旗舰：序同构保持上确界 —— 单调 + 反射 + 满射 ⇒ f (sup A) 是像族的上确界 ✓

写法约定：Monotone / OrderReflecting / IsSup / UpperBound 都是定义头 ⇒ 用之前先 λ 绑定（G-73 形状 ①）；库里有取用子（monotone_apply / reflecting_apply）优先用 ✓ 搬运等式要挑对引理与方向：rel_subst_left 改的是第二个坐标（向前），rel_subst_right 也是第二个坐标（向后）；要改第一个坐标就把关系翻过来（本单元实测）✓

练习 8orderReflecting_of_monotone_inverse定理附录解答

练习 8（L 类，旗舰之一）：单调的左逆给出反射（若 g 单调且 g (f a) = a，则 f 反射序）。

theorem orderReflecting_of_monotone_inverse (α β : Type) (r : α → α → Prop)
    (s : β → β → Prop) (f : α → β) (g : β → α)
    (hg : Monotone β α s r g) (hgf : ∀ (a : α), (g (f a)) = a) :
    OrderReflecting α β r s f := by
  sorry
提示 1思路

s (f a) (f b) 经 g 的单调性得 r (g (f a)) (g (f b))；再把两个坐标分别沿 g (f a) = a、g (f b) = b 换掉 ⇒ r a b。

提示 2目标形态

Monotone β α s r g → (∀ a, g (f a) = a) → OrderReflecting α β r s f。

提示 3关键件

monotone_apply · rel_subst_right（改第二个坐标）·改第一个坐标要把关系翻过来再走 rel_subst_left（本单元实测的用法）·Eq.symm（搬运要的是"旧 = 新"那个方向）✓

theorem orderReflecting_of_monotone_inverse (α β : Type) (r : α → α → Prop)
    (s : β → β → Prop) (f : α → β) (g : β → α)
    (hg : Monotone β α s r g) (hgf : ∀ (a : α), @Eq.{1} α (g (f a)) a) :  -- soko:notation-ok: G-73 形状 ②/③：前导实参或 `Eq` 层级在这些位置补不出来
    OrderReflecting α β r s f :=
  fun (a : α) => fun (b : α) => fun (hab : s (f a) (f b)) =>
    rel_subst_left α (fun (p : α) (q : α) => r q p) a b (g (f a))
      (@Eq.symm.{1} α (g (f a)) a (hgf a))
      (rel_subst_right α r (g (f a)) (g (f b)) b (hgf b)
