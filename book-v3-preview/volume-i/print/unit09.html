── 等势为什么是"数据"，不是"存在双射" ────────────────────────────────── 完整理由与读法在 lib/Equiv.sokonanoda 的文件头（先读它）。一句话版：若定义成 ∃f (单射 f ∧ 满射 f)，那么"对称"要从满射取回一个原像——那是选择公理，本单元没有，于是对称性根本证不出来。所以等势在这里是数据：一对互逆映射（f 去、g 回）+ 四条带域条件的命题，全部装在等势（记法 A ≈ B）里。拿数据的方法只有一条：Exists.elim 两次；造数据的方法是 Set.Equiv.mk。读法四条（造/用/展开）见 lib/Equiv 文件头，动手前务必先看一遍。

为什么每题都要求"亲手写出那对映射"（出处：Hamza & O'Shea 2011, MEI 4:192–202）：该研究里援引"双射判据"的学生没有一个在所有题上都真的用它，且极少把映射写出来；所以本单元的 7 条练习没有一条能靠"显然存在双射"蒙过去——四条条件都要落地。

9.1 演示 1（必证①）：等势自反——恒等映射。

9.2 演示 2（必证④）：从单射 + 满射（数据）构造等势。

9.3 反例脚手架（演示，已写好）：只为把"无限集上的真子集"陈述出来。

「真子集一定严格更小」在无限集上是假的，而本语言没有基数序，"更小"只能表述成"不等势"。要给出反例就需要 Nat 上的"减一"与"succ 不为 0"：这两条不是本单元的内容，属于脚手架（单元⑥ 的 match/Nat.rec 手法）。

  • Nat.isZero：把"是不是 0"做成一个 Prop 值的谓词（succ 支给 True，zero 支给 False）——它是下面 succ ≠ 0 的搬运工具；
  • Nat.pred：前驱（zero 支给 zero，succ k 支给 k）；
  • Nat.succ_ne_zero：succ n ≠ 0（把 Eq.subst 沿 Nat.isZero 走一趟）；
  • nonzero：非零自然数之集（自定名：Mathlib 里没有这个名字的 Set Nat），就是反例里的"真子集"那一半。

def Nat.isZero (n : Nat) : Prop := match n with
  | Nat.zero => False
  | Nat.succ k => True
定义Nat.pred声明 4
def Nat.pred (n : Nat) : Nat := match n with
  | Nat.zero => Nat.zero
  | Nat.succ k => k
