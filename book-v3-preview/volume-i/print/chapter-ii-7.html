Unit 17 — The Axiom of Choice

13 个定理 · 10 道练习 · 30 条提示 · 解答附录

靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§6.5 The Axiom of Choice（+ §6.4 的"无限公理"一节）；Halmos《Naive Set Theory》§15 The Axiom of Choice（+ §16 Zorn's Lemma 的开头）。大纲：set-theory-syllabus.md §4.1（I.7 章）。

本单元的"该学的定理"：选择公理怎么说（choice —— 它是外挂的公理，不是定理）·它给什么（一个选择函数）· 满射因此可以"裂开"（存在右逆）·右逆必是单射（这一半不需要 AC，是纯逻辑）。

写法约定（本单元特有）：AC 的用法是"应用一次公理，再把它的 ∃ 往下顺"——所以本单元到处是 Exists.elim/Exists.intro，前导实参写全（G-73 形状 ②）。

17.2 本单元旗舰：满射可以裂开（用 AC 造右逆）

练习 5surjective_split定理附录解答

"裂开"= 给每个 y 指定一个原像。注意结论仍然是 ∃ g, …（在 Prop 里）—— 我们没有真把 g 取出来（那要 G-58），只是证明了"它存在" ✓

练习 5（L 类，本单元旗舰）：满射 ⇒ 存在右逆。

theorem surjective_split (α β : Type) (f : α → β) (hf : Function.Surjective α β f) :
    ∃ (g : β → α), Function.RightInverse α β g f := by
  sorry
提示 1思路

对关系 P y x := f x = y 用选择公理（A := Set.univ β、B := @Set.univ α）。"对每个 y 都存在原像"正好是满射的定义；把 AC 输出的 ∃ g, ∀ y, …∧ f (g y) = y 里的"落在全集里"丢掉、把"逐点等式"留下，就是右逆。

提示 2目标形态

∃ (g : β → α), Function.RightInverse α β g f。

提示 3关键件

choice（关系取 fun (y : β) (x : α) => f x = y）·Exists.elim（前后两个 ∃ 的谓词形状要对齐——AC 的输出多两个 ∈ Set.univ）·Set.mem_univ · And.right · Exists.intro。

theorem surjective_split (α β : Type) (f : α → β) (hf : Function.Surjective α β f) :
    ∃ (g : β → α), Function.RightInverse α β g f :=
  @Exists.elim (β → α)
    (fun (g : β → α) => ∀ (y : β), y ∈ @Set.univ β → g y ∈ @Set.univ α ∧ f (g y) = y)
    (∃ (g : β → α), Function.RightInverse α β g f)
    (choice β α (@Set.univ β) (@Set.univ α) (fun (y : β) (x : α) => f x = y)
      (fun (y : β) (hy : y ∈ @Set.univ β) =>
        @Exists.elim α (fun (x : α) => f x = y)
          (∃ (x : α), x ∈ @Set.univ α ∧ f x = y) (hf y)
          (fun (x : α) (hx : f x = y) =>
            Exists.intro x
              (And.intro (Set.mem_univ x) hx))))
    (fun (g : β → α)
      (hg : ∀ (y : β), y ∈ @Set.univ β → g y ∈ @Set.univ α ∧ f (g y) = y) =>
      Exists.intro g
        (fun (y : β) =>
          (fun (hgy : g y ∈ @Set.univ α ∧ f (g y) = y) => And.right hgy)
            (hg y (Set.mem_univ y))))
