Unit 70 — Power Set Distributes over Intersection

11 个定理 · 8 道练习 · 10 条提示 · 解答附录

本单元的"该学的定理"：

  • 取用子：A ⊆ B 用在点上 ✓ · 交的两条出 + 一条进 ✓；
  • 旗舰：C ∈ 𝒫A ∩ 𝒫B ↔ C ∈ 𝒫(A ∩ B) ✓（幂集对交分配 ✓——教材里"幂集把交变成交"那条 ✓）；
  • C ∈ 𝒫A ∪ 𝒫B ⇒ C ∈ 𝒫(A ∪ B) ✓（反向为假 ✗ —— 教学点：取 A={0}, B={1} 时 {0,1} ∈ 𝒫(A ∪ B) 却不在任何一边 ✓）；
  • 幂等：C ∈ 𝒫A ∩ 𝒫A ↔ C ∈ 𝒫A ✓ · 只有空集：C ∈ 𝒫∅ ↔ ∀c, c ∉ C ✓

theorem mem_powerset_inter_iff (α : Type) (A B C : Set α) :
    C ∈ (𝒫 A ∩ 𝒫 B) ↔ C ∈ 𝒫 (A ∩ B) :=
  @Iff.intro (C ∈ (𝒫 A ∩ 𝒫 B)) (C ∈ 𝒫 (A ∩ B))
    (fun (h : C ∈ (𝒫 A ∩ 𝒫 B)) =>
      (fun (hu : C ∈ 𝒫 (A ∩ B) ↔ C ⊆ (A ∩ B)) =>
        Iff.mpr hu (fun (c : α) (hc : c ∈ C) =>
          mem_inter_intro α A B c
            (mem_of_subset α C A
              ((fun (hv : C ∈ 𝒫 A ↔ C ⊆ A) =>
                Iff.mp hv (mem_inter_left (Set α) (𝒫 A) (𝒫 B) C h))
                (Set.mem_powerset_iff A C)) c hc)
            (mem_of_subset α C B
              ((fun (hv : C ∈ 𝒫 B ↔ C ⊆ B) =>
                Iff.mp hv (mem_inter_right (Set α) (𝒫 A) (𝒫 B) C h))
                (Set.mem_powerset_iff B C)) c hc)))
        (Set.mem_powerset_iff (A ∩ B) C))
    (fun (h : C ∈ 𝒫 (A ∩ B)) =>
      mem_inter_intro (Set α) (𝒫 A) (𝒫 B) C
        ((fun (hu : C ∈ 𝒫 A ↔ C ⊆ A) =>
          Iff.mpr hu (fun (c : α) (hc : c ∈ C) =>
            mem_inter_left α A B c
              (mem_of_subset α C (A ∩ B)
                ((fun (hv : C ∈ 𝒫 (A ∩ B) ↔ C ⊆ (A ∩ B)) => Iff.mp hv h)

          (Set.mem_powerset_iff A C))
