6.1 三律与三条演示

关系就是"两元谓词"：Rel A B 与 A → B → Prop 是同一个东西（lib/Rel 的定义等式）。Tao 说的"自反 / 对称 / 传递"在这里写成三个 def——它们是词汇，内容全在练习里。注意三律都是"对关系而言"的：同一个 r 换一个论域，三律的真假可以完全不同。

定义Reflexive声明 1
def Reflexive (A : Type) (r : Rel A A) : Prop := ∀ (a : A), r a a
定义Symmetric声明 2
def Symmetric (A : Type) (r : Rel A A) : Prop := ∀ (a b : A), r a b → r b a
定义Transitive声明 3
def Transitive (A : Type) (r : Rel A A) : Prop := ∀ (a b c : A), r a b → r b c → r a c

空关系：没有任何一对元素相关（练习 8 的反例主角；对照单元② 的空集）。

定义EmptyRelation声明 4
def EmptyRelation (A : Type) : Rel A A := fun (a b : A) => False

演示 1：等号本身（"恒等关系"）是自反的——三律的最简例子。

定理demo_eq_reflexive声明 5
theorem demo_eq_reflexive (A : Type) : Reflexive A (fun (a b : A) => a = b) :=
证明 · 2 步 · 3 行
  1.   intro a
  2.   exact @Eq.refl.{1} A a

演示 2：空关系是对称的（前提永远不成立，所以"空洞成立"）。

定理demo_empty_symmetric声明 6
theorem demo_empty_symmetric (A : Type) : Symmetric A (EmptyRelation A) :=
证明 · 2 步 · 3 行
  1.   intro a b h
  2.   exact h

演示 3：空关系是传递的（同款空洞成立）。

定理demo_empty_transitive声明 7
theorem demo_empty_transitive (A : Type) : Transitive A (EmptyRelation A) :=
证明 · 2 步 · 3 行
  1.   intro a b c h1 h2
  2.   exact h1

6.2 逆与复合（lib/Rel 给的两个运算）

练习 1rel_inv_inv定理附录解答

(r ⁻¹) b a ↔ r a b （把两个参数对调）(r • s) a c ↔ ∃ (b : B), r a b ∧ s b c （先走 r 再走 s）两条展开引理 Rel.inv_apply / Rel.comp_apply 在 lib/Rel 里（证明是 Iff.rfl）。

练习 1（T 类）：逆的逆。

theorem rel_inv_inv (A B : Type) (r : Rel A B) :
    (r ⁻¹) ⁻¹ = r := by
  sorry
提示 1思路

把 (r ⁻¹) ⁻¹ 当成函数作用一次——外层换一次 b、a，里层又换回来。

提示 2目标形态

(r ⁻¹) ⁻¹ = r；两边逐元素展开都是同一个 r a b，是定义等式。

提示 3关键件

这是定义等式，不需要任何引理——Eq.refl 那一族里有一条正好能用（别去动 Rel.ext）。

查看解答 定理 · 3 行

逆换两次参数就回到原处，所以这是定义等式：证据就是 r 本身。 目标写成 … = r（记法），rfl 只认头是裸 Eq 的目标，所以交 Eq.refl 的点名项。

theorem rel_inv_inv (A B : Type) (r : Rel A B) :
    (r ⁻¹) ⁻¹ = r := by
  exact @Eq.refl.{1} (Rel A B) r
练习 2rel_comp_assoc定理附录解答

练习 2（T 类）：复合的结合律（本单元的必证题）。

theorem rel_comp_assoc (A B C D : Type) (r : Rel A B) (s : Rel B C) (t : Rel C D) :
    r • (s • t) = (r • s) • t := by
  sorry
提示 1思路

两条关系相等只能请 Rel.ext：逐对 (a, d) 把目标化归成一个 ↔；每个方向都是"拆 ∃ → 换两个证人的出场顺序 → 重新打包"。

提示 2目标形态

Rel.ext 之后是 ∀ (a : A) (d : D), (∃ (b : B), r a b ∧ (∃ (c : C), s b c ∧ t c d)) ↔ (∃ (c : C), (∃ (b : B), r a b ∧ s b c) ∧ t c d)。

提示 3关键件

拆 ∃ 用 cases（或 Exists.elim），两块用 And.left / And.right 取，最后 Exists.intro 按新顺序把证人交回去。

查看解答 定理 · 54 行

两条复合不是定义等式（∃ 要先交换两个证人的出场顺序），所以必须请出 Rel.ext： 逐对 (a, d) 证 ↔，每个方向都做"拆 Exists → 换顺序 → 重新打包"。 Rel.ext 的四条实参在这里点名写全：目标写成 … = … 记法时，apply Rel.ext 会把第二个类型参数解成同名的类型变量（内层 binder 拿到 B 而不是 D）， 所以逐对的 ↔ 由 fun (a : A) => fun (d : D) => … 直接交给 Rel.ext。 拆 ∃ 用 @Exists.elim、打包用点名的 Exists.intro / And.intro （目标两侧都是关系复合的定义，头不在归纳表里，use/constructor 够不着）。

theorem rel_comp_assoc (A B C D : Type) (r : Rel A B) (s : Rel B C) (t : Rel C D) :

    ((r • s) • t)

                      ((r • s) a c)
                      (t c d)

6.3 三律的性质（等价关系的三条法则不是孤立的——先看"逆"对它们做了什么）

练习 3transitive_inv定理附录解答

练习 3（T 类）：逆关系保持传递性（三律性质之一）。

theorem transitive_inv (A : Type) (r : Rel A A) :
    Transitive A (r ⁻¹) ↔ Transitive A r := by
  sorry
提示 1思路

↔ 的两个方向都要做；Transitive A (r ⁻¹) 展开后，三个参数与前提的顺序整个反了过来。

提示 2目标形态

左端展开是 ∀ (a b c : A), r b a → r c b → r c a；右端是 ∀ (a b c : A), r a b → r b c → r a c。

提示 3关键件

先弄清 h 展开后三个参数各占什么位置（它的结论是"第三个参数与第一个参数"），再决定三个位置分别填谁；两个方向写出来会几乎一样。

查看解答 定理 · 7 行

Transitive A (r ⁻¹) 展开后是 ∀ x y z, r y x → r z y → r z x： 想得到 r a c，三个人依次填 c、b、a。两个方向的代码一样（这正是"逆"的作用）。

theorem transitive_inv (A : Type) (r : Rel A A) :
    Transitive A (r ⁻¹) ↔ Transitive A r := by
  exact Iff.intro
    (fun (h : Transitive A (r ⁻¹)) => fun (a b c : A) =>
      fun (hab : r a b) => fun (hbc : r b c) => h c b a hbc hab)
    (fun (h : Transitive A r) => fun (a b c : A) =>
      fun (hab : (r ⁻¹) a b) => fun (hbc : (r ⁻¹) b c) => h c b a hbc hab)

6.4 等价类

等价类就是"与 a 相关的那些 x"（课上点名 EquivClass；Mathlib 里这个集合直接写成 {x | r a x} 这种集合建构式，我们还没有记法，所以立成一个 def）：

EquivClass A r a = fun (x : A) => r a x

注意它是 Set A，所以"x 在 a 的类里"与"r a x"是同一个命题（定义等式）。

定义EquivClass声明 11
def EquivClass (A : Type) (r : Rel A A) (a : A) : Set A := fun (x : A) => r a x
练习 4mem_equivClass_self定理附录解答

练习 4（T 类）：自己的元素在自己的等价类里。

theorem mem_equivClass_self (A : Type) (r : Rel A A) (hrefl : Reflexive A r) (a : A) :
    a ∈ EquivClass A r a := by
  sorry
提示 1思路

类里装的是"与 a 相关的 x"；把 x 取成 a，问题就只剩 a 与 a 相不相关。

提示 2目标形态

a ∈ EquivClass A r a，展开就是 r a a。

提示 3关键件

这一步归自反律管——手里只有 hrefl 一条前提，想想它能对哪个元素说话。

查看解答 定理 · 3 行
theorem mem_equivClass_self (A : Type) (r : Rel A A) (hrefl : Reflexive A r) (a : A) :
    a ∈ EquivClass A r a := by
  exact hrefl a
练习 5equivClass_eq_iff定理附录解答

练习 5（L 类）：等价类相同 ⟺ 两个元素相关（"等价类互斥或相同"里的"相同"那一半）。

theorem equivClass_eq_iff (A : Type) (r : Rel A A)
    (hrefl : Reflexive A r) (hsymm : Symmetric A r) (htrans : Transitive A r) (a b : A) :
    (EquivClass A r a = EquivClass A r b) ↔ r a b := by
  sorry
提示 1思路

← 方向用 Set.ext 逐元素把 r a x 与 r b x 互推；→ 方向把"a 在自己的类里"沿等式搬到 b 的类里去。

提示 2目标形态

(EquivClass A r a = EquivClass A r b) ↔ r a b。

提示 3关键件

← 是 Set.ext + Iff.intro（两个方向分别用 htrans 与 hsymm+htrans）；→ 用 Eq.subst.{1}（动机是"a 属于谁"）+ hsymm。

查看解答 定理 · 15 行

←：Set.ext 逐元素；→ 用 hsymm，← 用 htrans。 →：a 在自己的类里（练习 4），沿等式搬到 b 的类里得到 r b a，再 hsymm。 目标写成 … = …（记法）⇒ apply Set.ext 解不出前导类型参数，所以把 Set.ext A … 当点名项交给 exact（记法是连接符的糖，不是引理名的糖）。

theorem equivClass_eq_iff (A : Type) (r : Rel A A)
    (hrefl : Reflexive A r) (hsymm : Symmetric A r) (htrans : Transitive A r) (a b : A) :
    (EquivClass A r a = EquivClass A r b) ↔ r a b := by
  exact @Iff.intro
    ((EquivClass A r a) = (EquivClass A r b))
    (r a b)
    (fun (h : (EquivClass A r a) = (EquivClass A r b)) =>
      hsymm b a
        (@Eq.subst.{1} (Set A) (fun (X : Set A) => a ∈ X)
          (EquivClass A r a) (EquivClass A r b) h (hrefl a)))
    (fun (hab : r a b) =>
      Set.ext (EquivClass A r a) (EquivClass A r b)
        (fun (x : A) => Iff.intro
          (fun (hax : r a x) => htrans b a x (hsymm a b hab) hax)
          (fun (hbx : r b x) => htrans a b x hab hbx)))

6.5 划分 ↔ 等价关系

classes A r 是"等价类全体"：C 属于它，当且仅当 C 是某个 a 的等价类。IsPartition 是"划分"（Mathlib 的 Setoid.IsPartition 三条）：① 没有空块（写成"不是空集"，不是"有元素"——从 ① 里取不出见证）；② 覆盖（每个元素落在某块里）；③ 两块不相等就不交。⚠ 第 ③ 条为什么写成"不相等 ⇒ 无公共元素"，而不是"或者相等、或者不交"？后者要排中律（先判定两块相不相等），我们没有；前者是构造性的，而且更强：一旦有公共元素，两块就必然相等。这一条正是"划分 ↔ 等价关系"的接缝。

        (@Eq.subst.{1} (Set A) (fun (X : Set A) => a ∈ X)
          (EquivClass A r a) (EquivClass A r b) h (hrefl a)))
    (fun (hab : r a b) =>
      Set.ext (EquivClass A r a) (EquivClass A r b)
        (fun (x : A) => Iff.intro
          (fun (hax : r a x) => htrans b a x (hsymm a b hab) hax)
          (fun (hbx : r b x) => htrans a b x hab hbx)))
练习 6 · classes_isPartition 定理

① 拆开 C ∈ classes A r（一个 ∃）拿到 a 与 C = [a]；若 C = ∅，则 a ∈ [a] = ∅，撞 Set.notMem_empty。 ② 覆盖：证人取 [a] 本身，它属于 classes（证人 a、证据 Eq.refl），且 a ∈ [a]。 ③ 不交：拆两层 classes 拿到 a、b 与 C = [a]、D = [b]，再拆公共元素 x； r a x 与 r b x 经 hsymm/htrans 逼出 r a b，练习 5 把它变成 [a] = [b]， 于是 C = D，与 hne 相撞。 IsPartition 的头是 def（不在归纳表里）⇒ 三条用点名的 And.intro 拆， 每条里的 ∃ 用 @Exists.elim 拆、Exists.intro 打包。

theorem classes_isPartition (A : Type) (r : Rel A A)
    (hrefl : Reflexive A r) (hsymm : Symmetric A r) (htrans : Transitive A r) :
    IsPartition A (classes A r) := by
  exact @And.intro
    (∀ (C : Set A), C ∈ (classes A r) → ¬ (C = (∅)))
    ((∀ (a : A),
            ∃ (C : Set A), (C ∈ (classes A r)) ∧ (a ∈ C)) ∧
         (∀ (C D : Set A), C ∈ (classes A r) → D ∈ (classes A r) →
            ¬ (C = D) →
            ¬ (∃ (x : A), (x ∈ C) ∧ (x ∈ D))))
    -- ① 无空块
    (fun (C : Set A) => fun (hC : C ∈ (classes A r)) =>
      @Exists.elim A
        (fun (a : A) => C = (EquivClass A r a))
        (¬ (C = (∅)))
        hC
        (fun (a : A) => fun (ha : C = (EquivClass A r a)) =>
          fun (hEmpty : C = (∅)) =>
            let hEmpty2 : (EquivClass A r a) = (∅) :=
              @Eq.trans.{1} (Set A) (EquivClass A r a) C (∅)
                (@Eq.symm.{1} (Set A) C (EquivClass A r a) ha) hEmpty;
            let hBad : a ∈ (∅) :=
              @Eq.subst.{1} (Set A) (fun (X : Set A) => a ∈ X)
                (EquivClass A r a) (∅) hEmpty2 (hrefl a);
            Set.notMem_empty a hBad))
    (@And.intro
      (∀ (a : A),
          ∃ (C : Set A), (C ∈ (classes A r)) ∧ (a ∈ C))
      (∀ (C D : Set A), C ∈ (classes A r) → D ∈ (classes A r) →
         ¬ (C = D) →
         ¬ (∃ (x : A), (x ∈ C) ∧ (x ∈ D)))
      -- ② 覆盖
      (fun (a : A) =>
  -- soko:notation-ok: 严格档要求显式前导参数（strict @）
        @Exists.intro (Set A) (fun (C : Set A) => (C ∈ (classes A r)) ∧ (a ∈ C)) (EquivClass A r a)
          (@And.intro
            ((EquivClass A r a) ∈ (classes A r))
            (a ∈ (EquivClass A r a))
  -- soko:notation-ok: 严格档要求显式前导参数（strict @）
            (@Exists.intro A (fun (x : A) => (EquivClass A r a) = (EquivClass A r x)) a (@Eq.refl (Set A) (EquivClass A r a)))
            (hrefl a)))
      -- ③ 不相等就不交
      (fun (C D : Set A) =>
        fun (hC : C ∈ (classes A r)) =>
        fun (hD : D ∈ (classes A r)) =>
        fun (hne : ¬ (C = D)) =>
        fun (hCommon : ∃ (x : A), (x ∈ C) ∧ (x ∈ D)) =>
          @Exists.elim A
            (fun (a : A) => C = (EquivClass A r a))
            False
            hC
            (fun (a : A) => fun (ha : C = (EquivClass A r a)) =>
              @Exists.elim A
                (fun (b : A) => D = (EquivClass A r b))
                False
                hD
                (fun (b : A) => fun (hb : D = (EquivClass A r b)) =>
                  @Exists.elim A
                    (fun (x : A) => (x ∈ C) ∧ (x ∈ D))
                    False
                    hCommon
                    (fun (x : A) => fun (hx : (x ∈ C) ∧ (x ∈ D)) =>
                      let rax : r a x :=
                        @Eq.subst.{1} (Set A) (fun (X : Set A) => x ∈ X)
                          C (EquivClass A r a) ha
                          (And.left hx);
                      let rbx : r b x :=
                        @Eq.subst.{1} (Set A) (fun (X : Set A) => x ∈ X)
                          D (EquivClass A r b) hb
                          (And.right hx);
                      let rab : r a b := htrans a x b rax (hsymm b x rbx);
                      let hab : (EquivClass A r a) = (EquivClass A r b) :=
                        @Iff.mpr
                          ((EquivClass A r a) = (EquivClass A r b))
                          (r a b)
                          (equivClass_eq_iff A r hrefl hsymm htrans a b)
                          rab;
                      let hCD : C = D :=
                        @Eq.trans.{1} (Set A) C (EquivClass A r b) D
                          (@Eq.trans.{1} (Set A) C (EquivClass A r a) (EquivClass A r b) ha hab)
                          (@Eq.symm.{1} (Set A) D (EquivClass A r b) hb);
                      hne hCD)))))
练习 7 · nearStep_counterexample 定理

自反：第一个析取项 a = a。对称：三个析取项分别换边（第一个用 Eq.symm）。 非传递：假设传递，作用在 0、1、2 上得到 nearStep 0 2，再逐条否掉它的三个析取项。 nearStep 是 def ⇒ 目标上的三个析取项用点名的 @Or.inl 交； 假设上的析取用点名的 @Or.elim 拆（nearStep 会被 delta 展开到 Or）。 三个析取项的否证全部落到 Nat.zero_ne_succ / Nat.succ.inj 上。

theorem nearStep_counterexample :
    Reflexive Nat nearStep ∧ (Symmetric Nat nearStep ∧ ¬ (Transitive Nat nearStep)) := by
  exact And.intro
    (fun (a : Nat) =>
      @Or.inl (a = a)
        (((Nat.succ a) = a) ∨ (a = (Nat.succ a)))
        (@Eq.refl.{1} Nat a))
    (And.intro
      (fun (a b : Nat) => fun (h : nearStep a b) =>
        @Or.elim (a = b)
          (((Nat.succ a) = b) ∨ (a = (Nat.succ b)))
          (nearStep b a)
          (fun (hab : a = b) =>
            @Or.inl (b = a)
              (((Nat.succ b) = a) ∨ (b = (Nat.succ a)))
              (@Eq.symm.{1} Nat a b hab))
          (fun (h2 : ((Nat.succ a) = b) ∨ (a = (Nat.succ b))) =>
            @Or.elim ((Nat.succ a) = b) (a = (Nat.succ b))
              (nearStep b a)
              (fun (h2a : (Nat.succ a) = b) =>
                @Or.inr (b = a)
                  (((Nat.succ b) = a) ∨ (b = (Nat.succ a)))

              (fun (h2b : a = (Nat.succ b)) =>

                  (((Nat.succ b) = a) ∨ (b = (Nat.succ a)))
                  (@Or.inl ((Nat.succ b) = a) (b = (Nat.succ a))  -- soko:notation-ok: 目标经 intro 展开（非语句层）后期望类型传不到（引擎边界）

              h;

          @Or.inr (0 = 1)
            (((Nat.succ 0) = 1) ∨ (0 = (Nat.succ 1)))
            (@Or.inl ((Nat.succ 0) = 1) (0 = (Nat.succ 1))  -- soko:notation-ok: 目标经 intro 展开（非语句层）后期望类型传不到（引擎边界）
