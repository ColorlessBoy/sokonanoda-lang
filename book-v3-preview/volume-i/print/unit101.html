theorem subset_empty_elim (α : Type) (A : Set α) (h : A ⊆ ∅) :
    ∀ (x : α), x ∈ A → False :=
  fun (x : α) (hx : x ∈ A) =>
    (fun (hu : x ∈ ∅ ↔ False) => Iff.mp hu (h x hx))
      (Set.mem_empty_iff_false x)

编写注记 · 教材对照与课程边界（5 条）

靶子（教材）：Enderton《Elements of Set Theory》§1.2 / §1.3 ·Halmos《Naive Set Theory》§2 / §3。大纲 §4.1（回到基础层收口 ✓）。

⚠ 一条边界（值得记住 ✓）："含于空集 ⇒ A ≼ B"在这里证不出来 ✗ ——因为 LeOn 要求一个全函数 α → β ✓，而 A ⊆ ∅ 时 A 无成员 ✓ ⇒ 没有 β 的元素就造不出映射 ✗（构造性框架不含"从空集到任意集合的函数" ✓，除非已知 β 非空 ✓）。本单元只做点态结论 ✓，如实标注 ✓。

⚠ False.elim 要写全目标 ✓：False.elim (目标命题) h ✓（诊断原文："把参数写全" ✓） -- soko:notation-ok: False.elim 的目标位（手册边界）—— 只写 False.elim h 会报"隐式参数补不出来" ✗。

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 三样：lib.Set · lib.Rel · lib.Order。
