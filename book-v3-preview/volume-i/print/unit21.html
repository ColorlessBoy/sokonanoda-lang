靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§2.2 Arbitrary Unions and Intersections；Halmos《Naive Set Theory》§9 Families。大纲：set-theory-syllabus.md §4.1（I.9 章第一个单元）。

本单元的"该学的定理"：广义并/交的成员刻画（存在 vs 全称）·两条刻画定理（⋃₀ F ⊆ B ⟺ 族里每个 A 都 ⊆ B；B ⊆ ⋂₀ F ⟺ 族里每个 A 都 ⊇ B）·单调 / 反单调（F ⊆ G 时 ⋃₀ 单调、⋂₀ 反单调 —— 这是本单元最反直觉的一条）。

写法约定（本单元特有）：目标几乎全是 X ⊆ Y（定义头）⇒ 一律 fun (x : α) (hx : x ∈ X) => … 起手；而"把 ⊆ 假设当函数用"要先 fun (hs : ∀ z, z ∈ X → z ∈ Y) => … 把类型写出来（G-73 形状 ①）。Set.subset_sUnion / Set.sInter_subset 的结论在库里写成展开形态（∃/∀），因为期望类型是 Set.sUnion 这个定义头时构造子解析不出来（见 lib/SUnion 的注释）✓

21.1 两个定义：⋃₀ F 与 ⋂₀ F

读法（对偶）：⋃₀ F 是"存在一个 A ∈ F 装得下 x"；⋂₀ F 是"每个 A ∈ F 都装得下 x" —— 存在 vs 全称，广义并交的一切都从这儿来 ✓

21.2 本单元旗舰：两条刻画定理

练习 3sUnion_subset_elim定理附录解答

⋃₀ F ⊆ B ⟺ 族里每个 A 都 ⊆ B（存在那一侧：把见证喂进去）B ⊆ ⋂₀ F ⟺ 族里每个 A 都 ⊇ B（全称那一侧：把假设喂给每个成员）

练习 3（L 类）：从"广义并包含于 B"读出族里每个成员都包含于 B。

theorem sUnion_subset_elim (α : Type) (F : Set (Set α)) (B : Set α)
    (h : (⋃₀ F) ⊆ B) (A : Set α) (hA : A ∈ F) : A ⊆ B := by
  sorry
提示 1思路

任取 A ∈ F 与 x ∈ A；由练习 1 得 x ∈ ⋃₀ F，再由假设送到 B。

提示 2目标形态

(⋃₀ F) ⊆ B → A ∈ F → A ⊆ B。

提示 3关键件

练习 1 · 那条 ⊆ 假设（先 λ 绑定，G-73 形状 ①）。

查看解答 定理 · 4 行

theorem sUnion_subset_intro (α : Type) (F : Set (Set α)) (B : Set α)

提示 1思路

把 x ∈ ⋃₀ F 读成"存在 A ∈ F 且 x ∈ A"（存在量化：拆开它），把那个 A 的包含关系用上。

提示 3关键件

21.3 单调与反单调

练习 7sUnion_mono定理附录解答

练习 7（L 类）：广义并对族是单调的 —— 族变大，并变大。

theorem sUnion_mono (α : Type) (F G : Set (Set α)) (h : F ⊆ G) : (⋃₀ F) ⊆ (⋃₀ G) := by
  sorry
提示 1思路

x ∈ ⋃₀ F 拆出一个见证 A ∈ F 且 x ∈ A；A 也在 G 里（族包含），于是同一个 A 就是 ⋃₀ G 的见证。

提示 2目标形态

F ⊆ G → (⋃₀ F) ⊆ (⋃₀ G)。

提示 3关键件

Set.mem_sUnion_iff（正向）· Exists.elim/Exists.intro（前导实参写全）·族包含假设（先 λ 绑定）· Set.subset_sUnion。

    (fun (hx' : ∃ (A : Set α), A ∈ F ∧ x ∈ A) =>

          Set.subset_sUnion α G A
            ((fun (hu : ∀ (C : Set α), C ∈ F → C ∈ G) => hu A (And.left hA)) h) x (And.right hA)))

练习 8sInter_anti定理附录解答

练习 8（D 类，本单元最反直觉的一条）：广义交对族是"反"单调的 ——族变大，交变小（成员越多，能同时落在所有成员里的点越少）。

theorem sInter_anti (α : Type) (F G : Set (Set α)) (h : F ⊆ G) : (⋂₀ G) ⊆ (⋂₀ F) := by
  sorry
提示 1思路

任取 x ∈ ⋂₀ G（它在 G 的每个成员里）；要证它在 F 的每个成员里—— 而 F 的成员都是 G 的成员，喂给假设即可。

提示 2目标形态

F ⊆ G → (⋂₀ G) ⊆ (⋂₀ F)（注意方向与练习 7 相反）。

提示 3关键件

⋂₀ 的展开形态（两侧都是 ∀）· 族包含假设（先 λ 绑定）·把 G 那一侧的全称当成函数用。

查看解答 定理 · 6 行
theorem sInter_anti (α : Type) (F G : Set (Set α)) (h : F ⊆ G) : (⋂₀ G) ⊆ (⋂₀ F) :=

    (fun (hs : ∀ (A : Set α), A ∈ F → x ∈ A) => hs)
      (fun (A : Set α) (hA : A ∈ F) =>
        (fun (hu : ∀ (C : Set α), C ∈ G → x ∈ C) => hu A
