本单元的"该学的定理"（把"完备格"拆成可证的点态式 ✓）：

  • 取用子：B ∈ 𝒫A ↔ B ⊆ A ✓ · ∅ ⊆ A（bottom ✓）· A ∈ 𝒫A（top ✓）；
  • 旗舰一：⋃(𝒫A) ⊆ A ✓ · 旗舰二：A ⊆ ⋃(𝒫A) ✓（合起来 ⋃(𝒫A) = A ✓）；
  • ⋂(𝒫A) ⊆ A ✓（交回去也不超过自己 ✓）；
  • 单调：A ⊆ B ⇒ C ∈ 𝒫A ⇒ C ∈ 𝒫B ✓
