本单元的"该学的定理"：

  • 核定义：kernel f a b := f a = f b ✓（同一条纤维上的点 ✓）；
  • 自反 / 对称 / 传递 ✓ ⇒ 旗舰：IsEquivalence α (kernel f) ✓（每个函数都给出一个等价关系 ✓ —— 这就是"纤维分解" ✓）；
  • 与库里的等价类接口接上：Rel.EquivClass α (kernel f) a b ↔ f a = f b ✓；
  • 有共同像点 ⇒ 同核 ✓ · a = b ⇒ 同核 ✓ · 像点不等 ⇒ 不同核 ✓

theorem kernel_isEquivalence (α : Type) (β : Type) (f : α → β) :
    IsEquivalence α (kernel α β f) :=
  (fun (hu : IsEquivalence α (kernel α β f) ↔
      Reflexive α (kernel α β f) ∧ Symmetric α (kernel α β f) ∧ Transitive α (kernel α β f)) =>
    Iff.mpr hu (And.intro
      (kernel_refl α β f) (And.intro (kernel_symm α β f) (kernel_trans α β f))))
    (isEquivalence_def α (kernel α β f))

编写注记 · 教材对照与课程边界（5 条）

靶子（教材）：Enderton《Elements of Set Theory》§3.3（"the kernel of a function"）·Halmos《Naive Set Theory》§10。大纲 §4.1（I.10 章补强 —— 接单元㉕ 等价关系 ✓）。

⚠ 为什么值得单列 ✓：核关系是"函数 → 等价关系"这座桥 ✓ ——单元㉕㉖㉗ 讲的是"等价关系 → 商集" ✓，本单元补上另一半（函数给出等价关系 ✓），两边合起来就是教材里 §3.3 + §5 的完整往返 ✓。

⚠ 写法要点 ✓：a = b ⇒ kernel f a b 这件小事不用 congrArg ✗（它的宇宙层级是手册明说的边界 ✓）⇒ 改用 rel_subst_right（沿等式把关系搬过去 ✓）。

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 三样：lib.Set · lib.Rel · lib.Order。
