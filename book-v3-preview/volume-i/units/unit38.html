靶子（教材，逐条查过目录页）：Halmos《Naive Set Theory》§10 与 §14；Enderton《Elements of Set Theory》§7.1 Orderings。大纲：set-theory-syllabus.md §4.1（I.13 章第三个单元 —— 把单元⑬ 的序论用单元㊱㊲ 的代数语言重述一遍）。

本单元的"该学的定理"（把"反对称/非自反/非对称/偏序"翻译成代数式子）：

  • 反对称 ⟺ "两个方向同时成立 ⇒ 相等"（r ∩ r ⁻¹ ⊆ idRel 的逐点形态）；
  • 非自反 ⟺ 恒等关系那份被排除；非对称 ⟺ 两个方向不能同时成立；
  • 旗舰：非自反 + 传递 ⇒ 非对称（经典的"从 a < b 与 b < a 用传递性逼出 a < a"）；
  • 偏序 ⟺ 三条代数条件（idRel ⊆ r · 反对称 · r • r ⊆ r），反方向也成立 ✓

38.0 画布给的新词汇：恒等关系 与 非对称

定义idRel声明 1
def idRel (α : Type) : Rel α α :=
  fun (a : α) (b : α) => a = b

读法：Asymmetric α r = "两个方向不能同时成立" ✓ 它比"反对称"强：反对称允许"两个方向同时成立时两边相等"，非对称则一律不允许 ✓

定义Asymmetric声明 2
def Asymmetric (α : Type) (r : Rel α α) : Prop :=
  ∀ (a : α) (b : α), r a b → ¬ (r b a)

theorem antisymm_algebraic (α : Type) (r : Rel α α) :
    Antisymmetric α r ↔ ∀ (a : α) (b : α), r a b → (r ⁻¹) a b → (idRel α) a b :=
  @Iff.intro (Antisymmetric α r)
    (∀ (a : α) (b : α), r a b → (r ⁻¹) a b → (idRel α) a b)
    (fun (h : Antisymmetric α r) => fun (a : α) => fun (b : α) =>
      fun (hab : r a b) => fun (hba : (r ⁻¹) a b) =>
        (fun (hu : ∀ (x : α) (y : α), r x y → r y x → @Eq.{1} α x y) =>  -- soko:notation-ok: G-30/G-73 形状 ②③：前导实参或 `Eq` 层级在这些位置补不出来

theorem partialOrder_trans_algebraic (α : Type) (r : Rel α α) (h : IsPartialOrder α r) :
    ∀ (a : α) (c : α), (r • r) a c → r a c :=
  fun (a : α) => fun (c : α) => fun (hac : (r • r) a c) =>
    @Exists.elim α (fun (b : α) => r a b ∧ r b c) (r a c) hac
      (fun (b : α) (hb : r a b ∧ r b c) =>

练习 10algebraic_is_partialOrder定理附录解答

练习 10（D 类，本单元旗舰）：三条代数条件合起来 ⇒ 偏序（反方向）。

theorem algebraic_is_partialOrder (α : Type) (r : Rel α α)
    (h1 : ∀ (a : α), (idRel α) a a → r a a)
    (h2 : ∀ (a : α) (b : α), r a b → (r ⁻¹) a b → (idRel α) a b)
    (h3 : ∀ (a : α) (c : α), (r • r) a c → r a c) :
    IsPartialOrder α r := by
  sorry
提示 1思路

用智能构造子打包三条 —— ①自反：条件 1 用在 a = a 上；②反对称：条件 2 交出等式；③传递：先造出 ∃ b, r a b ∧ r b c（见证取 b）再交给条件 3。

提示 2目标形态

`(∀ a, idRel a a → r a a) → (∀ a b, r a b → (r ⁻¹) a b → idRel a b) →

(∀ac,(r•r)ac→rac)→IsPartialOrderαr

isPartialOrder_intro（参数：论域 · 关系 · 自反 · 反对称 · 传递）·Exists.intro/And.intro（前导实参写全）· Eq.refl ✓ ⚠ 不要把三条打包成一个巨大的 ↔（右边套三层 ∧ + ∀）—— 实测那个形态写不出来，本单元因此拆成"练习 7–9 + 练习 10"四条 ✓

theorem algebraic_is_partialOrder (α : Type) (r : Rel α α)
    (h1 : ∀ (a : α), (idRel α) a a → r a a)
    (h2 : ∀ (a : α) (b : α), r a b → (r ⁻¹) a b → (idRel α) a b)
    (h3 : ∀ (a : α) (c : α), (r • r) a c → r a c) :
    IsPartialOrder α r :=
  isPartialOrder_intro α r
    (fun (a : α) => h1 a (@Eq.refl.{1} α a))
    (fun (a : α) (b : α) => fun (hab : r a b) => fun (hba : r b a) => h2 a b hab hba)
    (fun (a : α) (b : α) (c : α) => fun (hab : r a b) => fun (hbc : r b c) =>
      h3 a c (Exists.intro b
        (And.intro hab hbc)))
编写注记 · 教材对照与课程边界（3 条）

⚠ 实测的三条写法教训（都写进 hint）：① 一个巨大的 ↔（右边还套三层 ∧）写不出来（单元㊲ 已记）⇒ 拆成"三个取用子 + 一个反方向"四条小定理（本单元的偏序部分就是这么落地的）；② Iff.mp / Iff.mpr 在这些位置解不出（「期望 Sort(1)，实际是 Rel α α」）⇒ 取用子直接重证更稳；③ 新发现（本单元实测）：And.right h 单独写没问题，但把它直接当函数用在实参位（And.right h (Eq.refl …)）会判红（「期望 Sort(0)，实际是 strictOf α r a a」） -- soko:notation-ok: 这里是反例式说明（讲"续应用会判红"），不是要写的代码 ⇒ 中间套一层 λ：(fun (hu : ¬ (a = a)) => hu (Eq.refl a)) (And.right h) ✓
