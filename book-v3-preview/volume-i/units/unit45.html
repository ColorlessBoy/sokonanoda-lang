111 关系的单值性与函数的图

Unit 45 — Single-Valued Relations and Graphs of Functions

4 个定义 · 13 个定理 · 10 道练习 · 30 条提示 · 解答附录

打印 / PDF 本单元

↑ 目录

靶子（教材，逐条查过目录页）：Halmos《Naive Set Theory》§8–10（functions as relations / inverses and composites）；Enderton《Elements of Set Theory》§3.3 的 "functions as relations" 一段。大纲：set-theory-syllabus.md §4.1（I.13 章收尾 —— 用单元㊱㊲ 的代数语言 把「函数 = 单值 + 全的关系」这句话证出来 ✓）。

本单元的"该学的定理"：

  • 单值与全两条定义 + 取用子；函数的图单值且全；
  • 旗舰一：单值 ⟺ r ⁻¹ • r ⊆ idRel —— "同一个点的两个像相等" ✓
  • 旗舰二（对偶）：r ⁻¹ 单值 ⟺ r • r ⁻¹ ⊆ idRel —— "有共同像的两点相等"= 图单射 ✓（注意这两条容易写反：⁻¹ 放左边管"单值"、放右边管"单射"✓）
  • 单值/全 在复合下保持；恒等关系单值；函数图的复合 = 复合函数的图 ✓

45.0 画布给的四个新词汇

idRel：恒等关系（单元㊱ 起就在用 ✓）SingleValued r：单值 —— 同一个点的两个像相等（函数的图满足它 ✓）TotalRel r：全 —— 每个点都有像 ⚠ 注意不叫 Total：那个名字 lib/Order 已经用了 ✗ graph f：函数 f 的图（fun a b => f a = b）✓

定义idRel声明 1
def idRel (α : Type) : Rel α α :=
  fun (a : α) (b : α) => a = b
定义SingleValued声明 2
def SingleValued (α β : Type) (r : Rel α β) : Prop :=
  ∀ (a : α) (b : β) (b1 : β), r a b → r a b1 → b = b1
定义TotalRel声明 3
def TotalRel (α β : Type) (r : Rel α β) : Prop :=
  ∀ (a : α), ∃ (b : β), r a b
定义graph声明 4
def graph (α β : Type) (f : α → β) : Rel α β :=
  fun (a : α) (b : β) => (f a) = b

45.3 旗舰：单值 ⟺ r ⁻¹ • r ⊆ idRel（与它的对偶）

练习 5singleValued_iff_inv_comp定理附录解答

练习 5（L 类，本单元旗舰）：单值 ⟺ r ⁻¹ • r ⊆ idRel。

theorem singleValued_iff_inv_comp (α β : Type) (r : Rel α β) :
    SingleValued α β r ↔ ∀ (b b1 : β), (r ⁻¹ • r) b b1 → (idRel β) b b1 := by
  sorry
提示 1思路

逐点看 (r ⁻¹ • r) b b1 就是 ∃ a, r a b ∧ r a b1 ——→：拆 ∃ 得同一个点的两个像 ⇒ 用单值性 ⇒ b = b1；←：给定 r a b 与 r a b1，造出那个 ∃（见证取 a）⇒ 假设给出 b = b1。

提示 2目标形态

SingleValued r ↔ ∀ b b1, (r ⁻¹ • r) b b1 → (idRel β) b b1。

提示 3关键件

Iff.intro（前导 Prop 实参写全）· Exists.elim/Exists.intro（写全）·练习 1 · And.left/And.right ✓ ⚠ ⁻¹ 放左边管"单值"（同一个点的两个像），放右边管"单射"（练习 6）——这两条极易写反 ✗

查看解答 定理 · 13 行
theorem singleValued_iff_inv_comp (α β : Type) (r : Rel α β) :
    SingleValued α β r ↔ ∀ (b b1 : β), (r ⁻¹ • r) b b1 → (idRel β) b b1 :=
  @Iff.intro (SingleValued α β r) (∀ (b b1 : β), (r ⁻¹ • r) b b1 → (idRel β) b b1)
    (fun (h : SingleValued α β r) => fun (b : β) => fun (b1 : β) =>
      fun (hbb : (r ⁻¹ • r) b b1) =>
        @Exists.elim α (fun (a : α) => r a b ∧ r a b1) (@Eq.{1} β b b1) hbb  -- soko:notation-ok: G-30/G-73 形状 ②③：前导实参或 `Eq` 层级在这些位置补不出来
          (fun (a : α) (ha : r a b ∧ r a b1) =>
            singleValued_apply α β r h a b b1 (And.left ha) (And.right ha)))
    (fun (h : ∀ (b b1 : β), (r ⁻¹ • r) b b1 → (idRel β) b b1) =>
      fun (a : α) => fun (b : β) => fun (b1 : β) =>
        fun (h1 : r a b) => fun (h2 : r a b1) =>
          h b b1 (Exists.intro a
            (And.intro h1 h2)))
练习 6inv_singleValued_iff_comp_inv定理附录解答

练习 6（L 类，旗舰的对偶）：r ⁻¹ 单值 ⟺ r • r ⁻¹ ⊆ idRel。

theorem inv_singleValued_iff_comp_inv (α β : Type) (r : Rel α β) :
    SingleValued β α (r ⁻¹) ↔ ∀ (a a1 : α), (r • r ⁻¹) a a1 → (idRel α) a a1 := by
  sorry
提示 1思路

与练习 5 逐字对偶（把 r 换成 r ⁻¹、把两个点的位置对调）——逐点看 (r • r ⁻¹) a a1 就是 ∃ b, r a b ∧ r a1 b（有共同的像）。

提示 2目标形态

SingleValued (r ⁻¹) ↔ ∀ a a1, (r • r ⁻¹) a a1 → (idRel α) a a1。

提示 3关键件

Iff.intro · Exists.elim/Exists.intro · 练习 1 ✓ ⚠ 两处"定义头"的坑：(r ⁻¹) b a 与 r a b 定义上相同，但别套 λ 去"换形"（fun (hu : r a b) => hu 反而判红 ✗）—— 直接把证据交出去即可 ✓

查看解答 定理 · 13 行
theorem inv_singleValued_iff_comp_inv (α β : Type) (r : Rel α β) :
    SingleValued β α (r ⁻¹) ↔ ∀ (a a1 : α), (r • r ⁻¹) a a1 → (idRel α) a a1 :=
  @Iff.intro (SingleValued β α (r ⁻¹)) (∀ (a a1 : α), (r • r ⁻¹) a a1 → (idRel α) a a1)
    (fun (h : SingleValued β α (r ⁻¹)) => fun (a : α) => fun (a1 : α) =>
      fun (haa : (r • r ⁻¹) a a1) =>
        @Exists.elim β (fun (b : β) => r a b ∧ (r ⁻¹) b a1) (@Eq.{1} α a a1) haa  -- soko:notation-ok: G-30/G-73 形状 ②③：前导实参或 `Eq` 层级在这些位置补不出来
          (fun (b : β) (hb : r a b ∧ (r ⁻¹) b a1) =>
            singleValued_apply β α (r ⁻¹) h b a a1 (And.left hb) (And.right hb)))
    (fun (h : ∀ (a a1 : α), (r • r ⁻¹) a a1 → (idRel α) a a1) =>
      fun (b : β) => fun (a : α) => fun (a1 : α) =>
        fun (h1 : (r ⁻¹) b a) => fun (h2 : (r ⁻¹) b a1) =>
          h a a1 (Exists.intro b
            (And.intro h1 h2)))

45.4 复合 · 恒等 · 图的复合

练习 7singleValued_comp定理附录解答

练习 7（L 类）：单值的复合还是单值。

theorem singleValued_comp (α β γ : Type) (r : Rel α β) (s : Rel β γ)
    (hr : SingleValued α β r) (hs : SingleValued β γ s) :
    SingleValued α γ (r • s) := by
  sorry
提示 1思路

两条 (r • s) a · 的成员各拆出一个中间点 b、b1；先用 r 的单值性得 b = b1，再把 s b c 沿这个等式搬到 s b1 c，最后用 s 的单值性收尾。

提示 2目标形态

SingleValued r → SingleValued s → SingleValued (r • s)。

提示 3关键件

两层 Exists.elim · 练习 1 · 搬运引理 rel_subst_right：要改的是 s 的第一个坐标 ⇒ 关系取翻过来的 fun u v => s v c ✓（关系取 fun u v => s u c 会判红 ✗ —— 单元㊳ 的实测教训）· And.left/And.right ✓

查看解答 定理 · 14 行
theorem singleValued_comp (α β γ : Type) (r : Rel α β) (s : Rel β γ)
    (hr : SingleValued α β r) (hs : SingleValued β γ s) :
    SingleValued α γ (r • s) :=
  fun (a : α) => fun (c : γ) => fun (c1 : γ) =>
    fun (h1 : (r • s) a c) => fun (h2 : (r • s) a c1) =>
      @Exists.elim β (fun (b : β) => r a b ∧ s b c) (@Eq.{1} γ c c1) h1  -- soko:notation-ok: G-30/G-73 形状 ②③：前导实参或 `Eq` 层级在这些位置补不出来
        (fun (b : β) (hb : r a b ∧ s b c) =>
          @Exists.elim β (fun (b1 : β) => r a b1 ∧ s b1 c1) (@Eq.{1} γ c c1) h2  -- soko:notation-ok: G-30/G-73 形状 ②③：前导实参或 `Eq` 层级在这些位置补不出来
            (fun (b1 : β) (hb1 : r a b1 ∧ s b1 c1) =>
              hs b1 c c1
                (rel_subst_right β (fun (u : β) (v : β) => s v c) b b b1
                  (singleValued_apply α β r hr a b b1 (And.left hb) (And.left hb1))
                  (And.right hb))
                (And.right hb1)))
