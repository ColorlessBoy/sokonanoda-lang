48 偏序、全序与严格序

Unit 13 — Partial, Linear and Strict Orders

14 个定理 · 11 道练习 · 33 条提示 · 解答附录

打印 / PDF 本单元

↑ 目录

靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§3.7 Ordering Relations + §7.1 Partial Orderings；Halmos《Naive Set Theory》§14 Order。大纲：docs/design/set-theory-syllabus.md §4.1（I.5 章的第一个单元）。

本单元的"该学的定理"：偏序 = 自反 + 反对称 + 传递（三条各自是一条取用子）；全序比偏序多一条可比性；严格序把"相等那一份"切掉；而 ⊆ 是 Set α 上的标准偏序，却不是全序 —— 这是本章的必破题。

本单元只 import 三样：lib.Order（序的词汇与取用子）· lib.Set（⊆ 与 {a}）· 以及 prelude（∧ ∨ ¬ → = ≠ 与 ∀，任何文件直接可用）。记法不用自己声明：⊆/∈/{a} 由 lib.Set 提供。

13.1 序的词汇：四个序类，六个性质

读法（lib/Order 文件头有完整出处）：

  • r : α → α → Prop 是一个二元关系（r a b 读作 "a 排在 b 前面"）；
  • 非严格序读 a ≤ b，严格序读 a < b —— 下面全用 r 写，不含任何记法糖；
  • 偏序 = 自反 + 反对称 + 传递；全序 = 偏序 + 可比；严格序 = 非自反 + 传递。

13.3 严格部分 / 非严格部分

练习 4strictOf_irrefl定理附录解答

strictOf α r a b = "r a b 且 a ≠ b"（切掉相等那一份）；nonstrictOf α r a b = "r a b 或 a = b"（把相等那一份补回来）。两条展开引理是演示里的 demo_strictOf_apply 与下面会用到的 nonstrictOf_apply。

练习 4（L 类）：严格部分非自反 —— 偏序的严格部分里，没有一个元素排在自己前面。

theorem strictOf_irrefl (α : Type) (r : α → α → Prop)
    (h : IsPartialOrder α r) : Irreflexive α (strictOf α r) := by
  sorry
提示 1思路

把"严格排在自前面"展开成合取，再拿它的右支（不相等）去撞自反性。

提示 2目标形态

Irreflexive α (strictOf α r)，展开后是 ∀ a, ¬ (strictOf α r a a)。

提示 3关键件

And.right 取出 a ≠ a；a ≠ a 是一个函数（吃 a = a 吐 False），喂给它的是自反那一份。注意：(And.right h) (…) 这种写法在本语言里判红，要先 fun (hne : a ≠ a) => … 把类型写出来再应用（台账 G-73）。

查看解答 定理 · 4 行

── 练习 4（L 类）：严格部分非自反 ─────────────────────────────────────────

theorem strictOf_irrefl (α : Type) (r : α → α → Prop)
    (h : IsPartialOrder α r) : Irreflexive α (strictOf α r) :=
  fun (a : α) (ha : strictOf α r a a) =>
    (fun (hne : a ≠ a) => hne (@Eq.refl.{1} α a)) (And.right ha)  -- soko:notation-ok: 等式族证明项的宇宙层级（AGENTS.md 明说的边界）

13.4 必破：⊆ 是偏序，不是全序

练习 9subset_isPartialOrder定理附录解答

这两道题是本单元的落点：它们把单元② 的三条包含律与单元④ 的外延性装成一个序，再当场证明这个序缺可比性。教材对应：Enderton §7.1 的样板偏序就是 ⊆。

练习 9（D 类）：⊆ 是 Set α 上的偏序（本单元旗舰）。

theorem subset_isPartialOrder (α : Type) :
    IsPartialOrder (Set α) (fun (A B : Set α) => A ⊆ B) := by
  sorry
提示 1思路

先展开成"自反 ∧ 反对称 ∧ 传递"，三条分别就是单元② 的包含三律；但别在单元里现搭 And.intro —— 期望类型是定义头时反解会判红（台账 G-73），库里有智能构造子 isPartialOrder_intro，参数正好是三条证据。

提示 2目标形态

IsPartialOrder (Set α) (fun (A B : Set α) => A ⊆ B)。

提示 3关键件

自反 = fun (A : Set α) (x : α) (hx : x ∈ A) => hx；反对称 = Set.ext 逐元素拼 Iff；传递 = 把 x ∈ A 经两条包含穿过两层。

查看解答 定理 · 8 行

── 练习 9（D 类）：⊆ 是 Set α 上的偏序（本单元旗舰）──────────────────── 三条证据就是单元② 的包含三律；装配交给库里的智能构造子（见台账 G-73）。

theorem subset_isPartialOrder (α : Type) :
    IsPartialOrder (Set α) (fun (A B : Set α) => A ⊆ B) :=
  isPartialOrder_intro (Set α) (fun (A B : Set α) => A ⊆ B)
    (fun (A : Set α) (x : α) (hx : x ∈ A) => hx)
    (fun (A B : Set α) (h1 : A ⊆ B) (h2 : B ⊆ A) =>
      Set.ext A B (fun (x : α) => Iff.intro (h1 x) (h2 x)))
    (fun (A B C : Set α) (h1 : A ⊆ B) (h2 : B ⊆ C) (x : α) (hx : x ∈ A) =>
      h2 x (h1 x hx))
练习 10strictOf_neq定理附录解答

练习 10（L 类）：严格部分传递要过的第一道坎 —— 两条严格关系给出"不相等"。

theorem strictOf_neq (α : Type) (r : α → α → Prop) (h : IsPartialOrder α r)
    (a b c : α) : strictOf α r a b → strictOf α r b c → a ≠ c := by
  sorry
提示 1思路

反证。假设 a = c，把第二条的"排在前面"沿着这个等式搬回去，于是 a 与 b 互相排在前面；反对称把它们压成相等，与第一条里的"不相等"冲突。

提示 2目标形态

strictOf α r a b → strictOf α r b c → a ≠ c。

提示 3关键件

搬等式用的是库里的 rel_subst_left（Eq.subst 的具名包装 ——本语言里 Eq.subst 嵌在别的应用里会判红，台账 G-73）；"不相等"那一支同样要先 fun (hne : …) => … 把类型写出来再应用。

查看解答 定理 · 8 行

── 练习 10（L 类）：两条严格关系给出"不相等" ──────────────────────────────

theorem strictOf_neq (α : Type) (r : α → α → Prop) (h : IsPartialOrder α r)
    (a b c : α) : strictOf α r a b → strictOf α r b c → a ≠ c :=
  fun (hab : strictOf α r a b) (hbc : strictOf α r b c) =>
    fun (hac : a = c) =>
      (fun (hne : a ≠ b) =>
        hne (partialOrder_antisymm α r h a b (And.left hab)
          (rel_subst_left α r a b c hac (And.left hbc))))
        (And.right hab)

练习 11（L 类）：偏序的严格部分是传递的（用第 10 题）。

练习 9 · subset_isPartialOrder 定理

── 练习 9（D 类）：⊆ 是 Set α 上的偏序（本单元旗舰）──────────────────── 三条证据就是单元② 的包含三律；装配交给库里的智能构造子（见台账 G-73）。

theorem subset_isPartialOrder (α : Type) :
    IsPartialOrder (Set α) (fun (A B : Set α) => A ⊆ B) :=
  isPartialOrder_intro (Set α) (fun (A B : Set α) => A ⊆ B)
    (fun (A : Set α) (x : α) (hx : x ∈ A) => hx)
    (fun (A B : Set α) (h1 : A ⊆ B) (h2 : B ⊆ A) =>
      Set.ext A B (fun (x : α) => Iff.intro (h1 x) (h2 x)))
    (fun (A B C : Set α) (h1 : A ⊆ B) (h2 : B ⊆ C) (x : α) (hx : x ∈ A) =>
      h2 x (h1 x hx))
练习 10 · strictOf_neq 定理

── 练习 10（L 类）：两条严格关系给出"不相等" ──────────────────────────────

theorem strictOf_neq (α : Type) (r : α → α → Prop) (h : IsPartialOrder α r)
    (a b c : α) : strictOf α r a b → strictOf α r b c → a ≠ c :=
  fun (hab : strictOf α r a b) (hbc : strictOf α r b c) =>
    fun (hac : a = c) =>
      (fun (hne : a ≠ b) =>
        hne (partialOrder_antisymm α r h a b (And.left hab)
          (rel_subst_left α r a b c hac (And.left hbc))))
        (And.right hab)
