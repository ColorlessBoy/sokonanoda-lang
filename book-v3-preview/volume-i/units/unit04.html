记法不用自己声明：∈ ⊆ ∪ ∩ \ ∅ 由 lib/Set 提供、随 import 生效；逻辑连接符 ∧ ∨ ↔ ¬、箭头 →、等号 = 与不等号 ≠ 是语言内建（Lean core 级），任何文件直接写。所以下面看不到一条 infix/notation。

两处书写例外：① ∅ 是零元记法，落在「被应用」的记法位置时补不出类型参数（(A \ A) x ↔ (∅) x）——演示 3 先把 Iff 写成源形态再交给 Set.ext；② \ 的左操作数本身是记法时（(A ∪ B) \ B）记法路径解不出类型参数，所以命题 8 的语句里 \ 与 ∪ 仍写点名形式（Set.sdiff / Set.union）。其余位置一律记法。练习配额：X 类 4 条（形式↔散文互译，散文写在题面注释里）· T 类 2 条（项填空）·R 类 2 条（读·评译）—— 其中第 8 条承担本单元的 D 类必破：(A ∪ B) \ B = A 是假的，要给出反例并把"不相等"证出来。

4.1 外延证明套路：要证两个集合相等，就逐元素证 Iff

A=B⟺∀x,(x∈A↔x∈B)

这就是公理 Set.ext 的形状。本单元后面每一条等式都走这一条路：先 apply Set.ext 把集合等式换成"对任意 x 的 Iff"，再 constructor 拆成两个方向，然后对 x 做命题逻辑。

演示（已写好）：外延套路本身——逐元素 Iff 进，集合相等出。

theorem union_comm (α : Type) (A B : Set α) :
    A ∪ B = B ∪ A := by
  apply Set.ext
  intro x
  constructor
  intro h
  exact @Or.elim (x ∈ A) (x ∈ B) (x ∈ B ∪ A)
    (fun (ha : x ∈ A) => Or.inr ha)
    (fun (hb : x ∈ B) => Or.inl hb)
    h
  intro h
  exact @Or.elim (x ∈ B) (x ∈ A) (x ∈ A ∪ B)
    (fun (hb : x ∈ B) => Or.inr hb)
    (fun (ha : x ∈ A) => Or.inl ha)
    h

  • 散文 → 形式：读注释里的那句话，说出它对应哪条等式（本题已替你写好签名）；
  • 形式 → 散文：证完之后能反过来把等式读成那句话（写在笔记里，不必进文件）。

判卷只看形式证明：签名不许动，把 by 块里的 sorry 换成真的 tactic。

theorem union_inter_idem (α : Type) (A : Set α) :
    (A ∪ A = A) ∧ (A ∩ A = A) := by

  intro h

    A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) := by

theorem sdiff_sdiff (α : Type) (A B C : Set α) :
    (A \ B) \ C = A \ (B ∪ C) := by
  apply Set.ext
  intro x
  constructor
  intro h
  exact And.intro
    (@And.left (x ∈ A) (¬ (x ∈ B))  -- soko:notation-ok: 目标/假设经 intro 展开（非语句层）后期望类型传不到（引擎边界）
      (And.left h))
    (fun (hbc : x ∈ B ∪ C) =>
      @Or.elim (x ∈ B) (x ∈ C) False
        (fun (hb : x ∈ B) =>
          And.right  -- soko:notation-ok: 目标/假设经 intro 展开（非语句层）后期望类型传不到（引擎边界）
            (And.left h) hb)
        (fun (hcx : x ∈ C) =>
          And.right h hcx)  -- soko:notation-ok: 目标/假设经 intro 展开（非语句层）后期望类型传不到（引擎边界）
        hbc)
  intro h
  exact And.intro
    (And.intro
      (And.left h)
      (fun (hb : x ∈ B) =>
        And.right h (Or.inl hb)))  -- soko:notation-ok: 目标/假设经 intro 展开（非语句层）后期望类型传不到（引擎边界）
    (fun (hc : x ∈ C) =>
