本单元的"该学的定理"：

  • 等价类的两条取用子（进 · 出 ✓ —— 就是 r a b 的两个说法 ✓）；
  • 自反性给出自身在类里 ✓ · 对称/传递 ✓ · 成员的可交换性
（b∈[a]↔a∈[b]✓）
  • 旗舰一：相关的点的类互相包含（r a b ⇒ [a] ⊆ [b] ✓）；
  • 旗舰二（构造性形态的"相等或不相交"）：不相关 ⇒ 两个类没有公共点 ✓（¬ r a b ⇒ ¬ ∃ c, c ∈ [a] ∧ c ∈ [b] ✓ —— 教材里"两个类要么相等要么不相交" ✓；这里写成构造性可证的形态 ✓，避开"类的相等"那条要外延的路 ✓）。

theorem not_mem_both_of_not_rel (α : Type) (r : Rel α α) (he : IsEquivalence α r) (a b : α)
    (h : ¬ (r a b)) : ¬ (∃ (c : α), c ∈ (Rel.EquivClass α r a) ∧ c ∈ (Rel.EquivClass α r b)) :=

编写注记 · 教材对照与课程边界（4 条）

靶子（教材）：Enderton《Elements of Set Theory》§3.4 / §5（equivalence classes）·Halmos《Naive Set Theory》§7。大纲 §4.1（I.10 章继续深化 —— 接单元㉕㉖㉗ ✓）。

⚠ 为什么旗舰二这样写 ✓：[a] = [b] ∨ [a] ∩ [b] = ∅ 的两支都含集合相等 ✗ ⇒ 要外延（lib.Extensionality ✓）才能走 ✓；而"有公共点 ⇒ 相关"这条 逆否形态完全构造性 ✓ ⇒ 本单元取它 ✓（手册「求真 + 看逻辑强度」✓）。

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 三样：lib.Set · lib.Rel · lib.Order。
