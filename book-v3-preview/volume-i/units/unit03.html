theorem subset_inter_iff (α : Type) (A B C : Set α) :

提示 1思路

∩ 的泛性质（练习 3 的对偶）：→ 把 h x hx : B x ∧ C x 劈成两条包含； ← 把一对包含在同一 x hx 上取出来，再装回一对证据。

theorem subset_inter_iff (α : Type) (A B C : Set α) :
    (A ⊆ B ∩ C) ↔ (A ⊆ B ∧ A ⊆ C) := by
  constructor
  intro h
  constructor
  intro x
  intro hx
  exact And.left (h x hx)
  intro x
  intro hx
  exact And.right (h x hx)
  intro h
  intro x
  intro hx
  exact And.intro
    (@And.left (A ⊆ B) (A ⊆ C) h x hx)  -- soko:notation-ok: And.left/right 续应用被误判成旧写法（引擎边界）
    (@And.right (A ⊆ B) (A ⊆ C) h x hx)  -- soko:notation-ok: And.left/right 续应用被误判成旧写法（引擎边界）

3.4 幂集：𝒫 关于 ⊆ 单调（幂集元素是上一层类型的集合，注意层数）

练习 9powerset_mono定理附录解答

练习 9（T 类）：A ⊆ B 推出 𝒫 A ⊆ 𝒫 B。

theorem powerset_mono (α : Type) (A B : Set α) (h : A ⊆ B) :
    𝒫 A ⊆ 𝒫 B := by
  sorry
提示 1思路

𝒫 A 的元素是"A 的子集"；要证 𝒫 A ⊆ 𝒫 B，就是任给 X ⊆ A 去证 X ⊆ B——逐元素把 X 里的证据经 A ⊆ B 送一程。

提示 2目标形态

𝒫 A ⊆ 𝒫 B；内层展开是 ∀ (X : Set α), X ⊆ A → X ⊆ B，再展开是 ∀ (x : α), x ∈ X → x ∈ B，手里有 h : A ⊆ B。

提示 3关键件

Set.mem_powerset_iff（成员判定，第一个参数是"大集合"）把两边的"X ∈ 𝒫 ?"换成包含，Iff.mp / Iff.mpr 各走一个方向；最后一步用 h x。注意 intro 只把目标展开一层（∈ → 𝒫），所以内层包含要靠这条引理换出来。

查看解答 定理 · 5 行

── 3.4 幂集单调 ───────────────────────────────────────────────────────── 𝒫 A ⊆ 𝒫 B 的成员层要两层定义展开才到 ∀（Set.mem → Set.powerset → Set.subset），而 intro 只展开一层；所以内层那条包含整条交给 exact 一次判定：Iff.mpr 把 X ∈ 𝒫 B 换成 X ⊆ B，lambda 逐元素把证据经 h 送一程。

theorem powerset_mono (α : Type) (A B : Set α) (h : A ⊆ B) :
    𝒫 A ⊆ 𝒫 B := by
  exact fun (X : Set α) => fun (hX : X ∈ 𝒫 A) =>
    Iff.mpr (Set.mem_powerset_iff B X)
      (fun (x : α) => fun (hx : X x) => h x (hX x hx))

练习 10union_subset_inter_false定理附录解答

练习 10（D 类）：判断真假，假的给出反例。

命题："(A ∪ B) ⊆ (A ∩ B)"（也就是 3.1/3.2 那两条包含的逆）。判断：假。反例：取 A = 全集、B = 空集——只要 α 里有一个元素 a，它就在 A ∪ B 里，却不在 A ∩ B 里。下面把这条反例写成"原命题的否定"：假命题本身不能当 theorem 的靶子（那样只会留下一个永远填不上的 sorry）。

theorem union_subset_inter_false (α : Type) (a : α) :
    ¬ ((@Set.univ α ∪ ∅) ⊆ (@Set.univ α ∩ ∅)) := by
  sorry
提示 1思路

否定就是一个箭头——intro 假设 hsub（那条包含），目标是 False。

提示 2目标形态

¬ ((@Set.univ α ∪ ∅) ⊆ (@Set.univ α ∩ ∅))，展开之后目标是 False，手里有 hsub : (@Set.univ α ∪ ∅) ⊆ (@Set.univ α ∩ ∅)。

提示 3关键件

先造 a ∈ @Set.univ α ∪ ∅——Set.mem_univ α a 配上 Or.inl；把它喂给 hsub a 之后用 And.right 取出后半（展开即 False）。

查看解答 定理 · 8 行

── 3.5 D 类 ───────────────────────────────────────────────────────────── 反例：A = univ、B = empty（α 非空时的最小反例）；原命题的否定。

theorem union_subset_inter_false (α : Type) (a : α) :
    ¬ ((@Set.univ α ∪ ∅) ⊆ (@Set.univ α ∩ ∅)) := by
  intro hsub
  -- 目标经 `intro` 展开（非语句层）后 `∧`/`∨` 的期望类型传不到，而 `And.right`/`Or.inl`
  -- 的隐式实参只能**语法反解** ⇒ 先用两条带标注的 `have` 把 `∨`/`∧` 落成语法形态 ✓
  have hmem : a ∈ @Set.univ α ∨ a ∈ ∅ := Or.inl (Set.mem_univ a)
  have hm : a ∈ @Set.univ α ∧ a ∈ ∅ := hsub a hmem
  exact And.right hm
练习 11powerset_self_mem定理附录解答

练习 11（D 类）：判断真假并说明理由（本题把真的那条写成定理）。

命题甲：A ∈ 𝒫 A。 命题乙：A ⊆ 𝒫 A。甲：真——A ∈ 𝒫 A 展开就是 A ⊆ A。乙：连类型都不对——𝒫 A : Set (Set α) 的元素类型是 Set α，比 A : Set α 高一层，所以它当不了 A ⊆ ? 的右参数。这正是"∈ 与 ⊆ 混淆"在幂集上的样子：要写的是"属于"，不是"包含"。（Tao §3.1 的散文里 A ⊆ 𝒫A 有意义但一般不真；我们的编码用类型层把它提前挡住——本课程的设计判断。）（大纲单元③把"A ∈ 𝒫A"列为假命题：那是笔误，随本题解答一并更正。）

theorem powerset_self_mem (α : Type) (A : Set α) : A ∈ 𝒫 A := by
  sorry
提示 1思路

目标展开就是 A ⊆ A——先 have 一条包含（intro 一个元素与它的证据），再问自己还需要做什么。

提示 2目标形态

A ∈ 𝒫 A，展开是 ∀ (x : α), x ∈ A → x ∈ A。

theorem subset_inter_iff (α : Type) (A B C : Set α) :

  intro h
  constructor
  intro x
  intro hx
  exact And.left (h x hx)
  intro x
  intro hx
  exact And.right (h x hx)

练习 9 · powerset_mono 定理

── 3.4 幂集单调 ───────────────────────────────────────────────────────── 𝒫 A ⊆ 𝒫 B 的成员层要两层定义展开才到 ∀（Set.mem → Set.powerset → Set.subset），而 intro 只展开一层；所以内层那条包含整条交给 exact 一次判定：Iff.mpr 把 X ∈ 𝒫 B 换成 X ⊆ B，lambda 逐元素把证据经 h 送一程。

theorem powerset_mono (α : Type) (A B : Set α) (h : A ⊆ B) :
    𝒫 A ⊆ 𝒫 B := by
  exact fun (X : Set α) => fun (hX : X ∈ 𝒫 A) =>
    Iff.mpr (Set.mem_powerset_iff B X)
      (fun (x : α) => fun (hx : X x) => h x (hX x hx))

theorem union_subset_inter_false (α : Type) (a : α) :
    ¬ ((@Set.univ α ∪ ∅) ⊆ (@Set.univ α ∩ ∅)) := by
  intro hsub
  -- 目标经 `intro` 展开（非语句层）后 `∧`/`∨` 的期望类型传不到，而 `And.right`/`Or.inl`
  -- 的隐式实参只能**语法反解** ⇒ 先用两条带标注的 `have` 把 `∨`/`∧` 落成语法形态 ✓
  have hmem : a ∈ @Set.univ α ∨ a ∈ ∅ := Or.inl (Set.mem_univ a)
  have hm : a ∈ @Set.univ α ∧ a ∈ ∅ := hsub a hmem
  exact And.right hm
