讲 Cantor 之前先给一个假的枚举让你找矛盾（Zazkis & Mamolo 2009 的实证：学过 Cantor 定理的学生面对假的 ℝ 枚举只会说 "Cool!"——所以我们这里不放 ℝ，放 α → Set α 的假枚举，逼你指出那个漏掉的集合）。

本单元不用：Set.ext（一条集合等式都不证）、funext / propext（语言里根本没有）——对角线论证不需要外延性，也不需要 choice；choice 只在"从满射里挑原像"那一步上场。

注：练习 2 起都把「可数」按定义展开写成等势，不点名 Set.Countable——本单元的每条练习都独立判卷，不依赖前面那条是否已经填好。

10.1 假的枚举：先看它坏在哪

有人递给你一张"𝒫ℕ 的清单"：第 n 项就是单元素集 {n}。每项都在清单上，看起来挺像样。要戳穿它，只需指出一个永远不在清单上的集合：

D := fun (y : Nat) => ¬ (y = y)

它把"第 y 项含不含 y"逐项反过来，于是第 k 项 {k} 含 k，D 不含 k——两者不可能相等。

定义fake_enum声明 1
def fake_enum (n : Nat) : Set Nat := {n}

演示（已写好）：D 不等于清单里的任何一项——这就是对角线法在假枚举上的样子。证明走 by 块：假设 D = fake_enum k，把 k ∈ {k}（Set.mem_singleton_self）沿等式搬到 D 上，得到 ¬ (k = k)，与 Eq.refl k 相撞（absurd）。

定理demo_fake_enum_escapes声明 2
theorem demo_fake_enum_escapes (k : Nat) :
    ¬ ((fun (y : Nat) => ¬ (y = y)) = fake_enum k) :=

  1.   intro h
  2.   exact @absurd (k = k) False (@Eq.refl.{1} Nat k)  -- soko:notation-ok: R4：absurd 短写在 exact 里补不出 {a}{b}
    (@Eq.subst.{1} (Set Nat) (fun (X : Set Nat) => X k)
      (fake_enum k) (fun (y : Nat) => ¬ (y = y))
      (@Eq.symm.{1} (Set Nat) (fun (y : Nat) => ¬ (y = y)) (fake_enum k) h)
      (Set.mem_singleton_self k))

10.2 对角线法（通用形式）

把 10.1 的动作从"清单 {n}"升级成任意 f : α → Set α：取

D := fun (y : α) => ¬ (f y y)

则 D 不在 f 的像里——这就是对角线法，也是 Cantor 定理的全部内容。

证明的关键只有一句逻辑：D x = ¬ (f x x) 与 (f x) x = f x x，所以"D x 等于 f x 那一点的值"会给出 ¬ P 等于 P，而命题不可能与自己的否定等价。

演示（已写好）：对角线集合 D 不等于 f 的任何一项 f x。证明走 by 块：把假设 D = f x 经 congrArg 抬到"在 x 上取值"这一层，得到 ¬ (f x x) = f x x；于是 ¬ (f x x) 与 f x x 互相推出，撞出 False。

定理demo_diag声明 3
theorem demo_diag (α : Type) (f : α → Set α) (x : α) :
    ¬ ((fun (y : α) => ¬ (f y y)) = f x) :=
证明 · 4 步 · 9 行
  1.   intro h
  2.   have e : (¬ (f x x)) = (f x x) :=
    congrArg.{1} (fun (A : Set α) => A x) h
  3.   have hnp : ¬ (f x x) := by
    intro p
    exact @Eq.subst.{1} Prop (fun (Q : Prop) => Q → ¬ (f x x))
      (¬ (f x x)) (f x x) e (fun (np : ¬ (f x x)) => np) p p
  4.   exact @absurd (f x x) False (@Eq.subst.{1} Prop (fun (Q : Prop) => Q) (¬ (f x x)) (f x x) e hnp) hnp  -- soko:notation-ok: R4：absurd 短写在 exact 里补不出 {a}{b}

10.3 可数：定义

练习 1Set.Countable定义附录解答

练习 1（T 类）：把「可数」的定义填出来。Tao 的用法：X 可数 ⟺ X 与 ℕ 等势（"能排成一列"只是它的白话版；有限集的可数是单元⑨ 处理过的另一回事，本单元只做无限可数）。

def Set.Countable (α : Type) : Prop := by
  sorry
提示 1思路

可数不是描述句，而是一次等势断言——用单元⑨ 备好的等势记法 A ≈ B 写。

提示 2目标形态

目标类型是 Prop（定义体的类型），形状为 A ≈ B（两侧各一个集合）。

提示 3关键件

A ≈ B 的两侧各自带论域（A : Set α、B : Set β）；两侧集合都取"整个类型"，用 Set.univ。

def Set.Countable (α : Type) : Prop :=
  @Set.univ Nat ≈ @Set.univ α

10.4 亲手写出那个映射：ℕ 与自己的等势

练习 2nat_equiv_nat定理附录解答

lib/Equiv 的等势是数据版：交出一对互逆映射 f、g 与四条条件（进集合、回集合、g∘f = id、f∘g = id）。所以"等势"这道题永远从"写下那个映射"开始（Hamza & O'Shea 2011：援引双射判据的学生极少真的把映射写出来）。

练习 2（L 类）：恒等映射给出 ℕ 与自己的等势——这就是「ℕ 可数」的实例。

theorem nat_equiv_nat : (@Set.univ Nat) ≈ (@Set.univ Nat) := by
  sorry
提示 1思路

来回都用恒等函数（最省的一对互逆映射），再逐条交四样证据。

提示 2目标形态

(Set.univ Nat) ≈ (Set.univ Nat)；四条条件都只谈全集：两条"进集合"是 True 的证明，两条互逆律是 rfl 级。

提示 3关键件

Set.Equiv.mk 依次吃 f、g、①进集合、②回集合、③g∘f=id、④f∘g=id；全集的成员判定交给 Set.mem_univ，等式交给 Eq.refl。

练习 5powerset_nat_not_countable定理附录解答

    ¬ (∃ (f : α → Set α), Function.Surjective α (Set α) f) := by

10.6 选择公理：本卷唯一一次动手用它

lib/Exists 的文件头把这条留给了本单元：从"存在一个满足 p 的元素"取出一个元素。官方 Lean 里它是 Classical.choice（Mathlib 的基数理论建立在它之上）；本卷到单元⑩ 才正面碰上它，而卷 I 的证明一条都没用它——等势之所以定义成"一对互逆映射"的数据（lib/Equiv 文件头），就是为了让对称性与传递性不必挑原像。

选择公理在官方 Lean 4 里是成对的两条：Exists.choose 只交出元素，Exists.choose_spec 才说明所选的那个元素确实满足性质（Avigad《Logic and Proof》§16.4 的写法就是 choose h 配 choose_spec h）。为什么必须成对：没有后者，Exists.choose … 就只是一个来路不明的元素——既不知道它是谁，也用不上它的任何性质。

Förster 2006 观察到教学惯于略过选择公理的应用，学生因此没有形成它的心智图像、日后也认不出何时被使用（这是作者观点，不是实证研究）。

axiom Exists.choose_spec : (A : Type) → (p : A → Prop) → (h : ∃ (x : A), p x) →
