30.3 空集的确界：最小元与最大元

练习 3sup_empty_iff_bot定理附录解答

练习 3（L 类）：空集的上确界就是最小元。

theorem sup_empty_iff_bot (α : Type) (r : α → α → Prop) (b : α) :
    IsSup α r (fun (_ : α) => False) b ↔ ∀ (c : α), r b c := by
  sorry
提示 1思路

空集的"上界"条件是空的（没有任何点要检查）⇒ 上确界只剩"最小性"那一条，而它就是"比每个 c 都小"；反方向：给一个"比谁都小"的 b，最小性那一条直接就是它。

提示 2目标形态

IsSup α r (fun _ => False) b ↔ ∀ c, r b c。

提示 3关键件

isSup_intro/isSup_least · 空的上界条件要写成一个 λ（用 False.elim 消掉那个不可能的假设）· Iff.intro（前导 Prop 实参写全）。

theorem sup_empty_iff_bot (α : Type) (r : α → α → Prop) (b : α) :
    IsSup α r (fun (_ : α) => False) b ↔ ∀ (c : α), r b c :=
  @Iff.intro (IsSup α r (fun (_ : α) => False) b) (∀ (c : α), r b c)
    (fun (h : IsSup α r (fun (_ : α) => False) b) =>
      (fun (hu : ∀ (c : α), UpperBound α r (fun (_ : α) => False) c → r b c) =>
        fun (c : α) => hu c (fun (a : α) => fun (hf : False) => @False.elim (r a c) hf))  -- soko:notation-ok: G-73 形状 ③/②：`Eq` 或 `⋃₀`/`⋂₀` 在这些位置解不出，必须点名
        (isSup_least α r (fun (_ : α) => False) b h))

30.4 对偶原理：上界集的下确界就是上确界

练习 6sup_of_upperBounds_inf定理附录解答

练习 6（L 类，本单元旗舰）：设 b 是"A 的所有上界"这一族的下确界，则 b 是 A 的上确界。

theorem sup_of_upperBounds_inf (α : Type) (r : α → α → Prop) (A : α → Prop) (b : α)
    (hb : IsInf α r (fun (u : α) => UpperBound α r A u) b) : IsSup α r A b := by
  sorry
提示 1思路

①b 是 A 的上界：任取 a ∈ A —— 对每个上界 u 都有 a ≤ u（a 是一个下界）⇒ 由 b 的最大性得 a ≤ b；②b 最小：b 是那一族的下界，直接用在具体上界 c 上。

提示 2目标形态

IsInf α r (fun u => UpperBound α r A u) b → IsSup α r A b。

提示 3关键件

isSup_intro · isInf_greatest（最大性）· isInf_lower（下界）·两处定义头都要 λ 绑定（G-73 形状 ①）。

查看解答 定理 · 11 行
theorem sup_of_upperBounds_inf (α : Type) (r : α → α → Prop) (A : α → Prop) (b : α)
    (hb : IsInf α r (fun (u : α) => UpperBound α r A u) b) : IsSup α r A b :=
  isSup_intro α r A b
    (fun (a : α) => fun (ha : A a) =>
      (fun (hg : ∀ (c : α), LowerBound α r (fun (u : α) => UpperBound α r A u) c → r c b) =>

      (fun (hl : ∀ (u : α), UpperBound α r A u → r b u) => hl c hc)
