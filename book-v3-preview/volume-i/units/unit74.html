本单元的"该学的定理"：

  • 原像的两条取用子（x ∈ f ⁻¹' B ⇔ f x ∈ B ✓）；
  • 旗舰一：x ∈ f ⁻¹' (⋃F) ⇔ ∃A∈F, x ∈ f ⁻¹' A ✓（原像与并交换 ✓）；

编写注记 · 教材对照与课程边界（5 条）

靶子（教材）：Enderton《Elements of Set Theory》§3.5 · Halmos §10。大纲 §4.1（接单元73 —— 那里"像与交只能单向" ✗，这里原像两侧都成立 ✓，两片对照就是"像 vs 原像"最本质的差别 ✓）。

⚠ 类型要点（本轮实测两处判红换来的 ✓）：原像的族住在陪域里 ✓ ——f : α → β 时，族的类型是 Set (Set β) ✓（f ⁻¹' A 要求 A : Set β ✓）；而单元73 的像的族住在定义域里（F : Set (Set α) ✓）。我把两者混过一次 ✗（报「期望 Set β，实际 Set α」✓）⇒ 写原像题时先问"族住在哪边" ✓。

⚠ 拆链纪律 ✓：两条旗舰都拆成链式小引理（…_of_mem → …_of_exists → 打包 ✓），每条都在两层以内 ⇒ 一次判绿 ✓。
