靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§1.5 的"refuting statements"（教材在这里系统地讲"怎样说明一条陈述为假"）；Halmos《Naive Set Theory》全书贯穿的"给反例"手法。大纲：set-theory-syllabus.md §4.1（新主题块 —— 课程此前整块缺"反例"教学 ✓）。

本单元的"该学的定理/手法"：

  • 驳倒 ∀ 只需一个反例 —— ¬ (∀ x, P x) 由 (a) + ¬ (P a) 给出 ✓；
  • 驳倒 A ⊆ B 只需一个"在 A 里、不在 B 里"的见证 ✓ ——并把它做成可复用的引理 not_subset_of_witness ✓；
  • 三个实例：∀ x, x ∈ ∅ 假 ✓ · univ ⊆ ∅ 假 ✓ · （见练习）✓

55.2 两条总纲：驳倒 ∀ · 驳倒 ⊆

练习 1not_all_of_counterexample定理附录解答

练习 1（T 类，总纲一）：驳倒 ∀ 只需一个反例。

theorem not_all_of_counterexample (α : Type) (P : α → Prop) (a : α) (hna : ¬ (P a)) :
    ¬ (∀ (x : α), P x) := by
  sorry
提示 1思路

假设 ∀ x, P x 成立，把它用在见证 a 上，与 ¬ (P a) 冲突。

提示 2目标形态

(a : α) → ¬ (P a) → ¬ (∀ x, P x)。

提示 3关键件

假设按 点 应用（h a）· 见证的否定假设当函数用 ✓

查看解答 定理 · 3 行
theorem not_all_of_counterexample (α : Type) (P : α → Prop) (a : α) (hna : ¬ (P a)) :
    ¬ (∀ (x : α), P x) :=
  fun (h : ∀ (x : α), P x) => hna (h a)
练习 2not_subset_of_witness定理附录解答

练习 2（L 类，总纲二）：驳倒 ⊆ 只需一个见证。

theorem not_subset_of_witness (α : Type) (A B : Set α) (a : α)
    (ha : a ∈ A) (hna : ¬ (a ∈ B)) : ¬ (A ⊆ B) := by
  sorry
提示 1思路

假设 A ⊆ B，用在见证上得到 a ∈ B，与 ¬ (a ∈ B) 冲突。

提示 2目标形态

(a : α) → a ∈ A → ¬ (a ∈ B) → ¬ (A ⊆ B)。

提示 3关键件

包含假设按 点 · 前提 应用（h a ha）✓ · 见证的否定假设当函数用 ✓

查看解答 定理 · 3 行
theorem not_subset_of_witness (α : Type) (A B : Set α) (a : α)
    (ha : a ∈ A) (hna : ¬ (a ∈ B)) : ¬ (A ⊆ B) :=
  fun (h : A ⊆ B) => hna (h a ha)

55.3 三个反例（把总纲用在具体命题上）

练习 3not_all_mem_empty定理附录解答

练习 3（T 类，反例一）：「一切都属于空集」是假的。

theorem not_all_mem_empty (α : Type) (a : α) : ¬ (∀ (x : α), x ∈ (∅)) := by
  sorry
提示 1思路

把练习 1 用在任意见证上，¬ (a ∈ ∅) 由演示 2 给。

提示 2关键件

练习 1（总纲一）· 演示 2（空集没有成员）✓

查看解答 定理 · 3 行
theorem not_all_mem_empty (α : Type) (a : α) : ¬ (∀ (x : α), x ∈ (∅)) :=
  not_all_of_counterexample α (fun (x : α) => x ∈ (∅)) a
    (fun (h : a ∈ (∅)) => (Iff.mp (Set.mem_empty_iff_false a) h))
练习 4not_univ_subset_empty定理附录解答

练习 4（L 类，反例二）：「论域含于空集」是假的。

theorem not_univ_subset_empty (α : Type) (a : α) :
    ¬ (@Set.univ α ⊆ (∅)) := by
  sorry
提示 1思路

见证取任意 a；a ∈ univ 由库给 ✓、¬ (a ∈ ∅) 由演示 2 给 ✓。

提示 2目标形态

(a : α) → ¬ (univ ⊆ ∅)。

提示 3关键件

练习 2（总纲二）· Set.mem_univ（先写全论域实参）· 演示 2 ✓

查看解答 定理 · 4 行
theorem not_univ_subset_empty (α : Type) (a : α) :
    ¬ (@Set.univ α ⊆ (∅)) :=
  fun (h : @Set.univ α ⊆ (∅)) =>
    (Iff.mp (Set.mem_empty_iff_false a)) (h a (Set.mem_univ a))
