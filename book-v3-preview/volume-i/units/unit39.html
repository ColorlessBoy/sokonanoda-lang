本单元的「该学的定理」：

  • 像与原像：成员刻画 · 对集合单调 · 对关系单调 · 全集/空集两端；
  • 旗舰一：像穿过复合（img (r • s) A = img s (img r A)，原像对偶）；
  • 旗舰二：函数的等价核是等价关系（kernel f a b 读作 f a = f b）——这正是单元㉗「商掉核」那一步的来源 ✓
  • 旗舰三：单射 ⟺ 核退化成恒等关系（Injective f ↔ kernel f ⊆ idRel）✓

39.0 画布给的四个新词汇

idRel：恒等关系（单元㊱㊳ 已用过）✓ relImg r A：A 在关系 r 下的像（∃ a ∈ A, r a b）✓ relPre r B：B 在关系 r 下的原像（∃ b ∈ B, r a b）✓ kernel f：函数 f 的等价核（fun a b => f a = f b）—— 单元㉗ 商掉的那个关系 ✓

定义idRel声明 1
def idRel (α : Type) : Rel α α :=
  fun (a : α) (b : α) => a = b
定义relImg声明 2
def relImg (α β : Type) (r : Rel α β) (A : Set α) : Set β :=
  fun (b : β) => ∃ (a : α), A a ∧ r a b
定义relPre声明 3
def relPre (α β : Type) (r : Rel α β) (B : Set β) : Set α :=
  fun (a : α) => ∃ (b : β), B b ∧ r a b
定义kernel声明 4
def kernel (α β : Type) (f : α → β) : Rel α α :=
  fun (a : α) (b : α) => (f a) = (f b)

39.3 旗舰一：像穿过复合（原像对偶）

练习 6relImg_comp定理附录解答

练习 6（L 类，旗舰）：像与复合交换（img (r • s) A = img s (img r A)）。

theorem relImg_comp (α β γ : Type) (r : Rel α β) (s : Rel β γ) (A : Set α) :
    relImg α γ (r • s) A = relImg β γ s (relImg α β r A) := by
  sorry
提示 1思路

逐点看，两边都是「存在一条两步的路」，只是先拆哪一步的顺序不同 ——→：先拆 ∃ a，再拆 ∃ b，然后按「先造 b、再造 a」的顺序造回去；←：反过来。

提示 2目标形态

relImg (r • s) A = relImg s (relImg r A)（集合等式 ⇒ Set.ext）。

提示 3关键件

Set.ext（写全论域与两个集合）· 两个方向各拆一次嵌套 ∃ ·Exists.elim/Exists.intro（前导实参写全）· And.intro/And.left/And.right ·⚠ 嵌套超过两层就拆辅助定理（单元㊱ 的教训；解答里 relImg_comp_fwd/_bwd 就是为此）✓

查看解答 定理 · 6 行
theorem relImg_comp (α β γ : Type) (r : Rel α β) (s : Rel β γ) (A : Set α) :
    relImg α γ (r • s) A = relImg β γ s (relImg α β r A) :=
  Set.ext (relImg α γ (r • s) A) (relImg β γ s (relImg α β r A)) (fun (c : γ) =>
    @Iff.intro (c ∈ (relImg α γ (r • s) A)) (c ∈ (relImg β γ s (relImg α β r A)))
      (fun (h : c ∈ (relImg α γ (r • s) A)) => relImg_comp_fwd α β γ r s A c h)
      (fun (h : c ∈ (relImg β γ s (relImg α β r A))) => relImg_comp_bwd α β γ r s A c h))

练习 10（D 类，旗舰）：单射 ⟺ 核退化成恒等关系（kernel f ⊆ idRel）。

theorem injective_iff_kernel (α β : Type) (f : α → β) :

theorem relImg_univ_mem (α β : Type) (r : Rel α β) (b : β) :
    b ∈ (relImg α β r (@Set.univ α)) ↔ ∃ (a : α), r a b :=
  @Iff.intro (b ∈ (relImg α β r (@Set.univ α))) (∃ (a : α), r a b)

          Exists.intro a (And.right ha)))
