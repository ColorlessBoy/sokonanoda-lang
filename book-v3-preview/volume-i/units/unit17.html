靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§6.5 The Axiom of Choice（+ §6.4 的"无限公理"一节）；Halmos《Naive Set Theory》§15 The Axiom of Choice（+ §16 Zorn's Lemma 的开头）。大纲：set-theory-syllabus.md §4.1（I.7 章）。

本单元的"该学的定理"：选择公理怎么说（choice —— 它是外挂的公理，不是定理）·它给什么（一个选择函数）· 满射因此可以"裂开"（存在右逆）·右逆必是单射（这一半不需要 AC，是纯逻辑）。

写法约定（本单元特有）：AC 的用法是"应用一次公理，再把它的 ∃ 往下顺"——所以本单元到处是 Exists.elim/Exists.intro，前导实参写全（G-73 形状 ②）。

    (h : ∀ (x : α), x ∈ A → ∃ (y : β), y ∈ B ∧ P x y) :
    ∃ (f : α → β), ∀ (x : α), x ∈ A → P x (f x) :=

    (choice α β A B P h)

theorem choice_on_univ (α β : Type) (P : α → β → Prop)
    (h : ∀ (x : α), ∃ (y : β), P x y) :
    ∃ (f : α → β), ∀ (x : α), P x (f x) :=
  @Exists.elim (α → β)
    (fun (f : α → β) => ∀ (x : α), x ∈ @Set.univ α → f x ∈ @Set.univ β ∧ P x (f x))
    (∃ (f : α → β), ∀ (x : α), P x (f x))
    (choice α β (@Set.univ α) (@Set.univ β) P
      (fun (x : α) (hx : x ∈ @Set.univ α) =>
        @Exists.elim β (fun (y : β) => P x y)
          (∃ (y : β), y ∈ @Set.univ β ∧ P x y) (h x)
          (fun (y : β) (hy : P x y) =>

              (And.intro (Set.mem_univ y) hy))))

17.2 本单元旗舰：满射可以裂开（用 AC 造右逆）

练习 5surjective_split定理附录解答

"裂开"= 给每个 y 指定一个原像。注意结论仍然是 ∃ g, …（在 Prop 里）—— 我们没有真把 g 取出来（那要 G-58），只是证明了"它存在" ✓

练习 5（L 类，本单元旗舰）：满射 ⇒ 存在右逆。

theorem surjective_split (α β : Type) (f : α → β) (hf : Function.Surjective α β f) :
    ∃ (g : β → α), Function.RightInverse α β g f := by
  sorry
提示 1思路

对关系 P y x := f x = y 用选择公理（A := Set.univ β、B := @Set.univ α）。"对每个 y 都存在原像"正好是满射的定义；把 AC 输出的 ∃ g, ∀ y, …∧ f (g y) = y 里的"落在全集里"丢掉、把"逐点等式"留下，就是右逆。

提示 2目标形态

∃ (g : β → α), Function.RightInverse α β g f。

提示 3关键件

choice（关系取 fun (y : β) (x : α) => f x = y）·Exists.elim（前后两个 ∃ 的谓词形状要对齐——AC 的输出多两个 ∈ Set.univ）·Set.mem_univ · And.right · Exists.intro。

查看解答 定理 · 18 行
theorem surjective_split (α β : Type) (f : α → β) (hf : Function.Surjective α β f) :
    ∃ (g : β → α), Function.RightInverse α β g f :=
  @Exists.elim (β → α)
    (fun (g : β → α) => ∀ (y : β), y ∈ @Set.univ β → g y ∈ @Set.univ α ∧ f (g y) = y)
    (∃ (g : β → α), Function.RightInverse α β g f)
    (choice β α (@Set.univ β) (@Set.univ α) (fun (y : β) (x : α) => f x = y)
      (fun (y : β) (hy : y ∈ @Set.univ β) =>
        @Exists.elim α (fun (x : α) => f x = y)
          (∃ (x : α), x ∈ @Set.univ α ∧ f x = y) (hf y)
          (fun (x : α) (hx : f x = y) =>
            Exists.intro x
              (And.intro (Set.mem_univ x) hx))))
    (fun (g : β → α)
      (hg : ∀ (y : β), y ∈ @Set.univ β → g y ∈ @Set.univ α ∧ f (g y) = y) =>
      Exists.intro g
        (fun (y : β) =>
          (fun (hgy : g y ∈ @Set.univ α ∧ f (g y) = y) => And.right hgy)
            (hg y (Set.mem_univ y))))

17.3 必破：AC 不是处处都要用

练习 9empty_family_hypothesis定理附录解答

选择公理之所以是"公理"，是因为一般情形取不出函数；但在具体的小情形里，函数可以直接写出来 —— 这时不需要 AC ✓。下面两题就是这个对照。

练习 9（D 类）：空族上的假设是真空的 —— x ∈ ∅ 本身就不可能。

theorem empty_family_hypothesis (α β : Type) (B : Set β) (P : α → β → Prop) :
    ∀ (x : α), x ∈ ∅ → ∃ (y : β), y ∈ B ∧ P x y := by
  sorry
提示 1思路

拿到 x ∈ ∅ 这条假设，它与"空集没有元素"冲突。

提示 2目标形态

x ∈ ∅ → ∃ (y : β), y ∈ B ∧ P x y。

提示 3关键件

Set.notMem_empty（"没有任何元素属于空集"）+ False.elim（从矛盾里可以推出任何东西）。

查看解答 定理 · 3 行
theorem empty_family_hypothesis (α β : Type) (B : Set β) (P : α → β → Prop) :
    ∀ (x : α), x ∈ ∅ → ∃ (y : β), y ∈ B ∧ P x y :=

编写注记 · 教材对照与课程边界（4 条）

⚠ 本单元不含 Zorn 引理与良序定理：它们的证明要从 ∃ 里把函数取出来用（Classical.choose 那一档），而 ∃ 在 Prop 里 ⇒ 撞 G-58（大消去不可用）⇒ 已登记在台账里，等内核侧给"数据版消去"再补 ✓（不改成弱命题糊过去）。本单元只做不需要取出数据的那一半 —— 即"结论仍然是 ∃/Prop"的那些定理 ✓（choice 自己的结论就是 ∃ f, …，可以继续往下用，这正是本单元的技术要点）。

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 三样：lib.Choice（公理）· lib.Set · lib.Fun。

依赖：单元⑦（函数与单满双射）—— 本单元用它的 Function.Surjective。

⚠ 读法：choice 不是定理，是外挂的公理（与 Set.ext、regularity 同档）。为什么必须外挂：假设里是 ∃（在 Prop 里），结论里是一个函数（在 Type 里）—— 从 Prop 里取数据这一步，本语言不给（G-58）；选择公理就是那个"开关" ✓
