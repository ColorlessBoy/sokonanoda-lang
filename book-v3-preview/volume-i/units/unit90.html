本单元的"该学的定理"：

  • BijPair 的定义展开 ✓ · 换"函数参数格"的搬运（arg_subst_id ✓）；
  • 旗舰一（拆链换来的）：复合层的等式 ✓ ——f a = b ⇒ f a' = b' ⇒ g b = g b' ⇒ g (f a) = g (f a') ✓（把三层 Eq.trans 独立成一条引理 ✓ —— 这就是第 657 轮换招的做法 ✓）；
  • 旗舰二：满射 + 复合单射 ⇒ 外层单射 ✓ ——跨三轮判红三次的欠债，本轮还清 ✓（inj_of_comp_surj ✓）。
定义Injective声明 1
def Injective (α : Type) (β : Type) (f : α → β) : Prop :=
  ∀ (a : α) (b : α), f a = f b → a = b
定义Surjective声明 2
def Surjective (α : Type) (β : Type) (f : α → β) : Prop :=
  ∀ (b : β), ∃ (a : α), f a = b
定义BijPair声明 3
def BijPair (α : Type) (β : Type) (f : α → β) : Prop :=
  Injective α β f ∧ Surjective α β f

练习 4inj_of_comp_surj定理附录解答

练习 4（L 类，旗舰二，还三轮的债）：满射 + 复合单射 ⇒ 外层单射。思路：给 g b = g b'，用满射取 a、a' ⇒ 练习 3 得 g (f a) = g (f a') ⇒ 复合单射给 a = a' ⇒ 再用一次 Eq.subst（谓词 fun x => f a = f x）把它变成 f a = f a' ⇒ 最后 Eq.trans 串成 b = b'。关键件：练习 3 · Exists.elim · Eq.subst + 谓词 fun x => f a = f x（⚠ hgf 给的是 a = a'，不是 f a = f a'！）· Eq.trans / Eq.symm

theorem inj_of_comp_surj (α : Type) (β : Type) (γ : Type) (f : α → β) (g : β → γ)
    (hf : Surjective α β f) (hgf : Injective α γ (fun (x : α) => g (f x))) :
    Injective β γ g :=
  fun (b : β) (b' : β) (h : g b = g b') =>
    @Exists.elim α (fun (a : α) => f a = b) (b = b') (hf b)
      (fun (a : α) (ha : f a = b) =>
        @Exists.elim α (fun (a' : α) => f a' = b') (b = b') (hf b')
          (fun (a' : α) (ha' : f a' = b') =>
            @Eq.trans.{1} β b (f a) b' (@Eq.symm.{1} β (f a) b ha)
              (@Eq.trans.{1} β (f a) (f a') b'
                (@Eq.subst.{1} α (fun (x : α) => f a = f x) a a'
                  (hgf a a' (comp_eq_of_eq α β γ f g a a' b b' ha ha' h))
                  (@Eq.refl.{1} β (f a)))
                ha')))
