本单元的"该学的定理"：

细节清单（5 项，展开）
  • 幂集成员的两条取用子（C ∈ 𝒫A ⟺ C ⊆ A 的两个方向各一条）；
  • 单调：A ⊆ B ⇒ 𝒫A ⊆ 𝒫B（含显式复合的写法 ✓）；
  • A ∈ 𝒫A · A ∈ 𝒫(univ)；
  • 交的两条取用子（(A ∩ B) x ⇒ A x / ⇒ B x）与它们的子集版；
  • C ⊆ A ⇒ C ⊆ B ⇒ C ⊆ A ∩ B（合成一条 ⇒ 合起来就是 𝒫(A ∩ B) = 𝒫A ∩ 𝒫B 的两半 ✓）

    (C : Set α) (hC : C ∈ 𝒫 A) : C ∈ 𝒫 B :=

编写注记 · 教材对照与课程边界（3 条）

⚠ 本单元的写法纪律（三条实测教训的正面用法 ✓）：① λ 绑定注解里只放简单变元（C/A/B）✓ —— 注解里出现 A ∩ B 这种复合项会判红 ✗（G-73 第十八例）；② 子集链要显式复合（fun x hx => h (hCA x hx)）✗ 不能一次应用 ✓；③ ⊆ 目标用 λ（逐点给）最稳 ✓（⊆ 展开就是 ∀ x, … ✓）—— 记法直接可用 ✓（2026-10-13 实测：𝒫 A ⊆ 𝒫 B 与 C ⊆ A 判绿 ✓，不必点名形式 ✓）。

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 四样：lib.Set · lib.SUnion · lib.Order · lib.Rel。
