    (hirr : Irreflexive α r) (htrans : Transitive α r)
    (P : α → Prop) (m : α) (hm : P m) (hl : ∀ (y : α), P y → r m y) :
    ∀ (y : α), P y → ¬ (r y m) :=

编写注记 · 教材对照与课程边界（3 条）

⚠ 本单元的"读法"（也是 L-07 的教材化）：HasLeast α r P 是"比 P 里谁都小"（∀ y, P y → r m y），HasMin α r P 是"没有 P 里的点排在它前面"（∀ y, P y → ¬ (r y m)）✓ 两者在全序里重合（练习 6），在严格序里也重合（练习 7）—— 但不能乱配：非严格序含自反，配"极小"版会直接矛盾（这正是第 566 轮修掉的库缺陷 L-07）✓

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 三样：lib.Order · lib.Rel · lib.Set。

依赖：单元⑭（良序与极小元）· 单元⑬（序词汇）—— 本单元是它的"非严格"对偶面。
