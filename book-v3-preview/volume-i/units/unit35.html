Unit 35 — Inverse Functions

13 个定理 · 10 道练习 · 30 条提示 · 解答附录

打印 / PDF 本单元

靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§3.3 Functions 的 inverses 一段；Halmos《Naive Set Theory》§10 Inverses and Composites。大纲：set-theory-syllabus.md §4.1（I.12 章第三个单元，本章收口）。

本单元的"该学的定理"（"数据版"的逆 —— 逆函数由调用者交进来，而不是"存在"出来）：

  • 左逆 ⇒ 单射 · 右逆 ⇒ 满射 · 双边逆 ⇒ 双射（本单元旗舰）；
  • 左逆/右逆在合成下保持；
  • 左逆与右逆逐点相等（同一个 f 的左逆与右逆其实是同一个函数 —— 本单元写 逐点形态；函数相等的形态要外延，本语言有（lib.Extensionality）⇒ 见单元㊹）；
  • 逆的对称性（f 与 g 互为逆 ⇔ g 与 f 互为逆）✓

写法约定：「把 g 作用在等式两边」用搬运引理 rel_subst_left/rel_subst_right（关系取"g 两边相等"）—— 别用 congrArg（这些位置解不出宇宙层级，实测）✓ 搬运的方向要按引理的两条形状挑：rel_subst_right 把第二个坐标向前换，rel_subst_left 把它向后换 ✓（本单元为此改了一次）

35.3 逆给出单射 / 满射（本单元的正题）

练习 4injective_of_leftInverse定理附录解答

练习 4（L 类，旗舰之一）：有左逆 ⇒ 单射。

theorem injective_of_leftInverse (α β : Type) (g : β → α) (f : α → β)
    (h : Function.LeftInverse α β g f) : Function.Injective α β f := by
  sorry
提示 1思路

设 f a = f b；把 g 作用在两边（搬运引理）得 g (f a) = g (f b)；再各自用左逆换成 a、b ⇒ a = b（注意 Eq.symm 把左边那条掉头）。

提示 2目标形态

LeftInverse g f → Injective f。

提示 3关键件

练习 1 · rel_subst_right（关系取"g 两边相等"、沿 f a = f b 把 g (f a) = g (f a) 搬成 g (f a) = g (f b)）· Eq.symm/Eq.trans（写全宇宙层级与论域）✓

    (h : Function.LeftInverse α β g f) : Function.Injective α β f :=
  fun (a : α) => fun (b : α) => fun (hab : @Eq.{1} β (f a) (f b)) =>  -- soko:notation-ok: G-73 形状 ②/③：前导实参或 `Eq` 层级在这些位置补不出来

35.4 逆在合成下保持

练习 7leftInverse_comp定理附录解答

练习 7（L 类）：左逆的合成还是左逆（见证取"先 g 后 g1"）。

theorem leftInverse_comp (α β γ : Type) (f : α → β) (g : β → α) (f1 : β → γ) (g1 : γ → β)
    (hf : Function.LeftInverse α β g f) (hf1 : Function.LeftInverse β γ g1 f1) :
    Function.LeftInverse α γ (fun (c : γ) => g (g1 c)) (fun (a : α) => f1 (f a)) := by
  sorry
提示 1思路

算 g (g1 (f1 (f a)))：先用 g1 的左逆把内层换成 f a，再用 g 的左逆。

提示 2目标形态

LeftInverse g f → LeftInverse g1 f1 → LeftInverse (fun c => g (g1 c)) (fun a => f1 (f a))。

提示 3关键件

两处搬运（内层那步用 rel_subst_right，关系取"g 两边相等"、沿 g1 (f1 (f a)) = f a 把 g (g1 (f1 (f a))) = g (g1 (f1 (f a))) 搬成 … = g (f a)）·两条左逆假设先 λ 绑定（或直接用练习 1）· Eq.trans ✓

theorem leftInverse_comp (α β γ : Type) (f : α → β) (g : β → α) (f1 : β → γ) (g1 : γ → β)

    Function.LeftInverse α γ (fun (c : γ) => g (g1 c)) (fun (a : α) => f1 (f a)) :=

      (rel_subst_right β (fun (u : β) (v : β) => @Eq.{1} α (g u) (g v))  -- soko:notation-ok: G-73 形状 ②/③：前导实参或 `Eq` 层级在这些位置补不出来

35.5 必破：左逆与右逆其实是同一个函数（逐点形态）

练习 9inverse_unique_apply定理附录解答

练习 9（D 类，本单元最漂亮的一条）：同一个 f 的左逆 g 与右逆 g1 逐点相等。

theorem inverse_unique_apply (α β : Type) (f : α → β) (g : β → α) (g1 : β → α)
    (hl : Function.LeftInverse α β g f) (hr : Function.RightInverse α β g1 f) (y : β) :
    (g y) = (g1 y) := by
  sorry
提示 1思路

g y → 沿 f (g1 y) = y 把 y 换成 f (g1 y)（注意方向）→ 再用左逆把 g (f (g1 y)) 换成 g1 y。

提示 2目标形态

LeftInverse g f → RightInverse g1 f → ∀ y, g y = g1 y。

提示 3关键件

搬运方向：这一处要用 rel_subst_left（把第二个坐标向后换）——关系取"g 两边相等"、沿 f (g1 y) = y 把 g y = g y 换成 g y = g (f (g1 y))（本单元实测：用 rel_subst_right 会得到相反的方向而判红）· 练习 1 · Eq.trans ✓ ⚠ 再往前一步（"函数相等 g = g1"）要函数外延 —— 本语言有（lib.Extensionality）⇒ 那条在单元㊹里证出来了（inverse_unique_eq）✓

    (hl : Function.LeftInverse α β g f) (hr : Function.RightInverse α β g1 f) (y : β) :
