靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§2.1 的六条公理表（+ §7.3 Regularity 一节）；Halmos《Naive Set Theory》§2 The Axiom of Specification 前后的公理表（+ §14 的 Regularity）。大纲：set-theory-syllabus.md §4.1（I.7 章第二个单元）。

本单元的"该学的定理"：正则性公理怎么说（每个非空集合都有 ∈-极小元）·它怎么用（取出极小元、扔掉它的成员）· 外延性怎么用（空集唯一）·外延性的反向（相等 ⇒ 元素相同）—— 两条合起来才是"元素相同 ⟺ 相等" ✓

18.1 公理长什么样（三条演示 + 一条正则性）

读法：整个论域是一个类型 α，成员关系是二元谓词 E（E y x 读作 y ∈ x）。lib.ZF 的公理表里只有三条必须外挂（外延性 / 正则性 / 选择），因为它们说的是 相等、良基、取数据；"某个谓词存在"那几条（空集、无序对、并）在本语言里 是定义（IsEmpty / IsPair / IsUnionOf）✓

演示：正则性（每个非空集合有 E-极小元）—— 它在这里是假设 hreg：对任意关系断言这件事会立刻矛盾（取 E 恒真），所以它不是公理 ✓

18.2 外延性的两个用法

练习 6empty_unique定理附录解答

练习 6（L 类，本单元旗舰之一）：空集唯一 —— 两个空集相等。

theorem empty_unique (α : Type) (E : α → α → Prop) (he : Extensional α E) (x y : α)
    (hx : IsEmpty α E x) (hy : IsEmpty α E y) : x = y := by
  sorry
提示 1思路

用外延性："元素相同 ⇒ 相等"。两边都没有元素，所以"元素相同"那条 ↔ 的两个方向都是从矛盾里推（各自由"没有元素"消掉）。

提示 2目标形态

x = y。

提示 3关键件

extensional_apply（论域 · 关系 · 外延性证据 · 两个元素 ·元素相同的证明）· Iff.intro（前导 Prop 实参写全，G-73 形状 ②）·练习 3 的两条 ∀ · False.elim。

查看解答 定理 · 6 行
theorem empty_unique (α : Type) (E : α → α → Prop) (he : Extensional α E) (x y : α)
    (hx : IsEmpty α E x) (hy : IsEmpty α E y) : x = y :=
  extensional_apply α E he x y (fun (z : α) =>
    @Iff.intro (E z x) (E z y)
      (fun (hzx : E z x) => False.elim ((fun (he' : ∀ (y' : α), ¬ (E y' x)) => he' z) hx hzx))
      (fun (hzy : E z y) => False.elim ((fun (he' : ∀ (y' : α), ¬ (E y' y)) => he' z) hy hzy)))

查看解答 定理 · 6 行
theorem extensional_sound (α : Type) (E : α → α → Prop) (x y : α) (h : x = y) :
    ∀ (z : α), E z x ↔ E z y :=
  fun (z : α) =>
    @Iff.intro (E z x) (E z y)
      (fun (hzx : E z x) => rel_subst_right α E z x y h hzx)
      (fun (hzy : E z y) => rel_subst_left α E x z y h hzy)

18.3 必破：并集的刻画怎么用

练习 8union_empty_family定理附录解答

三个"存在性谓词"（空集 / 无序对 / 并）在本语言里是定义，不是公理；它们的用法就是把刻画读出来。上面 18.1 已经读了空集，这里读并集 ✓

练习 8（L 类）：空族的并是空集。

theorem union_empty_family (α : Type) (E : α → α → Prop) (x : α)
    (h : IsUnionOf α E x ∅) : IsEmpty α E x := by
  sorry
提示 1思路

要证 x 没有元素。若 z ∈ x，把刻画读出来得到"存在 A 属于空族且 z ∈ A" —— 但空族里没有 A，于是矛盾。

提示 2目标形态

IsEmpty α E x。

提示 3关键件

IsUnionOf 的刻画（先 λ 绑定再应用，G-73 形状 ①）·Iff.mp · Exists.elim（前导实参写全）· And.left（空族那一条是 False）。

查看解答 定理 · 7 行
theorem union_empty_family (α : Type) (E : α → α → Prop) (x : α)
    (h : IsUnionOf α E x ∅) : IsEmpty α E x :=
  fun (z : α) (hzx : E z x) =>
    @Exists.elim α (fun (A : α) => False ∧ E z A) False
      (Iff.mp ((fun (hs : ∀ (z' : α), E z' x ↔ ∃ (A : α), A ∈ ∅ ∧ E z' A) => hs z) h)
        hzx)  -- soko:notation-ok: G-73 形状 ①：定义头类型的假设必须先 λ 绑定再应用
      (fun (A : α) (hA : False ∧ E z A) => And.left hA)
