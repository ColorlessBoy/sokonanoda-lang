靶子（教材）：Enderton《Elements of Set Theory》§2.3 · Halmos §9。大纲 §4.1（I.7 章继续深化 —— 接单元69/71 的伴随式与分配律 ✓）。

⚠ 教学点：旗舰的"反向"是假的 ✗ —— ⋃F ∩ ⋃G ⊆ ⋃(F ∩ G) 不成立：取 F = {{a}}、G = {{b}}（a ≠ b）⇒ a ∈ ⋃F、a ∈ ⋃G 不成立 ✗；更直接的：取 F = {A, C}、G = {B, C} ⇒ ⋃F ∩ ⋃G 含 C 的元素，而 ⋃(F ∩ G) = ⋃{C} 也在 ⇒ 举 F = {A}、G = {B}：⋃F ∩ ⋃G = A ∩ B，而 ⋃(F ∩ G) = ⋃∅ = ∅ ✓ ⇒ 反向不真 ✓（本单元只证可证方向 ✓）。——本条按手册「命题先求真」先找反例再动手 ✓。

⚠ 成员层级 + 点名写法 ✓：⋃/⋂ 没有记法 ⇒ Set.sUnion/Set.sInter ✓。

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 三样：lib.Set · lib.SUnion · lib.Order。
