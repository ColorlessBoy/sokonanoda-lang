theorem acc_no_self (α : Type) (r : α → α → Prop) (x : α) (h : Acc α r x) :
    ¬ (r x x) :=
  acc_ind α r (fun (z : α) => ¬ (r z z))

编写注记 · 教材对照与课程边界（7 条）

靶子（教材）：Enderton《Elements of Set Theory》§4.3 / §7.4（递归定理的良基版本）·Halmos《Naive Set Theory》§18。大纲 §4.1（接单元⑬⑭⑯㊵㊷ 的良基/良序线 ✓）。

⚠⚠ 本单元是新解锁的能力 ✓：台账 G-56（「Acc 立不起来 ⇒ 语言里没有良基递归」）已修（内核线 7/9 ✓）⇒ 现在可以在库里声明 Acc、并用它的递归子做证明 ✓。库（lib/Order ✓）已备好三件 ✓：

  • Acc（带索引归纳：Acc α r : α → Prop ✓）· acc_ind（归纳原理 ✓）·
  • acc_unique（递归定义的唯一性 ✓ —— 教科书定理 ✓）· acc_inv（取用子 ✓）。

⚠ 一条关键分辨（本轮判红换来 ✓）：acc_ind 的 motive 只吃 x ⇒ 用它的归纳假设拿不到"前驱的 Acc" ✗ ⇒ acc_inv 必须用 Acc.rec 的下标感知 motive（吃 x 与 Acc α r x 两个参数 ✓）⇒ 已放进库 ✓，本单元只调用 ✓。

⚠ 写法提醒：∀ … 用逗号收尾（∀ (x : α), … ✓）—— 写成 => 会解析失败 ✗。

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 三样：lib.Set · lib.Rel · lib.Order。
