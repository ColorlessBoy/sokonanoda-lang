本单元的"该学的定理/手法"：

  • 两条外延工具：propext_spec（命题相等 ⇐ 互相蕴含 ✓）·funext_spec（函数相等 ⇐ 逐点相等 ✓）——Set α 就是 α → Prop ✓ ⇒ 集合等式 = 逐点 + 两条外延 ✓（这就是 Set.ext 的内容 ✓）；
  • 两条取用子 + 两条"没有成员"（顶层具名 ✓ —— 它们是打包的前件 ✓）；
  • 四条集合等式：A \ ∅ = A ✓ · A \ A = ∅ ✓ · A ∩ Aᶜ = ∅ ✓ · A ∩ univ = A ✓
