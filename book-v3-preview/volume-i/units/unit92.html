细节清单（5 项，展开）
  • 等势的数据版定义展开 ✓（一对互逆映射 + 四条件 ✓ —— 记法 A ≈ B ✓）；
  • Set.MapsTo / Set.LeftInvOn 的定义展开 ✓ · 恒等映射在 A 上是 A → A ✓；
  • 复合保 MapsTo ✓（A → B 与 B → C 复合 ⇒ A → C ✓）；
  • 旗舰一：等势自反 ✓（A ≈ A ✓，用 Set.Equiv.mk ✓）；
  • 旗舰二：等势对称 ✓（A ≈ B ⇒ B ≈ A ✓ —— 把两把映射与两条互逆律"对调" ✓：mk β α B A g f hg hf hfg hgf ✓，注意后两条的顺序也换了 ✓）。

theorem equiv_symm (α : Type) (β : Type) (A : Set α) (B : Set β) (h : A ≈ B) :
    B ≈ A :=
  Set.Equiv.elim α β A B (B ≈ A) h
    (fun (f : α → β) (g : β → α) (hf : Set.MapsTo α β f A B)
      (hg : Set.MapsTo β α g B A) (hgf : Set.LeftInvOn α β g f A)
      (hfg : Set.RightInvOn α β f g B) =>
      Set.Equiv.mk β α B A g f hg hf hfg hgf)
