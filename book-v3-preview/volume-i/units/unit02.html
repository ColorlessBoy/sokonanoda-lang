    (A = ∅) ↔ (∀ (x : α), ¬ (x ∈ A)) :=
  @Iff.intro (A = ∅) (∀ (x : α), ¬ (x ∈ A))  -- soko:notation-ok: G-30：分支含 `∅`，前导实参必须写全
    (fun (h : A = ∅) => fun (x : α) (hx : x ∈ A) =>
      Set.notMem_empty x (@Eq.subst.{1} (Set α) (fun (X : Set α) => x ∈ X) A ∅ h hx))

2.3 单元素集与配对集

练习 6singleton_ne_empty定理附录解答

练习 7（L 类）：单元素集不是空集。

theorem singleton_ne_empty (α : Type) (a : α) : {a} ≠ ∅ := by
  sorry
提示 1思路

要证"不相等"，就假设相等，然后制造矛盾。

提示 2目标形态

{a} ≠ ∅——≠ 展开后就是 {a} = ∅ → False。

提示 3关键件

intro 之后假设就是 {a} = ∅；把 a ∈ {a}（Set.mem_singleton_self）沿它搬到 a ∈ ∅，再交给 Set.notMem_empty 得到 False。

查看解答 定理 · 5 行

后四条的语句一度只能写点名形式（¬ (… = …)），因为 ≠ 展开成 Ne 之后定义体里的宇宙变量 u 没人实例化（源 AST 是记法节点、内核 pp 又是裸名， 两条路都不带 .{u}）⇒ intro 报 unknown universe level u。判卷器现在按 操作数的 sort 算层级提示（与 elab_notation 给记法求层级同一条规则）， 所以下面四题与画布逐字一致。

theorem singleton_ne_empty (α : Type) (a : α) : {a} ≠ ∅ :=
  fun (h : {a} = ∅) =>
    Set.notMem_empty a
      (@Eq.subst.{1} (Set α) (fun (X : Set α) => a ∈ X) {a} ∅ h
        (Set.mem_singleton_self a))
练习 7pair_subset_iff定理附录解答

练习 8（L 类）：{a, b} ⊆ A 当且仅当 a ∈ A 且 b ∈ A。

theorem pair_subset_iff (α : Type) (a b : α) (A : Set α) :
    {a, b} ⊆ A ↔ a ∈ A ∧ b ∈ A := by
  sorry
提示 1思路

配对集展开是"两个等式取或"；→ 方向分别喂 a、b；← 方向对 Or 分情况。

提示 2目标形态
{a,b}⊆A↔a∈A∧b∈A
提示 3关键件

→ 用 Or.inl/Or.inr 造出 a ∈ {a,b} 与 b ∈ {a,b}； ← 用 Or.elim（库里）配合 Eq.subst 把等式搬到 A 上。

查看解答 定理 · 16 行
theorem pair_subset_iff (α : Type) (a b : α) (A : Set α) :
    {a, b} ⊆ A ↔ a ∈ A ∧ b ∈ A :=
  Iff.intro  -- soko:notation-ok: 这里可以省前导实参（分支的期望类型传得进去）
    (fun (h : {a, b} ⊆ A) =>
      And.intro
        (h a (@Or.inl (a = a) (a = b) (@Eq.refl.{1} α a)))  -- soko:notation-ok: 复合项/λ 体的 Eq 型实参隐式反解判红（引擎边界）
        (h b (@Or.inr (b = a) (b = b) (@Eq.refl.{1} α b))))  -- soko:notation-ok: 复合项/λ 体的 Eq 型实参隐式反解判红（引擎边界）
    (fun (h : a ∈ A ∧ b ∈ A) => fun (x : α) (hx : x ∈ {a, b}) =>
      @Or.elim (x = a) (x = b) (A x)  -- soko:notation-ok: 复合项/λ 体的 Eq 型实参隐式反解判红（引擎边界）
        (fun (hxa : x = a) =>
          @Eq.subst.{1} α (fun (y : α) => A y) a x (@Eq.symm.{1} α x a hxa)
            (And.left h))
        (fun (hxb : x = b) =>
          @Eq.subst.{1} α (fun (y : α) => A y) b x (@Eq.symm.{1} α x b hxb)
            (And.right h))
        hx)
练习 8pair_comm定理附录解答

练习 9（L 类）：{a, b} = {b, a}。

theorem pair_comm (α : Type) (a b : α) : {a, b} = {b, a} := by
  sorry
提示 1思路

外延 + 逐元素把"两个等式取或"的两支互换。

提示 2目标形态
{a,b}={b,a}
提示 3关键件

Set.ext + Iff.intro，两边都用 Or.elim 把 Or.inl 换成 Or.inr、Or.inr 换成 Or.inl。

查看解答 定理 · 13 行
theorem pair_comm (α : Type) (a b : α) : {a, b} = {b, a} :=
  Set.ext {a, b} {b, a} (fun (x : α) =>
    @Iff.intro (x ∈ {a, b}) (x ∈ {b, a})  -- soko:notation-ok: G-30：分支含集合字面量，前导实参必须写全
      (fun (h : x ∈ {a, b}) =>
        @Or.elim (x = a) (x = b) ((x = b) ∨ (x = a))  -- soko:notation-ok: λ 体要靠这个显式调用拿到期望类型（引擎边界）
          (fun (ha : x = a) => Or.inr ha)
          (fun (hb : x = b) => Or.inl hb)
          h)
      (fun (h : x ∈ {b, a}) =>
        @Or.elim (x = b) (x = a) ((x = a) ∨ (x = b))  -- soko:notation-ok: λ 体要靠这个显式调用拿到期望类型（引擎边界）
          (fun (hb : x = b) => Or.inr hb)
          (fun (ha : x = a) => Or.inl ha)
          h))

2.4 元素 vs 单元素（实证上最脆弱的一点）

练习 9singleton_of_singleton定理附录解答

Hendriyanto et al. 2024（183 名学生）：r ∈ M / s ∉ M 几乎人人答对，但 {r} ∈ M 没有一个人给出正确理由。所以这里单独练它。

练习 10（D/R 类）：下面这条是学生最常写错的形状——它连类型都不对：

theorem wrong (a : Nat) : {a} ∈ {a} := sorry

请回答：(1) 为什么它类型不对（写在注释里）；(2) 写出正确的那条并证明它——"{a} 是 {{a}} 的元素"。

theorem singleton_of_singleton (a : Nat) : {a} ∈ {{a}} := by
  sorry
提示 1思路

x ∈ A 要求 x 与 A 的元素同型；这里 A 是 Set Nat，所以 x 必须是 Set Nat， 而 {a} 恰好是 Set Nat——目标只能是"{a} 属于一个装着集合的集合"。

提示 2目标形态

{a} ∈ {{a}}——外层的 { } 装的是集合，里层的 {a} 才是元素。

提示 3关键件

Eq.refl.{1} (Set Nat) {a}。

查看解答 定理 · 2 行

theorem pair_comm (α : Type) (a b : α) : {a, b} = {b, a} :=
  Set.ext {a, b} {b, a} (fun (x : α) =>
    @Iff.intro (x ∈ {a, b}) (x ∈ {b, a})  -- soko:notation-ok: G-30：分支含集合字面量，前导实参必须写全
      (fun (h : x ∈ {a, b}) =>
        @Or.elim (x = a) (x = b) ((x = b) ∨ (x = a))  -- soko:notation-ok: λ 体要靠这个显式调用拿到期望类型（引擎边界）
          (fun (ha : x = a) => Or.inr ha)
          (fun (hb : x = b) => Or.inl hb)
          h)
      (fun (h : x ∈ {b, a}) =>
        @Or.elim (x = b) (x = a) ((x = a) ∨ (x = b))  -- soko:notation-ok: λ 体要靠这个显式调用拿到期望类型（引擎边界）
          (fun (hb : x = b) => Or.inr hb)
          (fun (ha : x = a) => Or.inl ha)
          h))
