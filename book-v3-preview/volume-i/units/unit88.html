定义Injective声明 1
def Injective (α : Type) (β : Type) (f : α → β) : Prop :=
  ∀ (a : α) (b : α), f a = f b → a = b
定义Surjective声明 2
def Surjective (α : Type) (β : Type) (f : α → β) : Prop :=
  ∀ (b : β), ∃ (a : α), f a = b
定义Bijective声明 3
def Bijective (α : Type) (β : Type) (f : α → β) : Prop :=
  Injective α β f ∧ Surjective α β f

练习 3（L 类，补单元87 的欠账）：满射的复合还是满射。思路：给 c，先用 g 的满射取 b 与 g b = c，再用 f 的满射取 a 与 f a = b；最后把 g b = c 沿 f a = b 搬成 g (f a) = c（练习 1 的形态）。关键件：Exists.elim / Exists.intro · Eq.subst（跨类型搬运）

theorem surj_comp (α : Type) (β : Type) (γ : Type) (f : α → β) (g : β → γ)
    (hf : Surjective α β f) (hg : Surjective β γ g) :
    Surjective α γ (fun (x : α) => g (f x)) :=
  fun (c : γ) =>
    @Exists.elim β (fun (b : β) => g b = c) (∃ (a : α), g (f a) = c) (hg c)
      (fun (b : β) (hb : g b = c) =>
        @Exists.elim α (fun (a : α) => f a = b) (∃ (a : α), g (f a) = c) (hf b)
          (fun (a : α) (ha : f a = b) =>
            Exists.intro a
              (@Eq.subst.{1} β (fun (x : β) => g x = c) b (f a) (@Eq.symm.{1} β (f a) b ha)
                hb)))

编写注记 · 教材对照与课程边界（4 条）

靶子（教材）：Enderton《Elements of Set Theory》§3.3/§3.6 ·Halmos《Naive Set Theory》§8。大纲 §4.1（I.4 章继续深化 —— 补齐单元87 的满射半边 ✓）。

⚠⚠ 格位表（本单元换来、务必记住 ✓）：* rel_subst_left / rel_subst_right 的关系是 α → α → Prop（同一类型 ✗），且两者都只换"第二格" ✓ ⇒ 只能用于"关系两槽同类型"的搬运 ✓；* 要换 "函数参数那一格"（g b = d ⇒ g a = d，跨类型 ✗）⇒ 必须用 Eq.subst + 谓词 ✓：Eq.subst.{1} α (fun x => g x = d) b a h hd ✓（谓词写成 fun x => g x = d 而不是 fun x => g a = g x ✗ —— 方向由谓词决定 ✓）。本轮就是在这两点上判红两次后钉死的 ✓（前四次踩坑见单元83 / 87 ✓）。
