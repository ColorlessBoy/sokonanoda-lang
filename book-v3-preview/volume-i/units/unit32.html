靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§7.1 Orderings 里"函数空间上的序"那一类练习；Halmos《Naive Set Theory》§14 Order。大纲：set-theory-syllabus.md §4.1（I.11 章第五个单元）。

本单元的"该学的定理"：逐点序的三条基本律（自反 · 传递 · 与常函数的关系）·逐点相等给出逐点序 · 单调函数逐点作用于两边 ·旗舰：逐点上确界就是"逐点取上确界" —— 若每个坐标的上确界都存在，那么把它们拼起来的那个函数就是函数族在逐点序下的上确界（下确界同理）✓

写法约定：PointwiseLe / IsSup / UpperBound / Monotone 都是定义头 ⇒ 用之前先 λ 绑定（G-73 形状 ①）；库里有取用子（pointwiseLe_apply / monotone_apply / isSup_upper / isSup_least）优先用 ✓ 标识符里不要用撇号（f' 解析不了，实测 —— 用 f1 / f2 之类）✓

32.5 旗舰：逐点上确界 = 逐点取上确界

练习 9isSup_pointwise定理附录解答

练习 9（L 类，本单元旗舰）：每个坐标的上确界都存在 ⇒ 拼起来的函数是函数族的上确界。

theorem isSup_pointwise (α β : Type) (r : β → β → Prop) (F : (α → β) → Prop) (h : α → β)
    (hh : ∀ (a : α),
      IsSup β r (fun (y : β) => ∃ (f : α → β), F f ∧ (f a) = y) (h a)) :
    IsSup (α → β) (PointwiseLe α β r) F h := by
  sorry
提示 1思路

①上界：给定族里一个函数 f 与前坐标 a —— f a 是坐标那一族的元素（见证取 f 自己，等式的见证是自反）⇒ 由该坐标的上界性得 r (f a) (h a)；②最小：给定逐点上界 g 与坐标 a，坐标那一族的上界条件取 g a（对族里每个 f，逐点上界给出 r (f a) (g a)）⇒ 由该坐标的最小性得 r (h a) (g a)。

提示 2目标形态

(∀ a, IsSup β r (坐标族) (h a)) → IsSup (α → β) (PointwiseLe α β r) F h。

提示 3关键件

isSup_intro · isSup_upper / isSup_least 取用子 ·Exists.intro / Exists.elim（前导实参写全）· rel_subst_right（沿 f a = y 搬）·逐点上界假设先 λ 绑定（G-73 形状 ①）✓ ⚠ 标识符不要带撇号（f' 解析不了，用 f1）✓
