靶子（教材，逐条查过目录页）：Halmos《Naive Set Theory》§10 Inverses and Composites（关系版的复合与逆）；Enderton《Elements of Set Theory》§3.3 的同一批。大纲：set-theory-syllabus.md §4.1（新章 I.13「关系的代数」开工）。

本单元的"该学的定理"（关系构成一个代数 —— 有乘法（复合）、有逆、有单位）：

  • 结合律（(r • s) • t = r • (s • t)）· 逆的对合（(r ⁻¹) ⁻¹ = r）；
  • 旗舰：逆反穿过复合（(r • s) ⁻¹ = s ⁻¹ • r ⁻¹ —— 顺序要反过来）；
  • 单位元（恒等关系 idRel：idRel • r = r、r • idRel = r）；
  • 单调性（复合与逆对"逐点蕴含"单调）✓

写法约定：∃ 的拆装前导实参一律写全（G-73 形状 ②）；嵌套太深就用辅助定理（本单元的 comp_assoc_fwd / comp_assoc_bwd 就是为此拆的 —— 实测一次写成会少数括号）✓ 搬运等式时"第一个点"可以随便给（它在关系里是自由位），但类型要对（实测踩过）✓

36.0 画布给的新词汇：恒等关系（复合的单位元）

读法：idRel α 就是"两个点相等"这条关系 ✓ 它将是复合的单位元（练习 9、10）✓

定义idRel声明 1
def idRel (α : Type) : Rel α α :=
  fun (a : α) (b : α) => a = b

练习 2inv_comp定理附录解答

练习 2（L 类，本单元旗舰之一）：逆反穿过复合：(r • s) ⁻¹ = s ⁻¹ • r ⁻¹（顺序反过来）。

theorem inv_comp (A B C : Type) (r : Rel A B) (s : Rel B C) :
    ((r • s) ⁻¹) = (s ⁻¹ • r ⁻¹) := by
  sorry
提示 1思路

逐点看，左边是 ∃ b, r a b ∧ s b c，右边是 ∃ b, s b c ∧ r a b—— 把合取的两个支对调而已（见证取同一个 b）。

提示 2目标形态

(r • s) ⁻¹ = s ⁻¹ • r ⁻¹（注意两边都在 Rel C A 里）。

提示 3关键件

Rel.ext · Exists.elim/Exists.intro（前导实参写全）·And.left/And.right · Iff.intro（前导 Prop 实参写全）✓ ⚠ 两边定义上就等价（⁻¹ 只是把两个点掉头、• 是 ∃），所以不需要搬运引理 ✓

查看解答 定理 · 16 行
theorem inv_comp (A B C : Type) (r : Rel A B) (s : Rel B C) :
    @Eq.{1} (Rel C A) ((r • s) ⁻¹) (s ⁻¹ • r ⁻¹) :=  -- soko:notation-ok: G-73 形状 ②/③：前导实参或 `Eq` 层级在这些位置补不出来
  Rel.ext C A ((r • s) ⁻¹) (s ⁻¹ • r ⁻¹) (fun (c : C) (a : A) =>
    @Iff.intro (((r • s) ⁻¹) c a) ((s ⁻¹ • r ⁻¹) c a)
      (fun (h : ((r • s) ⁻¹) c a) =>
        @Exists.elim B (fun (b : B) => r a b ∧ s b c)
          (∃ (b : B), (s ⁻¹) c b ∧ (r ⁻¹) b a) h
          (fun (b : B) (hb : r a b ∧ s b c) =>
            Exists.intro b
              (And.intro (And.right hb) (And.left hb))))
      (fun (h : (s ⁻¹ • r ⁻¹) c a) =>
        @Exists.elim B (fun (b : B) => (s ⁻¹) c b ∧ (r ⁻¹) b a)
          (∃ (b : B), r a b ∧ s b c) h
          (fun (b : B) (hb : (s ⁻¹) c b ∧ (r ⁻¹) b a) =>
            Exists.intro b
              (And.intro (And.right hb) (And.left hb)))))

((r • s) ⁻¹) c a ↔ (s ⁻¹ • r ⁻¹) c a。

36.3 复合：结合律（拆成两个方向的辅助定理）

练习 4comp_assoc定理附录解答

练习 4（L 类，本单元旗舰之一）：结合律（(r • s) • t = r • (s • t)）。

theorem comp_assoc (A B C D : Type) (r : Rel A B) (s : Rel B C) (t : Rel C D) :
    ((r • s) • t) = (r • (s • t)) := by
  sorry
提示 1思路

逐点看，两边都是"存在两个中间点把三段接起来"，只是归纳的顺序不同 ⇒ 两个方向各拆一次 ∃、再各造一次 ∃。

提示 2目标形态

(r • s) • t = r • (s • t)。

提示 3关键件

Rel.ext · 两个方向各一个 Exists.elim 嵌套 · Exists.intro ·And.intro/And.left/And.right · 嵌套超过两层就拆成辅助定理 ——本题的解答里 comp_assoc_fwd/comp_assoc_bwd 正是为此，一次写成实测会少数括号 ✓

查看解答 定理 · 6 行
theorem comp_assoc (A B C D : Type) (r : Rel A B) (s : Rel B C) (t : Rel C D) :
    @Eq.{1} (Rel A D) ((r • s) • t) (r • (s • t)) :=  -- soko:notation-ok: G-73 形状 ②/③：前导实参或 `Eq` 层级在这些位置补不出来
  Rel.ext A D ((r • s) • t) (r • (s • t)) (fun (a : A) (d : D) =>
    @Iff.intro (((r • s) • t) a d) ((r • (s • t)) a d)
      (fun (h : ((r • s) • t) a d) => comp_assoc_fwd A B C D r s t a d h)
      (fun (h : (r • (s • t)) a d) => comp_assoc_bwd A B C D r s t a d h))

36.4 单调性（复合与逆对"逐点蕴含"单调）

练习 5comp_mono_left定理附录解答

练习 5（L 类）：复合对左边单调。

theorem comp_mono_left (A B C : Type) (r r1 : Rel A B) (s : Rel B C)
    (h : ∀ (a : A) (b : B), r a b → r1 a b) (a : A) (c : C)
    (hac : (r • s) a c) : (r1 • s) a c := by
  sorry
提示 1思路

拆开左边的 ∃，把中间点原样交出去，只把"第一个支"换成更强的那条。

提示 2目标形态

(∀ a b, r a b → r1 a b) → (r • s) a c → (r1 • s) a c。

提示 3关键件

Exists.elim/Exists.intro（前导实参写全）· And.intro ✓

查看解答 定理 · 8 行
theorem comp_mono_left (A B C : Type) (r r1 : Rel A B) (s : Rel B C)
    (h : ∀ (a : A) (b : B), r a b → r1 a b) (a : A) (c : C)
    (hac : (r • s) a c) : (r1 • s) a c :=

    (∃ (b : B), r1 a b ∧ s b c) hac
