23.0 两个新词汇（画布给出，不是练习）：柯里化与反柯里化

读法：curry 把"吃一个序对"的函数变成"吃两个参数"的函数，uncurry 反过来 ✓ 这一对就是"n 元关系 ↔ 逐次一元关系"的翻译（Enderton §3.5 的 n 元关系那一节）✓

定义curry声明 1
def curry (A B C : Type) (f : Prod A B → C) : A → B → C :=
  fun (a : A) (b : B) => f (@prod_mk A B a b)
定义uncurry声明 2
def uncurry (A B C : Type) (g : A → B → C) : Prod A B → C :=
  fun (p : Prod A B) => g (Prod.fst A B p) (Prod.snd A B p)

23.3 积与交：两个方向

练习 7pi_inter_subset定理附录解答

练习 7（L 类）：pi (A ∩ B) ⊆ pi A ∩ pi B（逐坐标取合取的左/右支）。

theorem pi_inter_subset (ι α : Type) (A B : ι → Set α) :
    (Set.pi ι α (fun (i : ι) => A i ∩ B i)) ⊆ ((Set.pi ι α A) ∩ (Set.pi ι α B)) := by
  sorry
提示 1思路

f 在交的积里 ⇒ 每个坐标 f i 同时在两个因子里（合取的左支与右支）⇒ 于是 f 同时在两个积里（合取打包）。

提示 2目标形态

(Set.pi ι α (fun i => A i ∩ B i)) ⊆ ((Set.pi ι α A) ∩ (Set.pi ι α B))。

提示 3关键件

Set.mem_pi_elim（取用子）· Set.mem_pi_intro（构造子）· And.left/And.right· And.intro（前导 Prop 实参可能补不出来时要写全，G-73 形状 ②）。

查看解答 定理 · 12 行
theorem pi_inter_subset (ι α : Type) (A B : ι → Set α) :
    (Set.pi ι α (fun (i : ι) => A i ∩ B i)) ⊆ ((Set.pi ι α A) ∩ (Set.pi ι α B)) :=
  fun (f : ι → α) (hf : f ∈ (Set.pi ι α (fun (i : ι) => A i ∩ B i))) =>
    And.intro
      (Set.mem_pi_intro ι α A f
        (fun (i : ι) =>
          (fun (hi : f i ∈ (A i ∩ B i)) => And.left hi)
            (Set.mem_pi_elim ι α (fun (i' : ι) => A i' ∩ B i') f i hf)))
      (Set.mem_pi_intro ι α B f
        (fun (i : ι) =>
          (fun (hi : f i ∈ (A i ∩ B i)) => And.right hi)
            (Set.mem_pi_elim ι α (fun (i' : ι) => A i' ∩ B i') f i hf)))

f 同时在两个积里 ⇒ 每个坐标左支来自第一个积、右支来自第二个 ⇒ f i 落在交里 ⇒ f 在交的积里。

((Set.pi ι α A) ∩ (Set.pi ι α B)) ⊆ (Set.pi ι α (fun i => A i ∩ B i))。

查看解答 定理 · 8 行
theorem pi_inter_subset_rev (ι α : Type) (A B : ι → Set α) :
    ((Set.pi ι α A) ∩ (Set.pi ι α B)) ⊆ (Set.pi ι α (fun (i : ι) => A i ∩ B i)) :=
  fun (f : ι → α) (hf : f ∈ ((Set.pi ι α A) ∩ (Set.pi ι α B))) =>
    Set.mem_pi_intro ι α (fun (i : ι) => A i ∩ B i) f
      (fun (i : ι) =>
        And.intro
          (Set.mem_pi_elim ι α A f i ((fun (hp : (Set.pi ι α A) f ∧ (Set.pi ι α B) f) => And.left hp) hf))
          (Set.mem_pi_elim ι α B f i ((fun (hp : (Set.pi ι α A) f ∧ (Set.pi ι α B) f) => And.right hp) hf)))

23.4 n 元关系：柯里化（把"二元输入"换成"两次一元输入"）

练习 9uncurry_curry定理附录解答

这一节的两个定义是画布给的（它们是新词汇）：curry 把 Prod A B → C 变成 A → B → C，uncurry 反过来 ✓

练习 9（L 类）：先 curry 再 uncurry 回到原地。

theorem uncurry_curry (A B C : Type) (f : Prod A B → C) (a : A) (b : B) :
    uncurry A B C (curry A B C f) (@prod_mk A B a b) = f (@prod_mk A B a b) := by
  sorry
提示 1思路

两边定义上就是同一个东西（把两个定义各展开一次，计算就完成了）⇒ 自反那一条。

提示 2目标形态

uncurry (curry f) (prod_mk a b) = f (prod_mk a b)。

提示 3关键件

Eq.refl（要写全宇宙层级与论域：结果的类型是 C）。

查看解答 定理 · 3 行
theorem uncurry_curry (A B C : Type) (f : Prod A B → C) (a : A) (b : B) :
    uncurry A B C (curry A B C f) (@prod_mk A B a b) = f (@prod_mk A B a b) :=
  @Eq.refl.{1} C (f (@prod_mk A B a b))

23.5 必破：选择公理正是"非空族的积非空"

练习 10pi_nonempty_of_choice定理附录解答

这是选择公理最经典的形式之一（Halmos §15 / Enderton §6.5）：要同时为所有因子挑元素，就得有一条"把 ∃ 兑现成函数"的规则 —— 本卷里那就是 lib.Choice 的 choice ✓

练习 10（D 类，本单元旗舰）：每个因子非空 ⇒ 积非空（用选择公理）。

theorem pi_nonempty_of_choice (ι α : Type) (A : ι → Set α)
    (h : ∀ (i : ι), ∃ (x : α), x ∈ A i) :
    ∃ (f : ι → α), f ∈ (Set.pi ι α A) := by
  sorry
提示 1思路

把选择公理用在关系"x 落在 A i 里"上（两侧集合都取全集）——它直接给你一个函数 f 与"逐点满足关系"；把"落在全集里"那一半丢掉，剩下的正是 f ∈ pi A。

提示 2目标形态

(∀ i, ∃ x, x ∈ A i) → ∃ f, f ∈ (Set.pi ι α A)。

提示 3关键件

choice（参数表：两个论域 · 两侧集合 · 关系 · 逐点存在性）·Exists.elim（前导实参写全）· Set.mem_pi_intro · And.right。⚠ 这就是为什么"积非空"在本卷里不是一条无条件定理：没有选择公理时它不成立 ✓

查看解答 定理 · 19 行
theorem pi_nonempty_of_choice (ι α : Type) (A : ι → Set α)
    (h : ∀ (i : ι), ∃ (x : α), x ∈ A i) :
    ∃ (f : ι → α), f ∈ (Set.pi ι α A) :=
  @Exists.elim (ι → α)
    (fun (f : ι → α) => ∀ (i : ι), i ∈ @Set.univ ι → f i ∈ @Set.univ α ∧ f i ∈ A i)
    (∃ (f : ι → α), f ∈ (Set.pi ι α A))
    (choice ι α (@Set.univ ι) (@Set.univ α) (fun (i : ι) (x : α) => x ∈ A i)
      (fun (i : ι) (hi : i ∈ @Set.univ ι) =>
        @Exists.elim α (fun (x : α) => x ∈ A i)
          (∃ (x : α), x ∈ @Set.univ α ∧ x ∈ A i) (h i)
          (fun (x : α) (hx : x ∈ A i) =>
            Exists.intro x
              (And.intro (Set.mem_univ x) hx))))
    (fun (f : ι → α)
      (hf : ∀ (i : ι), i ∈ @Set.univ ι → f i ∈ @Set.univ α ∧ f i ∈ A i) =>
      Exists.intro f
        (Set.mem_pi_intro ι α A f
          (fun (i : ι) =>
            (fun (hi : f i ∈ @Set.univ α ∧ f i ∈ A i) => And.right hi) (hf i (Set.mem_univ i)))))
