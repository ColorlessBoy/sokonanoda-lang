theorem subset_extensional (α : Type) :
    Extensional (Set α) (fun (A B : Set α) => A ⊆ B) :=
  fun (A B : Set α) (h : ∀ (C : Set α), C ⊆ A ↔ C ⊆ B) =>
    Set.ext A B (fun (x : α) =>

        ((fun (hAB : A ⊆ B) => hAB x) (Iff.mp (h A) (fun (y : α) (hy : y ∈ A) => hy)))

16.2 良基关系是反对称的：没有 2-循环

练习 3asymmetric_of_wellFounded定理附录解答

证明的骨架是"极小元作用在两个元素上"：取谓词 E a · ∨ E b ·（把 a、b 一起放进去），它的极小元 m 无论是被 a 还是被 b 见证，都会立刻撞上自己的极小性 ✓

练习 3（L 类）：良基 ⇒ 反对称（E a b 与 E b a 不能同时成立）。

theorem asymmetric_of_wellFounded (α : Type) (E : α → α → Prop)
    (hwf : IsWellFounded α E) (a b : α) : E a b → E b a → False := by
  sorry
提示 1思路

谓词取 fun z => E a z ∨ E b z（非空：b 在里，因为 E a b）。极小元 m 的极小性是"P 里的元素都不排在 m 前面"；而 a 与 b 都在 P 里（E a b / E b a 各证一条），于是 E a m、E b m 都被否掉 —— 但 P m 本身就是这两条之一，直接冲突。

提示 2目标形态

E a b → E b a → False。

提示 3关键件

wellFounded_hasMin + hasMin_elim + Or.elim（前导 Prop 实参写全，G-73 形状 ②）+ Exists.elim（同样写全）· 析取的两支各用一次极小性，注意 Or.inl/Or.inr 的方向别接反。

查看解答 定理 · 6 行
theorem asymmetric_of_wellFounded (α : Type) (E : α → α → Prop)
    (hwf : IsWellFounded α E) (a b : α) : E a b → E b a → False :=
  fun (hab : E a b) (hba : E b a) =>
    asymmetric_body α E a b hab hba
      (wellFounded_hasMin α E hwf (fun (z : α) => E a z ∨ E b z)
        (Exists.intro b (Or.inl hab)))
练习 4ordinal_no_self_mem定理附录解答

练习 4（L 类）：序数不属于自己。

theorem ordinal_no_self_mem (α : Type) (E : α → α → Prop) (x : α)
    (h : IsOrdinal α E x) : ¬ (E x x) := by
  sorry
提示 1思路

反证。谓词取 fun z => E x z（"排在 x 前面"），它非空（x 自己在里，这正是假设）。极小元 m 的极小性说"E x · 里的元素都不排在 m 前面"——把它用在 x 上，得到 ¬ E x m；而极小元自己就满足 E x m，冲突。

提示 2目标形态

¬ (E x x)。

提示 3关键件

ordinal_wellFounded（序数 ⇒ 环境良基）· wellFounded_hasMin ·hasMin_elim · 极小性那一条要先 fun (hall : …) => … 把类型写出来再应用（G-73 形状 ①）。

theorem ordinal_no_self_mem (α : Type) (E : α → α → Prop) (x : α)
    (h : IsOrdinal α E x) : ¬ (E x x) :=
  fun (hxx : E x x) =>
    (fun (hm : HasMin α E (fun (z : α) => E x z)) =>
      @Exists.elim α (fun (m : α) => (fun (z : α) => E x z) m ∧
          ∀ (y : α), (fun (z : α) => E x z) y → ¬ (E y m)) False
        (hasMin_elim α E (fun (z : α) => E x z) hm)
        (fun (m : α) (hmm : (fun (z : α) => E x z) m ∧
            ∀ (y : α), (fun (z : α) => E x z) y → ¬ (E y m)) =>
          (fun (hnot : ¬ (E x m)) => (fun (hxm : E x m) => hnot hxm) (And.left hmm))
            ((fun (hall : ∀ (y : α), (fun (z : α) => E x z) y → ¬ (E y m)) =>
              hall x hxx) (And.right hmm))))
      (wellFounded_hasMin α E (ordinal_wellFounded α E x h) (fun (z : α) => E x z)
        (Exists.intro x hxx))

theorem zero_unique (α : Type) (E : α → α → Prop) (he : Extensional α E)
    (x y : α) (hx : IsZero α E x) (hy : IsZero α E y) : x = y :=
  extensional_apply α E he x y (fun (z : α) =>
    @Iff.intro (E z x) (E z y)
      (fun (hzx : E z x) => False.elim (zero_no_elem α E x hx z hzx))
      (fun (hzy : E z y) => False.elim (zero_no_elem α E y hy z hzy)))

编写注记 · 教材对照与课程边界（4 条）

⚠ 本单元有意不含"三歧性"（"任意两个序数可比或相等"）：那是 §20 的核心，但它 不是直觉主义可证的 —— 证明要判"这个元素与那个元素可比吗"并消掉双重否定，即需要排中律（Lean 4 的 Classical.em / Decidable）；本语言两者都没有 ⇒ 已登记为台账 G-74，等语言侧给出古典逻辑再补这一课 ✓（不改成弱命题糊过去）。

本单元只允许用：intro / exact / apply / constructor / cases / have，加 import 进来的库引理。解答一律项风格。本单元 import 两样：lib.Ordinal（序数）与 lib.ZF（外延性）。

依赖：单元⑮（传递集与序数）—— 本单元用它的三条取用子。

⚠ 注意它是假设而不是公理：任意二元关系 E 当然可以不是外延的。Set α 那一侧的对应物是单元④ 用的公理 Set.ext —— 见练习 2 的对账。
