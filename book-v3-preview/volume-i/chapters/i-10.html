Unit 24 — Closure of Relations

13 个定理 · 10 道练习 · 30 条提示 · 解答附录

↑ 目录

靶子（教材，逐条查过目录页）：Enderton《Elements of Set Theory》§3.5 的关系运算 + §7.3 的传递集（闭包那一节）；Halmos《Naive Set Theory》§10 Relations 与 §18 的开头。大纲：set-theory-syllabus.md §4.1（I.9 之后新增的关系论单元）。

本单元的"该学的定理"：三种闭包的两条定律各一份 ——① 包含（原来的关系在闭包里）· ② 极小性（闭包是"最小的"那个闭关系）；传递闭包另外加两条：自己传递与幂等 ✓

写法约定（本单元特有）：闭包的定义都是定义头形态（∀ s, … → … → s a b）⇒ 凡是要"用它"的地方都得 先 fun (hh : <展开形态>) => … 把类型写出来再应用（G-73 形状 ①）；库里给了取用子 Rel.transClosure_elim，优先用它 ✓

24.3 自反闭包：它是自反的，而且是最小的

练习 4reflClosure_refl定理附录解答

练习 4（L 类）：自反闭包是自反的。

theorem reflClosure_refl (α : Type) (r : Rel α α) :
    Reflexive α (Rel.reflClosure α r) := by
  sorry
提示 1思路

要证 r⁼ a a，取析取的右支 a = a，用自反。

提示 2目标形态

Reflexive α (Rel.reflClosure α r)。

提示 3关键件

Or.inr（第三个实参是那条等式，写 Eq.refl 时要点名宇宙层级与论域）·Reflexive 是定义头 ⇒ 用 λ 交付。

查看解答 定理 · 4 行
theorem reflClosure_refl (α : Type) (r : Rel α α) :
    Reflexive α (Rel.reflClosure α r) :=
  fun (a : α) =>
    @Or.inr (r a a) (@Eq.{1} α a a) (@Eq.refl.{1} α a)  -- soko:notation-ok: G-73 形状 ③：`=` 的记法在这个位置解不出宇宙层级，必须点名声明星
练习 5reflClosure_min定理附录解答

练习 5（L 类，本单元旗舰之一）：自反闭包是最小的自反关系。

theorem reflClosure_min (α : Type) (r s : Rel α α) (hs : Reflexive α s)
    (hsub : ∀ (a : α) (b : α), r a b → s a b) :
    ∀ (a : α) (b : α), Rel.reflClosure α r a b → s a b := by

提示 1思路

把 r⁼ a b 拆成两支：左支直接交给"r ⊆ s"，右支（a = b）交给"s 自反"那一条 —— 注意右支要先沿等式把 s a a 搬成 s a b。

提示 2目标形态

Reflexive α s → (∀ a b, r a b → s a b) → ∀ a b, r⁼ a b → s a b。

提示 3关键件

Or.elim（前导 Prop 实参写全，含 = 的那一支要点名，G-73 形状 ⑧）·rel_subst_right（沿 a = b 把 s a a 搬成 s a b）· 自反那条假设（定义头 ⇒ λ 绑定后应用）。

    (hsub : ∀ (a : α) (b : α), r a b → s a b) :
    ∀ (a : α) (b : α), Rel.reflClosure α r a b → s a b :=
  fun (a : α) (b : α) (hab : Rel.reflClosure α r a b) =>

24.4 对称闭包：同两条定律

练习 6symClosure_symm定理附录解答

练习 6（L 类）：对称闭包是对称的（把两个析取支换个位置）。

theorem symClosure_symm (α : Type) (r : Rel α α) :
    Symmetric α (Rel.symClosure α r) := by
  sorry
提示 1思路

rˢ a b 是"r a b 或 r b a"；要证 rˢ b a（"r b a 或 r a b"）—— 两支互换即可。

提示 2目标形态

Symmetric α (Rel.symClosure α r)。

提示 3关键件

Or.elim（前导实参写全）· Or.inl/Or.inr（注意方向别接反）。

查看解答 定理 · 7 行
theorem symClosure_symm (α : Type) (r : Rel α α) :
    Symmetric α (Rel.symClosure α r) :=
  fun (a : α) (b : α) (hab : Rel.symClosure α r a b) =>
    @Or.elim (r a b) (r b a) (r b a ∨ r a b)
      (fun (h1 : r a b) => Or.inr h1)
      (fun (h2 : r b a) => Or.inl h2)
      hab

24.5 传递闭包：它传递，而且是最小的（本单元的正题）

练习 8transClosure_trans定理附录解答

练习 8（L 类，本单元旗舰）：传递闭包是传递的。

theorem transClosure_trans (α : Type) (r : Rel α α) :
    Transitive α (Rel.transClosure α r) := by
  sorry
提示 1思路

要证 r⁺ a c，展开形态说"给我传递的 s 与 r ⊆ s"；手里有 r⁺ a b 与 r⁺ b c —— 把同一组 s、r ⊆ s 分别喂给它们，得到 s a b 与 s b c，再用 s 自己的传递性接起来。

提示 2目标形态

Transitive α (Rel.transClosure α r)。

提示 3关键件

库里的取用子 Rel.transClosure_elim（参数表：关系 · 目标关系 s ·两个点 · 闭包证据 · s 的传递性 · r ⊆ s）—— 用两次 · Transitive 是定义头 ⇒ λ 交付。

theorem transClosure_trans (α : Type) (r : Rel α α) :
    Transitive α (Rel.transClosure α r) :=
  fun (a : α) (b : α) (c : α)
    (hab : Rel.transClosure α r a b) (hbc : Rel.transClosure α r b c) =>

        (hr : ∀ (x : α) (y : α), r x y → s x y) =>

        (Rel.transClosure_elim α r s b c hbc hs hr)

本单元的"该学的定理"（等价关系 = 划分这一定理的两半）：

  • 同类点有同样的类（r a b ⇒ ∀ c, r a c ↔ r b c）；
  • 类相同 ⟺ 相关（把两半合成一条 ↔）；
  • 不同的类不交（¬ r a b ⇒ 没有点同时在两个类里）；
  • 划分的三条：每个类非空 · 每个点落在某个类里 · 有公共点的两个类逐点相同 ✓

读法：Set α 就是 α → Prop ⇒ "等价类"直接写成谓词 Rel.EquivClass α r a（"与 a 相关的那些点"），"商集"写成"是某个等价类"这条性质 Rel.Classes α r ✓—— 于是整章不需要新类型（与 ST1 的谓词式口径一致）✓
