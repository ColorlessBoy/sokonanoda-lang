5.3 D 类：A × B = B × A 吗？

练习 6prod_set_swap_ne定理附录解答

先看"等式"本身：s ×ˢ t : Set (Prod A B)，而 t ×ˢ s : Set (Prod B A)。两个类型不同 —— 只要 A 与 B 不是同一个类型，"A × B = B × A" 这句话根本写不出来；换成数学语言：需要先有一个 A × B 到 B × A 的交换双射

fun (p : Prod A B) => prod_mk B A (Prod.snd A B p) (Prod.fst A B p)

（双射的正式定义在单元⑦ 与 ⑨；这里只点名，不证。）

退化情形（这时它才成立）：

  • A 与 B 取成同一个类型、并且 s = t：两侧是同一个表达式，等式自明；
  • s 或 t 是空集：两侧都是空集（用上面那个交换映射 + 空集成员刻画说明，本单元不证）。

但即使把类型取成同一个，s ≠ t 时两侧一般也不相等 —— 底下的原因是序对连交换都做不到：只有 a = b 时 prod_mk A A a b 与 prod_mk A A b a 才是同一个序对。下面的练习把这个反例证出来。（设计判断：有序对与 Kuratowski 编码没有实证研究支撑，此处不作"研究表明"的断言。）

练习 6（D 类）：A ×ˢ B = B ×ˢ A 的反例（同一类型上 s = {a}、t = {b}）。 把 prod_mk A A a b ∈ {a} ×ˢ {b} 沿假设的等式搬到 {b} ×ˢ {a} 上， 搬完它就变成 a = b ∧ b = a。

theorem prod_set_swap_ne (A : Type) (a b : A) (h : a ≠ b) :
    {a} ×ˢ {b} ≠ {b} ×ˢ {a} := by
  intro e
  -- `And.left` 的隐式实参只能按「显式实参的类型 + 期望类型」**语法反解**，而
  -- `@prod_mk A A a b ∈ ({b} ×ˢ {a})` 是 def 头（要 delta 展开才看得见 `∧`）⇒
  -- 先用一个**带标注的 λ** 把它落成语法上的 `∧`，体内就能写短写 `And.left hm` 
  exact h ((fun (hm : a = b ∧ b = a) => And.left hm)
    (@Eq.subst.{1} (Set (Prod A A))
      (fun (S : Set (Prod A A)) => @prod_mk A A a b ∈ S)
      ({a} ×ˢ {b}) ({b} ×ˢ {a}) e
      ((fun (hmem : a ∈ {a} ∧ b ∈ {b}) => hmem)
        (And.intro (Set.mem_singleton_self a) (Set.mem_singleton_self b)))))

theorem kura_degenerate (α : Type) (a b : α) (h : a = b) :
    {{a}, {a, b}} = {{a}} := by
  apply Set.ext
  intro x
  constructor
  intro hX
  have hmem : x = {a} := by
    cases hX with
      | Or.inl h1 => exact h1
      | Or.inr h2 =>
