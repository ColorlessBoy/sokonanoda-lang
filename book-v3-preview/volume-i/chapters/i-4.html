11.1 概括公理为什么在这里写不出来

概括公理（comprehension axiom）说：给定任何性质 P，都有集合

{ x | P x }

P x := 「x 不属于 x」，

得到 Ω = { x | x ∉ x }，然后问「Ω 属不属于 Ω」：答「属于」就说明 Ω 满足 P，按定义它不该属于；答「不属于」就说明它不满足 P，按定义它该属于。

这条论证在本语言里第一步就走不动。卡住的地方是记法：

  • 集合是 Set α，也就是 α → Prop：它总是某个固定类型 α 的谓词。隶属判定 x ∈ A 要求 x : α、A : Set α，两个参数的类型必须对上。
  • 于是「x ∈ x」要成立，同一个 x 得同时是 α 与 Set α——两个不同的类型，写不出来。Russell 集 { x | x ∉ x } 因此连写都写不出，更谈不上判真假。
  • 「一切集合」同样不是一个类型：Set α 与 Set β 是两个类型，Type 不是 Type。「存在一个集合包含一切集合」这句里的量词没有落脚的地方。

类型论对「一切」的处置是逐层给全集：11.2 就是它。

11.2 类型论的答案：每个类型有自己的全集

@Set.univ α 的定义是「不管来什么元素都答 True」，所以它是本类型里最大的集合（最大元），也就是这个类型的论域（universe of discourse）。下面三条把「最大」和「唯一」两件事做出来，第三条把 11.1 里写不出的那句话限制到一个类型内，于是它变成真的。

演示 1（已写好）：本类型里每个集合都被 univ 包含——univ 是「⊆」下的最大元。目标展开是 ∀ x, x ∈ A → x ∈ @Set.univ α，而 x ∈ @Set.univ α 就是 True，每个元素交 True.intro 即可（Set.mem_univ 正是这条）。

11.4 「一切集合」在类型论里的合法落点

练习 2mem_powerset_univ定理附录解答

概括公理要的是「把满足性质 P 的对象收成一个集合」。类型论里能收的只有 本类型的对象；要收「本类型的一切集合」，收出来的东西类型就升一层：

theorem mem_powerset_univ (α : Type) (A : Set α) :
    A ∈ 𝒫 (Set.univ) := by
  have hsub : A ⊆ Set.univ := by
    intro x
    intro hx
    exact Set.mem_univ x
  exact (Iff.mpr (Set.mem_powerset_iff (Set.univ) A)) hsub
