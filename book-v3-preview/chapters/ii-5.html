    进入 II.5：ℝ 的商、代数与序。第一件事是把 realRel 补成等价关系：㊵ 做了自反、㊷ 做了对称，还差传递性；传递性的标准证法是三角不等式加 ε 折半，而三角不等式要用的第一块地基正是「ℚ 的序是全序」。

  2. 46序的反对称性：两边夹出相等Unit 46 — Antisymmetry of the Order

    ㊺ 结清了「ℚ 的序是全序」，但要把序用在绝对值上还差一条反对称性：x ≤ y 且 y ≤ x 推出 x ~ y。

    4 个定理 · 4 道练习 · 12 条提示
  3. 47绝对值的唯一性：同一个数的两个见证相等Unit 47 — Uniqueness of the Absolute Value

    ㊺ 证了每个有理数都有绝对值，㊻ 证了序的反对称性。两者合起来就能回答绝对值是函数的那个问题：同一个 x 的两个见证 d、d' 相等。

    3 个定理 · 3 道练习 · 9 条提示
  4. 48三角不等式：|u + v| ≤ |u| + |v|Unit 48 — Triangle Inequality

    先看一个反例：1 的绝对值见证是 1，-1/2 的见证是 -1/2；把两个见证相加得到 3/2，而 |1 + (-1/2)| = 1/2。见证相加得不到 x+y 的见证。

    6 个定理 · 6 道练习 · 18 条提示
  5. 49严格序的传递与 close 对 ε 的单调性Unit 49 — Transitivity of the Strict Order; Monotonicity of close in ε

    ㊽ 给了三角不等式，close 的传递性还差两件工程件：ε 一旦定下来，往大走不改变 close；严格序 a < b < c 可以串起来——折半之后 0 < ε/2、ε/2 < ε 这类链条都要靠它。

    4 个定理 · 4 道练习 · 12 条提示
  6. 50严格序与加法相容：加法消去Unit 50 — Strict Order Compatible with Addition; Cancellation

    ㊹ 证明了 x ≤ y 推出 x+z ≤ y+z；严格序还差反方向的工程件：从 x+z ~ y+z 要能推回 x ~ y。这就是加法消去。

    5 个定理 · 5 道练习 · 15 条提示
  7. 51严格序的传递与加法相容Unit 51 — Transitivity of the Strict Order and Compatibility with Addition

    ㊾ 给了严格序自身的传递，㊿ 给了它与右加的相容。close 的传递性还要把弱序与严格序混着串，并把两个严格界相加：a ≤ b 且 b < c 推出 a < c；a < b 且 b ≤ c 推出 a < c；以及 a < b 且 c < d 推出 a+c < b+d。
