30有理数的严格序：< 与不相等

Unit 30 — Strict Order on Rationals

2 个定义 · 4 个定理 · 4 道练习 · 8 条提示 · 解答附录

单元㉙ 定义了非严格序 ratLeRep。严格序在数学上是「≤ 且不等」，在商上「不等」仍然用 ratRel 的否定表达（Rat 的相等就是 ratRel）：ratLtRep x y 当且仅当 ratLeRep x y 且非 ratRel x y。

这里先结清严格序的三条定义展开级事实：它不是自反的；它蕴含非严格序；非严格序加上不相等就是它。再加一个具体计算 0 < 1：序的部分用 ㉙ 的 le_succ，不等的部分把 ratRel 0 1 化成 0 = 1，由 succ_ne_zero 否定。

传递性、全序与加法/乘法相容仍要先通分，留给后续单元。

定义ratLeRep声明 1
def ratLeRep (x y : ratRep) : Prop :=
  leRep (mulRep (numOf x) (den (denOf y)))
        (mulRep (numOf y) (den (denOf x)))
定义ratLtRep声明 2
def ratLtRep (x y : ratRep) : Prop :=
  ratLeRep x y ∧ ¬ ratRel x y
练习 1ratLtRep_irrefl定理附录解答

㉚.1 严格序不⊂自反

-- 严格序是「≤ 且不等」，所以它首先不可能自反。

theorem ratLtRep_irrefl (x : ratRep) : ¬ ratLtRep x x :=
  sorry
提示 1目标形态

¬ ratLtRep x x。

提示 2关键件

And.right（取第二分量）· ratRel_refl · Not.elim（或 fun h => (And.right h) (ratRel_refl x)）。

查看解答 定理 · 2 行
theorem ratLtRep_irrefl (x : ratRep) : ¬ ratLtRep x x :=
  fun (h : ratLtRep x x) => (And.right h) (ratRel_refl x)

-- 严格序蕴含非严格序：取下合取式的左分量。

theorem ratLtRep_implies_le (x y : ratRep) (h : ratLtRep x y) : ratLeRep x y :=

ratLtRep x y → ratLeRep x y。

And.left。

㉚.3 非严格序 + 不相等 = 严格序

-- 反方向：≤ 加上不相等就是 <。

theorem ratLtRep_of_le_ne (x y : ratRep)
    (hle : ratLeRep x y) (hne : ¬ ratRel x y) : ratLtRep x y :=

ratLeRep x y → ¬ ratRel x y → ratLtRep x y。

提示 2关键件

And.intro。

theorem ratLtRep_of_le_ne (x y : ratRep)
    (hle : ratLeRep x y) (hne : ¬ ratRel x y) : ratLtRep x y :=
  And.intro hle hne

㉚.4 具体数字：0 < 1

-- 具体算 0 < 1：序用 le_succ，不等的部分化成 0 = 1 再否定。

theorem demo_zero_lt_one :
    ratLtRep (qrep Nat.zero Nat.zero Nat.zero) (qrep 1 Nat.zero Nat.zero) :=
  sorry
提示 1目标形态

ratLtRep (qrep 0 0 0) (qrep 1 0 0)。

提示 2关键件

And.intro · le_succ · le_refl · Eq.symm · succ_ne_zero。

查看解答 定理 · 6 行
theorem demo_zero_lt_one :
    ratLtRep (qrep Nat.zero Nat.zero Nat.zero) (qrep 1 Nat.zero Nat.zero) :=
  And.intro
    (le_succ Nat.zero Nat.zero (le_refl Nat.zero))
    (fun (h : ratRel (qrep Nat.zero Nat.zero Nat.zero) (qrep 1 Nat.zero Nat.zero)) =>
      succ_ne_zero Nat.zero (Eq.symm h))
