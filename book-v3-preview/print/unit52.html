close 的传递性要把两个 ε/2 的界加起来，所以先要有「半数」：对任意有理数 x，构造 x/2 的一个代表元，并证明 x/2 + x/2 与 x 相等。

代表元层不需要除法：(a-b)/(m+1) 的一半就是 (a-b)/(2m+2)，也就是把分母字段从 m 换成 2m+1（真正的分母 2m+2 = 2(m+1)）。于是 ratHalf (qrep a b m) := qrep a b (2m+1)，分子序对根本不用动。

先补一条定义性等式：2m+2 = (m+1)+(m+1)（注意 Nat.add 对第二个参数递归，所以这条不是 Eq.refl，要走 succ_add 与 add_succ）；再证两条纯 ℕ 算术：D(m+1)+D(m+1) = D·D（D = 2m+2）与 (x·D+x·D)(m+1) = x·(D·D)。最后把这两条装成 x/2 + x/2 与 x 相等，再用 aux 把字面三元组搬到任意代表元（ratRep 是定义别名，match 只认展开类型）。
