Unit 12 — Order on Representatives

3 个定义 · 8 个定理 · 1 个归纳类型 · 6 道练习 · 18 条提示 · 解答附录

加法和乘法都在代表元上安顿好了，现在轮到序。整数 a-b 不大于 c-d，两边同加 b+d 就能把减法消掉：它等价于 a+d ≤ c+b。于是 ℤ 上的序化归成 ℕ 上的序——但 ℕ 上的 ≤ 本语言也没有内建，得先自己造一个。

造法沿用通常的归纳定义：LeNat 有两条构造规则——自反，以及从 m ≤ n 得到 m ≤ n+1。序因此是命题而不是布尔值：证明 leRep p q，就是给出这条构造子链。有了它，代表元层的序就取 a+d ≤ c+b；它的良定义性与序公理留给后续单元。

归纳类型LeNat声明 1
inductive LeNat : Nat → Nat → Prop
ctor le_refl (n : Nat) : LeNat n n
ctor le_succ (m : Nat) (n : Nat) : LeNat m n → LeNat m (Nat.succ n)
end
定义intRel声明 2
def intRel (a b : Prod Nat Nat) : Prop :=
  Nat.add (Prod.fst Nat Nat a) (Prod.snd Nat Nat b) =
  Nat.add (Prod.fst Nat Nat b) (Prod.snd Nat Nat a)
定义Int声明 3
def Int : Type := @Quot.{1} (Prod Nat Nat) intRel

代表元层的序：a-b ≤ c-d 当且仅当 a+d ≤ c+b。

定义leRep声明 4
def leRep (p q : Prod Nat Nat) : Prop :=
  LeNat (Nat.add (Prod.fst Nat Nat p) (Prod.snd Nat Nat q))
        (Nat.add (Prod.fst Nat Nat q) (Prod.snd Nat Nat p))

先看构造子本身：每个自然数都不大于它的后继。

练习 1leRep_mk定理附录解答

先确认 leRep 只是 LeNat 的改名：代进去两边定义性相等。

theorem leRep_mk (a b c d : Nat) :
    leRep (@prod_mk Nat Nat a b) (@prod_mk Nat Nat c d) =
    LeNat (Nat.add a d) (Nat.add c b) :=
  sorry
提示 1思路

leRep 是定义，把 prod_mk a b 与 prod_mk c d 代进去就是右边的形状，两边定义性相等。

提示 2目标形态
leRep(a,b)(c,d)=LeNat(a+d)(c+b)
提示 3关键件

Eq.refl（定义性相等，不需要归纳）。

查看解答 定理 · 4 行
theorem leRep_mk (a b c d : Nat) :
    leRep (@prod_mk Nat Nat a b) (@prod_mk Nat Nat c d) =
    LeNat (Nat.add a d) (Nat.add c b) :=
  Eq.refl (LeNat (Nat.add a d) (Nat.add c b))
练习 2leRep_refl定理附录解答

每个差都不大于自己：任意序对 p 都是某个 (a,b)，两边都是 a+b。

theorem leRep_refl (p : Prod Nat Nat) : leRep p p :=
  sorry
提示 1思路

任意 p 都是某个序对 prod_mk a b；此时 leRep p p 的两边都是 a+b。

提示 2目标形态

leRep (a,b) (a,b)，即 LeNat (a+b) (a+b)。

提示 3关键件

对 p 做 match（拆成 prod_mk a b）· le_refl。

查看解答 定理 · 3 行
theorem leRep_refl (p : Prod Nat Nat) : leRep p p :=
  match p with
  | prod_mk a b => le_refl (Nat.add a b)
练习 3leRep_one_two定理附录解答

具体例子：1-0 ≤ 2-0 即 1 ≤ 2，从 1 ≤ 1 往上抬一层。

theorem leRep_one_two :

提示 1思路

1 - 0 ≤ 2 - 0 即 1 + 0 ≤ 2 + 0，也就是 1 ≤ 2；从 1 ≤ 1 往上抬一层。

提示 2目标形态

LeNat (Nat.add 1 Nat.zero) (Nat.add 2 Nat.zero)，字面量会算成 LeNat 1 2。

提示 3关键件

le_succ 1 1 (le_refl 1)。

theorem leRep_one_two :

  le_succ 1 1 (le_refl 1)

练习 6leNat_zero_le定理附录解答

再证基本事实：0 不大于任何自然数（对 n 归纳）。

theorem leNat_zero_le (n : Nat) : LeNat Nat.zero n :=
  sorry
提示 1思路

对 n 归纳。零情形用 le_refl；后继情形把归纳假设 ih : LeNat 0 k 用 le_succ 抬一层。

提示 2目标形态

LeNat Nat.zero n（n = 0 与 n = succ k 两个分支）。

提示 3关键件

match n（后继分支自动带 ih）· le_refl · le_succ。

查看解答 定理 · 4 行
theorem leNat_zero_le (n : Nat) : LeNat Nat.zero n := by
  match n with
  | Nat.zero => le_refl Nat.zero
  | Nat.succ k => le_succ Nat.zero k ih
