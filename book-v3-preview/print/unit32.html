单元㉛ 有了负元，减法就是 x - y := x + (-y)，代表元上即 ratSubRep x y := ratAddRep x (ratNegRep y)。由于 -(c-d)/(n+1) = (d-c)/(n+1)，减法的分子是 a(n+1) + d(m+1)，负部是 b(n+1) + c(m+1)——与加法公式只差第二个分子的两个坐标互换。

这里要结清三件事：计算规则（一条 ι 归约）；对第一、第二因子的良定义性（都化归到 ㉖ 的加法义务与 ㉛ 的负元义务）；以及具体计算 1 - 1/2 = 1/2。

减法的代数律（x - x 与 0 相等、x - y 与 -(y - x) 相等）留给后续单元。
