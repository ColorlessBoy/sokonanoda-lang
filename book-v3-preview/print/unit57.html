Unit 57 — Transitivity of Close: Adding Two ε/2 Bounds

4 个定理 · 4 道练习 · 12 条提示 · 解答附录

㊱ 把实数的相等定义成 Cauchy 序列逐点 close，而 close x y eps 说的是「存在一个 d，它等于 |x-y| 且 d < eps」。要证明 realRel 是等价关系，还差传递性：close x y ε/2 与 close y z ε/2 推出 close x z ε。

57.1 严格序在右端沿 ratRel 搬运

练习 1ratLtRep_congr_snd定理附录解答

直觉是「三角不等式加 ε 折半」，但代表元层要把三件事接起来：|x-z| 与 |(x-y)+(y-z)| 是同一个数的两个见证（上一单元把后者的和认成 x-z，再沿相等把绝对值搬过去）；三角不等式给出 d ≤ dx+dy；而 dx < ε/2 与 dy < ε/2 加起来是 dx+dy < ε（严格序传递与半数加倍）。

先补一条严格序沿右端搬相等的引理，再证两个半数界相加，然后拼出主定理，最后落在 close 0 0 2 上。前序事实证明已在 lib/RatClose。

严格序沿右端搬相等：弱序搬过去，不相等反之。

theorem ratLtRep_congr_snd (a b c : ratRep)
    (h : ratLtRep a b) (hbc : ratRel b c) : ratLtRep a c :=
  sorry
提示 1思路

ratLtRep a b 是 ratLeRep a b ∧ ¬ ratRel a b。弱序沿 b ~ c 用 ㊴ 的 ratLeRep_congr_gen 搬过去（第一个因子取 ratRel_refl a）；不相等部分假设 a ~ c，与 c ~ b 串成 a ~ b，撞上第二分量。

提示 2目标形态

ratLtRep a b → ratRel b c → ratLtRep a c。

提示 3关键件

ratLtRep a b 是 ratLeRep a b ∧ ¬ ratRel a b：弱序沿 b ~ c 搬 （㊴ 的 ratLeRep_congr_gen），不相等部分把 a ~ c 与 c ~ b 串成 a ~ b。

theorem ratLtRep_congr_snd (a b c : ratRep)
    (h : ratLtRep a b) (hbc : ratRel b c) : ratLtRep a c :=
  And.intro
    (ratLeRep_congr_gen a a b c (ratRel_refl a) hbc (And.left h))
    (fun (hac : ratRel a c) =>
      And.right h
        (ratRel_trans_gen a c b hac (ratRel_symm b c hbc)))

57.2 两个半数界相加：dx < ε/2、dy < ε/2 ⇒ dx + dy < ε

两个半数界相加：dx < ε/2 与 dy < ε/2 推出 dx+dy < ε。

theorem ratAdd_lt_half (dx dy eps : ratRep)

查看解答 定理 · 9 行

theorem ratAdd_lt_half (dx dy eps : ratRep)

57.3 主定理：close 的传递性

练习 3close_trans定理附录解答

主定理：两个 close ε/2 拼成 close ε。

theorem close_trans (x y z eps : ratRep) (heps : ratLtRep ratZeroRep eps)
    (hxy : close x y (ratHalf eps)) (hyz : close y z (ratHalf eps)) :
    close x z eps :=
  sorry
提示 1思路

两个 Exists.elim 取出见证 dx、dy；用 ㊺ 的 ratAbsRel_total 给 (x - y) + (y - z) 取见证 d；三角不等式（㊽ 的 ratLeRep_abs_add）给 d ≤ dx + dy；57.2 给 dx + dy < ε；d < ε 由 51 的 ratLtRep_of_le_lt 夹出来。绝对值的第一分量沿 56 的 ratSubRep_add 用 ㊷ 的 ratAbsRel_wd_left 搬到 x - z。

提示 2目标形态

close x y (ratHalf eps) → close y z (ratHalf eps) → close x z eps。

提示 3关键件

Exists.elim · Exists.intro · ratAbsRel_total · ratSubRep_add · ratAbsRel_wd_left · ratLeRep_abs_add · ratLtRep_of_le_lt · ratAdd_lt_half。

查看解答 定理 · 29 行

展开两个 close 得见证 dx、dy；用 ㊺ 的 ratAbsRel_total 给 (x - y) + (y - z) 取一个见证 d，三角不等式给 d ≤ dx + dy， 绝对值的第一分量沿 56 的 ratSubRep_add 搬到 x - z。

theorem close_trans (x y z eps : ratRep) (heps : ratLtRep ratZeroRep eps)
    (hxy : close x y (ratHalf eps)) (hyz : close y z (ratHalf eps)) :
    close x z eps :=
  Exists.elim hxy
    (fun (dx : ratRep)
        (hdx : ratAbsRel (ratSubRep x y) dx ∧ ratLtRep dx (ratHalf eps)) =>
      Exists.elim hyz
        (fun (dy : ratRep)
            (hdy : ratAbsRel (ratSubRep y z) dy ∧ ratLtRep dy (ratHalf eps)) =>
          Exists.elim
            (ratAbsRel_total
              (ratAddRep (ratSubRep x y) (ratSubRep y z)))
            (fun (d : ratRep)
                (hd : ratAbsRel
                  (ratAddRep (ratSubRep x y) (ratSubRep y z)) d) =>
              Exists.intro d
                (And.intro
                  (ratAbsRel_wd_left
                    (ratAddRep (ratSubRep x y) (ratSubRep y z))
                    (ratSubRep x z)
                    d
                    (ratSubRep_add x y z)
                    hd)
                  (ratLtRep_of_le_lt d (ratAddRep dx dy) eps
                    (ratLeRep_abs_add
                      (ratSubRep x y) (ratSubRep y z) dx dy d
                      (And.left hdx) (And.left hdy) hd)
                    (ratAdd_lt_half dx dy eps
                      (And.right hdx) (And.right hdy)))))))
