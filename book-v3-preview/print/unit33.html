Unit 33 — Absolute Value of Rationals

4 个定义 · 4 个定理 · 4 道练习 · 8 条提示 · 解答附录

绝对值 |x| 在代表元上要按 x ≥ 0 与 x ≤ 0 分情况，但本语言没有可判定的序（也就没有 if），所以用关系而不是函数来定义它：ratAbsRel x y 当且仅当 (0 ≤ x 且 y ~ x) 或 (x ≤ 0 且 y ~ -x)。

读作「y 是 x 的绝对值」。两条引入规则正好对应两个分支；具体计算 |-1/2| = 1/2 走右分支。唯一性（|x| 真的只有一个值）需要序的三歧性，留给后续单元；这里先把定义与两条引入规则立起来，供 Cauchy 序列的 |x_n - x_m| 使用。

完整代码 · 3 行
def ratAbsRel (x y : ratRep) : Prop :=
  (ratLeRep ratZeroRep x ∧ ratRel y x) ∨
    (ratLeRep x ratZeroRep ∧ ratRel y (ratNegRep x))
