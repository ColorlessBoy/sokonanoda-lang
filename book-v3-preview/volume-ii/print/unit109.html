109完备性收口：Cauchy 序列的极限类

Unit 109 — Completeness: Limit Classes of Cauchy Sequences

1 个定义 · 11 个定理 · 8 道练习 · 24 条提示 · 解答附录

104 到 108 把极限类当已知对象使用：给定一个类，谈它的加、减、取负。这里回答最后的问题——每个 Cauchy 序列究竟有没有极限类？有，而且唯一。存在性来自 68 的代表元层完备性：Cauchy 序列收敛到自己的类。两条合起来说明「Cauchy」与「在 ℝ 中有极限」是同一件事。

反方向也要补：序列在代表元层收敛到一个 Cauchy 序列时，它自己是 Cauchy 的。这不是定义展开，要把两条误差界合起来重新估计：四个见证合并到同一个下标，两支界各减去中间项，再由绝对值见证收成 close。109.0–109.3 备好这些估计，109.4 证明反方向，109.5–109.9 把等价、存在唯一与常序列收齐。

边界：只断言 Cauchy 序列有极限类。商里还有不代表 Cauchy 序列的杂点，它们不在任何极限类的像里，这里不声称每个实数都是某条序列的极限。不新增公理。

109.3 两条半个 eps 的界合成 close

练习 2close_of_half_bounds定理附录解答

close a b eps 要一个严格小于 eps 的绝对值的见证。全性先给出一个见证 d；两条半个 eps 的界把 d 压到 eps/2，再由 eps/2 < eps 收紧。两条界分别是差本身与它的相反数。

theorem close_of_half_bounds (a b eps : ratRep)
    (heps : ratLtRep ratZeroRep eps)
    (h1 : ratLeRep (ratSubRep a b) (ratHalf eps))
    (h2 : ratLeRep (ratNegRep (ratSubRep a b)) (ratHalf eps)) :
    close a b eps :=
  sorry
提示 1思路

ratAbsRel_total 给出见证 d；ratAbsRel_le_of_bounds 用两条界把 d 压到 eps/2；ratLtRep_of_le_lt 与 ratHalf_lt_self 把 d 收到 eps 以下。

提示 3关键件

查看解答 定理 · 12 行

全性给出差的一个绝对值见证 d。两条界把 d 压到 eps/2：把正支与 负支分别与 a - b、-(a - b) 比较，取较大的一支就是 eps/2。再用 eps/2 < eps 把非严格的 d ≤ eps/2 收紧成 d < eps。

theorem close_of_half_bounds (a b eps : ratRep)
    (heps : ratLtRep ratZeroRep eps)
    (h1 : ratLeRep (ratSubRep a b) (ratHalf eps))
    (h2 : ratLeRep (ratNegRep (ratSubRep a b)) (ratHalf eps)) :
    close a b eps :=
  Exists.elim (ratAbsRel_total (ratSubRep a b))
    (fun (d : ratRep) (hd : ratAbsRel (ratSubRep a b) d) =>
      Exists.intro d
        (And.intro hd
          (ratLtRep_of_le_lt d (ratHalf eps) eps
            (ratAbsRel_le_of_bounds (ratSubRep a b) (ratHalf eps) d hd h1 h2)
            (ratHalf_lt_self eps heps))))

109.4 有极限类 ⇒ Cauchy

练习 3tendsTo_cauchy定理附录解答

对 eps > 0，以 eps8 eps 调用收敛性，得到阈值 N。对 n, m ≥ N 抽出四个见证：x n 与 x m 各自的两条界。四个阈值用 leNat_max 并成同一个下标 K，在 K 上：

  • x n - L K ≤ e + e，L K - x m ≤ e + e，相加得 x n - x m 不超过 eps/2；
  • 交换 n 与 m 得另一支，x m - x n 也不超过 eps/2。
