Unit 102 — Equivalent Forms of the Cauchy Condition

7 个定理 · 7 道练习 · 21 条提示 · 解答附录

Cauchy 定义对尾巴上任意两项同时提要求。实际估计往往只固定一个下标 n，把另一项写成 n + k；如果每个 k 都要重新挑阈值，工作量会翻倍。把两项比较改写成定向比较与尾部跳跃两种形状，后面的级数部分和只需处理一个方向。

102.0 定向形式：只比较 n ≤ m 的一侧

练习 1cauchy_oriented定理附录解答

102.0–102.2 收定向形式：只比较 n ≤ m 的一侧。102.3–102.5 收跳跃形式：固定 n，让 k 任意跑。两种形式都与原定义等价，常序列作为实例。

边界：跳跃形式要求对 k 一致成立；只要求相邻项接近（k = 1）不足以推出 Cauchy，反例属于级数章，这里不展开。本单元只改写定义，不新增公理。

原定义对 n、m 对称；定向形式保留 n ≤ m 的一支。正向是直接削弱：Cauchy 本来就对任意一对下标给接近性，多出来的 n ≤ m 用不上。

theorem cauchy_oriented (x : Seq) (h : Cauchy x) :
    ∀ (eps : ratRep), ratLtRep ratZeroRep eps →
      ∃ (N : Nat), ∀ (n m : Nat), LeNat N n → LeNat n m →
        close (x n) (x m) eps :=
  sorry
提示 1思路

拆开 h eps heps 得阈值 N；对 n、m ≥ N，先用 leNat_trans N n m hn hnm 得到 N ≤ m，再把两条界交给 hN n m。

提示 2目标形态

∃ (N : Nat), ∀ (n m : Nat), LeNat N n → LeNat n m → close (x n) (x m) eps。

提示 3关键件

Exists.elim · Exists.intro。

theorem cauchy_oriented (x : Seq) (h : Cauchy x) :
    ∀ (eps : ratRep), ratLtRep ratZeroRep eps →
      ∃ (N : Nat), ∀ (n m : Nat), LeNat N n → LeNat n m →
        close (x n) (x m) eps :=
  fun (eps : ratRep) (heps : ratLtRep ratZeroRep eps) =>
    Exists.elim (h eps heps)
      (fun (N : Nat)
          (hN : ∀ (n m : Nat), LeNat N n → LeNat N m →
            close (x n) (x m) eps) =>
        Exists.intro N
          (fun (n m : Nat) (hn : LeNat N n) (hnm : LeNat n m) =>
            hN n m hn (leNat_trans N n m hn hnm)))

      ∃ (N : Nat), ∀ (n m : Nat), LeNat N n → LeNat n m →

theorem cauchy_oriented (x : Seq) (h : Cauchy x) :
    ∀ (eps : ratRep), ratLtRep ratZeroRep eps →
      ∃ (N : Nat), ∀ (n m : Nat), LeNat N n → LeNat n m →
        close (x n) (x m) eps :=
  fun (eps : ratRep) (heps : ratLtRep ratZeroRep eps) =>
    Exists.elim (h eps heps)
      (fun (N : Nat)

        Exists.intro N
