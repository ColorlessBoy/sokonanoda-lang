Unit 70 — The Number Chain: Addition Across the Four Layers

3 个定义 · 6 个定理 · 6 道练习 · 18 条提示 · 解答附录

69 把序从 ℕ 一路搬到 ℝ。本单元搬加法：

  • ℕ 的 Nat.add 在 ℤ 的代表元上就是 addRep；
  • ℚ 的代表元加法是 ratAddRep；
  • ℝ 的加法是 61 的三元关系 addRel a b c（存在 + 唯一），不是函数——Quot.lift 外层要函数相等，而杂点让像不唯一。

于是「嵌入保持加法」在 ℝ 层写成：

addRel (natToReal n) (natToReal m) (natToReal (n + m))

每一层都只做定义性归约 + 一条已知律：

细节清单（5 项，展开）
  • 70.1：addRep (n,0) (m,0) 与 (n+m, 0) 定义性相等（0+0 归约成 0）；
  • 70.2：ratAddRep 在分母 1 上归约成 (p+q)/1；
  • 70.4：addRel_intro 直接给出和，两个 Cauchy 守卫由 68.1 付清；
  • 70.5：70.2 与 70.4 的合成；
  • 70.6/70.7：具体数字与唯一性（addRel_unique）。

代价说明：ℝ 层是关系而不是函数，所以本单元没有「嵌入是群同态」的函数等式可写；写成 addRel 的三元组正是 61 的诚实部分结论。

本单元：

细节清单（8 项，展开）

  • 70.1 natToInt_add —— ℕ 的加法进 ℤ；

addRel_intro 要两个 Cauchy 守卫；常序列的 Cauchy 性是 68.1。 addSeq (constSeq x) (constSeq y) 与 constSeq (ratAddRep x y) 在 fun n => x + y 上定义性相等。

theorem ratToReal_add (x y : ratRep) :
    addRel (Real.mk (constSeq x)) (Real.mk (constSeq y))
      (Real.mk (constSeq (ratAddRep x y))) :=
  addRel_intro (constSeq x) (constSeq y) (cauchy_const x) (cauchy_const y)

    addRel (natToReal n) (natToReal m) (natToReal (Nat.add n m)) :=
  ratToReal_add (intToRatRep (natToIntRep n)) (intToRatRep (natToIntRep m))
