Unit 63 — Addition on the Reals: Associativity (Ternary Relation)

4 个定理 · 4 道练习 · 12 条提示 · 解答附录

上一单元给了三元关系 addRel 的交换律与零元。现在补上结合律：若 a+b = s 且 s+c = t，则 b+c 有输出 u，且 a+u = t。写成存在形式就是 addRel a b s 推出 addRel s c t 推出「存在 u，使 addRel b c u 且 addRel a u t」。

63.1 代表元层：(x + y) + z ~ x + (y + z)

练习 1realRel_add_assoc定理附录解答

它是重括号的合法性：左边的 (a+b)+c 与右边的 a+(b+c) 落在同一个 t 上。注意右边不是函数，所以结论只能写成「存在 u」；而上单元的 addRel_unique 保证这样的 u 唯一。

证明分两层。代表元层先证 (x+y)+z 与 x+(y+z) 相等（㉔ 的结合律经 close 的桥逐点搬到 realRel）；再把已知的 (x+y)+z = t 换成 t = mk (x+(y+z))；然后在商层对 a、b、c 各做一次 Quot.ind，用 mk 层的结果收口。

边界仍是上一单元的部分关系：addRel a b s 的两个前提分量带着 Cauchy 守卫，所以 mk 层要显式接收 Cauchy x、Cauchy y；不新增信任。

代表元层：(x+y)+z 与 x+(y+z) 相等。

theorem realRel_add_assoc (x y z : Seq) (hx : Cauchy x) (hy : Cauchy y)
    (hz : Cauchy z) :
    realRel (addSeq (addSeq x y) z) (addSeq x (addSeq y z)) :=
  sorry
提示 1思路

两个 Cauchy 分量各是两次 60 的 cauchy_add；第三分量取 N := 0，逐点用㉔的 ratAdd_assoc 加 62 的 close_of_ratRel。

theorem realRel_add_assoc (x y z : Seq) (hx : Cauchy x) (hy : Cauchy y)
    (hz : Cauchy z) :
    realRel (addSeq (addSeq x y) z) (addSeq x (addSeq y z)) :=
  And.intro
    (cauchy_add (addSeq x y) z (cauchy_add x y hx hy) hz)
    (And.intro
      (cauchy_add x (addSeq y z) hx (cauchy_add y z hy hz))
      (fun (eps : ratRep) (heps : ratLtRep ratZeroRep eps) =>
        Exists.intro Nat.zero
          (fun (n : Nat) (_hn : LeNat Nat.zero n) =>
            close_of_ratRel (addSeq (addSeq x y) z n)
              (addSeq x (addSeq y z) n)
              (ratAdd_assoc (x n) (y n) (z n)) eps heps)))

63.2 mk 层：(x + y) + z = t ⇒ ∃ u, y + z = u ∧ x + u = t

练习 2addRel_assoc_mk定理附录解答

mk 层：已知 (x+y)+z = t，构造 u := mk (y+z)。

theorem addRel_assoc_mk (x y z : Seq) (t : Real)
    (hx : Cauchy x) (hy : Cauchy y)
    (h : addRel (Real.mk (addSeq x y)) (Real.mk z) t) :
    ∃ (u : Real), addRel (Real.mk y) (Real.mk z) u ∧
      addRel (Real.mk x) u t :=
  sorry
提示 1思路

见证取 u := mk (y+z)。第一个 addRel 用 61 的 addRel_intro（Cauchy y 是假设，Cauchy z 从 h 的第二个守卫取）；第二个要 Cauchy x、cauchy_add y z，以及 t = mk (x+(y+z))——用 Eq.trans 把 h 给出的 t = mk ((x+y)+z) 与 63.1 经 Real.sound 的等式接起来。

提示 2目标形态

∃ u, addRel (mk y) (mk z) u ∧ addRel (mk x) u t。

提示 3关键件

Exists.intro · addRel_intro · cauchy_add · Eq.trans · Real.sound · realRel_add_assoc。

查看解答 定理 · 17 行

见证取 u := mk (y + z)。 addRel (mk y) (mk z) u：61 的 addRel_intro，要 Cauchy y（假设） 与 Cauchy z（从 h 的第二个守卫）；；addRel (mk x) u t：Cauchy x 是假设，Cauchy (y+z) 是 cauchy_add，第三分量是 t = mk ((x+y)+z) = mk (x+(y+z))——后半段由 63.1 经 Real.sound。

theorem addRel_assoc_mk (x y z : Seq) (t : Real)
    (hx : Cauchy x) (hy : Cauchy y)
    (h : addRel (Real.mk (addSeq x y)) (Real.mk z) t) :
    ∃ (u : Real), addRel (Real.mk y) (Real.mk z) u ∧
      addRel (Real.mk x) u t :=
  Exists.intro (Real.mk (addSeq y z))
    (And.intro
      (addRel_intro y z hy (And.left (And.right h)))
      (And.intro
        hx
        (And.intro
          (cauchy_add y z hy (And.left (And.right h)))
          (Eq.trans
            (And.right (And.right h))
            (Real.sound (addSeq (addSeq x y) z) (addSeq x (addSeq y z))
              (realRel_add_assoc x y z hx hy
                (And.left (And.right h))))))))

63.3 商层：三元关系的结合律

练习 3addRel_assoc定理附录解答

商层：对三个因子各做一次 Quot.ind。

theorem addRel_assoc (a b c s t : Real)
    (h1 : addRel a b s) (h2 : addRel s c t) :
    ∃ (u : Real), addRel b c u ∧ addRel a u t :=
  sorry
提示 1思路

对 a、b、c 各做一次 Quot.ind（动机依次写在 Real 上）。进入 mk x、mk y、mk z 后，h1 的 ι 归约给出 s = mk (x+y)；用 Eq.subst 把它代进 h2，得到 addRel (mk (x+y)) (mk z) t，正好交给 63.2。

addRel a b s → addRel s c t → ∃ u, addRel b c u ∧ addRel a u t。

提示 3关键件

Quot.ind（三次，动机写明）· ι 归约 · Eq.subst · addRel_assoc_mk。

    (h1 : addRel a b s) (h2 : addRel s c t) :
    ∃ (u : Real), addRel b c u ∧ addRel a u t :=
  @Quot.ind.{1} Seq realRel
    (fun (a : Real) =>
      ∀ (b c s t : Real), addRel a b s → addRel s c t →
        ∃ (u : Real), addRel b c u ∧ addRel a u t)
    (fun (x : Seq) =>
      fun (b c s t : Real)
          (h1 : addRel (Real.mk x) b s) (h2 : addRel s c t) =>
        @Quot.ind.{1} Seq realRel
          (fun (b : Real) =>
            ∀ (c s t : Real), addRel (Real.mk x) b s → addRel s c t →
              ∃ (u : Real), addRel b c u ∧ addRel (Real.mk x) u t)
          (fun (y : Seq) =>

                (h1 : addRel (Real.mk x) (Real.mk y) s) (h2 : addRel s c t) =>

                  ∀ (s t : Real), addRel (Real.mk x) (Real.mk y) s →

                    ∃ (u : Real), addRel (Real.mk y) c u ∧ addRel (Real.mk x) u t)
