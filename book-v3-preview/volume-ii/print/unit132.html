Unit 132 — Local Boundedness: The First Box a Limit Gives

2 个定义 · 7 个定理 · 7 道练习 · 21 条提示 · 解答附录

两个函数相乘再取极限，最容易想到的估计是

|fx·gx−L·M|≤|fx|·|gx−M|+|M|·|fx−L|

右边第二项由 g 的极限控制，第一项里的 |g x - M| 也由极限控制，可 |f x| 本身没有被任何极限陈述直接管住：f x 趋于 L 说的是「离 L 近」，不是「有界」。这一步差的正是一个局部估计：只要极限有限，f 在 a 附近就落进一个以 L 为中心、半径 1 的盒子里，再由三角不等式换成以 0 为心的界。

连续与极限给出的盒子形状不同。连续管的是整个 δ 邻域，a 本身也在内，于是可以直接取 ε = 1 把 |f x - f a| 压到 1 以下，再用 |f a| 抬成 |f x| ≤ |f a| + 1。函数极限的定义排掉了 a 点，得到的只是去心邻域里的界；乘积与商要的正是这个去心版本，因为在 a 点取值不影响极限。

盒子的半径依赖 a，不是整片定义域的统一界：这正是「局部」二字的含义，也是后面一致连续与最值问题要跨过的门槛。乘积还要乘法对序的相容性，那是另一层估计；函数仍取 ratRep → ratRep，停在有理代表元层。不新增公理。

定义：整邻域有界与去心邻域有界

整邻域版本：有一个正半径 δ 和一个非负界 B，δ 邻域里每个点的 |f x| 都有见证不超过 B。「有见证不超过 B」写成 ∃ d, ratAbsRel (f x) d ∧ d ≤ B，因为库里的绝对值是关系而不是函数，B 不必是某个点的绝对值本身。

定义LocallyBoundedAt声明 1
def LocallyBoundedAt (f : ratRep → ratRep) (a : ratRep) : Prop :=
  ∃ (delta : ratRep), ratLtRep ratZeroRep delta ∧
    ∃ (B : ratRep), ratLeRep ratZeroRep B ∧
      ∀ (x : ratRep), close x a delta →
        ∃ (d : ratRep), ratAbsRel (f x) d ∧ ratLeRep d B

去心版本：与上面同形，只在 x 与 a 代表元等价时不做要求。函数极限不管 a 点的取值，乘积与商需要的也正是这一版。
