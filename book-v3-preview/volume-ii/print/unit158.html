Unit 158 — Upper and Lower Sums: Integrability as a Small Gap

3 个定义 · 9 个定理 · 9 道练习 · 27 条提示 · 解答附录

上界与下界还是函数，不能直接比较大小；把每一段的高乘上这一段的宽，再加起来，才得到两个数。上面的那摞台阶给出上和，下面的那摞给出下和。同一个分割上，每一段的下界都不超过上界，于是下和不超过上和。两条台阶贴得越近，曲线底下的面积就被夹得越窄。

「贴得足够近」可以写成一条 ε 判据：任给正数 ε，都存在一个分割，使它的上和与下和之差小于 ε。满足这条判据的函数叫可积。常值函数是最先能验证的例子：上下两摞台阶取同一个常数，差恰好是零，而零小于任何正数。取负把两摞台阶对调，上和与下和也跟着对调，这是后面把可积性接到代数运算上的第一步。

边界：只做到可积性的 ε 判据与常值函数的验证，不证明连续或单调函数可积，也不定义积分值。函数取 ratRep → ratRep，停在有理代表元层。不新增公理，也不碰 kernel/front。

把一摞台阶变成一块面积

上和的候选值：有一摞上界 u，它的矩形和就是 U。用关系而不是函数，是因为同一个分割上的上界可以有很多摞，谁都不是唯一的那一摞。

定义UpperSum声明 1
def UpperSum (a b : ratRep) (p : Partition) (f : ratRep → ratRep)
    (U : ratRep) : Prop :=
  ∃ (u : Nat → ratRep), UpperStep a b p f u ∧ ratRel U (stepSum p u)

下和同理：从一摞下界出发，取它的矩形和。

定义LowerSum声明 2
def LowerSum (a b : ratRep) (p : Partition) (f : ratRep → ratRep)
    (L : ratRep) : Prop :=
  ∃ (l : Nat → ratRep), LowerStep a b p f l ∧ ratRel L (stepSum p l)

可积：每个正 ε 都配得上一个分割，使这个分割的上和与下和之差小于 ε。分割必须真的是区间 [a, b] 的分割，否则「差」可以靠退化的分割作假。

定义Integrable声明 3
def Integrable (a b : ratRep) (f : ratRep → ratRep) : Prop :=
  ∀ (eps : ratRep), ratLtRep ratZeroRep eps →
    ∃ (p : Partition), IsPartition a b p ∧
      ∃ (L : ratRep), ∃ (U : ratRep),
        LowerSum a b p f L ∧ UpperSum a b p f U ∧
          ratLtRep (ratSubRep U L) eps

查看解答 定理 · 21 行

逐段的下界不超过上界，乘上同一个正宽之后每一段的乘积也不超过；矩形和的 保序把段数那么多条不等式收成一条。两端的 L、U 只是矩形和的等价写法， 沿等价关系搬过去。

theorem lowerSum_le_upperSum (a b : ratRep) (p : Partition)
    (f : ratRep → ratRep) (L U : ratRep) (hp : IsPartition a b p)
    (hL : LowerSum a b p f L) (hU : UpperSum a b p f U) :
    ratLeRep L U :=
  @Exists.elim (Nat → ratRep)
    (fun (l : Nat → ratRep) => LowerStep a b p f l ∧ ratRel L (stepSum p l))
    (ratLeRep L U) hL
    (fun (l : Nat → ratRep)
        (hl : LowerStep a b p f l ∧ ratRel L (stepSum p l)) =>
      @Exists.elim (Nat → ratRep)
        (fun (u : Nat → ratRep) => UpperStep a b p f u ∧ ratRel U (stepSum p u))
        (ratLeRep L U) hU
        (fun (u : Nat → ratRep)
            (hu : UpperStep a b p f u ∧ ratRel U (stepSum p u)) =>
          ratLeRep_congr_gen (stepSum p l) L (stepSum p u) U
            (ratRel_symm L (stepSum p l) (And.right hl))
            (ratRel_symm U (stepSum p u) (And.right hu))
            (stepSum_mono a b p hp l u
              (fun (i : Nat) (hi : LeNat (Nat.succ i) (partCount p)) =>
                lowerStep_le_upperStep a b p f l u hp
                  (And.left hl) (And.left hu) i hi))))

练习 4 · lowerSum_le_upperSum 定理

逐段的下界不超过上界，乘上同一个正宽之后每一段的乘积也不超过；矩形和的 保序把段数那么多条不等式收成一条。两端的 L、U 只是矩形和的等价写法， 沿等价关系搬过去。

theorem lowerSum_le_upperSum (a b : ratRep) (p : Partition)
    (f : ratRep → ratRep) (L U : ratRep) (hp : IsPartition a b p)
    (hL : LowerSum a b p f L) (hU : UpperSum a b p f U) :
    ratLeRep L U :=
  @Exists.elim (Nat → ratRep)
    (fun (l : Nat → ratRep) => LowerStep a b p f l ∧ ratRel L (stepSum p l))
    (ratLeRep L U) hL
    (fun (l : Nat → ratRep)
        (hl : LowerStep a b p f l ∧ ratRel L (stepSum p l)) =>
      @Exists.elim (Nat → ratRep)
        (fun (u : Nat → ratRep) => UpperStep a b p f u ∧ ratRel U (stepSum p u))
        (ratLeRep L U) hU
        (fun (u : Nat → ratRep)
            (hu : UpperStep a b p f u ∧ ratRel U (stepSum p u)) =>
          ratLeRep_congr_gen (stepSum p l) L (stepSum p u) U
            (ratRel_symm L (stepSum p l) (And.right hl))
            (ratRel_symm U (stepSum p u) (And.right hu))
            (stepSum_mono a b p hp l u
              (fun (i : Nat) (hi : LeNat (Nat.succ i) (partCount p)) =>
                lowerStep_le_upperStep a b p f l u hp
                  (And.left hl) (And.left hu) i hi))))
