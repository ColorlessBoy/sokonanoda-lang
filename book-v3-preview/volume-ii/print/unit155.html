Unit 155 — Rectangular Sums Preserve Addition and Negation

2 个定义 · 7 个定理 · 7 道练习 · 21 条提示 · 解答附录

两块阶梯叠在同一组切点上，如果每一段的高度都写成两个高度之和，那么底下的面积是不是正好等于两块面积之和？这个问题不能靠直觉回答：面积被定义成一串乘积的和，而乘积只对一个因子分配，不会自动对两个高度函数分配。要把它拆开，得先在一段上把乘积拆成两份，再把每一份分别求和。

高度全为零时，每一项都是零乘宽，整条和为零。高度相加时，第 i 段的乘积先换成两份乘积之和，有限和的加法律再把它们按段分开，收成两个矩形和。高度取负时，乘积的负号可以搬到和的外面，因为取负对加法分配。有了加法与取负两条，矩形和对高度就是一个加群同态：先拆高度再算面积，与先算面积再拆，结果相同。差是加法的特例，于是同一高度减去自己，面积为零。

边界：只谈同一个分割上的矩形和，不在两个分割之间作比较，也不谈加细；高度取有理代表元，停在 ratRep 层。不新增公理。

矩形的宽与面积

第 i 段的宽：右切点减左切点。段数记作 n 时，第 i 段只在 i < n 时存在。

定义segLen声明 1
def segLen (p : Partition) (i : Nat) : ratRep :=
  ratSubRep (partPoint p (Nat.succ i)) (partPoint p i)

阶梯函数的矩形和：每段的高度乘上那一段的宽，再把段数那么多项加起来。

定义stepSum声明 2
def stepSum (p : Partition) (c : Nat → ratRep) : ratRep :=
  sumTo (fun (i : Nat) => ratMulRep (c i) (segLen p i)) (partCount p)
