134闭区间上的最值：上确界与达到

Unit 134 — Extreme Values on a Closed Interval: The Supremum Must Be Attained

5 个定义 · 21 个定理 · 16 道练习 · 48 条提示 · 解答附录

连续函数在闭区间上取到最大值，这是分析里第一个「存在性」结论：它不是从定义直接读出来的，而是先取像的上确界，再证明这个上确界被某个点取到。前一半只依赖序，后一半才是真正的分析内容。

把两半分开写，结构就清楚了。设 A 是区间里的点，f 的像指所有 f x 的等价类。若像有上确界 M，并且有 c ∈ A 使 f c ~ M，那么 M 就是最大值：上界给出 f x ≤ M，而 f c ~ M 说明 M 本身在像里。反过来，若最大值存在，它的值就是像的上确界。于是「最大值存在」与「像的上确界存在且被取到」是同一件事；连续性的全部工作，都花在证明后一句的后半段上。

这一步在 ℚ 上会断。像的上确界可能是一个无理数，因而没有任何有理点取到它；要把它写成一个具体反例，需要乘法与序的相容性，以及 2 没有有理平方根这条数论事实。课程库还没有这两样，所以这里先把「上确界被取到」留作假设，等 ℝ 层的完备性接上以后再用。

能立刻证明的充分条件是单调。f 在 [a,b] 上不降时，右端点 b 就是最大值：每个 x ≤ b，单调性直接把 f x 压到 f b 以下；左端点 a 同理给出最小值。这条定理不需要完备性，也不需要乘法，是闭区间上最值问题的一块干净样本。

闭区间三个字不能省。把 [0,1] 换成开区间 (0,1)，恒等函数就没有最大值：任取 c ∈ (0,1)，c + (1-c)/2 仍落在区间里，而且比 c 大。取中点是构造性的，只用加法和减法，正好说明「端点闭」在最大值的论证里承担了什么。

边界：函数取 ratRep → ratRep，序取有理代表元上的 ratLeRep；不新增公理，也不碰 kernel/front。连续函数的无条件最值定理留到完备性一章。

定义：区间、像、最大值与单调

闭区间的成员谓词：两端都取非严格序。把它写成谓词而不是集合，后面的上界与上确界就能直接套 lib/Order 里的定义。

定义InClosed声明 1
def InClosed (a b x : ratRep) : Prop :=
  ratLeRep a x ∧ ratLeRep x b

像里的一个值：存在 A 中的点，其函数值与 y 代表元等价。用 ratRel 而不是字面相等，是因为函数的输出本来就只在商的意义下比较。

定义ImageOn声明 2
def ImageOn (f : ratRep → ratRep) (A : ratRep → Prop) (y : ratRep) : Prop :=
  ∃ (x : ratRep), A x ∧ ratRel (f x) y

「M 是 f 在 A 上的最大值」分两件事：M 确实被某点取到，且 M 压住所有函数值。两件事缺一不可：只有上界不知道是否取到，只有取到不知道是不是最大。

定义IsMaxOn声明 3
def IsMaxOn (f : ratRep → ratRep) (A : ratRep → Prop) (M : ratRep) : Prop :=
  (∃ (c : ratRep), A c ∧ ratRel (f c) M) ∧
    ∀ (x : ratRep), A x → ratLeRep (f x) M

「f 在 A 上取到最大值」：有一个点，它的函数值压住 A 上所有函数值。

定义AttainsMaxOn声明 4
def AttainsMaxOn (f : ratRep → ratRep) (A : ratRep → Prop) : Prop :=
  ∃ (c : ratRep), A c ∧ ∀ (x : ratRep), A x → ratLeRep (f x) (f c)

闭区间上的单调不降：只比较区间里的点，所以量词带着两个成员前提。

定义NondecreasingOn声明 5
def NondecreasingOn (f : ratRep → ratRep) (a b : ratRep) : Prop :=
  ∀ (x y : ratRep), InClosed a b x → InClosed a b y →
    ratLeRep x y → ratLeRep (f x) (f y)

两个最大值互相压住：M 压 M' 取 hM 的点，M' 压 M 取 hM' 的点，反对称收口。

theorem maxValue_unique (f : ratRep → ratRep) (A : ratRep → Prop)
    (M M' : ratRep) (hM : IsMaxOn f A M) (hM' : IsMaxOn f A M') :
    ratRel M M' :=
  Exists.elim (And.left hM)
    (fun (c : ratRep) (hc : A c ∧ ratRel (f c) M) =>
      Exists.elim (And.left hM')
        (fun (d : ratRep) (hd : A d ∧ ratRel (f d) M') =>
          ratLeRep_antisymm M M'
            (ratLeRep_trans M (f c) M'
              (ratLeRep_of_ratRel M (f c)
                (ratRel_symm (f c) M (And.right hc)))
              ((And.right hM') c (And.left hc)))
            (ratLeRep_trans M' (f d) M
              (ratLeRep_of_ratRel M' (f d)
                (ratRel_symm (f d) M' (And.right hd)))
              ((And.right hM) d (And.left hd)))))
练习 8 · attMax_const 定理

任取定义域里的点当见证；所有函数值相等，ratLeRep_refl 直接付清。

theorem attMax_const (A : ratRep → Prop) (c : ratRep)
    (hA : ∃ (a : ratRep), A a) :
    AttainsMaxOn (fun (_ : ratRep) => c) A :=
  Exists.elim hA
    (fun (a : ratRep) (ha : A a) =>
      Exists.intro a
        (And.intro ha (fun (x : ratRep) (_hx : A x) => ratLeRep_refl c)))
练习 9 · attMax_of_monotone 定理

右端点 b 属于 [a,b] 要用 a ≤ b 与自反；其余每个 x 的界由单调性给出。

theorem attMax_of_monotone (f : ratRep → ratRep) (a b : ratRep)
    (hab : ratLeRep a b) (h : NondecreasingOn f a b) :
    AttainsMaxOn f (InClosed a b) :=
  Exists.intro b
    (And.intro (And.intro hab (ratLeRep_refl b))
      (fun (x : ratRep) (hx : InClosed a b x) =>
        h x b hx (And.intro hab (ratLeRep_refl b))
          (inClosed_right a b x hx)))
练习 10 · attMin_of_monotone 定理

把序反过来：左端点 a 是最小值，证明与上一条对称。

theorem attMin_of_monotone (f : ratRep → ratRep) (a b : ratRep)
    (hab : ratLeRep a b) (h : NondecreasingOn f a b) :
    ∃ (c : ratRep), InClosed a b c ∧
      ∀ (x : ratRep), InClosed a b x → ratLeRep (f c) (f x) :=
  Exists.intro a
    (And.intro (And.intro (ratLeRep_refl a) hab)
      (fun (x : ratRep) (hx : InClosed a b x) =>
        h a x (And.intro (ratLeRep_refl a) hab) hx
          (inClosed_left a b x hx)))
练习 11 · attMax_id_closed 定理

恒等函数在 [0,1] 上不降，交给上一条定理；0 ≤ 1 是库里的 ratLtRep_zero_one。

theorem attMax_id_closed :
    AttainsMaxOn (fun (x : ratRep) => x)
      (InClosed ratZeroRep ratOneRep) :=
  attMax_of_monotone (fun (x : ratRep) => x) ratZeroRep ratOneRep
    (ratLtRep_le ratZeroRep ratOneRep ratLtRep_zero_one)
    (fun (x y : ratRep) (_hx : InClosed ratZeroRep ratOneRep x)
        (_hy : InClosed ratZeroRep ratOneRep y) (hxy : ratLeRep x y) => hxy)
练习 12 · ratLtRep_add_right 定理

严格序对右加同一个数稳定：弱序来自 ratLeRep_add_right，严格性用加法 消去——两边相加后若相等，消去公共加数就回到原来的相等，撞上严格序。

theorem ratLtRep_add_right (x y z : ratRep) (h : ratLtRep x y) :
    ratLtRep (ratAddRep x z) (ratAddRep y z) :=
  And.intro
    (ratLeRep_add_right x y z (ratLtRep_le x y h))
    (fun (hxy : ratRel (ratAddRep x z) (ratAddRep y z)) =>
      ratLtRep_right x y h (ratRel_add_cancel_gen x y z hxy))
练习 13 · ratLtRep_self_add_pos 定理

正数加在右边会把数抬大。0 + x < h + x 由严格序的加法得到，右端 交换成 x + h，左端再用 0 + x ~ x 收回。

theorem ratLtRep_self_add_pos (x h : ratRep) (hh : ratLtRep ratZeroRep h) :
    ratLtRep x (ratAddRep x h) :=
  ratLtRep_of_le_lt x (ratAddRep ratZeroRep x) (ratAddRep x h)
    (ratLeRep_of_ratRel x (ratAddRep ratZeroRep x)
      (ratRel_symm (ratAddRep ratZeroRep x) x (ratAdd_zero_left x)))
    (ratLtRep_congr_snd (ratAddRep ratZeroRep x) (ratAddRep h x)
      (ratAddRep x h)
      (ratLtRep_add_right ratZeroRep h x hh)
      (ratAdd_comm h x))
练习 14 · lt_add_mid 定理

中点严格大于左端点：0 < b - c，半数仍是正的，再交给上一条。

theorem lt_add_mid (b c : ratRep) (h : ratLtRep c b) :
    ratLtRep c (ratAddRep c (ratHalf (ratSubRep b c))) :=
  ratLtRep_self_add_pos c (ratHalf (ratSubRep b c))
    (ratLtRep_half (ratSubRep b c) (ratLtRep_sub_pos b c h))
练习 15 · add_mid_lt_right 定理

中点仍落在 b 的左侧：半数小于 b - c，两边同加 c 后把 (b-c)+c 收回 b， 再把 h + c 交换成 c + h。左端用弱序接上 c + h ~ h + c。

theorem add_mid_lt_right (b c : ratRep) (h : ratLtRep c b) :
    ratLtRep (ratAddRep c (ratHalf (ratSubRep b c))) b :=
  ratLtRep_of_le_lt
    (ratAddRep c (ratHalf (ratSubRep b c)))
    (ratAddRep (ratHalf (ratSubRep b c)) c)
    b
    (ratLeRep_of_ratRel (ratAddRep c (ratHalf (ratSubRep b c)))
      (ratAddRep (ratHalf (ratSubRep b c)) c)
      (ratAdd_comm c (ratHalf (ratSubRep b c))))
    (ratLtRep_congr_snd
      (ratAddRep (ratHalf (ratSubRep b c)) c)
      (ratAddRep (ratSubRep b c) c)
      b
      (ratLtRep_add_right (ratHalf (ratSubRep b c)) (ratSubRep b c) c
        (ratHalf_lt_self (ratSubRep b c) (ratLtRep_sub_pos b c h)))
      (ratSubRep_add_self b c))
练习 16 · not_attMax_id_open 定理

任取 c ∈ (0,1)，中点 c + (1-c)/2 仍在区间里，而且严格大于 c；于是没有 哪个 c 能压住所有函数值。

theorem not_attMax_id_open :
    ¬ AttainsMaxOn (fun (x : ratRep) => x)
      (fun (x : ratRep) => ratLtRep ratZeroRep x ∧ ratLtRep x ratOneRep) :=
  fun (h : AttainsMaxOn (fun (x : ratRep) => x)
      (fun (x : ratRep) => ratLtRep ratZeroRep x ∧ ratLtRep x ratOneRep)) =>
    Exists.elim h
      (fun (c : ratRep)
          (hc : (ratLtRep ratZeroRep c ∧ ratLtRep c ratOneRep) ∧
            ∀ (x : ratRep),
              (ratLtRep ratZeroRep x ∧ ratLtRep x ratOneRep) →
                ratLeRep x c) =>
        ratLtRep_right c
          (ratAddRep c (ratHalf (ratSubRep ratOneRep c)))
          (lt_add_mid ratOneRep c (And.right (And.left hc)))
          (ratRel_symm
            (ratAddRep c (ratHalf (ratSubRep ratOneRep c))) c
            (ratLeRep_antisymm
              (ratAddRep c (ratHalf (ratSubRep ratOneRep c))) c
              ((And.right hc)
                (ratAddRep c (ratHalf (ratSubRep ratOneRep c)))
                (And.intro
                  (ratLtRep_trans ratZeroRep c
                    (ratAddRep c (ratHalf (ratSubRep ratOneRep c)))
                    (And.left (And.left hc))
                    (lt_add_mid ratOneRep c (And.right (And.left hc))))
                  (add_mid_lt_right ratOneRep c (And.right (And.left hc)))))
              (ratLtRep_le c
                (ratAddRep c (ratHalf (ratSubRep ratOneRep c)))
                (lt_add_mid ratOneRep c (And.right (And.left hc)))))))
