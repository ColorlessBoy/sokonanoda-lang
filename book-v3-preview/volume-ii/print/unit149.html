149极值点的导数为零：曲线在最高处没有斜率

Unit 149 — The Derivative Vanishes at Interior Extrema

2 个定义 · 9 个定理 · 9 道练习 · 27 条提示 · 解答附录

山坡的最高点处，切线若还是斜的，曲线就会有一侧继续往上走，那里也就不再是最高点。换成函数的语言：在局部极大值点附近，函数值不能随 x 往右增大，也不能随 x 往左增大；单元148 已经把导数的正负翻译成曲线往哪一侧抬高，于是一个局部极大值点把导数的两个符号都排除，只剩零。

定义先把「局部」写成半径为 delta 的邻域：邻域内每一点的函数值都不超过 f a，就是局部极大；反过来每一点都不低于 f a，就是局部极小。邻域同时管两侧，所以 a 必须是定义域的内点；端点上的极值不在讨论范围内。

证明只做极大。若 L > 0，risesRight_of_deriv_pos 在 a 的右侧给出一点 x，使 f a < f x，与局部极大的 f x ≤ f a 冲突；若 L < 0，risesLeft_of_deriv_neg 在左侧给出同样的冲突。两个严格不等式都被排除，再用 ℚ 的序全性把 0 ≤ L 与 L ≤ 0 两支各收到 0 ~ L 或 L ~ 0 上。极小值不重做一遍：把曲线关于 x 轴翻过来，极小变极大，导数变成 -L，而 -L 为零与 L 为零是同一件事。

边界：只讨论内点上的双侧极值，单侧极值与整段区间上的最值需要别的工具。恒等函数在零点可导，却既不是局部极大也不是局部极小，这条反例说明可导本身不保证任何极值。

局部极大与局部极小

「局部极大」：有一个正半径，邻域内每一点的函数值都不超过 f a。邻域不排除 a 本身，这与单元133 的保号邻域不同；把 a 算进来不影响结论。

theorem deriv_zero_of_localMax (f : ratRep → ratRep) (a L : ratRep)
    (h : HasDerivAt f a L) (hmax : LocalMaxAt f a) :
    ratRel L ratZeroRep :=
  @Or.elim (ratLeRep ratZeroRep L) (ratLeRep L ratZeroRep) (ratRel L ratZeroRep)
    (fun (hge : ratLeRep ratZeroRep L) =>
      @Or.elim (ratRel ratZeroRep L) (ratLtRep ratZeroRep L) (ratRel L ratZeroRep)
        (fun (heq : ratRel ratZeroRep L) => ratRel_symm ratZeroRep L heq)
        (fun (hlt : ratLtRep ratZeroRep L) =>
