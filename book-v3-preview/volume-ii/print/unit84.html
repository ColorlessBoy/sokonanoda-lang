84.1 上界可以放大

练习 1upperBound_of_le定理附录解答

lib/Order 里已有对任意类型、任意关系的定义：

UpperBoundαrAM:⟺∀a,Aa→raM
IsSupαrAs:⟺UpperBoundαrAs∧
∀M,UpperBoundαrAM→rsM

本单元把类型取成 Real、关系取成 realLe，只证这个实例上的比较律。关系 realLe 只对带 Cauchy 见证的类有自反性，所以凡是需要自反的地方都显式带上 Cauchy x，不把「每个实数都与自己可比」当作公理。

证明按下面的路线展开。

细节清单（6 项，展开）
  • 84.1 上界可以放大：M 是上界、M ≤ M'，则 M' 也是上界；
  • 84.2 在上确界处，s ≤ M 与「M 是上界」等价；
  • 84.3 上确界唯一；
  • 84.4 集合含自己的上界时，这个元素就是上确界；
  • 84.5 单点集的上确界是那个点（带 Cauchy 见证）；
  • 84.6 常零序列的类上的单点集。

边界：只证唯一性与比较，不证存在性。一般「非空有上界的集合有上确界」要选择公理或 Dedekind 切割，本课程的库没有这些；存在性能证到哪里，留到后面的单元盘点。不新增公理。

    (hM : UpperBound Real realLe A M) (h : realLe M M') :
    UpperBound Real realLe A M' :=

84.2 上确界处 s ≤ M 与「M 是上界」等价

练习 2sup_le_iff定理附录解答
theorem sup_le_iff (A : Real → Prop) (s M : Real)
    (hs : IsSup Real realLe A s) :
    realLe s M ↔ UpperBound Real realLe A M :=
  sorry
提示 1思路

两个方向。若 s ≤ M，对 a ∈ A 用 a ≤ s（hs 的第一分量）与 s ≤ M 走传递；反过来「M 是上界」正是 hs 的第二分量在 M 上的取值。

提示 2目标形态

realLe s M ↔ UpperBound Real realLe A M。

提示 3关键件

Iff.intro · And.left hs · And.right hs · realLe_trans。

查看解答 定理 · 8 行

正方向：a ≤ s（第一分量）与 s ≤ M 走传递。反方向是第二分量。

theorem sup_le_iff (A : Real → Prop) (s M : Real)
    (hs : IsSup Real realLe A s) :
    realLe s M ↔ UpperBound Real realLe A M :=
  Iff.intro
    (fun (h : realLe s M) =>
      fun (a : Real) (ha : A a) =>
        realLe_trans a s M ((And.left hs) a ha) h)
    (fun (hM : UpperBound Real realLe A M) => (And.right hs) M hM)

84.3 上确界唯一

练习 3sup_unique定理附录解答
theorem sup_unique (A : Real → Prop) (s t : Real)
    (hs : IsSup Real realLe A s) (ht : IsSup Real realLe A t) : s = t :=
  sorry
提示 1思路

s 不超过 t（t 是上界，用 hs 的第二分量），t 不超过 s（反过来），再交给 realLe_antisymm。

提示 2目标形态

s = t。

提示 3关键件

And.left · And.right · realLe_antisymm。

查看解答 定理 · 5 行

两个上确界互相不超过，再交给反对称。

theorem sup_unique (A : Real → Prop) (s t : Real)
    (hs : IsSup Real realLe A s) (ht : IsSup Real realLe A t) : s = t :=
  realLe_antisymm s t
    ((And.right hs) t (And.left ht))
    ((And.right ht) s (And.left hs))

84.4 集合含自己的上界时，它就是上确界

练习 4sup_of_max定理附录解答
theorem sup_of_max (A : Real → Prop) (m : Real)
    (hm : A m) (hub : UpperBound Real realLe A m) :
    IsSup Real realLe A m :=

提示 1思路

上界分量直接是假设 hub；最小性对任意上界 M 只用把 hM 作用在 m 与 hm 上，得到 m ≤ M。

提示 2目标形态

提示 3关键件

And.intro · 逐点应用 hM m hm。

查看解答 定理 · 4 行

上界分量是假设；最小性把任一上界作用在集合内的那个元素上。

theorem sup_of_max (A : Real → Prop) (m : Real)
    (hm : A m) (hub : UpperBound Real realLe A m) :
    IsSup Real realLe A m :=
  And.intro hub (fun (M : Real) (hM : UpperBound Real realLe A M) => hM m hm)

84.5 单点集的上确界

练习 5sup_singleton_mk定理附录解答

A := fun a => a = Real.mk x。上界：把 a = mk x 代进目标，目标变成 realLe (mk x) (mk x)，由 realLe_refl_mk 给。最小性：任一上界 M 作用在 mk x 与 rfl 上，直接得到 mk x ≤ M。

theorem sup_singleton_mk (x : Seq) (hx : Cauchy x) :
    IsSup Real realLe (fun (a : Real) => a = Real.mk x) (Real.mk x) :=
  sorry
提示 1思路

And.intro 两半。第一半用 Eq.subst 把等式 a = mk x 反向搬进目标，再用 realLe_refl_mk x hx；第二半把 hM 作用在 Real.mk x 与 Eq.refl 上。

提示 2目标形态

IsSup Real realLe (fun a => a = Real.mk x) (Real.mk x)。

提示 3关键件

Eq.subst · Eq.symm · Eq.refl · realLe_refl_mk。

查看解答 定理 · 8 行

上界：把 a = mk x 反向搬进 realLe a (mk x)，用自反性收口。 最小性：任一上界作用在 mk x 与 rfl 上。

theorem sup_singleton_mk (x : Seq) (hx : Cauchy x) :
    IsSup Real realLe (fun (a : Real) => a = Real.mk x) (Real.mk x) :=
  And.intro
    (fun (a : Real) (ha : a = Real.mk x) =>
      @Eq.subst.{1} Real (fun (z : Real) => realLe z (Real.mk x))
        (Real.mk x) a (Eq.symm ha) (realLe_refl_mk x hx))
    (fun (M : Real) (hM : UpperBound Real realLe (fun (a : Real) => a = Real.mk x) M) =>
      hM (Real.mk x) (@Eq.refl.{1} Real (Real.mk x)))

两个上确界互相不超过，再交给反对称。

theorem sup_unique (A : Real → Prop) (s t : Real)
    (hs : IsSup Real realLe A s) (ht : IsSup Real realLe A t) : s = t :=
  realLe_antisymm s t
    ((And.right hs) t (And.left ht))
    ((And.right ht) s (And.left hs))
练习 4 · sup_of_max 定理

上界分量是假设；最小性把任一上界作用在集合内的那个元素上。

theorem sup_of_max (A : Real → Prop) (m : Real)
    (hm : A m) (hub : UpperBound Real realLe A m) :
    IsSup Real realLe A m :=
  And.intro hub (fun (M : Real) (hM : UpperBound Real realLe A M) => hM m hm)
练习 5 · sup_singleton_mk 定理

上界：把 a = mk x 反向搬进 realLe a (mk x)，用自反性收口。 最小性：任一上界作用在 mk x 与 rfl 上。

theorem sup_singleton_mk (x : Seq) (hx : Cauchy x) :
    IsSup Real realLe (fun (a : Real) => a = Real.mk x) (Real.mk x) :=
  And.intro
    (fun (a : Real) (ha : a = Real.mk x) =>
      @Eq.subst.{1} Real (fun (z : Real) => realLe z (Real.mk x))
        (Real.mk x) a (Eq.symm ha) (realLe_refl_mk x hx))
    (fun (M : Real) (hM : UpperBound Real realLe (fun (a : Real) => a = Real.mk x) M) =>
      hM (Real.mk x) (@Eq.refl.{1} Real (Real.mk x)))
练习 6 · demo_sup_zero 定理
theorem demo_sup_zero :
    IsSup Real realLe (fun (a : Real) => a = Real.mk zeroSeq) (Real.mk zeroSeq) :=
  sup_singleton_mk zeroSeq cauchy_zero
