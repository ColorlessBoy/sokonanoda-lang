129单侧极限：只看一边

Unit 129 — One-Sided Limits: Looking Only One Way

2 个定义 · 8 个定理 · 8 道练习 · 24 条提示 · 解答附录

函数在 a 的左右两侧可以走不同的路。符号函数在 0 的左边取负值、右边取正值，它在 0 处没有双侧极限，但两侧各自的行为都很清楚。双侧极限把两边混在同一个邻域里，正好丢掉了这种区分；闭区间的端点更麻烦，端点外侧根本没有定义，双侧邻域无从谈起。

单侧极限把「只看右边」与「只看左边」写成两条独立的 ε-δ：半径之外还要一条 a < x 或 x < a。有了它，函数在端点处的连续性、单调函数的极限、介值定理才有地方落脚。两条定义与双侧定义的差别只在方向条件，常函数与恒等函数的单侧极限因此可以直接算出来。

双侧极限推出两个单侧极限是直接的：把「x 不是 a」那条前提用方向条件消掉。反方向要把两块半径拼成一块：邻域里的点要么在左边、要么在右边、要么与 a 相等。前两支交给两个单侧极限，第三支要靠函数在 a 处对代表元的选择不敏感，否则 x ~ a 而 f x 与 f a 可以毫不相干。这条对等价的相容性写成显式假设，定理对任意函数都成立。

边界：函数取 ratRep → ratRep，左右极限都停在有理代表元层。不新增公理。

左极限与右极限

右极限：x 落在 a 的 δ 邻域里，并且严格在 a 的右边。

theorem tendsToAtRight_of_tendsToAt (f : ratRep → ratRep) (a L : ratRep)
    (h : TendsToAt f a L) : TendsToAtRight f a L :=
  fun (eps : ratRep) (heps : ratLtRep ratZeroRep eps) =>

      (fun (delta : ratRep)
