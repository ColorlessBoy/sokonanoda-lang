74.1 (x - y) + y ~ x

练习 1ratSubRep_add_self定理附录解答

在 ℚ 上，「唯一」就是 ratRel L L'。路线分三层：

  • 第一层（74.1–74.3）：把减法与序接起来——(x - y) + y ~ x、0 ~ x - y ⇒ x ~ y、y < x ⇒ 0 < x - y；
  • 第二层（74.4–74.6）：把「任意 ε 内接近」压成 ratLeRep——先用 ㊺ 的全性把 x ≤ y 归到 y ≤ x 的情形，再用 74.4 的「≤ 是相等或严格小」二选一：相等直接转，严格小则令 d := x - y，取 eps := d/2，close x y (d/2) 给 d ≤ d/2，74.5 给 d/2 < d，反对称性把 d/2 ~ d 夹出来撞矛盾；
  • 第三层（74.7–74.9）：两个极限在同一个 n 上各占 eps/2，57 的 close_trans 得 ∀ eps > 0, close L L' eps，再过 74.6 得 ratRel L L'；Real.sound 把它送进商，得 ℝ 里的相等。

边界：74.4 用的是 ㊺ 的 leNat_eq_or_succ（≤ 拆成「相等」或「严格小」），这不是排中律：Nat 的 ≤ 是归纳定义的，两支由构造子直接给出；不新增公理，也不用 Classical.choice。

本单元按顺序做下面几件事。

74.4 ≤ 是「相等」或「严格小」

练习 4ratLeRep_eq_or_lt定理附录解答

ratLeRep x y 的展开是 LeNat (A.fst + B.snd) (B.fst + A.snd)，其中 A = leNum x y、B = leNum y x。

theorem ratLeRep_eq_or_lt (x y : ratRep) (h : ratLeRep x y) :
    ratRel x y ∨ ratLtRep x y :=
  sorry
提示 1思路

把 ratLeRep 的头部展开成 LeNat k m（不要展开 leNum 里的 Prod.fst），交给 ㊺ 的 leNat_eq_or_succ：相等那支的等式正是 ratRel x y；严格小那支假设 ratRel x y，用 ratLeRep_of_ratRel y x 反着给出 LeNat m k，与 leNat_succ_not_self 撞矛盾。

提示 2目标形态

ratRel x y ∨ ratLtRep x y。

提示 3关键件

leNat_eq_or_succ · leNat_succ_not_self · leNat_trans · ratLeRep_of_ratRel · ratRel_symm · And.intro。

查看解答 定理 · 24 行

ratLeRep x y 展开成 LeNat k m；㊺ 的 leNat_eq_or_succ 把它拆成 k = m（这正是 ratRel x y）或 succ k ≤ m（严格小）。后一支用 ratLeRep_of_ratRel y x 反着给出 LeNat m k，与 leNat_succ_not_self 撞矛盾。这里的 Or.elim 三个命题写全——ratRel / ratLtRep 是定义 别名，推断不会替你展开成 Or。

theorem ratLeRep_eq_or_lt (x y : ratRep) (h : ratLeRep x y) :
    ratRel x y ∨ ratLtRep x y :=
  Or.elim
    (fun (heq : Nat.add (leNumFst x y) (leNumSnd y x) =
                Nat.add (leNumFst y x) (leNumSnd x y)) =>
      Or.inl heq)
    (fun (hlt : LeNat (Nat.succ (Nat.add (leNumFst x y) (leNumSnd y x)))
                     (Nat.add (leNumFst y x) (leNumSnd x y))) =>
      Or.inr
        ((fun (hp : ratLeRep x y ∧ ¬ ratRel x y) => hp)
          (And.intro h
            (fun (hxy : ratRel x y) =>
            leNat_succ_not_self
              (Nat.add (leNumFst x y) (leNumSnd y x))
              (leNat_trans
                (Nat.succ (Nat.add (leNumFst x y) (leNumSnd y x)))
                (Nat.add (leNumFst y x) (leNumSnd x y))
                (Nat.add (leNumFst x y) (leNumSnd y x))
                hlt
                (ratLeRep_of_ratRel y x (ratRel_symm x y hxy)))))))
    (leNat_eq_or_succ
      (Nat.add (leNumFst x y) (leNumSnd y x))
      (Nat.add (leNumFst y x) (leNumSnd x y))
      h)
