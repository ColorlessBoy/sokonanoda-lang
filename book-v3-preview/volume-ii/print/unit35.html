35有理 Cauchy 序列：close 与 Cauchy 的定义

Unit 35 — Cauchy Sequences: Definitions

9 个定义 · 4 个定理 · 3 道练习 · 9 条提示 · 解答附录

ℚ 的加法、乘法与序已经搭好，但 ℚ 还有洞：x²=2 没有有理根，1/n 也没有有理极限。要造 ℝ，得先抓住“序列的项最终挤在一起”这件事。直接说“越来越近”没有可检验的内容；我们把它拆成 close 与 Cauchy 两个定义。

close x y eps 说 x 与 y 的距离小于 eps。本语言没有可判定的绝对值函数，不能写 |x-y|；于是改用关系 ratAbsRel：存在一个 d，它等于 |x-y| 且 d<eps。这是定义上最直接的写法，不是绕路。

Cauchy x 说：任给 eps>0，都存在 N，使得 n,m≥N 时 close (x n) (x m) eps。量词顺序是先给 eps、再找 N、最后对 n,m；与 Tao 的定义一致。常零序列是最简单的例子：任给 eps>0，取 N=0，两项都是 0，close 0 0 eps 成立。

我们把这些词汇立起来；有界性、等价关系与 ℝ 的载体留给后面。下一步先看 Cauchy 序列怎样在等价关系下代表同一个实数。

定义ratNegRep声明 1
def ratNegRep (x : ratRep) : ratRep :=
  @prod_mk (Prod Nat Nat) Nat (negRep (numOf x)) (denOf x)
定义ratSubRep声明 2
def ratSubRep (x y : ratRep) : ratRep :=
  ratAddRep x (ratNegRep y)
定义ratLeRep声明 3
def ratLeRep (x y : ratRep) : Prop :=
  leRep (mulRep (numOf x) (den (denOf y)))
        (mulRep (numOf y) (den (denOf x)))
定义ratLtRep声明 4
def ratLtRep (x y : ratRep) : Prop :=
  ratLeRep x y ∧ ¬ ratRel x y
定义ratZeroRep声明 5
def ratZeroRep : ratRep := qrep Nat.zero Nat.zero Nat.zero
定义ratAbsRel声明 6
def ratAbsRel (x y : ratRep) : Prop :=
  (ratLeRep ratZeroRep x ∧ ratRel y x) ∨
    (ratLeRep x ratZeroRep ∧ ratRel y (ratNegRep x))
定义Seq声明 7
def Seq : Type := Nat → ratRep
定义close声明 8
def close (x y : ratRep) (eps : ratRep) : Prop :=
  ∃ (d : ratRep), ratAbsRel (ratSubRep x y) d ∧ ratLtRep d eps
定义Cauchy声明 9
def Cauchy (x : Seq) : Prop :=
  ∀ (eps : ratRep), ratLtRep ratZeroRep eps →
    ∃ (N : Nat), ∀ (n m : Nat), LeNat N n → LeNat N m → close (x n) (x m) eps
