86 扩展实数：±∞ 与序

Unit 86 — Extended Reals and Their Order

8 个定理 · 8 道练习 · 24 条提示 · 解答附录

打印 / PDF 本单元

84 和 85 给上确界与下确界立了唯一性，两处的陈述却都带着一个前提：集合要有实数的上界或下界。无上界的集合在 ℝ 里没有上界，于是「它的上确界」这句话没有指称。把 -∞ 与 +∞ 两个形式端点接到 ℝ 的两端，缺口就补上了：任何集合都至少以 +∞ 为上界。

86.1 负无穷是底

练习 1negInf_le定理附录解答

先把载体与序立起来。自反只在有限点的 Cauchy 代表元上成立；传递与反对称要对三种点逐一检查。端点与有限点的分离也在这里做，后面的上确界运算才能把三种点当成不同的情形处理。

证明按下面的路线展开。

细节清单（6 项，展开）
  • 86.1 / 86.2 负无穷是底、正无穷是顶；
  • 86.3 两个有限点之间的序就是实数的序；
  • 86.4 传递；
  • 86.5 反对称；
  • 86.6 / 86.7 端点与有限点不相等；
  • 86.8 常零序列的类与自身可比。

载体、序、嵌入与判别式在 lib/ExtReal，这里只证序律。

ele negInf b 对三种 b 都展开成 True。

theorem negInf_le (b : ExtReal) : ele negInf b :=
  sorry
提示 1思路

对 b 分三种构造子；三种情形都交给 True.intro。

提示 2目标形态

提示 3关键件

查看解答 定理 · 5 行

载体与序在 lib/ExtReal：三个构造子 negInf、fin、posInf，序 ele 按行定义，判别式 isNegInf / isPosInf 不依赖序。这里证序律。 证明的主要负担是三种点的组合。match 只允许一层，所以每个二元分类都 写成 ExtReal.rec.{0}：把第二个点写进 motive，分支里的假设就会带上 具体的构造子，ele (fin x) negInf 这类前提也才展开成 False。 自反只在 fin (Real.mk x) 且 Cauchy x 时成立；本单元把它作为最后一个 具体例，不写成对所有 Real 成立的公理。 三个分支都只有 True 要证。

theorem negInf_le (b : ExtReal) : ele negInf b :=
  match b with
  | negInf => True.intro
  | fin y => True.intro
  | posInf => True.intro

86.3 有限点之间的序

练习 3ele_fin_fin定理附录解答

ele (fin x) (fin y) 按定义就是 realLe x y，所以两个方向都是同一个证明。

theorem ele_fin_fin (x y : Real) : ele (fin x) (fin y) ↔ realLe x y :=
  sorry
提示 1思路

展开 ele，两个方向都原样返回 realLe x y。

提示 2目标形态

ele (fin x) (fin y) ↔ realLe x y。

提示 3关键件

Iff.intro · 定义性展开。

查看解答 定理 · 2 行

两个方向都不改变证明：展开后两边是同一个 realLe x y。

theorem ele_fin_fin (x y : Real) : ele (fin x) (fin y) ↔ realLe x y :=
  Iff.intro (fun (h : realLe x y) => h) (fun (h : realLe x y) => h)

86.4 传递

练习 4ele_trans定理附录解答

三种点的组合里，只有「有限、有限、有限」这一支需要实数序的传递；其余组合或者结论直接是 True，或者前提已经展开成 False。

注意：本语言的 match 不允许在一个分支里再写一个 match。把下一个要分的点写进 ExtReal.rec.{0} 的 motive，分支里的假设才会被特化成对应的构造子，False 也才认得出来。

theorem ele_trans (a b c : ExtReal) (hab : ele a b) (hbc : ele b c) : ele a c :=
  sorry
提示 1思路

先对 a 分三种。a = negInf 时结论为 True；a = fin x 时对 b 分三种，只有 b = fin y 与 b = posInf 可能；a = posInf 时 b 只能是 posInf，再对 c 分三种。

提示 2目标形态

ele a b → ele b c → ele a c。

提示 3关键件

ExtReal.rec.{0} · realLe_trans · not_ele_fin_negInf · not_ele_posInf_negInf · not_ele_posInf_fin。

查看解答 定理 · 7 行

对第一个点分三种，把三块拼起来。

theorem ele_trans (a b c : ExtReal) (hab : ele a b) (hbc : ele b c) : ele a c :=
  @ExtReal.rec.{0}
    (fun (a' : ExtReal) => ele a' b → ele b c → ele a' c)
    (fun (_ : ele negInf b) (_ : ele b c) => True.intro)
    (fun (x : Real) => ele_trans_fin x b c)
    (ele_trans_posInf b c)
    a hab hbc

86.5 反对称

练习 5ele_antisymm定理附录解答

两个有限点互相不超过时，realLe_antisymm 给出实数的相等，再对 fin 用一次 congrArg。其余八种组合里总有一个前提是 False。

theorem ele_antisymm (a b : ExtReal) (hab : ele a b) (hba : ele b a) : a = b :=
  sorry
提示 1思路

对 a 分三种，再对 b 分三种。有限与有限那一支用 realLe_antisymm 得到 x = y，再用 congrArg fin；其余组合用 not_ele_fin_negInf / not_ele_posInf_negInf / not_ele_posInf_fin 消去。

提示 2目标形态

a = b。

提示 3关键件

ExtReal.rec.{0} · realLe_antisymm · congrArg。

查看解答 定理 · 10 行
theorem ele_antisymm (a b : ExtReal) (hab : ele a b) (hba : ele b a) : a = b :=
  @ExtReal.rec.{0}
    (fun (a' : ExtReal) => ele a' b → ele b a' → a' = b)
    (fun (h : ele negInf b) (h' : ele b negInf) =>
      ele_antisymm_negInf b h h')
    (fun (x : Real) (h : ele (fin x) b) (h' : ele b (fin x)) =>
      ele_antisymm_fin x b h h')
    (fun (h : ele posInf b) (h' : ele b posInf) =>
      ele_antisymm_posInf b h h')
    a hab hba

86.6 负无穷不等于有限点

练习 6negInf_ne_fin定理附录解答

判别式 isNegInf 在 negInf 上是 True，在 fin x 上是 False。把等式代进判别式，就从 True 得到 False。

theorem negInf_ne_fin (x : Real) : ¬ (negInf = fin x) :=
  sorry
提示 1思路

假设 negInf = fin x，用 Eq.subst 把 isNegInf negInf 的证明搬到 isNegInf (fin x)；后者按定义是 False。

提示 2目标形态

¬ (negInf = fin x)。

提示 3关键件

isNegInf · Eq.subst · True.intro。

查看解答 定理 · 3 行

isNegInf negInf 是 True，isNegInf (fin x) 是 False。

theorem negInf_ne_fin (x : Real) : ¬ (negInf = fin x) :=
  fun (h : negInf = fin x) =>
    @Eq.subst.{1} ExtReal isNegInf negInf (fin x) h True.intro

86.7 有限点不等于正无穷

练习 7fin_ne_posInf定理附录解答

与 86.6 对称，判别式换成 isPosInf。等式要从 fin x = posInf 翻成 posInf = fin x，才能把 posInf 上的 True 搬到 fin x 上。

theorem fin_ne_posInf (x : Real) : ¬ (fin x = posInf) :=
  sorry
提示 1思路

假设 fin x = posInf，先取对称得到 posInf = fin x；再用 Eq.subst 把 isPosInf posInf 搬到 isPosInf (fin x)。

提示 2目标形态

¬ (fin x = posInf)。

提示 3关键件

isPosInf · Eq.symm · Eq.subst · True.intro。

查看解答 定理 · 4 行

先把等式翻向，才能从 posInf 的 True 搬到 fin x 的 False。

theorem fin_ne_posInf (x : Real) : ¬ (fin x = posInf) :=
  fun (h : fin x = posInf) =>
    @Eq.subst.{1} ExtReal isPosInf posInf (fin x)
      (@Eq.symm.{1} ExtReal (fin x) posInf h) True.intro

练习 1 · negInf_le 定理

载体与序在 lib/ExtReal：三个构造子 negInf、fin、posInf，序 ele 按行定义，判别式 isNegInf / isPosInf 不依赖序。这里证序律。 证明的主要负担是三种点的组合。match 只允许一层，所以每个二元分类都 写成 ExtReal.rec.{0}：把第二个点写进 motive，分支里的假设就会带上 具体的构造子，ele (fin x) negInf 这类前提也才展开成 False。 自反只在 fin (Real.mk x) 且 Cauchy x 时成立；本单元把它作为最后一个 具体例，不写成对所有 Real 成立的公理。 三个分支都只有 True 要证。

theorem negInf_le (b : ExtReal) : ele negInf b :=
  match b with
  | negInf => True.intro
  | fin y => True.intro
  | posInf => True.intro

练习 6 · negInf_ne_fin 定理

isNegInf negInf 是 True，isNegInf (fin x) 是 False。

theorem negInf_ne_fin (x : Real) : ¬ (negInf = fin x) :=

    @Eq.subst.{1} ExtReal isNegInf negInf (fin x) h True.intro
