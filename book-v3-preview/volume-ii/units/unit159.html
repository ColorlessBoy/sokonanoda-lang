159 可积性的直接判据：把上下和搬到台阶上

Unit 159 — A Direct Criterion for Integrability

8 个定理 · 8 道练习 · 24 条提示 · 解答附录

打印 / PDF 本单元

可积的定义先取两个数，一个来自上界那摞台阶，一个来自下界那摞台阶，再要求这两个数之差小于 ε。做估计时，这两层存在量词总要一次走完：给定 ε，先取分割，再从上和与下和里各自取出产生它们的台阶。把这两步合成一条判据，估计就只谈台阶本身，不必每回都先把两个数拆开。

练习 1stepGap_nonneg定理附录解答

判据的两个方向各是一段搬动。从可积到台阶：已知 U - L < ε，而上和 U 与上界的矩形和只差一次等价，下和同理；把两条等价送进减法，就得到两摞台阶的矩形和之差小于 ε。从台阶到可积：把下界的矩形和直接当作下和、上界的矩形和直接当作上和，它们与自己的等价关系是自反的。

这条判据还带来两个小读数。差已经小于 ε 时，把 ε 放大仍然成立；上界与下界取同一摞高度时，两个矩形和是同一个数，差为零。常值函数的可积性可以直接引用库里已经判过的结论，这里只把它作为判据的一个例子。

边界：只改写可积性的陈述，不证明新的函数可积，也不定义积分值。函数取 ratRep → ratRep，停在有理代表元层。不新增公理，也不碰 kernel/front。

提示 1思路

先把上和与下和换成台阶；stepSum u - stepSum l 沿减法等价于 U - L，再把「差小于 ε」搬过去。

提示 2目标形态

∃ l, ∃ u, LowerStep … ∧ UpperStep … ∧ stepSum u - stepSum l < ε。

提示 3关键件

lowerSum_witness · upperSum_witness · ratSubRep_wd · ratLtRep_congr_fst。

查看解答 定理 · 22 行

上和与下和先各自展开成一摞台阶。矩形和之差与 U - L 的等价关系由减法 的同余给出：两个因子分别沿 stepSum u ~ U、stepSum l ~ L 换过去。原来 的严格界沿这条等价关系的左端搬一次，就是台阶版本的差。

theorem gap_of_sums (a b : ratRep) (p : Partition) (f : ratRep → ratRep)
    (L U eps : ratRep) (hL : LowerSum a b p f L) (hU : UpperSum a b p f U)
    (hgap : ratLtRep (ratSubRep U L) eps) :
    ∃ (l : Nat → ratRep), ∃ (u : Nat → ratRep),
      LowerStep a b p f l ∧ UpperStep a b p f u ∧
        ratLtRep (ratSubRep (stepSum p u) (stepSum p l)) eps :=
  Exists.elim (lowerSum_witness a b p f L hL)
    (fun (l : Nat → ratRep)
        (hl : LowerStep a b p f l ∧ ratRel L (stepSum p l)) =>
      Exists.elim (upperSum_witness a b p f U hU)
        (fun (u : Nat → ratRep)
            (hu : UpperStep a b p f u ∧ ratRel U (stepSum p u)) =>
          Exists.intro l
            (Exists.intro u
              (And.intro (And.left hl)
                (And.intro (And.left hu)
                  (ratLtRep_congr_fst
                    (ratSubRep (stepSum p u) (stepSum p l))
                    (ratSubRep U L) eps hgap
                    (ratSubRep_wd (stepSum p u) U (stepSum p l) L
                      (ratRel_symm U (stepSum p u) (And.right hu))
                      (ratRel_symm L (stepSum p l) (And.right hl)))))))))

      ∃ (p : Partition), IsPartition a b p ∧
        ∃ (l : Nat → ratRep), ∃ (u : Nat → ratRep),
          LowerStep a b p f l ∧ UpperStep a b p f u ∧
            ratLtRep (ratSubRep (stepSum p u) (stepSum p l)) eps :=

练习 2 · gap_of_sums 定理

上和与下和先各自展开成一摞台阶。矩形和之差与 U - L 的等价关系由减法 的同余给出：两个因子分别沿 stepSum u ~ U、stepSum l ~ L 换过去。原来 的严格界沿这条等价关系的左端搬一次，就是台阶版本的差。

theorem gap_of_sums (a b : ratRep) (p : Partition) (f : ratRep → ratRep)
    (L U eps : ratRep) (hL : LowerSum a b p f L) (hU : UpperSum a b p f U)
    (hgap : ratLtRep (ratSubRep U L) eps) :
    ∃ (l : Nat → ratRep), ∃ (u : Nat → ratRep),
      LowerStep a b p f l ∧ UpperStep a b p f u ∧
        ratLtRep (ratSubRep (stepSum p u) (stepSum p l)) eps :=
  Exists.elim (lowerSum_witness a b p f L hL)
    (fun (l : Nat → ratRep)
        (hl : LowerStep a b p f l ∧ ratRel L (stepSum p l)) =>
      Exists.elim (upperSum_witness a b p f U hU)
        (fun (u : Nat → ratRep)
            (hu : UpperStep a b p f u ∧ ratRel U (stepSum p u)) =>
          Exists.intro l
            (Exists.intro u
              (And.intro (And.left hl)
                (And.intro (And.left hu)
                  (ratLtRep_congr_fst
                    (ratSubRep (stepSum p u) (stepSum p l))
                    (ratSubRep U L) eps hgap
                    (ratSubRep_wd (stepSum p u) U (stepSum p l) L
                      (ratRel_symm U (stepSum p u) (And.right hu))
                      (ratRel_symm L (stepSum p l) (And.right hl)))))))))
练习 3 · gap_of_integrable 定理

把可积性的定义逐层拆开：分割、下和、上和，最后交给上一条。每一层都只 消去一个存在量词，结论里的 IsPartition 从第一层原样保留。

theorem gap_of_integrable (a b : ratRep) (f : ratRep → ratRep)
    (h : Integrable a b f) :
    ∀ (eps : ratRep), ratLtRep ratZeroRep eps →
      ∃ (p : Partition), IsPartition a b p ∧
        ∃ (l : Nat → ratRep), ∃ (u : Nat → ratRep),
          LowerStep a b p f l ∧ UpperStep a b p f u ∧
            ratLtRep (ratSubRep (stepSum p u) (stepSum p l)) eps :=
  fun (eps : ratRep) (heps : ratLtRep ratZeroRep eps) =>
    Exists.elim (h eps heps)
      (fun (p : Partition)
          (hp : IsPartition a b p ∧
            ∃ (L : ratRep), ∃ (U : ratRep),
              LowerSum a b p f L ∧ UpperSum a b p f U ∧
                ratLtRep (ratSubRep U L) eps) =>
        Exists.elim (And.right hp)
          (fun (L : ratRep)
              (hLex : ∃ (U : ratRep),
                LowerSum a b p f L ∧ UpperSum a b p f U ∧
                  ratLtRep (ratSubRep U L) eps) =>
            Exists.elim hLex
              (fun (U : ratRep)
                  (hTriple : LowerSum a b p f L ∧ UpperSum a b p f U ∧
                    ratLtRep (ratSubRep U L) eps) =>
                Exists.intro p
                  (And.intro (And.left hp)
                    (gap_of_sums a b p f L U eps
                      (And.left hTriple)
                      (And.left (And.right hTriple))
                      (And.right (And.right hTriple)))))))

            ratLtRep (ratSubRep (stepSum p u) (stepSum p l)) eps) :
    Integrable a b f :=
  fun (eps : ratRep) (heps : ratLtRep ratZeroRep eps) =>
    Exists.elim (h eps heps)
      (fun (p : Partition)
          (hp : IsPartition a b p ∧
            ∃ (l : Nat → ratRep), ∃ (u : Nat → ratRep),
              LowerStep a b p f l ∧ UpperStep a b p f u ∧
                ratLtRep (ratSubRep (stepSum p u) (stepSum p l)) eps) =>

              (hlu : ∃ (u : Nat → ratRep),
                LowerStep a b p f l ∧ UpperStep a b p f u ∧
                  ratLtRep (ratSubRep (stepSum p u) (stepSum p l)) eps) =>
