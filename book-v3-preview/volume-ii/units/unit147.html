147 乘法的符号：负因子把不等号翻过来

Unit 147 — Signs of Products: Negative Factors Flip Inequalities

9 个定理 · 9 道练习 · 27 条提示 · 解答附录

打印 / PDF 本单元

曲线在一点取极大值，意味着往左往右走，函数值都不再增加。把这句话翻译成斜率，最后要判断两个量相乘的符号：自变量的改变是正还是负，函数值的改变又跟着谁走。正正得正、正负得负、负负得正，这条关于乘法的常识在 ℚ 上要回到代表元才能落地。

练习 1ratLtRep_of_neg_pos定理附录解答

证明的骨架是单元141 的 ratMul_neg：x·(-y) ~ -(x·y)。把 (-x)·y 先交换成 y·(-x)，再用这条等式收成 -(x·y)；于是「负数乘正数」化归为「正数乘正数的积取负」。单元146 的 ratMul_pos 给出正积，ratLtRep_neg_of_pos 与 ratLtRep_pos_of_neg 负责把积的符号翻回去。两个负因子相乘则连翻两次，回到正积。

边界：只做符号的乘法表（同号得正、异号得负），不反过来从积的符号反推因子的符号；那一步要用「积为零则因子为零」，留到后面的单元。函数仍取 ratRep → ratRep，不新增公理，也不碰 kernel/front。

乘法的符号：负因子把不等号翻过来

练习 1 · ratLtRep_of_neg_pos 定理

曲线在一点取极大值，意味着往左往右走函数值都不增加。把这件事翻译成 斜率，就要知道两个差的符号：自变量往右挪是正的还是负的，函数值的改变 又跟着谁走。导数的判别最后落在一句常识上——正正得正、正负得负、 负负得正。这条常识在 ℚ 上要回到代表元，把取负与乘法的交换接起来。 证明的骨架是单元141 的 ratMul_neg：x·(-y) ~ -(x·y)。把 (-x)·y 先交换成 y·(-x)，再用这条等式收成 -(x·y)；于是「负数乘正数」化归 为「正数乘正数的积取负」。单元146 的 ratMul_pos 给出正积， ratLtRep_neg_of_pos 与 ratLtRep_pos_of_neg 负责把积的符号翻回去。 0 < -z ⇒ z < 0：把 ratLtRep_neg_of_pos 用在 -z 上，得到 -(-z) < 0，再把左端点沿 -(-z) ~ z 换回来。

theorem ratLtRep_of_neg_pos (z : ratRep)
    (h : ratLtRep ratZeroRep (ratNegRep z)) :
    ratLtRep z ratZeroRep :=
  ratLtRep_congr_fst z (ratNegRep (ratNegRep z)) ratZeroRep
    (ratLtRep_neg_of_pos (ratNegRep z) h)
    (ratRel_symm z (ratNegRep (ratNegRep z)) (ratNegRep_invol z))
练习 2 · ratLtRep_of_neg_neg 定理

反方向：-z < 0 ⇒ 0 < z。同样先翻一次，再把右端点换回 z。

    ratLtRep ratZeroRep z :=

练习 3 · ratMul_neg_left 定理

(-x)·y ~ -(x·y)：交换之后就是 y·(-x)，交给单元141 的 ratMul_neg， 最后把里面那个 y·x 换成 x·y。

theorem ratMul_neg_left (x y : ratRep) :
    ratRel (ratMulRep (ratNegRep x) y) (ratNegRep (ratMulRep x y)) :=
  ratRel_trans_gen
    (ratMulRep (ratNegRep x) y)
    (ratNegRep (ratMulRep y x))
    (ratNegRep (ratMulRep x y))
    (ratRel_trans_gen
      (ratMulRep (ratNegRep x) y)
      (ratMulRep y (ratNegRep x))
      (ratNegRep (ratMulRep y x))
      (ratMul_comm (ratNegRep x) y)
      (ratMul_neg y x))
    (ratNegRep_wd (ratMulRep y x) (ratMulRep x y)
      (ratRel_symm (ratMulRep x y) (ratMulRep y x) (ratMul_comm x y)))
练习 4 · ratMul_neg_pos 定理

负数乘正数得负数。-x 为正，正积 (-x)·y 为正，而它等于 -(x·y)； 最后一步把「积的相反数为正」翻成「积为负」。

theorem ratMul_neg_pos (x y : ratRep)
    (hx : ratLtRep x ratZeroRep) (hy : ratLtRep ratZeroRep y) :
    ratLtRep (ratMulRep x y) ratZeroRep :=
  ratLtRep_of_neg_pos (ratMulRep x y)
    (ratLtRep_congr_snd ratZeroRep (ratMulRep (ratNegRep x) y)
      (ratNegRep (ratMulRep x y))
      (ratMul_pos (ratNegRep x) y (ratLtRep_pos_of_neg x hx) hy)
      (ratMul_neg_left x y))
练习 5 · ratMul_pos_neg 定理

正的被乘数配负的乘数，同样得负数。交换一下乘积就是上一条。

theorem ratMul_pos_neg (x y : ratRep)
    (hx : ratLtRep ratZeroRep x) (hy : ratLtRep y ratZeroRep) :
    ratLtRep (ratMulRep x y) ratZeroRep :=
  ratLtRep_congr_fst (ratMulRep x y) (ratMulRep y x) ratZeroRep
    (ratMul_neg_pos y x hy hx)
    (ratMul_comm x y)
练习 6 · ratMul_neg_neg 定理

两个负数相乘得正数。-x 与 -y 都为正，积 (-x)·(-y) 为正； 它等于 -(-(x·y))，再沿双重负号回到 x·y。

theorem ratMul_neg_neg (x y : ratRep)
    (hx : ratLtRep x ratZeroRep) (hy : ratLtRep y ratZeroRep) :

      (ratMulRep (ratNegRep x) (ratNegRep y))
      (ratNegRep (ratMulRep x (ratNegRep y)))
