07 整数加法的交换律与结合律

Unit 7 — Addition Laws on Integers

3 个定义 · 10 个定理 · 5 道练习 · 15 条提示 · 解答附录

打印 / PDF 本单元

单元⑥ 证了 addRep 尊重 intRel（加法的良定义性）。现在把代表元上的两条算术律搬到商上：交换律与结合律。商上的等式只有一个来源 ——Quot.sound : r a b → mk a = mk b（相关的代表元在商里相等）。本单元先在代表元上证 intRel，再用 Quot.sound 得到 Int 里的等式。

注意：本语言没有 funext，所以不把加法「下降」成 Int → Int → Int 的函数，而是对代表元给出的整数陈述等式；这也正是课程后面 ℚ/ℝ 章要处理的形式。

定义intRel声明 1
def intRel (a b : Prod Nat Nat) : Prop :=
  Nat.add (Prod.fst Nat Nat a) (Prod.snd Nat Nat b) =
  Nat.add (Prod.fst Nat Nat b) (Prod.snd Nat Nat a)
定义Int声明 2
def Int : Type := @Quot.{1} (Prod Nat Nat) intRel
定义addRep声明 3
def addRep (a b : Prod Nat Nat) : Prod Nat Nat :=
  @prod_mk Nat Nat
    (Nat.add (Prod.fst Nat Nat a) (Prod.fst Nat Nat b))
    (Nat.add (Prod.snd Nat Nat a) (Prod.snd Nat Nat b))

以下四条是单元③的 ℕ 加法律，本单元自用（L3：律必须留在单元里）。
