143 极限只看邻域：换掉远处的函数值

Unit 143 — Limits Only See a Neighborhood: Changing Values Far Away

1 个定义 · 11 个定理 · 11 道练习 · 33 条提示 · 解答附录

打印 / PDF 本单元

求 f 在 a 处的极限时，只让 x 落在 a 附近。f 在很远的地方取什么值，与这个极限无关。这句话听起来理所当然，可定义里的全称量词是「对所有满足 0 < |x - a| < δ 的 x」，并没有禁止远处的 x。要把「远处的值可以随便换」变成可用的定理，得把「在 a 附近相等」写成一个明确的假设：存在一个正半径，邻域里（除 a 本身外）两个函数逐点相等。

有了这个假设，证明只是把两个半径取小：原来的极限给一个 δ，相等性给一个 δ₀，落在较小半径里的 x 同时满足两边。接近性从 f x 搬到 g x，靠的是「减去同一个数保持等价」：f x - L 与 g x - L 等价，绝对值见证原样保留。

这条局部性在微分里马上要用。导数是斜率函数的极限，而极限只看 a 附近那一小片；讨论斜率函数时，真正要紧的是它在 a 附近的值。反过来，两个在 a 附近重合的函数若都有极限，它们的极限也重合：局部性给出一边，唯一性收口。

边界：函数取 ratRep → ratRep，停在有理代表元层；邻域用 close 的 ε 半径表述，不引入拓扑。不新增公理，也不碰 kernel/front。

定义：在 a 附近相等

「f 与 g 在 a 附近相等」：有一个正半径 δ，邻域里凡是不等于 a 的点，两个函数值都相等。a 本身不要求：极限本来就不看 a 处的取值。

定义AgreeNear声明 1
def AgreeNear (f g : ratRep → ratRep) (a : ratRep) : Prop :=
  ∃ (delta : ratRep), ratLtRep ratZeroRep delta ∧
    ∀ (x : ratRep), close x a delta → ¬ ratRel x a → ratRel (f x) (g x)

theorem close_transport (u v L eps : ratRep)
    (h : close u L eps) (huv : ratRel u v) : close v L eps :=
  Exists.elim h
    (fun (d : ratRep)
        (hd : ratAbsRel (ratSubRep u L) d ∧ ratLtRep d eps) =>
      Exists.intro d
        (And.intro
          (ratAbsRel_wd_left (ratSubRep u L) (ratSubRep v L) d
            (ratSubRep_wd u v L L huv (ratRel_refl L))
            (And.left hd))
          (And.right hd)))

theorem tendsToAt_same_radius (f g : ratRep → ratRep) (a L eps d d0 : ratRep)
    (hd : ratLtRep ratZeroRep d)
    (hd0 : ratLtRep ratZeroRep d0)
    (hclose : ∀ (x : ratRep), close x a d → ¬ ratRel x a →
      close (f x) L eps)
    (hagree : ∀ (x : ratRep), close x a d0 → ¬ ratRel x a →
      ratRel (f x) (g x)) :
    ∃ (delta : ratRep), ratLtRep ratZeroRep delta ∧
      ∀ (x : ratRep), close x a delta → ¬ ratRel x a →
        close (g x) L eps :=
  @Or.elim (ratLeRep d d0) (ratLeRep d0 d)
    (∃ (delta : ratRep), ratLtRep ratZeroRep delta ∧
      ∀ (x : ratRep), close x a delta → ¬ ratRel x a →
        close (g x) L eps)
    (fun (hle : ratLeRep d d0) =>
      Exists.intro d
        (And.intro hd
          (fun (x : ratRep) (hx : close x a d)
              (hne : ¬ ratRel x a) =>
            close_transport (f x) (g x) L eps
              (hclose x hx hne)
              (hagree x (close_mono_eps x a d d0 hx hle) hne))))
    (fun (hle : ratLeRep d0 d) =>
      Exists.intro d0
        (And.intro hd0
