㉖ 立了 ℚ 加法的代表元公式：a−bm+1 + c−dn+1 等于 [a(n+1)+c(m+1) - (b(n+1)+d(m+1))] / ((m+1)(n+1))，并结清了两条良定义义务；但运算律还没证。先证两条最常用的：交换律 x + y 与 y + x 相等；零元 x + 0 与 x 相等、0 + x 与 x 相等。

练习 1ratAdd_zero_num定理附录解答

为什么先做它们：下一单元的「序与加法相容」要把 x ≤ y 搬到 x+z ≤ y+z，而左加（z+x ≤ z+y）靠的是「先交换、用右加、再交换回来」——没有交换律就变不出左加版本。

证明分两层。先是加零的算术小件：a·1 定义性展开成 a+a*0，再消掉 a*0；分母字段 ratDenRep m 0 同理退化成 m。然后在代表元层比较 x+y 与 y+x：两边用 mulRep_den_form 化成「分子乘正分母」的规范形，用 prod_mk_congr 与 congrArg 证成相等，最后 intRel_of_eq 收口。x+0 则先把三元组搬成 qrep a b m（消掉零项），再用自反性。

通用陈述要先在展开类型上 match 到字面三元组（ratRep 是定义别名，match 只认归纳类型本身），再把字面结果转发给通用陈述——与 ㊷ 的 ratSubRep_neg_aux 是同一写法。

theorem ratAdd_zero_num (a m : Nat) :

    (Nat.add (myMul a (Nat.succ Nat.zero)) (myMul Nat.zero (Nat.succ m)))
    (Nat.add (Nat.add a Nat.zero) (myMul Nat.zero (Nat.succ m)))
    a
    (congrArg.{1}
      (fun (Z : Nat) => Nat.add Z (myMul Nat.zero (Nat.succ m)))
      (@Eq.trans.{1} Nat
        (myMul a (Nat.succ Nat.zero))
        (Nat.add a (myMul a Nat.zero))
        (Nat.add a Nat.zero)
        (myMul_succ a Nat.zero)
        (congrArg.{1} (fun (Z : Nat) => Nat.add a Z) (myMul_zero a))))

      (Nat.add (Nat.add a Nat.zero) (myMul Nat.zero (Nat.succ m)))
