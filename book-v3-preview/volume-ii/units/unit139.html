139 单调函数：介值性反过来给出连续

Unit 139 — Monotone Functions: Intermediate Values Force Continuity

2 个定义 · 24 个定理 · 13 道练习 · 39 条提示 · 解答附录

打印 / PDF 本单元

134 到 136 用连续性换来了最值与介值：连续函数在闭区间上取到最值，从一个负值走到正值时必经过零。这些结论都从连续性出发。反过来的问题同样值得问：「不跳过中间值」这一条性质，能不能把连续性认出来？

单调函数是回答这个问题最省的对象。它的图像只朝一个方向走，所以不连续的方式只剩一种：在某个点跳过去，把一段区间里的值整段让开。若它从不跳过任何一个中间值，就无处可跳，只能连续。ℚ 上的连续函数未必有介值性（x² - 2 在 [1,2] 上连续却没有有理零点），所以这里的介值性是一条显式假设，不是自动成立的事实。

证明把连续性拆成两个单侧的上界。给定 eps，在 c 的右边找一个分界点 u，使 c 到 u 之间的函数值都不超过 f c + eps/2。若右端点的值本来就不超过这个阈值，右端点本身就是 u；否则介值性在 c 与 b 之间给出一个点，它的值正好是阈值。左边对称地得到 l。δ 取 u - c 与 c - l 中较小的那个，于是 c 的 δ 邻域被夹在 [l, u] 里，两次单侧估计合起来就是 |f x - f c| < eps。

边界：函数取 ratRep → ratRep，停在有理代表元层；介值性作为假设出现，因为它在 ℚ 上不是连续性的推论。不新增公理，也不碰 kernel/front。

定义：严格递增与介值性

严格递增只看严格序：x < y 时 f x < f y。它不假设函数尊重代表元的等价，所以这条性质只在不跨越等价类的地方使用，构造单射时正好够用。

定义StrictlyIncreasing声明 1
def StrictlyIncreasing (f : ratRep → ratRep) : Prop :=
  ∀ (x y : ratRep), ratLtRep x y → ratLtRep (f x) (f y)

介值性把「不跳过中间值」写成一个量词句：区间里两点之间取到的每个值，都被某个严格的中间点取到。函数停在代表元层，取到的值只能报到等价类，所以结论写成 ratRel (f c) v 而不是相等。
