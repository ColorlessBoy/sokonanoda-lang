138 无穷远处极限的代数与序列判据

Unit 138 — Algebra of Limits at Infinity and the Sequential Criterion

1 个定义 · 7 个定理 · 7 道练习 · 21 条提示 · 解答附录

打印 / PDF 本单元

上一单元只立了定义，能算的例子还只有常函数与平移。若两个函数各自在无穷远处靠近 L 与 M，它们的和是否靠近 L + M？把 x 一直往右推，两个误差都变小，答案应当是肯定的。证明与一点处的和律同形：ε 折半，两个分界线用序的全性合成一条，越过它之后两条接近性同时成立。

取负、减法、加常数都是同一条和律的变形。真正把「无穷远处的极限」接回序列语言的是下面这条判据：如果自变量序列 x_n 最终越过任何一条分界线，那么 f(x_n) 就收敛到 L。它说明这里的极限仍然是 ε-N 式的极限，只不过阈值从下标换成了数轴上的位置。

边界：函数取 ratRep → ratRep，序列取 Nat → ratRep，都停在有理代表元层；不把 ±∞ 当成数，也不讨论函数值趋于无穷。不新增公理，也不碰 kernel/front。

序列趋于无穷

读法：无论把分界线 M 放在哪里，序列最终都越过它。这里不说「极限是无穷大」，只说「最终超过每个给定的有理数」，避免引入新的极限对象。

定义TendsToInfinity声明 1
def TendsToInfinity (x : Seq) : Prop :=
  ∀ (M : ratRep), ∃ (N : Nat), ∀ (n : Nat), LeNat N n → ratLeRep M (x n)

theorem tendsToAtInfinity_add (f g : ratRep → ratRep) (L M : ratRep)
    (hf : TendsToAtInfinity f L) (hg : TendsToAtInfinity g M) :
    TendsToAtInfinity (fun (x : ratRep) => ratAddRep (f x) (g x))
      (ratAddRep L M) :=
  fun (eps : ratRep) (heps : ratLtRep ratZeroRep eps) =>
    @Exists.elim ratRep
      (fun (Mf : ratRep) => ∀ (x : ratRep), ratLeRep Mf x →
        close (f x) L (ratHalf eps))
      (∃ (K : ratRep), ∀ (x : ratRep), ratLeRep K x →
        close (ratAddRep (f x) (g x)) (ratAddRep L M) eps)
      (hf (ratHalf eps) (ratLtRep_half eps heps))
      (fun (Mf : ratRep)
          (hMf : ∀ (x : ratRep), ratLeRep Mf x →
            close (f x) L (ratHalf eps)) =>
        @Exists.elim ratRep
          (fun (Mg : ratRep) => ∀ (x : ratRep), ratLeRep Mg x →
            close (g x) M (ratHalf eps))
          (∃ (K : ratRep), ∀ (x : ratRep), ratLeRep K x →
            close (ratAddRep (f x) (g x)) (ratAddRep L M) eps)
          (hg (ratHalf eps) (ratLtRep_half eps heps))
          (fun (Mg : ratRep)
              (hMg : ∀ (x : ratRep), ratLeRep Mg x →
                close (g x) M (ratHalf eps)) =>
            @Exists.elim ratRep
              (fun (K : ratRep) => ratLeRep Mf K ∧ ratLeRep Mg K)
              (∃ (K : ratRep), ∀ (x : ratRep), ratLeRep K x →
                close (ratAddRep (f x) (g x)) (ratAddRep L M) eps)
              (exists_ge_both Mf Mg)
              (fun (K : ratRep)
                  (hK : ratLeRep Mf K ∧ ratLeRep Mg K) =>
                Exists.intro K
                  (fun (x : ratRep) (hx : ratLeRep K x) =>
                    close_add (f x) L (g x) M eps
                      (hMf x (ratLeRep_trans Mf K x (And.left hK) hx))
                      (hMg x (ratLeRep_trans Mg K x (And.right hK) hx))))))

序列判据：把自变量换成一条趋于无穷的序列

给定 ε，f 的极限给出一条分界线 M；序列的假设对同一条 M 给出阈值 N。N 之后每个 x n 都越过 M，于是 f (x n) 落在 ε 界内。

theorem tendsToAtInfinity_comp (f : ratRep → ratRep) (L : ratRep)
    (x : Seq) (hf : TendsToAtInfinity f L) (hx : TendsToInfinity x) :
    Converges (fun (n : Nat) => f (x n)) L :=

theorem tendsToAtInfinity_add (f g : ratRep → ratRep) (L M : ratRep)
    (hf : TendsToAtInfinity f L) (hg : TendsToAtInfinity g M) :
    TendsToAtInfinity (fun (x : ratRep) => ratAddRep (f x) (g x))
      (ratAddRep L M) :=
  fun (eps : ratRep) (heps : ratLtRep ratZeroRep eps) =>
    @Exists.elim ratRep
      (fun (Mf : ratRep) => ∀ (x : ratRep), ratLeRep Mf x →
        close (f x) L (ratHalf eps))
      (∃ (K : ratRep), ∀ (x : ratRep), ratLeRep K x →
        close (ratAddRep (f x) (g x)) (ratAddRep L M) eps)
      (hf (ratHalf eps) (ratLtRep_half eps heps))
      (fun (Mf : ratRep)
          (hMf : ∀ (x : ratRep), ratLeRep Mf x →
            close (f x) L (ratHalf eps)) =>
        @Exists.elim ratRep
          (fun (Mg : ratRep) => ∀ (x : ratRep), ratLeRep Mg x →
            close (g x) M (ratHalf eps))
          (∃ (K : ratRep), ∀ (x : ratRep), ratLeRep K x →
            close (ratAddRep (f x) (g x)) (ratAddRep L M) eps)
          (hg (ratHalf eps) (ratLtRep_half eps heps))
          (fun (Mg : ratRep)
              (hMg : ∀ (x : ratRep), ratLeRep Mg x →
                close (g x) M (ratHalf eps)) =>
            @Exists.elim ratRep
              (fun (K : ratRep) => ratLeRep Mf K ∧ ratLeRep Mg K)
              (∃ (K : ratRep), ∀ (x : ratRep), ratLeRep K x →
                close (ratAddRep (f x) (g x)) (ratAddRep L M) eps)
              (exists_ge_both Mf Mg)

                  (hK : ratLeRep Mf K ∧ ratLeRep Mg K) =>
                Exists.intro K
                  (fun (x : ratRep) (hx : ratLeRep K x) =>
                    close_add (f x) L (g x) M eps
