46 序的反对称性：两边夹出相等

Unit 46 — Antisymmetry of the Order

4 个定理 · 4 道练习 · 12 条提示 · 解答附录

打印 / PDF 本单元

↑ 目录

㊺ 结清了「ℚ 的序是全序」，但要把序用在绝对值上还差一条反对称性：x ≤ y 且 y ≤ x 推出 x ~ y。

练习 1leNat_succ_not_self定理附录解答

为什么它挡在三角不等式前面：㉝ 的绝对值是关系而不是函数；同一个 x 的两个绝对值见证 d、d' 可能落在不同分支上（一个取 x、一个取 -x）。要把它们认成同一个，必须先知道「0 ≤ x 与 x ≤ 0 同时成立时 x ~ 0」——这正是反对称性。

先证一条辅助事实：n+1 ≤ n 不成立（没有数严格大于自己）。做法是把它化成 n = (n+1)+k，再用后继运算搬成 n = n+(k+1)，交给对 n 归纳的辅助引理。再证 ℕ 与 ℚ 的反对称性：ℕ 上把 a ≤ b 拆成「a = b」与「a+1 ≤ b」，后者与 b ≤ a 串起来就是矛盾；ℚ 上交叉相乘后交给 ℕ 的反对称性。最后在具体数字上验证 1/2 与 2/4 互相 ≤ 所以相等。

ratLeRep 只在头部展开成 leRep (leNum x y) (leNum y x)，再交给 leRep_antisymm；不把 leNum 再展开（Prod.fst 会卡在定义上，内核不归约）。

㊻.1 n + 1 ≤ n 不成立

先证没有数严格大于自己。

theorem leNat_succ_not_self (n : Nat) (h : LeNat (Nat.succ n) n) : False :=
  sorry
提示 1思路

把 h : n+1 ≤ n 交给 leNat_exists_add，得到 k 与 n = (n+1) + k；用 succ_add 把 (n+1)+k 化成 succ (n+k)，再用 add_succ 的对称把它写成 n + (k+1)。于是 n = n + (k+1)，交给辅助引理 nat_add_succ_ne_self（对 n 归纳；零情形 succ_ne_zero，后继情形 Nat.succ.inj 剥一层）。

提示 2目标形态

LeNat (Nat.succ n) n → False。

提示 3关键件

leNat_exists_add · Exists.elim · succ_add · add_succ（取对称）· nat_add_succ_ne_self。

查看解答 定理 · 22 行
theorem leNat_succ_not_self (n : Nat) (h : LeNat (Nat.succ n) n) : False :=
  Exists.elim
    (leNat_exists_add (Nat.succ n) n h)
    (fun (k : Nat) (hk : n = Nat.add (Nat.succ n) k) =>
      nat_add_succ_ne_self n k
        (@Eq.symm.{1} Nat
          n
          (Nat.add n (Nat.succ k))
          (@Eq.trans.{1} Nat
            n
            (Nat.add (Nat.succ n) k)
            (Nat.add n (Nat.succ k))
            hk
            (@Eq.trans.{1} Nat
              (Nat.add (Nat.succ n) k)
              (Nat.succ (Nat.add n k))
              (Nat.add n (Nat.succ k))
              (succ_add n k)
              (@Eq.symm.{1} Nat
                (Nat.add n (Nat.succ k))
                (Nat.succ (Nat.add n k))
                (add_succ n k))))))

㊻.2 ℕ 的序反对称

ℕ 的反对称性：把 a ≤ b 拆成相等或 a+1 ≤ b。

theorem leNat_antisymm (a b : Nat) (h1 : LeNat a b) (h2 : LeNat b a) : a = b :=
  sorry
提示 1思路

用 ㊺ 的 leNat_eq_or_succ 把 h1 : a ≤ b 拆成两支。第一支 a = b 就是答案；第二支 a+1 ≤ b，与 h2 : b ≤ a 用 leNat_trans 串成 a+1 ≤ a，交给 ㊻.1 得到 False，再 False.elim。

提示 2目标形态

LeNat a b → LeNat b a → a = b。

提示 3关键件

leNat_eq_or_succ · leNat_trans · leNat_succ_not_self · @False.elim（显式给目标类型）· Or.elim。

查看解答 定理 · 7 行
theorem leNat_antisymm (a b : Nat) (h1 : LeNat a b) (h2 : LeNat b a) : a = b :=
  Or.elim
    (fun (heq : a = b) => heq)
    (fun (hlt : LeNat (Nat.succ a) b) =>
      @False.elim (a = b)
        (leNat_succ_not_self a (leNat_trans (Nat.succ a) b a hlt h2)))
    (leNat_eq_or_succ a b h1)

theorem nat_add_succ_ne_self (n k : Nat) :
    Nat.add n (Nat.succ k) = n → False :=
  Nat.rec
    (fun (m : Nat) => ∀ (k : Nat), Nat.add m (Nat.succ k) = m → False)
    (fun (k : Nat) (h : Nat.add Nat.zero (Nat.succ k) = Nat.zero) =>
      succ_ne_zero k
        (@Eq.trans.{1} Nat
          (Nat.succ k)
          (Nat.add Nat.zero (Nat.succ k))
          Nat.zero
          (@Eq.symm.{1} Nat (Nat.add Nat.zero (Nat.succ k)) (Nat.succ k)
            (zero_add (Nat.succ k)))
          h))
    (fun (m : Nat)
         (ih : ∀ (k : Nat), Nat.add m (Nat.succ k) = m → False) =>
      fun (k : Nat) (h : Nat.add (Nat.succ m) (Nat.succ k) = Nat.succ m) =>
        ih k
          (Nat.succ.inj (Nat.add m (Nat.succ k)) m
            (@Eq.trans.{1} Nat
              (Nat.succ (Nat.add m (Nat.succ k)))
              (Nat.add (Nat.succ m) (Nat.succ k))
              (Nat.succ m)
              (@Eq.symm.{1} Nat
                (Nat.add (Nat.succ m) (Nat.succ k))
                (Nat.succ (Nat.add m (Nat.succ k)))
                (succ_add m (Nat.succ k)))
              h)))
    n k
