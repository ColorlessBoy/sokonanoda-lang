36 实数的载体：Real := Quot realRel

Unit 36 — The Carrier of the Reals

13 个定义 · 6 个定理 · 3 道练习 · 9 条提示 · 解答附录

打印 / PDF 本单元

↑ 目录

单元㉟ 有了 Cauchy 序列。两个 Cauchy 序列「等价」当且仅当它们逐项最终任意接近：realRel x y 当且仅当 x、y 都是 Cauchy 序列，且对任意 eps>0 存在 N，使 n ≥ N 时 close (x n) (y n) eps 成立。实数就是这些序列的商：Real := Quot realRel。

这里只立载体与构造子：Real.mk 把序列放进商；Real.sound 说相关的序列在商里相等（就是 Quot.sound）；realRel_zero 说常零序列与自身等价，推论是

mkzero=mkzero

等价关系的传递性（realRel_trans）与 Quot.exact 的反向消去都要三角不等式与序的加法相容，留给后续单元。

定义ratNegRep声明 1
def ratNegRep (x : ratRep) : ratRep :=
  @prod_mk (Prod Nat Nat) Nat (negRep (numOf x)) (denOf x)
定义ratSubRep声明 2
def ratSubRep (x y : ratRep) : ratRep :=
  ratAddRep x (ratNegRep y)
定义ratLeRep声明 3
def ratLeRep (x y : ratRep) : Prop :=
  leRep (mulRep (numOf x) (den (denOf y)))
        (mulRep (numOf y) (den (denOf x)))
定义ratLtRep声明 4
def ratLtRep (x y : ratRep) : Prop :=
  ratLeRep x y ∧ ¬ ratRel x y
定义ratZeroRep声明 5
def ratZeroRep : ratRep := qrep Nat.zero Nat.zero Nat.zero
定义ratAbsRel声明 6
def ratAbsRel (x y : ratRep) : Prop :=
  (ratLeRep ratZeroRep x ∧ ratRel y x) ∨
    (ratLeRep x ratZeroRep ∧ ratRel y (ratNegRep x))
定义Seq声明 7
def Seq : Type := Nat → ratRep
定义close声明 8
def close (x y : ratRep) (eps : ratRep) : Prop :=
  ∃ (d : ratRep), ratAbsRel (ratSubRep x y) d ∧ ratLtRep d eps
定义Cauchy声明 9
def Cauchy (x : Seq) : Prop :=
  ∀ (eps : ratRep), ratLtRep ratZeroRep eps →
    ∃ (N : Nat), ∀ (n m : Nat), LeNat N n → LeNat N m → close (x n) (x m) eps
定义realRel声明 10
def realRel (x y : Seq) : Prop :=
  Cauchy x ∧ Cauchy y ∧
    ∀ (eps : ratRep), ratLtRep ratZeroRep eps →
      ∃ (N : Nat), ∀ (n : Nat), LeNat N n → close (x n) (y n) eps
定义Real声明 11
def Real : Type := @Quot.{1} Seq realRel
定义Real.mk声明 12
def Real.mk (x : Seq) : Real := @Quot.mk.{1} Seq realRel x
