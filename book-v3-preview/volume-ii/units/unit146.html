146 乘法的保序性：正因子不改变不等号

Unit 146 — Multiplication Preserves Order: Positive Factors Do Not Flip Inequalities

10 个定理 · 10 道练习 · 30 条提示 · 解答附录

打印 / PDF 本单元

导数要回答的一个问题是：曲线整体乘上一个常数，斜率会怎么变？把逐点相乘写成差商，绕不开一条关于乘法的常识——正数乘在不等式两边，不等号的方向不变。这条常识在 ℚ 上不是免费的：乘法先通分再运算，正因子在分母里留下的因子要靠约分消掉，而约分本身要用乘法的交换、结合与分配。

练习 1ratLeRep_mul_pos_right定理附录解答

证明把 x ≤ y 与 0 < z 都拆到整数代表元。x ≤ y 是交叉相乘之后两个 ℕ 的和的大小比较；0 < z 说明 z 的分子两格一严一宽（f ≤ e），并且两格不相等，于是第二格可以写成第一格加上一个正数 t。把 e = f + t 代进目标，交叉乘积的两边都长出相同的四项，相消之后剩下的是 x ≤ y 两边同乘 t。ℕ 的乘法保序（leNat_mul_right）负责这一步，分配律负责把多出来的项摆回原位。

严格版本多一步：若乘完之后两边相等，就用非零因子消去律把 z 约掉，得到 x ~ y，与严格小矛盾。两个正数的积为正，是把 0 < y 乘上正数 x，得到 x·0 < x·y，再把左边收回零。

边界：只做正因子。负因子要把不等号翻过来，需要先接上取负与乘法的交换；常数倍的导数还要一条更细的估计，都留到后面的单元。不新增公理。
