Unit 73 — Sequences and Limits: The ε-N Definition

2 个定义 · 6 个定理 · 6 道练习 · 18 条提示 · 解答附录

↑ 目录

数系造到 ℝ 之后，下一步要谈「越来越接近」。有理数上的 close 只能比较两个点，极限却要比较一列点与一个点，并且允许前有限项不满足。缺的正是这两个层次：先把「从某项起」与 ε-N 收敛写成定义，后面的唯一性、夹逼与四则运算才有共同的语言。

这里的 Seq 是 Nat → ratRep（㉟ 的 Seq），close 是「两个有理数在 ε 内接近」。于是 ε-N 极限在这一层是：

Converges x L :⟺ ∀ eps > 0, 终究 (close (x n) L eps)

其中 Eventually P 是「存在阈值 N，从 N 起 P 一直成立」。把「终究」单独命名，是因为后面几乎每条极限证明都要合并两个阈值（唯一性、夹逼、四则运算）；这里先把它自己的两条结构律备齐。

边界：Real 上的加法在本课程里是三元关系 addRel 而不是函数，所以「实数列的 ε-N」暂时不能写成 L + eps 这样的项。这里停在有理代表元层；68.6 的 TendsTo 已经是类层的写法，把两者接起来留到后续单元。不新增公理。

73.0 终究与 ε-N 极限

「从某个阈值起一直成立」。注意阈值是存在给出的，不是「对每个 n」。

定义Eventually声明 1
def Eventually (P : Nat → Prop) : Prop :=
  ∃ (N : Nat), ∀ (n : Nat), LeNat N n → P n

ε-N 极限：每个正有理 ε 都有一个阈值，从那里起 x n 与 L 在 ε 内。

定义Converges声明 2
def Converges (x : Seq) (L : ratRep) : Prop :=
  ∀ (eps : ratRep), ratLtRep ratZeroRep eps →
    Eventually (fun (n : Nat) => close (x n) L eps)

两条假设各给一个阈值；58 的 leNat_max 取一个同时 ≥ 两者的 N， 再对 n ≥ N 用 leNat_trans 落回两个旧阈值。

theorem eventually_and (P Q : Nat → Prop) (hp : Eventually P) (hq : Eventually Q) :
    Eventually (fun (n : Nat) => P n ∧ Q n) :=
  Exists.elim hp
    (fun (Np : Nat) (hNp : ∀ (n : Nat), LeNat Np n → P n) =>
      Exists.elim hq
        (fun (Nq : Nat) (hNq : ∀ (n : Nat), LeNat Nq n → Q n) =>
          Exists.elim (leNat_max Np Nq)
            (fun (N : Nat) (hN : LeNat Np N ∧ LeNat Nq N) =>
              Exists.intro N
                (fun (n : Nat) (hn : LeNat N n) =>
                  And.intro
                    (hNp n (leNat_trans Np N n (And.left hN) hn))
                    (hNq n (leNat_trans Nq N n (And.right hN) hn))))))

theorem close_of_ratRel (x y : ratRep) (h : ratRel x y) (eps : ratRep)
    (heps : ratLtRep ratZeroRep eps) : close x y eps :=
  Exists.intro ratZeroRep
    (And.intro
      (ratAbsRel_wd_left ratZeroRep (ratSubRep x y) ratZeroRep
        (ratRel_symm (ratSubRep x y) ratZeroRep
          (ratRel_trans_gen (ratSubRep x y) (ratSubRep y y) ratZeroRep
            (ratAddRep_wd_gen x y (ratNegRep y) h)
            (ratAdd_neg_gen y)))
        ratAbsRel_zero)
      heps)

Unit 83 — Convergent Sequences are Cauchy

5 个定理 · 4 道练习 · 12 条提示 · 解答附录

收敛把序列的尾巴拴在一个固定的点 L 上：从某个阈值起，每一项都落在 L 的 ε 邻域里。尾巴上的任意两项因此也彼此靠近——它们各自离 L 不到 ε/2，折半相加就得到 ε。这就是 Cauchy 条件：任意正 ε，存在阈值，从那里起任意两项都在 ε 内。

这条推理把极限的 ε-N 语言接到前面定义的 Cauchy 上，也让一个收敛序列有资格作为实数的代表元：Real.mk x 与 Real.mk (constSeq L) 相等。反方向——Cauchy 序列在 ℚ 上收敛——不成立；截断的 √2 近似就是反例，要等 ℝ 的完备性，不能在这里假设。
