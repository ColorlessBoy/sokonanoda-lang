Unit 167 — The Integral Value: Pinning Upper and Lower Sums

1 个定义 · 6 个定理 · 6 道练习 · 18 条提示 · 解答附录

↑ 目录

可积性说上和与下和能靠得任意近，可是「这块面积是多少」还没有答案。一列越来越窄的区间围住的是一个数，还是一族数？如果围住的是一个数，它该满足什么条件？

一个候选值 I 要同时满足三件事：它不低于任何分割的下和，不高于任何分割的上和，并且曲线可积。前两条把它钉在所有分割之间，第三条保证这些分割之间的缝能任意窄。这样的 I 至多有一个：可积性给一个缝比 ε 窄的分割，两个候选同时被这个分割夹住，它们的差就不超过 ε。

常值曲线给出第一个可算的读数。k 的任何下界不超过 k，任何上界不小于 k，所以 k·(b-a) 符合规格。

这里没有断言这样的 I 一定存在。有理数里，一列越来越窄的区间可以围住一个无理数；上下和共同靠近的数未必落在有理数里。存在性要等实数完备性，而唯一性已经让「面积值」成为一个确定的对象：若它存在，它是谁已经定死。

函数取 ratRep → ratRep，停在有理代表元层；不新增公理，也不碰 kernel/front。

面积值

一个数 I 是曲线在 [a,b] 上的面积值，当它夹在所有分割的上下和之间，并且曲线确实可积。两条「所有分割」把数钉住，可积性保证这些区间能任意窄；缺了后者，任何小于所有下和的数都能混进来。

def HasIntegral (a b : ratRep) (f : ratRep → ratRep) (I : ratRep) : Prop :=
  (∀ (p : Partition) (L : ratRep),
    IsPartition a b p → LowerSum a b p f L → ratLeRep L I) ∧
  (∀ (p : Partition) (U : ratRep),
    IsPartition a b p → UpperSum a b p f U → ratLeRep I U) ∧
  Integrable a b f

三条并起来：下界的界由 lowerSum_add_const_le 给，上界的界由 upperSum_add_const_ge 给，可积性由 integrable_add_const 给。

theorem hasIntegral_add_const (a b : ratRep) (f : ratRep → ratRep)
    (I k : ratRep) (h : HasIntegral a b f I) :
    HasIntegral a b (fun (x : ratRep) => ratAddRep (f x) k)
      (ratAddRep I (ratMulRep k (ratSubRep b a))) :=
  And.intro
    (fun (p : Partition) (L : ratRep) (hp : IsPartition a b p)
        (hL : LowerSum a b p (fun (x : ratRep) => ratAddRep (f x) k) L) =>
      lowerSum_add_const_le a b f I k L h p hp hL)
    (And.intro
      (fun (p : Partition) (U : ratRep) (hp : IsPartition a b p)
          (hU : UpperSum a b p (fun (x : ratRep) => ratAddRep (f x) k) U) =>
        upperSum_add_const_ge a b f I k U h p hp hU)
      (integrable_add_const a b f k (hasIntegral_integrable a b f I h)))
练习 8 · demo_hasIntegral_shift_const 定理

常值 c 的面积值是 c(b-a)；平移定理把它换成 c(b-a) + k(b-a)。

theorem demo_hasIntegral_shift_const (a b c k : ratRep) (hab : ratLtRep a b) :
    HasIntegral a b (fun (_ : ratRep) => ratAddRep c k)
      (ratAddRep (ratMulRep c (ratSubRep b a))
        (ratMulRep k (ratSubRep b a))) :=
  hasIntegral_add_const a b (fun (_ : ratRep) => c)
    (ratMulRep c (ratSubRep b a)) k (hasIntegral_const a b c hab)
