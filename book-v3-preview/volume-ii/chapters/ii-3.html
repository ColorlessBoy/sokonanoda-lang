29有理数的序：代表元公式与自反性

2 个定义 · 4 个定理 · 4 道练习 · 8 条提示 · 解答附录

卷 II 把 ℚ 建成 Quot ratRel（单元⑳），并在代表元层结清了加法与乘法的良定义性（㉖–㉘）。接下来进入 ℚ 的性质：序、绝对值、幂、间隙。先做序，因为后面的绝对值与极限都要用它。

序的定义沿用整数序的同一套想法：a−bm+1 ≤ c−dn+1 等价于交叉相乘后的 ℕ 不等式 a·(n+1) + d·(m+1) ≤ c·(m+1) + b·(n+1)。右边不是笔误：(a-b)(n+1) ≤ (c-d)(m+1) 移项后，负部 -b(n+1) 与 -d(m+1) 都搬到对面。分母 (m+1)(n+1) 是正的，所以交叉相乘不改变方向。

这里先立起序的定义、自反、以及「相等蕴含序」；传递性、全序与加法/乘法相容都要先把两个代表元换到公分母，留给后续单元。

单元㉙ 定义了非严格序 ratLeRep。严格序在数学上是「≤ 且不等」，在商上「不等」仍然用 ratRel 的否定表达（Rat 的相等就是 ratRel）：ratLtRep x y 当且仅当 ratLeRep x y 且非 ratRel x y。

这里先结清严格序的三条定义展开级事实：它不是自反的；它蕴含非严格序；非严格序加上不相等就是它。再加一个具体计算 0 < 1：序的部分用 ㉙ 的 le_succ，不等的部分把 ratRel 0 1 化成 0 = 1，由 succ_ne_zero 否定。

传递性、全序与加法/乘法相容仍要先通分，留给后续单元。

单元㉙–㉚ 建立了 ℚ 的序与严格序。现在补上取负：一个分数取负，就是分子序对的两个坐标对调——a−bm+1 的负是 b−am+1。代表元上正是 ratNegRep x = (negRep (numOf x), denOf x)。

减法在这里不做：它只是加法与取负的组合，留到下一单元。
