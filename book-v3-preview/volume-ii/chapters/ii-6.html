close 的传递性要把 x-y 与 y-z 加起来，再把 x-z 认成 (x-y)+(y-z)。这条等式在代表元层要先把 -y+y 收成 0，也就是这里要证的加法逆元律：x 加自己的负元与 0 相等。

55.1 字面三元组：qrep a b m + -(qrep a b m) ~ 0

练习 1ratAdd_neg_mk定理附录解答

它看着「显然」，但在商构造里要穿过三层。第一层是 ratNegRep 只是把分子序对交换（分母字段不动）；第二层是相加后公分母是 ratDenRep m m，交叉乘积会把 myMul 0 (succ D) 带进来（内核不替你归约 0*n，要用 zero_mul）；第三层是两个坐标只差加法交换，但 ratRel 要的是交叉和相等，两边的 x+0、0+0 尾巴都得用 add_zero 或 zero_add 显式收掉。

先在字面三元组上把这条律证出来，再搬到任意代表元；然后把减法读成「加负元」，最后落在 1/2 - 1/2 上。全部停在代表元层，不碰商、不碰函数外延性、不加公理。

先在字面三元组上展开，把零尾巴收掉。

theorem ratAdd_neg_mk (a b m : Nat) :

先展开。ratAddRep (qrep a b m) (ratNegRep (qrep a b m)) 的分子是 (A, B)，其中 A = a·(m+1) + b·(m+1)、B = b·(m+1) + a·(m+1)，分母字段是 ratDenRep m m。ratRel 的交叉乘积把 den 0 = (1,0) 与 den (ratDenRep m m) 带进来，于是左边多出 (x+0)+0 的尾巴、右边多出 myMul 0 (succ D)。

提示 2关键件

zero_mul（把 myMul Nat.zero (Nat.succ D) 换成 0；Eq.subst 的方向要写成 0 = z）· zero_add / add_zero（收掉零尾巴）· add_comm（两个分子坐标交换）· Eq.trans。

练习 1 · ratLtRep_congr_snd 定理

ratLtRep a b 是 ratLeRep a b ∧ ¬ ratRel a b：弱序沿 b ~ c 搬 （㊴ 的 ratLeRep_congr_gen），不相等部分把 a ~ c 与 c ~ b 串成 a ~ b。

theorem ratLtRep_congr_snd (a b c : ratRep)
    (h : ratLtRep a b) (hbc : ratRel b c) : ratLtRep a c :=
  And.intro
    (ratLeRep_congr_gen a a b c (ratRel_refl a) hbc (And.left h))
    (fun (hac : ratRel a c) =>
      And.right h
        (ratRel_trans_gen a c b hac (ratRel_symm b c hbc)))

theorem close_trans (x y z eps : ratRep) (heps : ratLtRep ratZeroRep eps)
    (hxy : close x y (ratHalf eps)) (hyz : close y z (ratHalf eps)) :
    close x z eps :=
  Exists.elim hxy
    (fun (dx : ratRep)
        (hdx : ratAbsRel (ratSubRep x y) dx ∧ ratLtRep dx (ratHalf eps)) =>
      Exists.elim hyz
        (fun (dy : ratRep)
            (hdy : ratAbsRel (ratSubRep y z) dy ∧ ratLtRep dy (ratHalf eps)) =>

            (ratAbsRel_total
              (ratAddRep (ratSubRep x y) (ratSubRep y z)))

                (hd : ratAbsRel
                  (ratAddRep (ratSubRep x y) (ratSubRep y z)) d) =>

58.1 两个 ℕ 阈值的合并

练习 1leNat_max定理附录解答

要证 realRel x z 需要三件：Cauchy x 直接是 hxy 的第一分量，Cauchy z 直接是 hyz 的第二分量，逐点 close 才是这里的内容。逐点部分不能直接把 hxy 与 hyz 用在同一个 ε 上：两个前提各给一个 N，而且分别只保证 ε（而不是 ε/2）的界。所以先对 ε/2 取两个阈值（0 < ε 推出 0 < ε/2），再取一个同时大于等于两者的 N（ℕ 的 ≤ 全性与传递），最后在 n ≥ N 上把两个 ε/2 的界交给上一单元的 close 传递性。

theorem cauchy_add (x y : Seq) (hx : Cauchy x) (hy : Cauchy y) :

                        (leNat_trans N1 N m (And.left hN) hm))

上一单元在代表元层建立了 addSeq，并交清了两条下降义务：cauchy_add（Cauchy 对加法封闭）与 realRel_add（realRel 对加法同余）。二元运算仍然不能直接写成 Real → Real → Real 的函数：Quot.lift 的外层还要一次「函数相等」，而 realRel 只在 Cauchy 序列上自反——商里还有非 Cauchy 代表元形成的「杂点」，同一条 Cauchy 序列在杂点上的像不唯一。

于是把加法写成三元关系：addRel a b c 当且仅当 a、b 有 Cauchy 代表元 x、y，且 c = mk (x+y)。这个关系在 Cauchy 代表元上存在且唯一；在杂点上没有输出——这是诚实的分关系，不是把洞绕过去。定义要经两次 Quot.lift，两次的良定义性就是两个 def 里的函数外延性与命题外延性义务，用的都是课程里已经有的东西，不新增信任。

62.1 代表元层：x ~ y ⇒ x - y ~ 0

68完备性：有理 Cauchy 序列在 ℝ 中收敛到自己的类

Unit 68 — Completeness: Rational Cauchy Sequences Converge in ℝ

3 个定义 · 7 个定理 · 7 道练习 · 21 条提示 · 解答附录

↑ 目录

实数按 Cauchy 序列商构造。本单元证明这个构造的完备性在代表元层的形式：每个有理 Cauchy 序列 x，其类 Real.mk x 是常序列 n ↦ Real.mk (constSeq (x n)) 的极限。极限不引入 Real 上的绝对值或减法，而写成两条非严格界：a ≤ L + eps 且

L≤a+eps

两条界都归约到同一个代表元引理：a-b ≤ eps 推出 a-(b+eps) ≤ e（任意 e>0）。Cauchy 性同时给出 x n - x k ≤ eps 与 x k - x n ≤ eps，正好供两条界使用；Real.mk 的 ι 规则把代表元层的结论送回商。

一个明说的边界：本课程没有选择公理，「任意非空有上界集合有最小上界」的集合版 LUB 不在本单元；这里只做不需要选择的代表元序列完备性；不新增公理、不把 ℝ 直接立成公理。

先立常序列与它的 Cauchy 性，再证加常数仍 Cauchy、close 给减法界、减 eps 后仍非正，然后定义代表元层的收敛并证主定理与极限存在，最后落在常零序列上。
