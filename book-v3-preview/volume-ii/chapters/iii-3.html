Unit 91 — Subsequences

1 个定义 · 7 个定理 · 6 道练习 · 18 条提示 · 解答附录

收敛说的是整条序列的尾巴最终落在 L 附近。若每隔几项取一项，得到一条子序列，它看到的项更少；更少的项为什么还落在同一个点附近？因为子序列的下标只会越走越远，收敛给出的阈值仍然管得住它。这条观察把「丢掉无穷多项」变成合法操作，后面的极限点与 Bolzano–Weierstrass 都要用它。

证明按下面的路线展开。

细节清单（6 项，展开）
  • 91.1 严格递增的轨道不回头：n ≤ g n；
  • 91.2 轨道保序：a ≤ b 时 g a ≤ g b；
  • 91.3 两条子序列的复合仍是子序列；
  • 91.4 子序列继承原序列的极限；
  • 91.5 所有子序列都收敛到 L，与原序列收敛到 L 等价；
  • 91.6 平移 n ↦ n + k 是子序列，接上单元80 的平移序列。

边界：一条子序列收敛推不出原序列收敛——它只看了下标的一个子集。反方向要「所有子序列」，91.5 给出的正是这个形式。不新增公理。

91.0 轨道：严格递增的下标映射

Subseq g 读作「g 是一条严格递增的轨道」：第 n 步之后至少再走一格。

  ∀ (n : Nat), LeNat (Nat.succ (g n)) (g (Nat.succ n))

91.1 轨道不回头

练习 1subseq_ge定理附录解答
theorem subseq_ge (g : Nat → Nat) (h : Subseq g) :

提示 1思路

对 n 归纳。零情形用 leNat_zero_le；后继情形把归纳假设 n ≤ g n 抬一格得到 n+1 ≤ g n+1（leNat_succ_succ），再与严格性 g n+1 ≤ g (n+1) 传递。

提示 2目标形态

∀ (n : Nat), LeNat n (g n)。

提示 3关键件

Nat.rec · leNat_zero_le · leNat_succ_succ · leNat_trans。

查看解答 定理 · 9 行

对 n 归纳。零情形是「零最小」；后继情形把 n ≤ g n 两边加一， 得到 n+1 ≤ g n+1，再与严格性给的 g n+1 ≤ g (n+1) 传递。

theorem subseq_ge (g : Nat → Nat) (h : Subseq g) :
    ∀ (n : Nat), LeNat n (g n) :=
  fun (n : Nat) =>
    @Nat.rec (fun (k : Nat) => LeNat k (g k))
      (leNat_zero_le (g Nat.zero))
      (fun (k : Nat) (ih : LeNat k (g k)) =>
        leNat_trans (Nat.succ k) (Nat.succ (g k)) (g (Nat.succ k))
          (leNat_succ_succ k (g k) ih) (h k))
      n

theorem subseq_le (g : Nat → Nat) (h : Subseq g) :

提示 1思路

对 a ≤ b 的证明归纳。自反那一支用 LeNat.le_refl；后继那一支把归纳假设与「g n < g (n+1)」接起来，后者由严格性和 LeNat.le_succ 得到。

提示 2目标形态

∀ (a b : Nat), LeNat a b → LeNat (g a) (g b)。

提示 3关键件

LeNat.rec · LeNat.le_refl · LeNat.le_succ · leNat_trans。

查看解答 定理 · 10 行

对 a ≤ b 的证明归纳。自反那一支两边都是 g n；后继那一支先把 归纳假设 g a ≤ g n 与「g n ≤ g n+1」（le_succ）接起来，再与 严格性给的 g n+1 ≤ g (n+1) 传递。

theorem subseq_le (g : Nat → Nat) (h : Subseq g) :
    ∀ (a b : Nat), LeNat a b → LeNat (g a) (g b) :=
  fun (a b : Nat) (hab : LeNat a b) =>
    @LeNat.rec (fun (m n : Nat) (_ : LeNat m n) => LeNat (g m) (g n))
      (fun (n : Nat) => LeNat.le_refl (g n))
      (fun (m n : Nat) (_ : LeNat m n) (ih : LeNat (g m) (g n)) =>
        leNat_trans (g m) (g n) (g (Nat.succ n)) ih
          (leNat_trans (g n) (Nat.succ (g n)) (g (Nat.succ n))
            (LeNat.le_succ (g n) (g n) (LeNat.le_refl (g n))) (h n)))
      a b hab

theorem subseq_converges (x : Seq) (L : ratRep) (hx : Converges x L)

    Converges (fun (n : Nat) => x (g n)) L :=

练习 1 · subseq_ge 定理

对 n 归纳。零情形是「零最小」；后继情形把 n ≤ g n 两边加一， 得到 n+1 ≤ g n+1，再与严格性给的 g n+1 ≤ g (n+1) 传递。

theorem subseq_ge (g : Nat → Nat) (h : Subseq g) :
    ∀ (n : Nat), LeNat n (g n) :=
  fun (n : Nat) =>
    @Nat.rec (fun (k : Nat) => LeNat k (g k))
      (leNat_zero_le (g Nat.zero))
      (fun (k : Nat) (ih : LeNat k (g k)) =>
        leNat_trans (Nat.succ k) (Nat.succ (g k)) (g (Nat.succ k))
          (leNat_succ_succ k (g k) ih) (h k))
      n
练习 2 · subseq_le 定理

对 a ≤ b 的证明归纳。自反那一支两边都是 g n；后继那一支先把 归纳假设 g a ≤ g n 与「g n ≤ g n+1」（le_succ）接起来，再与 严格性给的 g n+1 ≤ g (n+1) 传递。

theorem subseq_le (g : Nat → Nat) (h : Subseq g) :
    ∀ (a b : Nat), LeNat a b → LeNat (g a) (g b) :=
  fun (a b : Nat) (hab : LeNat a b) =>
    @LeNat.rec (fun (m n : Nat) (_ : LeNat m n) => LeNat (g m) (g n))
      (fun (n : Nat) => LeNat.le_refl (g n))
      (fun (m n : Nat) (_ : LeNat m n) (ih : LeNat (g m) (g n)) =>
        leNat_trans (g m) (g n) (g (Nat.succ n)) ih
          (leNat_trans (g n) (Nat.succ (g n)) (g (Nat.succ n))
            (LeNat.le_succ (g n) (g n) (LeNat.le_refl (g n))) (h n)))
      a b hab

单元91 说明子序列继承原序列的极限。反过来，一个点即使不是整条序列的极限，也可能是某条子序列的极限：序列在两个值之间来回跳时，两条子序列可以各自停在一个值上。这样的点记录「序列反复靠近哪里」，不要求整条序列最后停在哪里。

定义直接用子序列的极限：L 是 x 的极限点，若存在严格递增的轨道 g，使 x ∘ g 收敛到 L。这样不需要选择公理；代价是反方向不能倒过来用（见边界）。

直接写「极限点集合的上确界」会遇到存在性问题：课程没有选择公理，也没有一般集合的最小上界。于是这里把「L 是极限点集合的上确界」整体写成谓词 Limsup x L，证明它给出的关系，而不声称每条序列都有这样的 L。得到的是三条：每个极限点不超过 L；任何压住所有极限点的数不小于 L；满足这两条的数彼此相等。收敛序列只有一个极限点，上极限于是回到极限本身。
