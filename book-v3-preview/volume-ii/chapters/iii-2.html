提示 1思路

两个方向。若 s ≤ M，对 a ∈ A 用 a ≤ s（hs 的第一分量）与 s ≤ M 走传递；反过来「M 是上界」正是 hs 的第二分量在 M 上的取值。

提示 2目标形态

提示 3关键件

查看解答 定理 · 8 行

正方向：a ≤ s（第一分量）与 s ≤ M 走传递。反方向是第二分量。

theorem sup_le_iff (A : Real → Prop) (s M : Real)
    (hs : IsSup Real realLe A s) :
    realLe s M ↔ UpperBound Real realLe A M :=
  Iff.intro
    (fun (h : realLe s M) =>
      fun (a : Real) (ha : A a) =>
        realLe_trans a s M ((And.left hs) a ha) h)
    (fun (hM : UpperBound Real realLe A M) => (And.right hs) M hM)

把集合 A 的每个元素换成 fin a，得到扩展实数里的集合 finImage A。若 s 是 A 在 ℝ 里的上确界，则 fin s 是 finImage A 在扩展实数里的上确界；反过来，finImage A 的上确界若落在有限点上，那个点就是 A 的实数上确界。正方向要求 A 非空：空集在扩展实数里的上确界是 negInf，不可能是任何 fin s。

88 把实数集合经 fin 搬进扩展实数，说明两套上确界是同一个点。下侧还没有对应的桥：已知实数集合的下确界，能否直接把它搬进扩展实数？反过来的问题同样要回答——扩展实数里的下确界若落在有限点上，它是不是原来的实数下确界？

与 88 一样，把 A 的每个元素换成 fin a，得到 finImage A。非空前提仍然要带上，但挡住的方向换了：上确界那边，空集的扩展上确界是 negInf，搬不过去；下确界这边，空集的扩展下确界是 posInf，它不是任何有限点的下界。有限点上两套下确界一一对应，空集是唯一的例外。

这条桥在 liminf 里要用：先在实数层算下界，再搬进扩展实数做大小比较。

theorem finImage_lowerBound (A : Real → Prop) (m : Real)
    (hm : LowerBound Real realLe A m) :
    LowerBound ExtReal ele (finImage A) (fin m) :=
  fun (e : ExtReal) (he : finImage A e) =>

提示 3关键件

查看解答 定理 · 24 行

下界分量是 90.2。最大性对候选下界 M 分三种： 负无穷那一支直接是底；有限点 fin t 归到实数层，t 是 A 的下界， s 最大，于是 t ≤ s；正无穷不可能是非空集合的下界，用 90.1 的 见证与 not_ele_posInf_fin 消去。

theorem ext_inf_fin_of_inf (A : Real → Prop) (s : Real)
    (hne : ∃ (a : Real), A a)
    (hs : IsInf Real realLe A s) :
    IsInf ExtReal ele (finImage A) (fin s) :=
  And.intro
    (finImage_lowerBound A s (isInf_lower Real realLe A s hs))
    (fun (M : ExtReal) (hM : LowerBound ExtReal ele (finImage A) M) =>
      @ExtReal.rec.{0}
        (fun (M' : ExtReal) =>
          LowerBound ExtReal ele (finImage A) M' → ele M' (fin s))
        (fun (_ : LowerBound ExtReal ele (finImage A) negInf) =>
          negInf_le (fin s))
        (fun (t : Real) (hMt : LowerBound ExtReal ele (finImage A) (fin t)) =>
          Iff.mpr (ele_fin_fin t s)
            (isInf_greatest Real realLe A s hs t
              (fun (a : Real) (ha : A a) =>
                Iff.mp (ele_fin_fin t a)
                  (hMt (fin a) (finImage_mem A a ha)))))
        (fun (hMtop : LowerBound ExtReal ele (finImage A) posInf) =>
          Exists.elim hne
            (fun (a : Real) (ha : A a) =>
              False.elim
                (not_ele_posInf_fin a (hMtop (fin a) (finImage_mem A a ha)))))
        M hM)

下界：把 isInf_lower 作用在 fin a 上，成员资格由 90.1 给，再用 ele_fin_fin 展开。最大性：实数下界 M 经 90.2 变成扩展下界 fin M，用 isInf_greatest 得 fin M ≤ fin s，再展开。

IsInf Real realLe A s。

提示 3关键件

isInf_lower · isInf_greatest · ele_fin_fin · finImage_lowerBound。

查看解答 定理 · 12 行

下界：fin a 在 finImage A 里，fin s 是它的下界，展开就是 s ≤ a。 最大性：实数下界 M 经 90.2 变成扩展下界 fin M，于是 fin M ≤ fin s， 展开就是 M ≤ s。

theorem real_inf_of_ext_inf (A : Real → Prop) (s : Real)
    (hs : IsInf ExtReal ele (finImage A) (fin s)) :
    IsInf Real realLe A s :=
  And.intro
    (fun (a : Real) (ha : A a) =>
      Iff.mp (ele_fin_fin s a)
        (isInf_lower ExtReal ele (finImage A) (fin s) hs (fin a)
          (finImage_mem A a ha)))
    (fun (M : Real) (hM : LowerBound Real realLe A M) =>
      Iff.mp (ele_fin_fin M s)
        (isInf_greatest ExtReal ele (finImage A) (fin s) hs (fin M)
          (finImage_lowerBound A M hM)))
