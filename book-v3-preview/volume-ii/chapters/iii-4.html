Cauchy 的定义要求尾巴上的任意两项彼此靠近。这个量词管两个下标，估计时要同时照看 n 与 m。实际使用中往往只需要一个参照点：尾巴的第一项 x N。证明这两种写法等价，是把 Cauchy 性用到具体序列上的第一步。

100.0 与尾巴的第一项比较

练习 1cauchy_tail定理附录解答

从「两项比较」到「与 x N 比较」是直接的削弱；反过来要把 ε 折半，两个尾巴项各自落在 x N 的 ε/2 邻域里，再由三角不等式合成。

边界：这里只改写 Cauchy 的定义，不证明 Cauchy 序列收敛。有理数上的 Cauchy 序列未必有有理极限（截断的 √2 近似是一例），完备性在实数层谈。不新增公理。

原定义对 n、m 同时要求；把 m 固定成 N，右边的 N ≤ N 由自反性付清。

一个 Cauchy 序列在 ℝ 里有极限，这是 68 已经证明的代表元层结论。到了商上还要回答一个更基本的问题：极限是一个实数，而实数有多个代表元；换一个收敛到同一序列的代表元，极限类会不会变？如果不证明它不变，「这条序列的极限」就还不是一个可以反复引用的对象。

104.0–104.2 先把减法估计整理成可复用的形状：把加在减数上的常数并进误差，把两段半边估计相加。104.3 固定一个下标，把两条尾部估计合成类序的一个方向。104.4 用序的反对称性得到两个极限类相等。104.5–104.6 把「极限类」写成谓词并证明它唯一。104.7 是常序列的实例。

边界：只讨论同一个序列的两个极限类，不声称每个实数都有代表元，也不在类层构造减法。不新增公理。
