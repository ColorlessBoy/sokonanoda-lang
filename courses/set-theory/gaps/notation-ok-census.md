## 二、⚠ 口径问题（必须先定，否则数字会假 ✗）

§0.2 写的做法是「**试删豁免 → 跑 `grade` → 看红多少**」✓ —— 但实测发现**这两步不同口径** ✗：

  （标记不进内核 ✓）⇒ "删标记 → 跑 grade" 恒绿 ✗ = **空转普查** ✗。
- 真正要测的是：**把该处改写成记法形式后，能不能判绿** ✓ —— 即需要「**豁免点 → 记法形式的候选改写**」这一步 ✗
  （不是纯删标记 ✓）。

**⇒ 建议的普查口径（下一棒照这个做，可测且可复算 ✓）**：
1. 从 `notation-lint.py` 的豁免登记里**逐处取出原始片段**（豁免标记自带理由 ✓，函数已能定位 ✓）；
2. 对每处**生成记法形式的候选**（机械替换：`Set.sUnion α F` ⇒ 无记法可换 ✗ ⇒ 标 D 类跳过 ✓；
   `Eq.{1}` ⇒ `=` ✓；`And.intro` 前导实参 ⇒ 省略 ✓ ……）；
3. 把候选写进**该处的副本文件**跑 `grade` ✓ ⇒ **绿 = 现已可适配 ✓ / 红 = 引擎仍不够 ✓**；
4. 产出「**试改 N 处 → 绿 x / 红 y**」+ 按 A/B/C/D/E 分类 ✓。
