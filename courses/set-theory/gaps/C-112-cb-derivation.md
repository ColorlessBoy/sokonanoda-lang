## 0. 前提（全部是集合论事实，无选择）

`f : A → B` 单射 ✓、`g : B → A` 单射 ✓（`A ⊆ α`、`B ⊆ β` ✓）。记 `f '' S`、`g '' T` 为像 ✓。

## 1. 选对算子：`K` 必须是**单调**的（**这里是我上一轮错的地方** ✗）

    K(C) := A ∖ g '' (B ∖ f '' C)          （C ⊆ A）

**单调性**：若 `C₁ ⊆ C₂` ✓，则 `f '' C₁ ⊆ f '' C₂` ✓ ⇒ `B ∖ f '' C₂ ⊆ B ∖ f '' C₁` ✓
⇒ `g '' (B ∖ f '' C₂) ⊆ g '' (B ∖ f '' C₁)` ✓ ⇒ `K(C₁) ⊆ K(C₂)` ✓。**∎（单调 ✓）**

> ✗ 我上一轮用的是 `K'(C) = (A∖g''B) ∪ g''(B∖f''C)` ✓ —— 它带**并集**这一项 ⇒
> `C₁ ⊆ C₂ ⇒ K'(C₂) ⊆ K'(C₁)`（**反单调** ✗）⇒ 后面"逐成员比"那一步方向相反 ⇒ 推不动 ✓。
> **改法**：把 `A∖g''B` 那一项**去掉**（它下面会作为**推论**自动出来 ✓，见第 3 步 ✓）。

## 2. 最小不动点

`𝓕 := {C ⊆ A | K(C) ⊆ C}` ✓；`A ∈ 𝓕`（因 `K(A) ⊆ A` ✓：`A∖g''(…) ⊆ A` ✓）⇒ `𝓕 ≠ ∅` ✓；
取 `C₀ := ⋂ 𝓕` ✓（**这就是链构造** ✓）。

## 3. `C₀ ∈ 𝓕`（**关键一步，单调性在这里用**）

设 `C ∈ 𝓕` ✓。由 `C₀ ⊆ C` ✓（`⋂` 的取用 ✓）与**第 1 步的单调性** ✓：`K(C₀) ⊆ K(C)` ✓；
又由 `C ∈ 𝓕` ✓：`K(C) ⊆ C` ✓ ⇒ **`K(C₀) ⊆ C`** ✓ —— 对**每个** `C ∈ 𝓕` 成立 ✓
⇒ `K(C₀) ⊆ ⋂ 𝓕 = C₀` ✓。**∎**

## 4. 两条推论（CB 双射的两个分支正好需要它们）

- (a) `A ∖ g '' B ⊆ C₀` ✓：对 `C ∈ 𝓕` ✓，`K(C) ⊆ C` ✓ 且 `A∖g''B ⊆ K(C)` ✓（去掉的那一项在这里回来 ✓）
  ⇒ `A∖g''B ⊆ C` ✓ 逐成员 ⇒ `⊆ ⋂𝓕 = C₀` ✓。**∎**
- (b) 第 3 步展开即 `A ∖ g '' (B ∖ f '' C₀) ⊆ C₀` ✓。**∎**

## 5. 双射（**唯一用到选择的一步** ✗）

对 `x ∈ A`：
- 若 `x ∈ C₀` ✓ ⇒ 置 `h x := f x` ✓（`f x ∈ B` ✓）；
- 若 `x ∉ C₀` ✓ ⇒ 由 (a) 得 `x ∈ g '' B` ✓ ⇒ 存在 `y ∈ B` 使 `g y = x` ✓；**由 `g` 单射，这个 `y` 唯一** ✓
  ⇒ 置 `h x := y` ✓（**本课用 `choice` 把它取出来** ✗ —— 数学上这里只需**确定摹状词** ✓，
  所以"经选择公理"是**实现偏离**，不是数学必需 ✓）。

`h` 是双射 ✓：**单射**分三种情形（同在 `C₀` 用 `f` 单射 ✓；同在补集用 `g` 单射 ✓；
一在 `C₀` 一在补集 ⇒ 像分别在 `f '' C₀` 与 `B ∖ f '' C₀` ✓ —— **后者由 (b) 保证** ✓）；
**满射**：`B = f '' C₀ ∪ (B ∖ f '' C₀)` ✓ —— 左边被 `h` 打到 ✓；右边每个 `b` 满足
`g b ∈ A ∖ g '' (B ∖ f '' C₀)` ✓ ⇒ 由 (b) `g b ∈ C₀` ✓ ⇒ `h (g b) = f (g b) = b` ✓（`f∘g = id` 于 `B` ✓）。**∎**

## 8. 第 5 步的**完整案情分析**（纸面推完 ✓，下一棒直接照写 Lean）

**假设**（写 Lean 时的前提，全部 Prop 层 ✓）：`hA : ∀ x, x ∈ A` 无关项不管；
只需两条映射条件：`hfB : ∀ x ∈ A, f x ∈ B` ✓、`hgA : ∀ b ∈ B, g b ∈ A` ✓、
`hf_inj : ∀ x y ∈ A, f x = f y → x = y` ✓、`hg_inj : ∀ b c ∈ B, g b = g c → b = c` ✓ ——
**（写单元时这四条要写成显式前提 ✓，因为本课没有"`A → B` 的函数"类型 ✓。）**

**关系版图（Prop 层 ✓，绕开 C-04 ✓）**：
`cbRel x y := (x ∈ C₀ ∧ f x = y) ∨ (x ∉ C₀ ∧ g y = x)` ✓

**四件的案情（每件都可独立复核 ✓）**：

| 件 | 情形 | 用哪条已绿的事实 |
|---|---|---|
| **全**：`x ∈ A ⇒ ∃ y ∈ B, cbRel x y` | `x ∈ C₀` ⇒ 取 `y := f x`（`hfB` ✓） | — |
| | `x ∉ C₀` ⇒ 需 `x ∈ g '' B` ✓：若 `x ∉ g''B` 则 `x ∈ A∖g''B ⊆ C₀` ✗ 矛盾 ⇒ **用 `byContradiction`** ✓ ⇒ 取前像 `y`（`hgA` ✓） | **`cbC0_sdiff`（第 4(a) 步 ✓ 已绿）** |
| **单值**：`cbRel x y ∧ cbRel x y' ⇒ y = y'` | 两分支同 ⇒ 直接 ✓；跨分支 ⇒ `f x = y` 与 `g y' = x` ⇒ 由 `hg_inj`/`hf_inj` 归结到 `g (f x) ∈ C₀` 那一步 ✗（见下） | 需补 **`cbC0_gf`**（下） |
| **单射**：`cbRel x₁ y ∧ cbRel x₂ y ⇒ x₁ = x₂` | 同在 `C₀` ⇒ `hf_inj` ✓；同不在 ⇒ `g y = x₁ = x₂` ✓；一在 `C₀` 一不在 ⇒ `y = f x₁` 且 `g y = x₂` ⇒ `x₂ = g (f x₁)` ✗ 需 `cbC0_gf` ✓ 把它拉回 `C₀` 与"不在"矛盾 ✓ | 需 **`cbC0_gf`**（下） |
| **满射**：`y ∈ B ⇒ ∃ x ∈ A, cbRel x y` | `g y ∈ C₀` ⇒ 取 `x := g y` ✓（此时 `f (g y) = y`? ✗ —— 需要"第二分支" ✓：由 `cbC0_sdiff` 的补形式 ✓，或直接取 `x := g y` 并用 `x ∉ C₀` 分支 ✗ ⇒ **须二分 `g y ∈ C₀`** ✓：在 ⇒ 用 `cbC0_gf` 造 `x` ✓；不在 ⇒ 取 `x := g y` ✓（`hgA` ✓） | **`cbC0_in_fix` + `cbC0_gf`** |

**⇒ 唯一还缺的零件：`cbC0_gf`** ✓（"`C₀` 对 `g∘f` 封闭"那一半）：

- 要证：`x ∈ C₀ ⇒ g (f x) ∈ C₀` ✓。
- 证：只需 `g (f x) ∈ K(C₀)` ✓（`cbC0_in_fix` ✓ 已绿 ✓），而 `K(C₀) = A ∖ g '' (B ∖ f '' C₀)` ✓：
  * `g (f x) ∈ A` ✓ ← `hgA` ✓（需 `f x ∈ B` ✓ ← `hfB` ✓）；
  * `g (f x) ∉ g '' (B ∖ f '' C₀)` ✓ ← **反证**：设 `g (f x) = g b` 且 `b ∈ B ∖ f '' C₀` ✓
    ⇒ 由 `hg_inj` ✓ `f x = b` ⇒ `b ∈ f '' C₀` ✗ 与 `b ∉ f '' C₀` 矛盾 ✓。
- ⇒ **`cbC0_gf` 是一条短引理 ✓**（两小步 + 一次反证 ✓），写完它**四件都可直接落** ✓。
