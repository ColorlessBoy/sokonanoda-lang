## §0 一屏结论

1. **任务书里的「徐明曜/赵春来《集合论》」查无此书**——二人是北大社《抽象代数Ⅰ》（9787301141687）与《抽象代数(二)》（9787301085288）的作者；北大社书目按「集合论」检索只有 5 条，作者只有刘壮虎与耿素云（§1.1）。
2. **耿素云《集合论与图论（离散数学二分册）》确实存在**（北大社 1998-01，ISBN 9787301036044，381 页），**但书内目录本轮未取到**（§1.2/§6.2）。替代证据：以它为教材的**北大刘田课**有 25 讲逐字讲次 + 5 讲逐字内容提要。
3. **「关系 vs 函数谁先」在中文本科课里是 6:2，不是共识**——6 门关系先于函数（北大刘田课、北大信科官方简介、张锦文、郝兆宽/杨跃、冯琦、耿素云 2015）；**2 门函数先于关系**（**哈工大官方 MOOC 大纲**「第2章 映射 → 第3章 关系」、刘壮虎《素朴集合论》「第二章 映射 → 第三章 关系」）。**基数靠后是稳定规律**（§5.1）。
4. **选择公理只在「数理逻辑/哲学」路线讲，计算机离散数学路线不讲** [F]：讲的有北大哲学系《公理集合论》/《集合论专题》、北师大研究生《公理集合论》、复旦《集合论》（讲义逐字含 `Axiom of choice`）；**哈工大整份 MOOC 大纲无任何 ZFC/选择公理条目**，北大两门《集合论与图论》简介亦无（§5.3）。
5. **Russell 悖论有 [F] 级铁证**：复旦杨睿之 2015 秋《集合论》讲义 L01 p32–34 逐字给出 `Russell: Consider the set R = {x | x ∉ x}`，L02 立刻转入 `Here comes the axiomatic set theory, ZFC`——**「悖论 → ZFC」的首节型处理在中文课程里有现成范式**（§5.3）。

## §1 三本指定教材的核查结果

### 1.1 徐明曜/赵春来《集合论》——**查无此书**（负面结论）

- **[A] 北大社书目反证**（`api.pup.cn/pkusite-web/book/index?bookTitle=集合论`，HTTP 200）：按书名「集合论」返回**恰好 5 条**，无一条作者为徐明曜或赵春来：`9787301051139 素朴集合论/刘壮虎/2001`、`9787301036044 集合论与图论(离散数学二分册)/耿素云/1998`、`9787301019900 离散数学习题集(数理逻辑与集合论分册)/耿素云/1993 与 1995`、`9787301003343 集合论导引/耿素云等/1990`。
- **[A] 同书目按「抽象代数」检索**，二人真实著作是 `9787301141687 抽象代数Ⅰ 徐明曜,赵春来` 与 `9787301085288 抽象代数(二) 赵春来,徐明曜`；**[A] 头条搜索**「徐明曜 赵春来 集合论」的结果**全是抽象代数材料**，无任何集合论书目。
- **结论**：这一条**极可能是把《抽象代数》记成了《集合论》**。无法排除存在非北大社的同名书，但**未取得任何支持其存在的证据**。
- 旁证 **[F]**：北大逻辑中心学科简史页列国家「七五」《现代逻辑丛书》8 本，含**《集合论导引》（晏成书）**与**《素朴集合论》（刘壮虎）**——北大口的集合论教材是这两本，仍非徐/赵。

## §5 三个问题的汇总答案

### 5.1 目录顺序：集合 / 关系 / 函数 / 基数谁先？

| 来源 | 顺序 | 证据 |
|---|---|---|

## §7 对本课程（sokonanoda 卷一集合论）的三条可用结论

1. **顺序：中文课程给的是「集合 → 关系/函数（两序并存）→ 自然数 → 基数」**（§5.1）。因为**同名课在不同学校给出相反顺序**（北大关系先、哈工大映射先），本课程**不必**把「关系先于函数」当成中文共识来辩护；真正稳定的是**基数靠后**。本语言 `Set α := α → Prop` 无 ZF 全域、无真序数，基数/序数都只能做成「势比较」，同样不必跟随任何一本。
2. **「函数 = 单值二元关系」在中文语境确实通用**（北大刘田第 9 讲、哈工大第 3 章逐字首句），可作为关系层与函数层衔接的现成话术。但**有序对普遍用 Kuratowski 编码 `{{a},{a,b}}` 并配引理证明**（北大刘田第 5 讲有引理1/引理2），这正是既有调研建议降级为阅读材料的那一条——**中文语境的默认预期比英文更「ZF」**，迁移时需显式说明取舍。
3. **「悖论 → ZFC」的入口在中文课程里有现成范式，且正是本课程的增量**：复旦杨睿之《集合论》L01 讲 `R = {x | x ∉ x}`、L02 立刻转 ZFC；而**计算机路线的《集合论与图论》完全不讲选择公理、不讲悖论**（哈工大整份 MOOC 大纲为证）。本课程若把悖论做成入口，并在基数处**显式点出 Mathlib 的基数依赖 `Classical.choice`**，正好补上中文课堂两套路线的共同空白。
